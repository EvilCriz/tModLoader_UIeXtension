`UIExGrid` is a layout container for arranging UI elements in two dimensions using rows and columns.

---

<h2 align="center"><code>UIExGrid</code> Styles</h2>

* `UIExGrid` fully uses all `StyleLayoutContainer` styles.
* `Orientation`: determines the main axis of the container. This value is relevant when using `JustifyContent`, `JustifySelf`, `AlignItems`, `AlignSelf`.
* `JustifyContent` and `AlignContent` determine the alignment of elements inside each cell along the main / cross axis.

It also uses `StyleLayoutChild` for child elements:

* `JustifySelf` and `AlignSelf` override the container's `JustifyContent` and `AlignContent` values for each individual element.
* `Margin` works as usual. If any of the margins are specified as percentages, the percentages are calculated from the size of the entire `UIExGrid`.

---

This style class allows you to configure the grid.
You can obtain the style class by calling the `Grid` method on the `StyleLayout` field:

```csharp
UIExGrid grid = new();
StyleLayoutContainer style = grid.StyleLayout;
StyleLayoutContainerGrid styleGrid = style.Canvas();
UIExAlignment rowsAlignment = styleGrid.RowsAlignment;
```

---

Grid settings are configured using the following methods:

* `Add(Row/Column)Definition(s)`;
* `Get(Row/Column)Definition(s)`;
* `Remove(Row/Column)DefinitionAt`;
* `Remove(Row/Column)DefinitionsRange`;
* `Replace(Row/Column)Definition`;
* `Insert(Row/Column)Definition(s)`;<br>

<!-- -->

* `Add(Row/Column)Definition(s)`:

  * Overload 1: adds a row/column with the size specified by `UIExGridLength`.
  * Overload 2: adds N rows/columns with the size specified by `UIExGridLength`.
  * Overload 3: adds an array of rows/columns with the size specified by `UIExGridLength`.
  * Overload 4: adds a list of rows/columns with the size specified by `UIExGridLength`.
* `Get(Row/Column)Definition(s)`:

  * Overload 1: Returns the `UIExGridLength` size at the specified row/column index.
  * Overload 2: Returns an array of `UIExGridLength` sizes from the starting to the ending (inclusive) row/column indices.
* `Remove(Row/Column)DefinitionAt`;

  * Overload 1: removes a row/column at the specified index.
* `Remove(Row/Column)DefinitionsRangle`:

  * Overload 1: removes rows/columns from the starting to the ending (inclusive) indices.
* `Replace(Row/Column)Definition`:

  * Overload 1: replaces the row/column at the specified index with the specified `UIExGridLength` size.
* `Insert(Row/Column)Definition(s)`:

  * Overload 1: inserts a row/column with the specified `UIExGridLength` size at the specified index.
  * Overload 2: inserts an array of row/column sizes specified by `UIExGridLength` at the specified index.
  * Overload 3: inserts a list of row/column sizes specified by `UIExGridLength` at the specified index.<br>

---

Row/column size structure.

```csharp
public struct UIExGridLength
{
    public Enums.UIExGridLengthType Type = Enums.UIExGridLengthType.Auto;

    public float Pixels = 0f;
    public float Precent = 0f;
    public float Fraction = 0f;


    public static UIExGridLength FromPx(float pixels) { /* ... */ }

    public static UIExGridLength FromPr(float precent) { /* ... */ }

    public static UIExGridLength FromFr(float fraction) { /* ... */ }

    public static UIExGridLength FromAuto() { /* ... */ }

    public static UIExGridLength Empty() { /* ... */ }
}

public enum UIExGridLengthType : byte
{
    Pixels,
    Precent,
    Fraction,
    Auto
}
```

Size types:

* `Pixels`: the size is specified in pixels in the `Pixels` field.
* `Precent`: the size is specified as a percentage in the `Precent` field.
* `Fraction`: the size is specified in fractions in the `Fraction` field. After all other row/column sizes have been calculated, the remaining space will be distributed among the rows/columns according to the size of their fractions.
* `Auto`: the size is determined by the maximum size of an element contained in the row/column.<br>

The structure also defines static methods for quickly creating a structure object of the required type.

---

`UIExGrid` allows you to specify the space between rows/columns using style fields:

```csharp
public StyleDimension RowsSpace = StyleDimension.Empty;
public StyleDimension ColumnsSpace = StyleDimension.Empty;
```

It also allows you to specify the grid alignment (if the grid height/width is smaller than the container's height/width).

```csharp
public Enums.UIExAlignment RowsAlignment = Enums.UIExAlignment.Start;
public Enums.UIExAlignment ColumnsAlignment = Enums.UIExAlignment.Start;
```

`Rows/ColumnsAlignment` can only take the values `Start`, `Center`, `End`.<br>
All other values will be treated as `Start`.

---

All elements contained in `UIExGrid` can use the `StyleLayoutChildGrid` style.
To use this style, you need to obtain the `StyleLayoutChild` style using the `StyleLayoutChild()` extension method of `UIElement`.
Then call the `Grid()` method on the obtained style.

```csharp
UIElement element = new();
StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildGrid styleGrid = style.Grid();
styleGrid.Row = 1;
```

The `StyleLayoutChildGrid` class itself has the following implementation:

```csharp
public class StyleLayoutChildGrid : Base.StyleLayoutChildBase
{
    public int Row = 0;
    public int Column = 0;

    public int RowSpan = 1;
    public int ColumnSpan = 1;
}
```

1. Allows you to specify the row and column where the element will be located. `Values < 0` will be clamped to `0`. `Values >= Rows/ColumnsCount` will be clamped to `Rows/ColumnsCount - 1`.
2. Allows you to specify how many rows/columns the element will occupy. `Values < 1` will be clamped to `1`. The element cannot extend beyond the grid boundaries using `Row/ColumnSpan`.

<h2 align="center">Helper Lines</h2>

`UIExLayout` provides the ability to display helper lines (see the `UIExLayout` article).<br>
If `UIExLayout.ShowLayoutLines == true`, helper lines will be drawn:

* Around each cell.
* Around the outer area of each element inside the container (which participates in the layout).<br>

`UIExGrid` provides an alternative way to draw helper lines using the following fields and methods:

```csharp
public bool ShowGridLines = false;
public float GridLinesThickness = 1f;
public Color GridLinesColor = Color.DarkGray;



public virtual void SetGridLinesInfoForTree(
	bool showGridLines, 
	float gridLinesThickness, 
	Color gridLinesColor) 
		{ /* ... */ }


public virtual void SetGridLinesInfoForBranch(
	bool showGridLines, 
	float gridLinesThickness, 
	Color gridLinesColor)
		{ /* ... */ }
```

In this case, the helper lines will be drawn as a grid.

* `ShowGridLines` - determines whether helper lines in the form of a grid will be drawn.
* `GridLinesThickness` - determines the size of the helper lines in the form of a grid in pixels.
* `GridLinesColor` - determines the color of the helper lines in the form of a grid.<br>

<!-- -->

* `SetGridLinesInfoForTree` - allows you to set all three values above for the entire element tree.
* `SetGridLinesInfoForBranch` - allows you to set all three values above for all descendants of this container.<br>

`ShowLayoutLines` and `ShowGridLines` work independently of each other.<br>
This means that all helper lines can be drawn simultaneously.

<h2 align="center">Example of Using <i>UIExGrid</i></h2>

<details>
<summary>Example of creating a calculator layout (without comments, explained below)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.MethodsExtensions;
using UIeXtension.Styles;

namespace UIeXtensionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // the OnActivate() method is used in this case only
    // for the "hot code reload" functionality in the development environment.
    // For a real interface, it would be more appropriate to use
    // the OnInitialize() method.
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 650f, panel);

        UIExGrid grid = new();
        grid.Stretch();

        ////////////////////////////

        StyleLayoutContainer styleLayout = grid.StyleLayout;
        StyleLayoutContainerGrid styleLayoutGrid = styleLayout.Grid();

        styleLayout.Set(
            justifyContent: UIExAlignment.Stretch,
            alignItems: 	UIExAlignment.Stretch);

        styleLayoutGrid.AddRowDefinition(UIExGridLength.FromFr(1f), repeat: 7);
        styleLayoutGrid.AddColumnDefinition(UIExGridLength.FromFr(1f), repeat: 4);

        styleLayoutGrid.Set(
            rowsSpace: 		StyleDimension.FromPixels(10f),
            columnSpace: 	StyleDimension.FromPixels(15f));

        ///////////////////////////

        AppendButton(grid, prefix: "RESULT:", row: 0, column: 0, rowSpan: 2, columnSpan: 4);

        AppendButton(grid, prefix: "AC", row: 2, column: 0);
        AppendButton(grid, prefix: "%", row: 2, column: 1);
        AppendButton(grid, prefix: "<<", row: 2, column: 2);
        AppendButton(grid, prefix: "/", row: 2, column: 3);

        AppendButton(grid, prefix: 7, row: 3, column: 0);
        AppendButton(grid, prefix: 8, row: 3, column: 1);
        AppendButton(grid, prefix: 9, row: 3, column: 2);
        AppendButton(grid, prefix: "*", row: 3, column: 3);

        AppendButton(grid, prefix: 4, row: 4, column: 0);
        AppendButton(grid, prefix: 5, row: 4, column: 1);
        AppendButton(grid, prefix: 6, row: 4, column: 2);
        AppendButton(grid, prefix: "-", row: 4, column: 3);

        AppendButton(grid, prefix: 1, row: 5, column: 0);
        AppendButton(grid, prefix: 2, row: 5, column: 1);
        AppendButton(grid, prefix: 3, row: 5, column: 2);
        AppendButton(grid, prefix: "+", row: 5, column: 3);

        AppendButton(grid, prefix: 0, row: 6, column: 0);
        AppendButton(grid, prefix: ",", row: 6, column: 1);
        AppendButton(grid, prefix: "=", row: 6, column: 2, rowSpan: 1, columnSpan: 2);

        ///////////////////////////

        panel.Append(grid);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AppendButton(UIExLayout layout, int prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
        => AppendButton(layout, prefix.ToString(), row, column, rowSpan, columnSpan);
    public UIButton<string> AppendButton(UIExLayout layout, string prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
    {
        UIButton<string> button = new(prefix);

        StyleLayoutChildGrid styleGrid = button.StyleLayoutChild().Grid();
        styleGrid.Set(row, column, rowSpan, columnSpan);

        layout.Append(button);
        return button;
    }
}
```

---

The first thing visible in the code is the creation of the main panel with a size of `450x650px`, centered on the screen.

```csharp
UIPanel panel = new UIPanel();
SetPixelsSizeCenter(width: 450f, height: 650f, panel);
```

The `SetPixelsSizeCenter` method is defined in this class for demonstration purposes and is not a method of this library.<br>

After that, the `UIExGrid` container is created:

```csharp
UIExGrid grid = new();
grid.Stretch();
```

The `Stretch()` method is defined in `UIExLayout` and makes the container stretch across the entire height and width of the parent element.<br>
In this example, `grid.Stretch()` stretches the element to the full size of `panel`.

---

A little about visual styles. This is the topic of the next section, but there is one important point for layout containers, so this note will appear in every article.<br>
As you can see, the hierarchy in this code is as follows: main panel -> container -> elements inside the container.<br>
A separate container is created for the main panel.<br>
This is unnecessary if the desired result is exactly the one shown in the image.<br>
`UIExElement` (from which `UIExLayout` inherits) has a style property: `StyleDisplay.tModLoaderStyle (bool)`.<br>
If this value is `true`, the visual element will use the corresponding **tModLoader** visual style.<br>
For `UIExElement`, a value of `true` will make its style equivalent to `UIPanel`.<br>
Therefore, our code could be shortened.<br>

This part:

```csharp
UIPanel panel = new UIPanel();
SetPixelsSizeCenter(width: 450f, height: 650f, panel);

UIExGrid grid = new();
grid.Stretch();

/*
...
*/

panel.Append(grid);
Append(panel);
```

Can be replaced with the following:

```csharp
UIExGrid grid = new();
grid.StyleDisplay.tModLoaderStyle = true;
SetPixelsSizeCenter(width: 450f, height: 650f, grid);

/*
...
*/

Append(grid);
```

As you can see in the second code sample, the `UIPanel panel` element has disappeared. The `grid` layout container has simultaneously become the main container.

---

Next, the base layout style of the container and the `UIExGrid` layout style are obtained:

```csharp
StyleLayoutContainer styleLayout = grid.StyleLayout;
StyleLayoutContainerGrid styleLayoutGrid = styleLayout.Grid();
```

Then the `justifyContent` and `alignItems` values are set to `UIExAlignment.Stretch`.

```csharp
styleLayout.Set(
	justifyContent: UIExAlignment.Stretch,
	alignItems: 	UIExAlignment.Stretch);
```

This code specifies that all elements inside the container should stretch across the width and height of the cell/cells they occupy.<br>

---

Next, the grid itself is defined:

```csharp
styleLayoutGrid.AddRowDefinition(UIExGridLength.FromFr(1f), repeat: 7);
styleLayoutGrid.AddColumnDefinition(UIExGridLength.FromFr(1f), repeat: 4);
```

This code specifies that:

* the grid should contain 7 rows, which evenly distribute the container's height among themselves.
* the grid should contain 4 columns, which evenly distribute the container's width among themselves.
* the space is distributed evenly because each row/column has a size of 1 fraction.<br>

Next, the space between rows and columns is specified:

```csharp
styleLayoutGrid.Set(
	rowsSpace: 		StyleDimension.FromPixels(10f),
	columnSpace: 	StyleDimension.FromPixels(15f));
```

---

Then the buttons are added using the following methods:

```csharp
public UIButton<string> AppendButton(UIExLayout layout, int prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
    => AppendButton(
		layout,
		prefix.ToString(),
		row, column,
		rowSpan, columnSpan);

public UIButton<string> AppendButton(UIExLayout layout, string prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
{
    UIButton<string> button = new(prefix);

    StyleLayoutChildGrid styleGrid = button.StyleLayoutChild().Grid();
    styleGrid.Set(row, column, rowSpan, columnSpan);

    layout.Append(button);
    return button;
}
```

These methods are also not defined in the library and were created for this example.<br>
`AppendButton` creates a button, assigns it `Row`, `Column`, `RowSpan`, `ColumnSpan`, and the specified text, and adds it to the specified container.

---

```csharp
AppendButton(grid, prefix: "RESULT:", row: 0, column: 0, rowSpan: 2, columnSpan: 4);
```

The first element is located in cell `{0, 0}` and occupies 2 rows and 4 columns.<br>
That is, this element occupies multiple cells:<br>

* `{`

  * `{0, 0}, {0, 1}, {0, 2}, {0, 3}`,
  * `{1, 0}, {1, 1}, {1, 2}, {1, 3}`
* `}`<br>

The last element is located in cell `{6, 2}` and occupies 1 row and 2 columns.<br>

```csharp
AppendButton(grid, prefix: "=", row: 6, column: 2, rowSpan: 1, columnSpan: 2);
```

That is, this element occupies the following cells:<br>

* `{ {6, 2}, {6, 3} }`.<br>

All other elements occupy 1 cell each and are positioned sequentially from left to right and top to bottom (positioned manually):

```csharp
AppendButton(grid, prefix: 7, row: 3, column: 0);
AppendButton(grid, prefix: 8, row: 3, column: 1);
AppendButton(grid, prefix: 9, row: 3, column: 2);
AppendButton(grid, prefix: "*", row: 3, column: 3);

AppendButton(grid, prefix: 4, row: 4, column: 0);
```
