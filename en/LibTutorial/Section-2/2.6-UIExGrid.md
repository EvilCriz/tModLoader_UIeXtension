`UIExGrid` It is a layout container for two-dimensional arrangement of interface elements in the form of rows and columns.

----

<h2 align="center">Styles. <code>UIExGrid</code></h2>

- `UIExGrid` Fully utilizes all styles `StyleLayoutContainer`.
- `Orientation`: defines the main axis of the container. This value plays a role when used `JustifyContent`, `JustifySelf`, `AlignItems`, `AlignSelf`.
- `JustifyContent` and `AlignContent` determines the alignment of the elements within each cell along the main / transverse axis.

And he uses it. `StyleLayoutChild` for nested elements:
- `JustifySelf` and `AlignSelf` - override values `JustifyContent` and `AlignContent` Container for each individual element.
- `Margin` If any of the indentations are listed as a percentage, the percentages are counted from the size of the total. `UIExGrid`.

----

Grid settings are set using methods:
- `Add(Row/Column)Definition(s)`;
- `Get(Row/Column)Definition(s)`;
- `Remove(Row/Column)DefinitionAt`;
- `Remove(Row/Column)DefinitionsRange`;
- `Replace(Row/Column)Definition`;
- `Insert(Row/Column)Definition(s)`;<br>
<!-- -->
- `Add(Row/Column)Definition(s)`:
  - Overload 1: Adds a row/column size `UIExGridLength`.
  - Overload 2: Adds N rows/pillars in size `UIExGridLength`.
  - Overload 3: Adds an array of rows/pillars in size `UIExGridLength`.
  - Overload 4: Adds a list of rows/pillars sized `UIExGridLength`.
- `Get(Row/Column)Definition(s)`:
  - Overload 1: Returns the size `UIExGridLength` by row/column index.
  - Overload 2: Returns an array of sizes `UIExGridLength` from the initial to the final (inclusive) indices of rows / columns.
- `Remove(Row/Column)DefinitionAt`;
  - Overload 1: removes the row/column from the transmitted index.
- `Remove(Row/Column)DefinitionsRangle`:
  - Overload 1: removes rows/columns from the initial to the final (inclusive) indices.
- `Replace(Row/Column)Definition`:
  - Overload 1: Replaces the row/column with the transmitted size `UIExGridLength` on the transmitted index.
- `Insert(Row/Column)Definition(s)`:
  - Overload 1: inserts row/column size `UIExGridLength` on the transmitted index.
  - Overload 2: inserts an array of row/column sizes `UIExGridLength` on the transmitted index.
  - Overload 3: inserts a list of row/column sizes `UIExGridLength` on the transmitted index.<br>

String/column size structure.
```csharp
public struct UIExGridLength
{
    public Enums.UIExGridLengthType Type = Enums.UIExGridLengthType.Auto;

    public float Pixels = 0f;
    public float Precent = 0f;
    public float Fraction = 0f;


    public static UIExGridLength FromPx(float pixels) { /* ... */ }

    public static UIExGridLength FromPr(float precent) { /* ... */ }

    public static UIExGridLength FromFr(float fraction) { /* ... */ }

    public static UIExGridLength FromAuto() { /* ... */ }

    public static UIExGridLength Empty() { /* ... */ }
}

public enum UIExGridLengthType : byte
{
    Pixels,
    Precent,
    Fraction,
    Auto
}
```

Size type:
- `Pixels`: Size is given in pixels in the field `Pixels`.
- `Precent`: the size is given as a percentage in the field `Precent`.
- `Fraction`: size is set in fractions in the field `Fraction`After calculating all other row/column sizes, the free space will be distributed between rows/columns according to the size of their fractions.
- `Auto`: size is determined by the maximum size of the element nested in the row/column.<br>

Structure also defines static methods for quickly creating a structure object of the desired type.

----

`UIExGrid` allows you to specify the space between rows / columns using style fields:
```csharp
public StyleDimension RowsSpace = StyleDimension.Empty;
public StyleDimension ColumnsSpace = StyleDimension.Empty;
```

It also allows you to specify the grid alignment (if the size of the height/width of the grid is less than the height/width) of the container.
```csharp
public Enums.UIExAlignment RowsAlignment = Enums.UIExAlignment.Start;
public Enums.UIExAlignment ColumnsAlignment = Enums.UIExAlignment.Start;
```
`Rows/ColumnsAlignment` can only take meanings `Start`, `Center`, `End`.<br>
All other values will be equated `Start`.

----

All invested `UIExGrid` elements can be used in style `StyleLayoutChildGrid`.
In order for you to use this style, you need to have a style. `StyleLayoutChild` expansionist `UIElement`: `StyleLayoutChild()`.
Then, in the resulting style, call the method `Grid()`.
```csharp
UIElement element = new();
StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildGrid styleGrid = style.Grid();
styleGrid.Row = 1;
```

Same class. `StyleLayoutChildGrid` has the following implementation:
```csharp
public class StyleLayoutChildGrid : Base.StyleLayoutChildBase
{
    public int Row = 0;
    public int Column = 0;

    public int RowSpan = 1;
    public int ColumnSpan = 1;
}
```

1. Allows you to specify the row and column where this element will be located. `Значения < 0` shall be equated with `0`. `Значение >= Rows/ColumnsCount` shall be equivalent to `Rows/ColumnsCount - 1`.
2. Allows you to specify how many rows/columns an element will occupy. `Значения < 1` shall be equated with `1`The element can't use it. `Row/ColumnSpan` Get out of the grid.

<h2 align="center">Auxiliary lines</h2>

`UIExLayout` It is possible to specify auxiliary lines (see the article). `UIExLayout`).<br>
If `UIExLayout.ShowLayoutLines == true`Auxiliary lines will be drawn:
- Around every cell.
- Around the outer region of each element inside the container (which is involved in the layout).<br>

`UIExGrid` Offers an alternative possibility of rendering auxiliary lines using fields and methods:
```csharp
public bool ShowGridLines = false;
public float GridLinesThickness = 1f;
public Color GridLinesColor = Color.DarkGray;



public virtual void SetGridLinesInfoForTree(
	bool showGridLines, 
	float gridLinesThickness, 
	Color gridLinesColor) 
		{ /* ... */ }


public virtual void SetGridLinesInfoForBranch(
	bool showGridLines, 
	float gridLinesThickness, 
	Color gridLinesColor)
		{ /* ... */ }
```

In this case, the auxiliary lines will be drawn in the form of a grid.

- `ShowGridLines` determines whether the auxiliary lines will be drawn in the form of a grid.
- `GridLinesThickness` determines the size of the auxiliary lines in the form of a grid in pixels.
- `GridLinesColor` - determines the color of the auxiliary lines in the form of a grid.<br>
<!-- -->
- `SetGridLinesInfoForTree` - allows you to set all three values above for the entire tree of elements.
- `SetGridLinesInfoForBranch` - allows you to set all three values above all by the descendant of the container.<br>

`ShowLayoutLines` and `ShowGridLines` They work independently of each other.<br>
This means that all auxiliary lines can be drawn simultaneously.

<h2 align="center">Example of use <i>UIExGrid</i></h2>

<details>
<summary>Example of creating a calculator layout (without comments, analysis below)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // method OnActivate(a) in this case, only
    // for the “hot code reboot” function in the development environment.
    // It would be better to use the real interface.
    // method OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 650f, panel);

        UIExGrid grid = new();
        grid.Stretch();

        ////////////////////////////

        StyleLayoutContainer styleLayout = grid.StyleLayout;
        StyleLayoutContainerGrid styleLayoutGrid = styleLayout.Grid();

        styleLayout.Set(
            justifyContent: UIExAlignment.Stretch,
            alignItems: 	UIExAlignment.Stretch);

        styleLayoutGrid.AddRowDefinition(UIExGridLength.FromFr(1f), repeat: 7);
        styleLayoutGrid.AddColumnDefinition(UIExGridLength.FromFr(1f), repeat: 4);

        styleLayoutGrid.Set(
            rowsSpace: 		StyleDimension.FromPixels(10f),
            columnSpace: 	StyleDimension.FromPixels(15f));

        ///////////////////////////

        AppendButton(grid, prefix: "RESULT:", row: 0, column: 0, rowSpan: 2, columnSpan: 4);

        AppendButton(grid, prefix: "AC", row: 2, column: 0);
        AppendButton(grid, prefix: "%", row: 2, column: 1);
        AppendButton(grid, prefix: "<<", row: 2, column: 2);
        AppendButton(grid, prefix: "/", row: 2, column: 3);

        AppendButton(grid, prefix: 7, row: 3, column: 0);
        AppendButton(grid, prefix: 8, row: 3, column: 1);
        AppendButton(grid, prefix: 9, row: 3, column: 2);
        AppendButton(grid, prefix: "*", row: 3, column: 3);

        AppendButton(grid, prefix: 4, row: 4, column: 0);
        AppendButton(grid, prefix: 5, row: 4, column: 1);
        AppendButton(grid, prefix: 6, row: 4, column: 2);
        AppendButton(grid, prefix: "-", row: 4, column: 3);

        AppendButton(grid, prefix: 1, row: 5, column: 0);
        AppendButton(grid, prefix: 2, row: 5, column: 1);
        AppendButton(grid, prefix: 3, row: 5, column: 2);
        AppendButton(grid, prefix: "+", row: 5, column: 3);

        AppendButton(grid, prefix: 0, row: 6, column: 0);
        AppendButton(grid, prefix: ",", row: 6, column: 1);
        AppendButton(grid, prefix: "=", row: 6, column: 2, rowSpan: 1, columnSpan: 2);

        ///////////////////////////

        panel.Append(grid);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AppendButton(UIExLayout layout, int prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
        => AppendButton(layout, prefix.ToString(), row, column, rowSpan, columnSpan);
    public UIButton<string> AppendButton(UIExLayout layout, string prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
    {
        UIButton<string> button = new(prefix);

        StyleLayoutChildGrid styleGrid = button.StyleLayoutChild().Grid();
        styleGrid.Set(row, column, rowSpan, columnSpan);

        layout.Append(button);
        return button;
    }
}
```

----

The first thing you see in the code is creating a master panel size. `450х650px`, which is centered on the screen.
```csharp
UIPanel panel = new UIPanel();
SetPixelsSizeCenter(width: 450f, height: 650f, panel);
```
Method `SetPixelsSizeCenter` It is defined in this class by way of example and is not the method of this library.<br>

Then a container is created. `UIExGrid`:
```csharp
UIExGrid grid = new();
grid.Stretch();
```
Method `Stretch()` determined `UIExLayout` and causes the container to stretch over the entire height and width of the parent element.<br>
In this example, `grid.Stretch()` stretches the element over its entire size `panel`.

----

A little bit about visual styles. This is the subject of the next section, but there's 1 important point for builders, so this footnote will be in every article.<br>
As you can see, in this code, the system is as follows: the main panel -> container -> elements inside the container.<br>
A container is created for the main panel.<br>
This is unnecessary if the result is exactly what we want to see in the image.<br>
`UIExElement` (from which he inherits) `UIExLayout`) has the property of style: `StyleDisplay.tModLoaderStyle (bool)`.<br>
If this value is true, then the visual element will adopt the appropriate style. **tModLoader**.<br>
For `UIExElement` significance `true` This means that the style will be similar. `UIPanel`.<br>
Therefore, our code could have been shortened.<br>

Here's the part:
```csharp
UIPanel panel = new UIPanel();
SetPixelsSizeCenter(width: 450f, height: 650f, panel);

UIExGrid grid = new();
grid.Stretch();

/*
...
*/

panel.Append(grid);
Append(panel);
```

Can be replaced by the following:
```csharp
UIExGrid grid = new();
grid.StyleDisplay.tModLoaderStyle = true;
SetPixelsSizeCenter(width: 450f, height: 650f, grid);

/*
...
*/

Append(grid);
```

As you can see in the second code, the `UIPanel panel` The container itself is gone. `grid` It became the main container at the same time.

----

Next, the code obtains the basic container layout style and layout style `UIExGrid`:
```csharp
StyleLayoutContainer styleLayout = grid.StyleLayout;
StyleLayoutContainerGrid styleLayoutGrid = styleLayout.Grid();
```

Then the values are set. `justifyContent` and `alignItems`: `UIExAlignment.Stretch`.
```csharp
styleLayout.Set(
	justifyContent: UIExAlignment.Stretch,
	alignItems: 	UIExAlignment.Stretch);
```
This code specifies that all elements inside the container must be stretched along the width and height of the cell/cells it occupies.<br>

----

The code then defines the grid itself:
```csharp
styleLayoutGrid.AddRowDefinition(UIExGridLength.FromFr(1f), repeat: 7);
styleLayoutGrid.AddColumnDefinition(UIExGridLength.FromFr(1f), repeat: 4);
```
This code indicates that:
- There should be 7 lines in the grid, which equally distribute the height of the container among themselves.
- The columns in the grid should be 4 pieces, which equally distribute the width of the container among themselves.
- The space is evenly distributed as the size of each row/column is 1 fraction.<br>

Next, the code defines the space between rows and columns:
```csharp
styleLayoutGrid.Set(
	rowsSpace: 		StyleDimension.FromPixels(10f),
	columnSpace: 	StyleDimension.FromPixels(15f));
```

Then buttons are added using methods:

AppendButton(grid, prefix: "RESULT:", row: 0, column: 0, rowSpan: 2, columnSpan: 4);
