---

`UIExDockPanel` is a layout container that **sequentially** docks child elements to one of five sides of the available area:

* `Left`
* `Right`
* `Top`
* `Bottom`<br>

The remaining space is also considered a separate side: `Fill`.<br>
It occupies all remaining available space after the previous sides have been calculated.<br>

`UIExDockPanel` can be conditionally represented as two layout levels:

1. First level: sequential allocation of the `Left`, `Right`, `Top`, `Bottom`, and `Fill` areas;
2. Second level: each side independently lays out the elements docked to it according to rules practically identical to `UIExStackPanel`.<br>

For each element (except for one exception, which will be discussed later), we specify the side to which we want to dock it.<br>
However, the key factor when working with this layout container is the order in which elements are added to the container.<br>

Suppose we have 4 buttons that we dock to a side according to the button name and add to the layout container in the following order:

1. `buttonTop`.
2. `buttonBottom`
3. `buttonLeft`
4. `buttonRight`<br>

You saw the result in the image above.<br>

But now let's change the order in which the elements are added. The buttons themselves will remain docked to the same sides, but their order in the container will be:

1. `buttonLeft`
2. `buttonTop`.
3. `buttonBottom`
4. `buttonRight`<br>

After changing the order in which the elements are added, we will get the following result:

---

The layout container does the following:

1. Remembers which side the first element was docked to, the second element, and so on. For example:

   * the first — to the left side;
   * the second — to the left side;
   * the third — to the right side;
   * the fourth — to the left side;
   * the fifth — to the bottom side.
2. Remembers the list of sides without repetitions, in the same order. Example (according to point 1):

   * left side;
   * right side;
   * bottom side.
3. Sequentially allocates the size of each side according to the list from point 2 and the algorithm below.<br>

The dimensions of a side are determined as follows:

1. Height of the `Left` and `Right` sides: the height of the free space in the container.
2. Width of the `Left` and `Right` sides: the width of the largest outer area among the elements docked to that side.
3. Width of the `Top` and `Bottom` sides: the width of the free space in the container.
4. Height of the `Top` and `Bottom` sides: the height of the largest outer area among the elements docked to that side.<br>

After the area of the first added side has been calculated, this area is excluded from the free space of the container.<br>
In the example from the previous image, the button docked to the left side was added first.<br>
This is what the free area looks like for `UIExDockPanel` after adding the first (left) side:

<details>
<summary>Code that produces the result shown in Fig. 1.1</summary>

```csharp
using Microsoft.Xna.Framework;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.MethodsExtensions;
using UIeXtension.Styles;

namespace UIeXtensionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // The OnActivate() method is used here only
    // for the "hot code reload" feature in the development environment.
    // For a real interface, it would be more appropriate to use
    // the OnInitialize() method.
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.25f, 0.25f, panel);

        UIExDockPanel dockPanel = new();
        dockPanel.Stretch();
        dockPanel.SetLayoutLinesInfoForBranch(
            state:      true,
            thickness:  3f,
            color:      Color.DarkOrange);

        dockPanel.StyleLayout.JustifyContent = UIExAlignment.Stretch;
        dockPanel.StyleLayout.AlignItems = UIExAlignment.Stretch;

        UIButton<string> buttonTop = CreateAndAddUIBottom(dockPanel, 50f, "top");
        UIButton<string> buttonBottom = CreateAndAddUIBottom(dockPanel, 50f, "bot");
        UIButton<string> buttonLeft = CreateAndAddUIBottom(dockPanel, 50f, "left");
        UIButton<string> buttonRight = CreateAndAddUIBottom(dockPanel, 50f, "right");

        var btTopStyleDock = buttonTop.StyleLayoutChild().DockPanel();
        var btBottomStyleDock = buttonBottom.StyleLayoutChild().DockPanel();
        var btLeftStyleDock = buttonLeft.StyleLayoutChild().DockPanel();
        var btRightStyleDock = buttonRight.StyleLayoutChild().DockPanel();

        btTopStyleDock.Side = UIExSide.Top;
        btBottomStyleDock.Side = UIExSide.Bottom;
        btLeftStyleDock.Side = UIExSide.Left;
        btRightStyleDock.Side = UIExSide.Right;

        ///////////////////

        panel.Append(dockPanel);
        Append(panel);
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> CreateAndAddUIBottom(UIExLayout layout, float pixelsSize, string text)
    {
        UIButton<string> button = new(text);
        button.Width.Pixels = pixelsSize;
        button.Height.Pixels = pixelsSize;
        layout.Append(button);
        return button;
    }
}
```

---

`UIExDockPanel` also has the `Fill` side. This side occupies all remaining space after the `Left`, `Right`, `Top`, and `Bottom` sides have been calculated.<br>
You can see an example of this below.<br>
The order in which elements with `Side == Fill` are added does not affect the order in which the sides are calculated.<br>
`Fill` is always calculated after `Left`, `Right`, `Top`, and `Bottom` and occupies all remaining space.<br>

At the beginning of the chapter, there was a warning that this article assumes you have already studied the `UIExStackPanel` layout element. There is an important reason for this.<br>

<h2 align="center"><code>UIExDockPanel</code> Styles</h2>

The base layout style `StyleLayoutContainer`:

```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    public Enums.UIExOrientation Orientation = Enums.UIExOrientation.Vertical;
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
}
```

* `Orientation`: determines the main axis of the **FILL** side along which elements inside it will be aligned.

  * For the `Left` and `Right` sides, the orientation is always vertical.
  * For the `Top` and `Bottom` sides, the orientation is always horizontal.

* `JustifyContent`: alignment of elements along the main axis (works for all sides; this value can be overridden for a specific side and/or a specific element).

* `AlignItems`: alignment of elements along the cross axis (works for all sides; this value can be overridden for a specific side and/or a specific element).<br><br>

* For `Left`, `Right`, `Top`, and `Bottom`, the layout direction is unambiguously determined by the side itself.<br>

* `Fill` has no fixed direction, so its orientation is specified through `StyleLayout.Orientation`.<br>

Alignment types:

```csharp
public enum UIExAlignment : byte
{
    Auto,
    Start,
    Center,
    End,
    Stretch
}
```

* `Auto`: equivalent to `Start`. Used for child elements and/or sides.
* `Start`: aligns elements to the start of the side axis (top/left).
* `Center`: aligns elements to the center of the side axis.
* `End`: aligns elements to the end of the side axis (bottom/right).
* `Stretch`: stretches the element across the entire side axis (minus `Margin`).

---

The base child element styles `StyleLayoutChild`:

```csharp
public partial class StyleLayoutChild : Base.StyleLayoutChildBase
{
    public Enums.UIExAlignment JustifySelf = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignSelf = Enums.UIExAlignment.Auto;
    public UIExThickness Margin = new();
    public StyleDimension Width = default(StyleDimension);
    public StyleDimension Height = default(StyleDimension);
}
```

* For child elements, the `JustifySelf` field ignores any values except `Stretch`. The `Auto` value means that the value will be controlled by the container/side.
* The `AlignSelf` field overrides the `AlignItems` value for a specific child element. The `Auto` value means that the value will be controlled by the container/side.
* The `Margin` field is taken into account when laying out the element and when determining the size of the outer area occupied by it.
* The `Width` and `Height` fields were discussed in detail in the first article of this section.

---

The `UIExDockPanel` class uses the `StyleLayoutContainerDockPanel` style class, which stores all layout styles for this class:

```csharp
public class StyleLayoutContainerDockPanel : Base.StyleLayoutContainerBase
{
    public StyleSide SideLeft;
    public StyleSide SideRight;
    public StyleSide SideTop;
    public StyleSide SideBottom;
    public StyleSide SideFill;
}
```

This style class contains styles for the four sides and for filling the remaining space.

```csharp
public class StyleSide : Base.StyleBase
{
    public UIExThickness Padding = default(UIExThickness);
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
    public StyleDimension Spacing = default(StyleDimension);
    public bool Reverse = false;
}
```

* `Padding`: spacing from the edges of the side to the allocated area where elements are placed.
* `JustifyContent`: alignment of elements along the main axis. Overrides the `JustifyContent` value of the container style for this specific side. The `Auto` value means that the value will be controlled by the container.
* `AlignItems`: alignment of elements along the cross axis. Overrides the `AlignItems` value of the container style for this specific side. The `Auto` value means that the value will be controlled by the container.
* `Spacing`: specifies the space between elements inside the side (the space between elements along the main axis).
* `Reverse`: specifies that the elements of this side should be arranged in reverse order.<br>

To obtain the `UIExDockPanel` style, use the `DockPanel()` method on the `StyleLayout` field:

```csharp
UIExDockPanel dockPanel = new();

StyleLayoutContainer styleLayout = dockPanel.StyleLayout;
StyleLayoutContainerDockPanel styleLayoutDockPanel = styleLayout.DockPanel();

styleLayoutDockPanel.SideLeft.Reverse = true;
```

---

The `UIExDockPanel` child element style:

```csharp
public class StyleLayoutChildDockPanel : Base.StyleLayoutChildBase
{
    public Enums.UIExSide Side = Enums.UIExSide.Left;
}

public enum UIExSide : byte
{
    Left,
    Right,
    Top,
    Bottom,
    Fill
}
```

As you can see, the child element style is only responsible for specifying which side the element should be docked to.<br>

To obtain the base child element style, use the `StyleLayoutChild()` extension method of `UIElement`.<br>
To obtain the child element style with parameters specific to `UIExDockPanel`, call `DockPanel()` on the base style:

```csharp
UIElement element = new();

StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildDockPanel styleDockPanel = style.DockPanel();

styleDockPanel.Side = UIExSide.Top;
```

<summary>Example of creating a user interface (without comments, explained below)</summary>

```csharp
using Microsoft.Xna.Framework;
using System;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.MethodsExtensions;
using UIeXtension.Styles;

namespace UIeXtensionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState

    // The OnActivate() method is used here only
    // for the "hot code reload" feature in the development environment.
    // For a real interface, it would be more appropriate to use
    // the OnInitialize() method.
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.8f, 0.8f, panel);

        UIExDockPanel dockPanel = new UIExDockPanel();
        dockPanel.Stretch();

        dockPanel.ShowLayoutLines = true;
        dockPanel.LayoutLinesThickness = 3f;
        dockPanel.LayoutLinesColor = Color.DarkOrange;

        StyleLayoutContainer styleLayout = dockPanel.StyleLayout;
        StyleLayoutContainerDockPanel styleLayoutDock = styleLayout.DockPanel();

        styleLayout.JustifyContent = UIExAlignment.Center;
        styleLayout.AlignItems = UIExAlignment.Center;

        ////////////////

        StyleSide sideBottom = styleLayoutDock.SideBottom;
        sideBottom.Spacing.Pixels = 100f;

        StyleLayoutChild[] cubsStylesBottom = new StyleLayoutChild[cubsBottom.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockBottom = new StyleLayoutChildDockPanel[cubsBottom.Length];

        for (int i = 0; i < cubsBottom.Length; i++)
        {
            cubsStylesBottom[i] = cubsBottom[i].StyleLayoutChild();
            cubsStylesDockBottom[i] = cubsStylesBottom[i].DockPanel();
            cubsStylesDockBottom[i].Side = UIExSide.Bottom;
        }

        cubsStylesBottom[0].Margin = new(pixels: true, size: 25f);
        cubsStylesBottom[0].JustifySelf = UIExAlignment.Stretch;

        ////////////////

        StyleSide sideLeft = styleLayoutDock.SideLeft;
        sideLeft.Spacing.Pixels = 50f;
        sideLeft.AlignItems = UIExAlignment.End;

        UIElement[] cubsLeft = AddCubs(dockPanel, "l", pixelSize: 50f, 4);
        StyleLayoutChild[] cubsStylesLeft = new StyleLayoutChild[cubsLeft.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockLeft = new StyleLayoutChildDockPanel[cubsLeft.Length];

        for (int i = 0; i < cubsLeft.Length; i++)

            cubsStylesLeft[i] = cubsLeft[i].StyleLayoutChild();

            cubsStylesDockLeft[i].Side = UIExSide.Left;
        }

        cubsStylesLeft[1].AlignSelf = UIExAlignment.Start;
        cubsStylesLeft[2].Margin = new(pixels: true, 50f);

        /////////////////

        StyleSide sideTop = styleLayoutDock.SideTop;
        sideTop.Spacing.Pixels = 10f;
        sideTop.JustifyContent = UIExAlignment.End;

        UIElement[] cubsTop = AddCubs(dockPanel, "t", pixelSize: 50f, 3);
        StyleLayoutChild[] cubsStylesTop = new StyleLayoutChild[cubsTop.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockTop = new StyleLayoutChildDockPanel[cubsTop.Length];

        for (int i = 0; i < cubsTop.Length; i++)
        {
            cubsStylesTop[i] = cubsTop[i].StyleLayoutChild();
            cubsStylesDockTop[i] = cubsStylesTop[i].DockPanel();
            cubsStylesDockTop[i].Side = UIExSide.Top;
        }

        cubsStylesTop[1].Margin = new(pixels: true, 10f);

        /////////////////

        StyleSide sideRight = styleLayoutDock.SideRight;
        sideRight.Spacing.Pixels = 30f;
        sideRight.JustifyContent = UIExAlignment.End;
        sideRight.Padding = new UIExThickness(pixels: true, size: 20f);

        UIElement[] cubsRight = AddCubs(dockPanel, "r", pixelSize: 50f, 5);
        StyleLayoutChild[] cubsStylesRight = new StyleLayoutChild[cubsRight.Length];
```

The first thing worth repeating is the order in which elements are added.<br>
The following elements were added to `UIExDockPanel`:

* 1 element with `Side == UIExSide.Bottom;`
* 4 elements with `Side == UIExSide.Left;`
* 3 elements with `Side == UIExSide.Top;`
* 5 elements with `Side == UIExSide.Right;`
* 1 element with `Side == UIExSide.Fill;`

This means that the sides are calculated in the following order:

1. Bottom.
2. Left.
3. Top.
4. Right.
5. Remaining space.<br>

The dimensions of the sides are determined as follows:

<table align="center">
  <tr>
    <th>Side</th>
    <th>Width</th>
    <th>Height</th>
  </tr>
  <tr>
    <td><code>Left</code></td>
    <td>Maximum outer width of the elements</td>
    <td>All free height</td>
  </tr>
  <tr>
    <td><code>Right</code></td>
    <td>Maximum outer width of the elements</td>
    <td>All free height</td>
  </tr>
  <tr>
    <td><code>Top</code></td>
    <td>All free width</td>
    <td>Maximum outer height of the elements</td>
  </tr>
  <tr>
    <td><code>Bottom</code></td>
    <td>All free width</td>
    <td>Maximum outer height of the elements</td>
  </tr>
  <tr>
    <td><code>Fill</code></td>
    <td>All remaining width</td>
    <td>All remaining height</td>
  </tr>
</table>

These are the areas of the sides themselves.<br>
Elements are laid out within the inner area of the sides (after subtracting the side's `padding`).<br>

---

The first thing visible in the code:

```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);

UIExDockPanel dockPanel = new UIExDockPanel();
dockPanel.Stretch();
```

The main `UIPanel` is created with a size of 80% of the screen and centered.<br>

The `SetPrecentSizeCenter` method sets the size as a percentage and centers the element.<br>
This method is not part of the library; it is defined in the same class below.<br>

Next, the `UIExDockPanel` container is created.<br>
It is stretched across the entire width of the parent element using the `Stretch();` method.<br>
This method is defined in the `UIExLayout` class.<br>

Instead of creating two panels, the main panel itself could have been the `UIExDockPanel dockPanel`.<br>
For this purpose, the **visual style** `UIExElement` contains the `tModLoaderStyle (bool)` field.<br>
Setting this field to `true` for layout containers causes them to have a visual style similar to `UIPanel`.<br>

In this case, the code above could be replaced with:

```csharp
UIExDockPanel dockPanel = new UIExDockPanel();
dockPanel.StyleDisplay.tModLoaderStyle = true;
SetPrecentSizeCenter(0.8f, 0.8f, dockPanel);
```

Now `dockPanel` will become the main panel with a size of 80% of the screen.

---

Next come the lines:

```csharp
dockPanel.ShowLayoutLines = true;
dockPanel.LayoutLinesThickness = 3f;
dockPanel.LayoutLinesColor = Color.DarkOrange;
```

This code tells the layout container to display helper lines with a size of `3px` and the specified color.<br>
For `UIExDockPanel`, setting `ShowLayoutLines` causes helper lines to be displayed around:

* the **inner** area of the sides;
* the **outer** area of the elements nested in the layout container.

Next, the following variables are obtained and stored:

1. The base layout container style.
2. The layout style of the `UIExDockPanel` container.<br>

```csharp
StyleLayoutContainer styleLayout = dockPanel.StyleLayout;
StyleLayoutContainerDockPanel styleLayoutDock = styleLayout.DockPanel();
```

---

Next comes the code responsible for aligning elements along the main/cross axis.<br>
The main axis of a side is determined automatically:

1. For the left/right side: the main axis is vertical.
2. For the top/bottom side: the main axis is horizontal.
3. For the fill area: the main orientation is determined by `UIExDockPanel >> StyleLayout.Orientation` (this will appear in the code below).

```csharp
styleLayout.JustifyContent = UIExAlignment.Center;
styleLayout.AlignItems = UIExAlignment.Center;
```

Elements will be aligned according to these values if:

1. The side does **NOT** override one of these values (discussed below).
2. The element does **NOT** override one of these values (discussed below).

---

Next, the style of the bottom side is obtained and stored:

```csharp
StyleSide sideBottom = styleLayoutDock.SideBottom;
```

Recall that `styleLayoutDock` is the stored layout style of the `UIExDockPanel` container.<br>
The `UIExDockPanel` style itself is defined as follows:<br>

```csharp
public class StyleLayoutContainerDockPanel : Base.StyleLayoutContainerBase
{
    public StyleSide SideLeft;
    public StyleSide SideRight;
    public StyleSide SideTop;
    public StyleSide SideBottom;
    public StyleSide SideFill;
}
```

As you can see, this class stores the styles of the sides. The `StyleSide` class looks as follows:

```csharp
public class StyleSide : Base.StyleBase
{
    public UIExThickness Padding = default(UIExThickness);
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
    public StyleDimension Spacing = default(StyleDimension);
    public bool Reverse = false;
}
```

Each side is practically a complete analogue of `UIExStackPanel` with two differences:

1. There is no `Orientation` field.
2. A `Padding` field is added.

<!-- -->

1. We have already discussed the orientation of the sides earlier.<br>
2. If `JustifyContent` and `AlignItems` have a value other than `Enums.UIExAlignment.Auto`, they override the corresponding values in `styleLayout` for the specific side.
3. All values except `Padding` work similarly to their counterparts in `UIExStackPanel`.
4. `Padding` is of type `UIExThickness` and defines the spacing from the **side area** to the **inner area** of the side. The areas are described in more detail in the article: *«UIExStackPanel class». Layout basics*.

```csharp
UIElement[] cubsBottom = AddCubs(dockPanel, "b", pixelSize: 50f, 1);
StyleLayoutChild[] cubsStylesBottom = new StyleLayoutChild[cubsBottom.Length];
StyleLayoutChildDockPanel[] cubsStylesDockBottom = new StyleLayoutChildDockPanel[cubsBottom.Length];

for (int i = 0; i < cubsBottom.Length; i++)
{
    cubsStylesBottom[i] = cubsBottom[i].StyleLayoutChild();
    cubsStylesDockBottom[i] = cubsStylesBottom[i].DockPanel();
    cubsStylesDockBottom[i].Side = UIExSide.Bottom;
}
```

The following happens in this part:

1. One square button with a side length of 50px is created. The text inside the button is `b` (bottom) + its index.
2. Memory is allocated for the `StyleLayoutChild` style array.
3. Memory is allocated for the `StyleLayoutChildDockPanel` style array.<br>

Then a loop runs in which:

1. The `StyleLayoutChild` class is obtained using the `StyleLayoutChild()` extension method of `UIElement`.
2. The `StyleLayoutChildDockPanel` class is obtained using `DockPanel()` from the `StyleLayoutChild` class.
3. It specifies that all buttons in this loop should be docked to the bottom side.<br>

---

```csharp
cubsStylesBottom[0].Margin = new(pixels: true, size: 25f);
cubsStylesBottom[0].JustifySelf = UIExAlignment.Stretch;
```

1. We specify that the first button (in this case, the only one) should have a `Margin: 25px` on each side.
2. The button should be stretched along the main axis (for the bottom side: horizontally).<br>

Looking at the bottom side in the image, you can notice the following:

1. The outline of the **inner area** of the bottom side coincides with the **outer side** of the button.
2. The height of the bottom side is `100px`: `50px` button height + `Margin.Bottom: 25px` + `Margin.Top: 25px`.<br>

Recall that the height of the bottom and top sides is determined by the largest **outer area** of the elements.

---

We will not examine the remaining side examples in detail. Instead, let's focus on the following.

The code adds elements in this order:

1. 1 button for the bottom side.
2. 4 buttons for the left side.
3. 3 buttons for the top side.
4. 5 buttons for the right side.
5. 2 buttons for the remaining space.<br>

In this case, the sides will be calculated in the following order:

1. Bottom.
2. Left.
3. Top.
4. Right.
5. Remaining space.<br>

If we changed the order of the code, the order in which space is allocated to the sides would also change.<br>
Except for `Fill` elements.<br>
The order in which elements with `Side == Fill` are added does not affect the order in which the sides are calculated.<br>
`Fill` is always calculated after `Left`, `Right`, `Top`, and `Bottom` and occupies all remaining space.<br>
Therefore, if we move the code responsible for adding elements to the remaining space to the very beginning, the layout result will not change.

---

Let's look at the right side in the image.<br>
You can notice that this side has spacing from the other edges.<br>
This is caused by the following line:

```csharp
StyleSide sideRight = styleLayoutDock.SideRight;
sideRight.Padding = new UIExThickness(pixels: true, size: 20f);
```

This line specifies that the **inner area** of the side should be offset by `20px` on each side.<br>
This is the area where the elements docked to this side will be placed.<br>
The helper lines are drawn specifically around the **inner area**.<br>
For the layout container itself, this side occupies its full size without taking `Padding` into account.<br>

---

Filling the remaining space.<br>

```csharp
StyleLayoutContainer styleLayout = dockPanel.StyleLayout;
/*
...
*/
styleLayout.Orientation = UIExOrientation.Horizontal;
```

This line specifies the orientation in which elements are arranged inside the `Fill` side.<br>
Otherwise, the rules for arranging elements are the same as for the other sides.

---

And finally: if no element is docked to one of the sides, that side will not exist for the layout container.
