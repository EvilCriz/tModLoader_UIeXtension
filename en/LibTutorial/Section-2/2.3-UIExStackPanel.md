---

`UIExStackPanel` is a layout container that arranges child elements in a single line (stack) vertically or horizontally.<br>

---

Base element layout style `StyleLayoutContainer`:

```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    public Enums.UIExOrientation Orientation = Enums.UIExOrientation.Vertical;
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
}
```

* `Orientation`: determines the main axis of the container along which the elements will be aligned.
* `JustifyContent`: alignment of elements along the main axis.
* `AlignItems`: alignment of elements along the cross axis.<br>

Alignment types:

```csharp
public enum UIExAlignment : byte
{
    Auto,
    Start,
    Center,
    End,
    Stretch
}
```

* `Auto`: equivalent to `Start`. Used by elements nested inside the container.
* `Start`: aligns elements to the start of the axis (top/left).
* `Center`: aligns elements to the center of the axis.
* `End`: aligns elements to the end of the axis (bottom/right).
* `Stretch`: stretches the element along the entire axis (minus `Margin`).<br>

---

Base child element styles `StyleLayoutChild`:

```csharp
public partial class StyleLayoutChild : Base.StyleLayoutChildBase
{
    public Enums.UIExAlignment JustifySelf = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignSelf = Enums.UIExAlignment.Auto;
    public UIExThickness Margin = new();
    public StyleDimension Width = default(StyleDimension);
    public StyleDimension Height = default(StyleDimension);
}
```

* The `JustifySelf` field of child elements ignores any values except `Stretch`.
* The `AlignSelf` field overrides the `AlignItems` value for a specific nested element.
* The `Margin` field works fully.
* The `Width` and `Height` fields were discussed in detail in the first article of this section.

---

The `UIExStackPanel` class uses the `StyleLayoutContainerStackPanel` style class, which stores all layout styles for this class.

```csharp
public class StyleLayoutContainerStackPanel : Base.StyleLayoutContainerBase
{
    public StyleDimension Spacing = StyleDimension.Empty;
    public bool Reverse = false;

    public void Set(StyleDimension spacing, bool reverse) { /* ... */ }
    public void Copy(StyleLayoutContainerStackPanel style) { /* ... */ }
    public StyleLayoutContainerStackPanel GetCopy() { /* ... */ }
}
```

* `Spacing`:

  * Defines the space between child elements of `UIExStackPanel`.
  * Works even if `JustifyContent` and/or `AlignItems` == `UIExAlignment.Stretch`
* `Reverse`:

  * A flag responsible for arranging elements in reverse order.
  * When `true` — all elements will be arranged in reverse order while preserving all other style characteristics.

    <br>

---

**DOES NOT IMPLEMENT** its own style class for child elements.<br>

---

* The base layout styles of the container are contained in the `StyleLayout` field.
* To get the layout styles of `UIExStackPanel`, use the `StackPanel()` method of the `StyleLayout` field.
* To get the base styles for elements nested inside the container, use the `StyleLayoutChild()` extension method for `UIElement`.<br>

```csharp
UIExStackPanel stackPanel = new();

StyleLayoutContainer style = stackPanel.StyleLayout;
StyleLayoutContainerStackPanel styleStackPanel = stackPanel.StyleLayout.StackPanel(); // or style.StackPanel();

UIElement element = new();
StyleLayoutChild styleChild = element.StyleLayoutChild();

style.JustifyContent = UIExAlignment.Center;
styleStackPanel.Reverse = true;

styleChild.JustifySelf = UIExAlignment.Stretch;
```

<h2 align="center">Example of using <i>UIExStackPanel</i></h2>

<details>
<summary>Example of creating a user interface (without comments, explained below)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.UI;
using Microsoft.Xna.Framework;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.MethodsExtensions;
using UIeXtension.Styles;

namespace UIeXtensionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // the OnActivate() method is used in this case only
    // for the «hot reload» feature in the development environment.
    // for a real interface, it would be more appropriate to use
    // the OnInitialize() method
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.8f, 0.8f, panel);

        UIExStackPanel HStackPanel = new();
        HStackPanel.Stretch();

        HStackPanel.StyleLayout.Set(
            orientation:        UIExOrientation.Horizontal,
            justifyContent:     UIExAlignment.Stretch,
            alignItems:         UIExAlignment.Stretch);
        HStackPanel.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.05f),
            reverse:            false);

        panel.Append(HStackPanel);

        //////

        UIPanel HPanel1 = new(), HPanel2 = new(), HPanel3 = new(), HPanel4 = new();
        HStackPanel.Append(HPanel1);
        HStackPanel.Append(HPanel2);
        HStackPanel.Append(HPanel3);
        HStackPanel.Append(HPanel4);

        /////

        UIExStackPanel VStackPanel1 = new(), VStackPanel2 = new(), VStackPanel3 = new(), VStackPanel4 = new();
        SetPrecentSizeCenter(1f, 1f, VStackPanel1, VStackPanel2, VStackPanel3, VStackPanel4);
        HPanel1.Append(VStackPanel1);
        HPanel2.Append(VStackPanel2);
        HPanel3.Append(VStackPanel3);
        HPanel4.Append(VStackPanel4);

        VStackPanel1.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Start,
            alignItems:         UIExAlignment.Start);
        VStackPanel1.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.1f),
            reverse:            false);

        UIElement[] cubs2_1 = AddCubs(VStackPanel1, pixelSize: 64f, count: 3);


        StyleLayoutChild stylePanel2_1 = cubs2_1[1].StyleLayoutChild();

        stylePanel2_1.AlignSelf = UIExAlignment.End;

        ////

        VStackPanel2.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Center,
            alignItems:         UIExAlignment.Center);
        VStackPanel2.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.15f),
            reverse:            true);

        UIElement[] cubs2_2 = AddCubs(VStackPanel2, 16f, 32f, 48f, 64f);


        StyleLayoutChild stylePanel2_2 = cubs2_2[2].StyleLayoutChild();

        stylePanel2_2.Set(
                                // does nothing, UIExStackPanel does not take JustifySelf into account,
                                // except for the Stretch value
            justifySelf:        UIExAlignment.End, 
            alignSelf:          UIExAlignment.Stretch,
            width:              stylePanel2_2.Width,
            height:             stylePanel2_2.Height,
            margin:             new UIExThickness(
                                    pixels: false,
                                    left:   0.25f,
                                    top:    0.075f,
                                    right:  0f,
                                    bottom: 0.015f));

        ////

        VStackPanel3.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.End,
            alignItems:         UIExAlignment.End);
        VStackPanel3.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.20f),
            reverse:            false);

        AddCubs(VStackPanel3, 32f, 48f, 64f);

        ////

        VStackPanel4.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Stretch,
            alignItems:         UIExAlignment.Stretch);
        VStackPanel4.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.20f),
            reverse:            false);

        AddCubs(VStackPanel4, pixelSize: 60f);
        AddCubs(VStackPanel4, pixelSize: 50f);
        AddCubs(VStackPanel4, pixelSize: 70f);

        ////

        HStackPanel.SetLayoutLinesInfoForBranch(
            state: true, 
            thickness: 3f, 
            color: Color.DarkOrange);

        ///

        Append(panel);
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
    {
        int count = pixelSizes.Length;
        var panels = new UIElement[count];
        for (int i = 0; i < count; i++)
            panels[i] = AddCubs(element, pixelSizes[i], count: 1)[0];
        return panels;
    }

    public UIElement[] AddCubs(UIElement element, float pixelSize, int count = 1)
    {
        var panels = new UIElement[count];
        for (int i = 0; i < count; i++)
        {
            panels[i] = new UIPanel();
            StyleLayoutChild style = panels[i].StyleLayoutChild();
            style.Width.Set(pixelSize, 0f);
            style.Height.Set(pixelSize, 0f);
            element.Append(panels[i]);
        }
        return panels;
    }
}
```

A little about visual styles. This is the topic of the next section, but there is 1 important point for layout containers, so this note will be included in every article.<br>
As you can see, the system in this code is as follows: main panel -> container -> section panel -> container -> cube panel.<br>
A separate container is created for each panel (except for the cubes).<br>
This is excessive if the result is exactly what we want to see in the image.<br>
`UIExElement` (from which `UIExLayout` inherits) has a style property: `StyleDisplay.tModLoaderStyle (bool)`.<br>
If this value is true, the visual element will use the corresponding **tModLoader** style.<br>
For `UIExElement`, setting it to `true` will result in a style similar to `UIPanel`.<br>
Therefore, our code could be shortened.<br><br>

For example, this part:

```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);

UIExStackPanel HStackPanel = new();
HStackPanel.Stretch();

HStackPanel.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Stretch,
    alignItems:         UIExAlignment.Stretch);
HStackPanel.StyleLayout.StackPanel().Set(
    spacing:            new StyleDimension(0f, 0.05f),
    reverse:            false);

panel.Append(HStackPanel);
/*
...
*/
Append(panel);
```

Can be replaced with the following:

```csharp
UIExStackPanel HStackPanel = new();
HStackPanel.StyleDisplay.tModLoaderStyle = true;
SetPrecentSizeCenter(0.8f, 0.8f, HStackPanel);

HStackPanel.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Stretch,
    alignItems:         UIExAlignment.Stretch);
HStackPanel.StyleLayout.StackPanel().Set(
    spacing:            new StyleDimension(0f, 0.05f),
    reverse:            false);
/*
...
*/
Append(HStackPanel);
```

As can be seen in the second code example, the `UIPanel panel` element is gone. The layout container `HStackPanel` itself has become the main container.

---

The first thing you see in the code:

```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);
```

This is the main panel that will be added to the `UIState`. The `UIExStackPanel` will be arranged inside it.<br><br>
`SetPrecentSizeCenter` is a helper method that does not exist in the library itself and is defined below in the same class.
It receives N `UIElement` objects, assigns them the specified height and width, and centers them. In this case, our `panel` has a size of: 80% × 80% of the screen.<br><br>

---

Next in the code comes the first `UIExStackPanel`:

```csharp
UIExStackPanel HStackPanel = new();
HStackPanel.Stretch();

HStackPanel.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Stretch,
    alignItems:         UIExAlignment.Stretch);
HStackPanel.StyleLayout.StackPanel().Set(
    spacing:            new StyleDimension(0f, 0.05f),
    reverse:            false);

panel.Append(HStackPanel);

//////

UIPanel HPanel1 = new(), HPanel2 = new(), HPanel3 = new(), HPanel4 = new();
HStackPanel.Append(HPanel1);
HStackPanel.Append(HPanel2);
HStackPanel.Append(HPanel3);
HStackPanel.Append(HPanel4);
```

* `HStackPanel.Stretch();` - sets the size of `HStackPanel`: 100% of the parent element.
* Below, we add `HStackPanel` to the main panel `panel.Append(HStackPanel);`, which means that `HStackPanel` will arrange elements across the entire main panel, that is, across the entire created interface.
* `Set` is a method available in every style class in the library. Each style `Set` accepts values for **ALL** existing fields of the style class.
* Its `StyleLayoutContainer StyleLayout` styles:

  * `Orientation`: The main axis of the container. `Vertical` - horizontal.
  * `JustifyContent` (alignment of elements along the main axis) (main axis - horizontal): `stretch` - elements occupy all available space along the width.
  * `AlignItems` (alignment of elements along the cross axis) (cross axis - vertical): `stretch` - elements occupy all available space along the height.
* Its `StyleLayoutContainerStackPanel StyleLayoutStackPanel` styles:

  * `Spacing`: 5% of the size of the container's main axis (in this case: 5% of the width of `HStackPanel`).
  * `Reverse`: false - elements are arranged in the order in which they are added to `HStackPanel`.

Below, 4 sections `HPanel_N` are added to `HStackPanel`:

* `HStackPanel` first allocates space for `Spacing (5% * HStackPanel.Width * (HStackPanel.GetWithLayoutElementsCount() - 1))`
* It then calculates the available space and divides it between these sections.
* You can see the result of this yourself. In the image, these are the 4 vertical sections extending across the entire height of the container.

---

```csharp
UIExStackPanel VStackPanel1 = new(), VStackPanel2 = new(), VStackPanel3 = new(), VStackPanel4 = new();
SetPrecentSizeCenter(1f, 1f, VStackPanel1, VStackPanel2, VStackPanel3, VStackPanel4);
HPanel1.Append(VStackPanel1);
HPanel2.Append(VStackPanel2);
HPanel3.Append(VStackPanel3);
HPanel4.Append(VStackPanel4);
```

Each of the sections created earlier (`HPanel_N`) gets its own `UIExStackPanel (VStackPanel_N)`.<br>
`VStackPanel_N` will arrange the cubes inside each section.
Then each `VStackPanel_N` receives a size of 100% of its parent and is added to the corresponding `HPanel_N`<br>

Next, for each layout container inside each section `VStackPanel_1–4`, a layout style is assigned, and cubes (`UIPanel`) are added using the methods:

```csharp
public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
{
    int count = pixelSizes.Length;
    var panels = new UIElement[count];
    for (int i = 0; i < count; i++)
        panels[i] = AddCubs(element, pixelSizes[i], count: 1)[0];
    return panels;
}

public UIElement[] AddCubs(UIElement element, float pixelSize, int count = 1)
{
    var panels = new UIElement[count];
    for (int i = 0; i < count; i++)
    {
        panels[i] = new UIPanel();
        StyleLayoutChild style = panels[i].StyleLayoutChild();
        style.Width.Set(pixelSize, 0f);
        style.Height.Set(pixelSize, 0f);
        element.Append(panels[i]);
    }
    return panels;
}
```

These methods were also created specifically for this example and do not exist in the library itself.<br>

Note that the size inside the method is set using the `StyleLayoutChild` style.
This is because the size of child elements inside the layout container can only be set in this way:

```csharp
panels[i] = new UIPanel();
StyleLayoutChild style = panels[i].StyleLayoutChild();
style.Width.Set(pixelSize, 0f);
style.Height.Set(pixelSize, 0f);
element.Append(panels[i]);
```
