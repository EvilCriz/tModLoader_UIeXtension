<h1 align="center">Style Structure</h1>

<hr>

* This library assumes that you have already studied the [basic tModLoader guide to user interfaces](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
* This library assumes that you have already studied the [advanced guide to customizing user interfaces](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>

<hr>

Styles in this library are divided into 4 types:

1. Visual display styles.
2. Visual styles of elements from **tModLoader**
3. Container layout styles.
4. Individual element layout styles.

---

* **Visual display styles** — these are all styles responsible for the entire visual part, except for the element's positioning (color, shape, outline, etc.).

---

* **Visual styles of elements from tModLoader** - these are styles that allow you to specify the style parameters of the basic **tModLoader** elements.<br><br>

This point requires clarification.<br>
Any element in this library can accept a visual style from this library (see the previous point) or a style of a **tModLoader** element.<br>
For example: the `UIExElement` element can accept the `UIPanel` visual style.<br>
More details below.

---

* **Container layout styles** — these are all styles used only by layout containers (*UIExStackPanel*, *UIExDockPanel*, *UIExGrid*, etc.). They contain general rules for how to arrange elements inside themselves.

---

* **Individual element layout styles** — these are all styles used by a layout container with respect to an individual *UIElement*. This will be discussed in more detail in the section dedicated to element layout.

---

Individual style classes will not be covered in this article. Each such class is associated with its own `UIExElement` (`UIExLayout` for layout styles) and will be discussed together with these elements in the following sections.

---

<h2 align="center"><b>Visual Display Styles</b></h2>

**IMPORTANT!** The library is under development.<br>
This block about **visual display styles** provides information for understanding the overall style system.<br>
At the moment, the library only contains layout containers (described below) and `UIExElement`.<br><br>

`UIExElement` contains a field:

```csharp
public class UIExElement : UIElement
{
  public Styles.StyleVisualElement StyleDisplay;
}
```

Accordingly, this field is inherited by all elements in this library.<br>
Visual styles for **any** element will be specified through this field.

The `StyleVisualElement` class contains the styles of all `UIExElement` classes and methods that return the styles of any classes derived from `UIExElement`.<br>
For example, there are classes (provided as an example; under development):

```csharp
public class UIExButton : UIExElement {}
public class UIExTextBlock : UIExButton {}
```

<br>

In this case, the library will have corresponding style classes:

```csharp
public class StyleVisualButton {}
public class StyleVisualTextBlock {}
```

<br>

And the `StyleVisualElement` class will have the following methods:

```csharp
public class StyleVisualElement
{
    public StyleVisualButton Button() { /* ... */ }
    public StyleVisualTextBlock TextBlock() { /* ... */ }
}
```

<br>

Now we can obtain styles as follows:

```csharp
UIExElement element = new();
UIExButton button = new();
UIExTextBlock textBlock = new();

StyleVisualElement elementStyleDisplay = element.StyleDisplay;
StyleVisualElement buttonStyleDisplay = button.StyleDisplay;
StyleVisualElement textBlockStyleDisplay = textBlock.StyleDisplay;

StyleVisualButton buttonStyle = buttonStyleDisplay.Button();

StyleVisualTextBlock textBlockStyle = textBlockStyleDisplay.TextBlock();
```

<br>

---

<h2 align="center"><b>Visual Styles of Elements from tModLoader</b></h2>

Instead of using the **visual display styles** of this library, you can specify that an element should use the style of a specific **tModLoader** element (the element itself decides which one).<br>
To do this, set `tModLoaderStyle = true` in the `StyleDisplay` field.

```csharp
UIExElement element = new();
element.StyleDisplay.tModLoaderStyle = true;
```

Each element decides for itself which **tModLoader** element's style to use.<br>
`UIExElement` and any layout element will use the `UIPanel` style in this case.<br>

* This library is under development. As of today, there are no other elements.<br><br>

You can obtain the base style class and modify its values.<br>

```csharp
UIExElement element = new();

element.StyleDisplay.tModLoaderStyle = true;

StyleTmlUIPanel styleTmlUIPanel =  element.StyleDisplay.TmlUIPanel();
styleTmlUIPanel.BackgroundColor = Color.Red;
```

In this example, the created `UIExElement` will look like a `UIPanel`, but its outline will be red.<br>

Style class and method naming:

* The class name starts with `StyleTml`, followed by the name of the corresponding **tModLoader** element.
* The method name starts with `Tml`, followed by the name of the corresponding **tModLoader** element.

---

<h2 align="center">Container Layout Styles</h2>

The storage and retrieval of container layout styles are identical to **visual display styles**<br>
The `UIExLayout` class (which all containers inherit) contains a field:

```csharp
class UIExLayout : UIExElement
{
    public StyleLayoutContainer StyleLayout
}
```

<br>

The `StyleLayoutContainer` class, by analogy with `StyleVisualElement`, contains methods that return the layout styles of classes derived from the container:

```csharp
// used as an example. In reality, this UIExLayout is abstract.
UIExLayout layout = new();
UIExCanvas canvas = new();
UIExStackPanel stackPanel = new();

StyleLayoutContainer styleLayout = layout.StyleLayout;
StyleLayoutContainer styleLayoutCanvas = canvas.StyleLayout;
StyleLayoutContainer styleLayoutStackPanel = stackPanel.StyleLayout;

StyleLayoutContainerCanvas styleCanvas = styleLayoutCanvas.Canvas();
StyleLayoutContainerStackPanel styleStackPanel = styleLayoutCanvas.StackPanel();
```

---

<h2 align="center">Individual Element Layout Styles</h2>

The system here is very similar. However, unlike the previous examples, an individual element layout style can be owned by any `UIElement` in **tModLoader**.<br>
Therefore, these styles are obtained using the `UIElement.StyleLayoutChild()` extension method.

```csharp
UIElement element = new();
StyleLayoutChild styleLayout = element.StyleLayoutChild();
StyleLayoutChildCanvas styleLayoutCanvas = styleLayout.Canvas();
```

<br>

The relationship between the names of container and individual element layout styles:

* `UIExLayout` - `StyleLayoutContainer` - `StyleLayoutChild`
* `UIExCanvas` - `StyleLayoutContainerCanvas` - `StyleLayoutChildCanvas`
* `UIExStackPanel` - `StyleLayoutContainerStackPanel` - `StyleLayoutChildStackPanel`<br>

As you can see, the class names begin with `StyleLayout` — followed by `Container/Child` — followed by the name of the layout container (except for `UIExLayout`).

<h2 align="center">Additional Information</h2>

All style classes inherit from the `StyleBase` class.<br>
This class has only 1 public method.

```csharp
public bool EqualsStylesFields(StyleBase other) { /* ... */ }
```

This method checks whether all fields of all passed styles match.<br>
For example:

```csharp
StyleLayoutChildCanvas styleCanvas = new();
StyleLayoutContainer style1 = new();
StyleLayoutContainer style2 = new();


//////////////////

// [1]: the method will return false
style1.EqualsStylesFields(styleCanvas);


//////////////////

// [2]: the method will return true
style1.EqualsStylesFields(style2);


//////////////////

style1.JustifyContent = UIExAlignment.Center;

// [3]: the method will return false
style1.EqualsStylesFields(style2);


//////////////////

style2.JustifyContent = UIExAlignment.Center;

// [4]: the method will return true
style1.EqualsStylesFields(style2);


//////////////////

style1.UniformGrid();

// [5]: the method will return false
style1.EqualsStylesFields(style2);


//////////////////

style2.UniformGrid();

// [6]: the method will return true
style1.EqualsStylesFields(style2);


//////////////////

style2.UniformGrid().ColumnsCount = 5;

// [7]: the method will return false
style1.EqualsStylesFields(style2);
```

Results of `EqualsStylesFields` calls:

1. Two different style classes are compared. Returns `false`.
2. Two styles with default field values are compared. Returns `true`.
3. The `JustifyContent` value of `style1` has changed. The value of `style2` has not changed. The style fields differ. Returns `false`.
4. The `JustifyContent` value of `style2` has been changed to the same value as `style1`. The style fields do not differ. Returns `true`.
5. The `StyleLayoutContainerUniformGrid` style is registered for `style1`. It is not registered for `style2`. Returns `false`.
6. The `StyleLayoutContainerUniformGrid` style is registered for `style2`. This style was previously registered for `style1`. Returns `true`.
7. The `ColumnsCount` field value of the registered `StyleLayoutContainerUniformGrid` style of `style2` has changed. These fields do not match between the styles. Returns `false`.

---

All style classes contain 2 constructors:

1. Default.
2. Accepting all values for the fields of this style class (unspecified values use their default values).

---

All style classes contain public methods following the template below:

```csharp
/*

public void Set(
	type FIELD_1 = default(type), 
	type FIELD_2 = default(type), 
	..., 
	type FIELD_N = default(type))
		=> SetAllFields(
			FIELD_1, 
			FIELD_2, 
			..., 
			FIELD_N);



public void Copy(TYPE_STYLE style)
    => SetAllFields(
			style.FIELD_1, 
			style.FIELD_2, 
			..., 
			style.FIELD_N);

public TYPE_STYLE GetCopy()
    => GetCopyBase<TYPE_STYLE>();

*/
```

1. The `Set` method accepts all field values contained by this style (unspecified values use their default values).
2. The `Copy` method accepts the corresponding style and copies all fields from the passed style.
3. The `GetCopy` method returns a new style object with a copy of all class fields (including copies of registered styles).

---

1. **Visual display styles** inherit from the class: `StyleVisualElementBase`.
2. **Visual styles of elements from tModLoader** inherit from the class: `StyleTmlBase`.
3. **Container layout styles** inherit from the class: `StyleLayoutContainerBase`.
4. **Styles of nested elements** inherit from the class: `StyleLayoutChildBase`.<br>
