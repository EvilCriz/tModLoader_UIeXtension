`UIExWrapPanel` is a layout container that arranges child elements in a single row (or column) and automatically wraps them to a new row when they do not fit within the current area.<br>

This container is essentially an advanced version of `UIExStackPanel`.<br>
This article will repeat the previous one in a highly condensed form, assuming that you are already familiar with it.<br>

---

Elements are wrapped when the next element does not fit in the line. For example:<br>

* A container with a width of `300px` and horizontal orientation.
* Space between elements: `50px`.
* Elements with widths of `200px`, `50px`, and `100px` are added to the container sequentially.<br>

<!-- -->

As a result, we get the following sequence:

1. The element with a width of `200px` fits into the container.
2. `50px` occupies the space between elements `0` and `1`.
3. The element with a width of `50px` fits into the container. (total occupied width: `300px`).
4. There is no free space left in the line, so the next element will be placed below.<br>

The offset of the last element (along the cross axis) will be determined by the size of the previous line + the configured space between lines (described below).<br>

1. The size of the line along the main axis occupies the entire available size of the container along the main axis.
2. The size of the line along the cross axis is determined by the largest element in the line along the cross axis.
3. The size of the lines is determined **BEFORE** the element is stretched (`Enums.UIExAlignment.Stretch`).<br>

<!-- -->

Below you will learn that elements can be inverted.<br>
Element inversion occurs **BEFORE** calculating the lines and the layout containers of the elements within them.

---

After the lines have been formed, the elements in each line are sorted separately in the same way as in `UIExStackPanel.`<br>
However, a different style class is used in this case.

---

Base layout style for elements `StyleLayoutContainer`:

```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    public Enums.UIExOrientation Orientation = Enums.UIExOrientation.Vertical;
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
}
```

* `Orientation`: determines the main axis of the container along which the elements will be aligned (within the lines).
* `JustifyContent`: alignment of elements along the main axis (within already formed lines).
* `AlignItems`: alignment of elements along the cross axis (within already formed lines).

---

Alignment types:

```csharp
public enum UIExAlignment : byte
{
    Auto,
    Start,
    Center,
    End,
    Stretch
}
```

* `Auto`: analogous to `Start`. Used for elements nested in the container.
* `Start`: aligns elements to the start of the axis (top/left).
* `Center`: aligns elements to the center of the axis.
* `End`: aligns elements to the end of the axis (bottom/right).
* `Stretch`: stretches the element along the entire axis (excluding Margin).

---

Base styles for child elements `StyleLayoutChild`:

```csharp
public partial class StyleLayoutChild : Base.StyleLayoutChildBase
{
    public Enums.UIExAlignment JustifySelf = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignSelf = Enums.UIExAlignment.Auto;
    public UIExThickness Margin = new();
    public StyleDimension Width = default(StyleDimension);
    public StyleDimension Height = default(StyleDimension);
}
```

* The `JustifySelf` field overrides the `JustifyContent` value of the container for a specific nested element. For child elements, it ignores any values except `Stretch`.
* The `AlignSelf` field overrides the `AlignItems` value of the container for a specific nested element.
* The `Margin` field works fully.
* The `Width` and `Height` fields were discussed in detail in the first article of this section.

---

The `UIExWrapPanel` class uses the `StyleLayoutContainerWrapPanel` style class, which stores all layout styles for this class.

```csharp
public class StyleLayoutContainerWrapPanel : Base.StyleLayoutContainerBase
{
    public StyleDimension SpacingWithinLine = StyleDimension.Empty;
    public StyleDimension SpacingBetweenLines = StyleDimension.Empty;
	
    public Enums.UIExAlignment AlignLines = Enums.UIExAlignment.Auto;
	
    public bool ReverseWithinLine = false;
    public bool ReverseAll = false;
}
```

* `SpacingWithinLine`: determines the spacing between elements within lines (works similarly to the `Spacing` of the `UIExStackPanel` container).
* `SpacingBetweenLines`: determines the spacing between lines.
* `AlignLines`: determines the alignment of all lines along the cross axis.
* `ReverseWithinLine`: if this value is `true` - elements within each line will be arranged in reverse order.
* `ReverseAll`: if this value is `true` - all elements will be arranged in reverse order (and will be reversed before layout begins).<br>

<!-- -->

* `ReverseWithinLine` and `ReverseAll` can reverse elements simultaneously. In this case, `ReverseAll` will be applied before layout, and the elements within the lines will then be reversed separately.

---

**DOES NOT IMPLEMENT** its own style class for child elements.

---

The base layout styles of the container are contained in the `StyleLayout` field.
To get the layout styles of `UIExWrapPanel`, use the `WrapPanel()` method of the `StyleLayout` field.
To get the base styles for elements nested in the container, use the `UIElement` extension method: `StyleLayoutChild()`.

```csharp
UIExWrapPanel wrapPanel = new();

StyleLayoutContainer style = wrapPanel.StyleLayout;
StyleLayoutContainerWrapPanel styleWrapPanel = stackPanel.StyleLayout.WrapPanel(); // or style.WrapPanel();

UIElement element = new();
StyleLayoutChild styleChild = element.StyleLayoutChild();

style.JustifyContent = UIExAlignment.Center;
styleWrapPanel.ReverseAll = true;

styleChild.JustifySelf = UIExAlignment.Stretch;
```

<summary>Example of how <code>ReverseWithinLine</code> and <code>ReverseAll</code> work:</summary>

```csharp
using Microsoft.Xna.Framework;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // the OnActivate() method in this case is used only
    // for the «hot code reload» functionality in the development environment.
    // for a real interface, it would be more appropriate to use
    // the OnInitialize() method
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 450f, panel);

        UIExWrapPanel wrapPanel = new();
        wrapPanel.Stretch();

        wrapPanel.SetLayoutLinesInfoForBranch(
            state: true,
            thickness: 3f,
            color: Color.DarkOrange);

        ////////////////////////////

        StyleLayoutContainer styleLayout = wrapPanel.StyleLayout;
        StyleLayoutContainerWrapPanel styleLayoutWrap = styleLayout.WrapPanel();

        styleLayout.Set(
            orientation: UIExOrientation.Horizontal,
            justifyContent: UIExAlignment.Center,
            alignItems: UIExAlignment.Center);

        styleLayoutWrap.Set(
            spacingWithinLine: StyleDimension.FromPixels(10f),
            spacingBetweenLines: StyleDimension.FromPixels(15f),
            alignLines: UIExAlignment.Center,
			// 4 combinations of these two values are shown in the images
            reverseWithinLine: true,
            reverseAll: true); //

        ///////////////////////////

        AddPixelButton(wrapPanel, prefix: 0, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 1, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 2, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 3, width: 200f, height: 200f);

        ///////////////////////////

        panel.Append(wrapPanel);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AddPixelButton(UIExLayout layout, int prefix, float width, float height)
        => AddPixelButton(layout, prefix.ToString(), width, height);
    public UIButton<string> AddPixelButton(UIExLayout layout, string prefix, float width, float height)
    {
        UIButton<string> button = new($"{prefix}");
        StyleLayoutChild style = button.StyleLayoutChild();
        style.Width.Pixels = width;
        style.Height.Pixels = height;
        layout.Append(button);
        return button;
    }
}
```

<summary>Example of creating a calculator layout using <code>UIExWrapPanel</code> (without comments, explanation below)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // the OnActivate() method in this case is used only
    // for the «hot code reload» functionality in the development environment.
    // for a real interface, it would be more appropriate to use
    // the OnInitialize() method
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 650f, panel);

        UIExWrapPanel wrapPanel = new();
        wrapPanel.Stretch();

        ////////////////////////////

        StyleLayoutContainer styleLayout = wrapPanel.StyleLayout;
        StyleLayoutContainerWrapPanel styleLayoutWrap = styleLayout.WrapPanel();

        styleLayout.Set(
            orientation:    UIExOrientation.Horizontal,
            justifyContent: UIExAlignment.Center,
            alignItems:     UIExAlignment.Center);

        styleLayoutWrap.Set(
            spacingWithinLine:      StyleDimension.FromPixels(10f),
            spacingBetweenLines:    StyleDimension.FromPixels(5f),
            alignLines:             UIExAlignment.Center,
            reverseWithinLine:      false,
            reverseAll:             false);

        ///////////////////////////

        AppendButton(wrapPanel, prefix: "RESULT:");

        AppendButton(wrapPanel, prefix: "AC");
        AppendButton(wrapPanel, prefix: "%");
        AppendButton(wrapPanel, prefix: "<<");
        AppendButton(wrapPanel, prefix: "/");

        AppendButton(wrapPanel, prefix: 7);
        AppendButton(wrapPanel, prefix: 8);
        AppendButton(wrapPanel, prefix: 9);
        AppendButton(wrapPanel, prefix: "*");

        AppendButton(wrapPanel, prefix: 4);
        AppendButton(wrapPanel, prefix: 5);
        AppendButton(wrapPanel, prefix: 6);
        AppendButton(wrapPanel, prefix: "-");

        AppendButton(wrapPanel, prefix: 1);
        AppendButton(wrapPanel, prefix: 2);
        AppendButton(wrapPanel, prefix: 3);
        AppendButton(wrapPanel, prefix: "+");

        AppendButton(wrapPanel, prefix: 0);
        AppendButton(wrapPanel, prefix: ",");
        AppendButton(wrapPanel, prefix: "=");

        int count = 0;
        foreach (var child in wrapPanel.Children)
            count++;

        UIButton<string>[] buttons = new UIButton<string>[count];
        count = 0;
        foreach (var child in wrapPanel.Children)
            buttons[count++] = (UIButton<string>)child;

        for (int i = 0; i < count; i++)
        {
            StyleLayoutChild style = buttons[i].StyleLayoutChild();
            if (i == 0)
            {
                style.Width.Precent = 1f;
                style.Height.Precent = 2f / 7.5f;
            }
            else
            {
                style.Width.Precent = 1 / 4.5f;
                style.Height.Precent = 1 / 7.5f;
            }

            if (i == count - 1)
                style.Width.Precent *= 2f;
        }

        ///////////////////////////

        panel.Append(wrapPanel);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AppendButton(UIExLayout layout, int prefix)
        => AppendButton(layout, prefix.ToString());
    public UIButton<string> AppendButton(UIExLayout layout, string prefix)
    {
        UIButton<string> button = new(prefix);
        layout.Append(button);
        return button;
    }
}
```

This section will **not** cover in detail the creation of the container element or obtaining and setting styles.<br>
Everything works similarly to `UIExStackPanel`.

```csharp
styleLayout.Set(
    orientation:    UIExOrientation.Horizontal,
    justifyContent: UIExAlignment.Center,
    alignItems:     UIExAlignment.Center);

styleLayoutWrap.Set(
    spacingWithinLine:      StyleDimension.FromPixels(10f),
    spacingBetweenLines:    StyleDimension.FromPixels(5f),
    alignLines:             UIExAlignment.Center,
    reverseWithinLine:      false,
    reverseAll:             false);
```

The layout styles will be:

* Vertical arrangement of elements.
* Centering of elements along all axes within the lines.
* Spacing between elements within lines: `10px`.
* Spacing between lines: `15px`.
* The lines will be centered.
* All elements will be arranged in the order in which they are added to the container.<br>

Adding elements.

* Elements start from the top-left (in this case, this is simply the left element with the `RESULT` label).
* All subsequent elements are placed to the left of the previous one and wrapped to the next row when necessary.
* The initial `Top`, `Left` offsets of the elements do not matter and are ignored by the layout container.

---

```csharp
int count = 0;
foreach (var child in wrapPanel.Children)
    count++;

UIButton<string>[] buttons = new UIButton<string>[count];
count = 0;
foreach (var child in wrapPanel.Children)
    buttons[count++] = (UIButton<string>)child;
```

This part of the code counts the number of created elements and stores them in an array.

---

```csharp
for (int i = 0; i < count; i++)
{
    StyleLayoutChild style = buttons[i].StyleLayoutChild();
    if (i == 0)
    {
        style.Width.Precent = 1f;
        style.Height.Precent = 2f / 7.5f;
    }
    else
    {
        style.Width.Precent = 1 / 4.5f;
        style.Height.Precent = 1 / 7.5f;
    }

    if (i == count - 1)
        style.Width.Precent *= 2f;
}
```

Before we begin analyzing this part of the code, we need to clarify:

* The layout contains 6 lines, each of which contains 4 elements (except for 2 of them).
* The element with the `RESULT` label (the first one added) will occupy the size of 2 lines and the entire width of the line.
* The element with the `=` label (the last one added) will occupy `2` times more width than the other elements (except for the 1st).
* All other elements will occupy a height of 1/7 of the container and a width of 1/4 of the line.<br>

All elements except the first and last receive their size in the `else` block.<br>
However, although I previously wrote that the elements should occupy 1/7 and 1/4 of the container size, in this code it can be seen that the elements occupy 1/7.5 and 1/4.5.<br>
This is because of the following:

* If it is assumed that there are 4 elements in a row, each should occupy 1/4 of its width.
* But in addition to the elements themselves, we also have spacing between the elements defined as `10px`.
* Therefore, I reduced the size of the elements themselves to prevent them from being wrapped to a new row.<br>

The situation with height is similar:

* We have 6 rows, one of which is twice as large as the others. That is, the elements should divide the available height by 1/7 (the first one: by 2/7).
* Such a value would mean that the rows would occupy 100% of the height of the container's inner area.
* But the code defines a line spacing of `15px`. This means that, in total, our buttons would occupy a height of: 100% + 15px * 5.
* Therefore, the lines also receive 1/7.5 of the height so that they do not go beyond the boundaries of the main panel.<br>

---

```csharp
if (i == 0)
{
    style.Width.Precent = 1f;
    style.Height.Precent = 2f / 7.5f;
}
```

A separate size is specified for the first element (`RESULT`):

* The element has a width equal to 100% of the container's width (which means that all subsequent elements will automatically be wrapped to the next line).
* The element has a height of 2/7.5 of a line (and since all other elements have a value of 1/7.5, this means that this line will occupy twice as much height as the others).<br>

---

```csharp
else
{
    style.Width.Precent = 1 / 4.5f;
    style.Height.Precent = 1 / 7.5f;
}

if (i == count - 1)
    style.Width.Precent *= 2f;
```

After the last element receives:

* A width of 1/4.5 of the container's width.
* A height of 1/7.5 of the container's height.<br>

Its width is additionally increased by 2 times.<br>
This makes it 2 times wider than all other elements (except for the 1st).

---

To summarize:

1. The element with index 0 occupied the size of 2 lines and the entire width.
2. There is no space left in the first line. All subsequent elements will be wrapped to the next line.
3. Then the next 4 elements (indices: 1-4) are added with sizes of 1/4.5 and 1/7.5.
4. There is no space left in the second line. All subsequent elements will be wrapped to the next line.
5. Then the next 4 elements (indices: 5-8) are added with sizes of 1/4.5 and 1/7.5.
6. There is no space left in the third line. All subsequent elements will be wrapped to the next line.
7. Then the next 4 elements (indices: 9-12) are added with sizes of 1/4.5 and 1/7.5.
8. There is no space left in the fourth line. All subsequent elements will be wrapped to the next line.
9. Then the next 4 elements (indices: 13-16) are added with sizes of 1/4.5 and 1/7.5.
10. There is no space left in the fifth line. All subsequent elements will be wrapped to the next line.
11. Then the next 2 elements (indices: 17-18) are added with sizes of 1/4.5 and 1/7.5. There is **still** space left in the line.
12. Then the next element (index: 19) is added with a size of 2/4.5 and 1/7.5.
13. There is no space left in the line. But no wrapping occurs because this was the last element.
