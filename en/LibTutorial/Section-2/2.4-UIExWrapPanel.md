----

`UIExWrapPanel` It is a layout container that places child elements in a single line (or column) and automatically transfers them to a new line if they do not fit in the current area.<br>

This container is actually a complicated version. `UIExStackPanel`.<br>
This article will repeat the previous one in a very abbreviated form, and assume that you are already familiar with it.<br>

----

Element transfer occurs when the next item is not placed in a row.<br>
- Container wide `300px` and horizontal orientation.
- The space between elements: `50px`.
- In the container sequentially nested elements width: `200px`, `50px`, `100px`.<br>
<!-- -->
As a result, we get the following chain:
1. Element wide `200px` I put myself in a container.
2. `50px` space between the elements `0` and `1`.
3. Element wide `50px` placed in the container. (total, occupied width: `300px`).
4. The line has run out of free space, the next element will be located below.<br>

The displacement of the last element (on the transverse axis) will be determined by the size of the previous row + the established space between the rows (more on this below).<br>

1. The line size on the main axis occupies the entire available container size on the main axis.
2. The transverse axis line size is determined by the size of the largest transverse axis line element.
3. The size of the lines is determined **DOO** how the element will be stretched (`Enums.UIExAlignment.Stretch`).<br>
<!-- -->
Below you will learn that elements can be inverted.<br>
Elements inversion occurs **DOO** Calculation of lines and the linkers of the element within them.

----

After the lines are formed, each of them individually the elements are sorted in the same way. `UIExStackPanel.`<br>
But in this case, a different class of styles is used.

----

Basic style of arrangement of elements `StyleLayoutContainer`:
```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    public Enums.UIExOrientation Orientation = Enums.UIExOrientation.Vertical;
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
}
```
- `Orientation`: determines the main axis of the container along which the elements will be aligned (within the lines).
- `JustifyContent`: alignment of elements along the main axis (within already formed lines).
- `AlignItems`: alignment of elements along the transverse axis (within already formed lines).

----

Levelling types:

```csharp
public enum UIExAlignment : byte
{
    Auto,
    Start,
    Center,
    End,
    Stretch
}
```
- `Auto`similarly `Start`It's used for elements embedded in the container.
- `Start`: alignment of elements at the start of the axis (top/left).
- `Center`: alignment of the elements in the center of the axis.
- `End`: alignment of elements at the end of the axis (bottom/right).
- `Stretch`Stretching the element along the entire axis (minus Margin).

----

Basic styles of child elements `StyleLayoutChild`:
```csharp
public partial class StyleLayoutChild : Base.StyleLayoutChildBase
{
    public Enums.UIExAlignment JustifySelf = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignSelf = Enums.UIExAlignment.Auto;
    public UIExThickness Margin = new();
    public StyleDimension Width = default(StyleDimension);
    public StyleDimension Height = default(StyleDimension);
}
```
- Field. `JustifySelf` redefine `JustifyContent` It ignores any value other than the value of a container for a particular nested element. `Stretch`.
- Field. `AlignSelf` redefine `AlignItems` Container for a particular nested item.
- Field. `Margin` It's working perfectly.
- Fields `Width` and `Height` This article is described in detail in the first article of this section.

----

For the class. `UIExWrapPanel` Style class used: `StyleLayoutContainerWrapPanel`It stores all the layout styles for this class.
```csharp
public class StyleLayoutContainerWrapPanel : Base.StyleLayoutContainerBase
{
    public StyleDimension SpacingWithinLine = StyleDimension.Empty;
    public StyleDimension SpacingBetweenLines = StyleDimension.Empty;
	
    public Enums.UIExAlignment AlignLines = Enums.UIExAlignment.Auto;
	
    public bool ReverseWithinLine = false;
    public bool ReverseAll = false;
}
```

- `SpacingWithinLine`: determines the indentation between the elements within the lines (works similarly) `Spacing` container `UIExStackPanel`).
- `SpacingBetweenLines`: determines the indentation between the lines.
- `AlignLines`: determines the alignment of all lines along the transverse axis.
- `ReverseWithinLine`: if this value `true` The elements inside each line will be arranged in reverse order.
- `ReverseAll`: if this value `true` All elements will be arranged in reverse order (and will be reversed before the start of the layout).<br>
<!-- -->
- `ReverseWithinLine` and `ReverseAll` They can be reversed at the same time, and in that case, the layout will work. `ReverseAll`And inside the lines, the elements will be reversed separately.

----

**It doesn't work.** Style class for child elements.

----

Basic container layout styles are contained in the field `StyleLayout`.
For obtaining layout styles `UIExWrapPanel` use the method `WrapPanel()` field StyleLayout.
To obtain basic styles for embedded elements in the container, use the expansion method.`UIElement`: `StyleLayoutChild()`.
```csharp
UIExWrapPanel wrapPanel = new();

StyleLayoutContainer style = wrapPanel.StyleLayout;
StyleLayoutContainerWrapPanel styleWrapPanel = stackPanel.StyleLayout.WrapPanel(); // or style.WrapPanel();

UIElement element = new();
StyleLayoutChild styleChild = element.StyleLayoutChild();

style.JustifyContent = UIExAlignment.Center;
styleWrapPanel.ReverseAll = true;

styleChild.JustifySelf = UIExAlignment.Stretch;
```

<summary>Example of work <code>ReverseWithinLine</code> and <code>ReverseAll</code>:</summary>

```csharp
using Microsoft.Xna.Framework;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // method OnActivate(a) in this case, only
    // for the “hot code reboot” function in the development environment.
    // It would be better to use the real interface.
    // method OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 450f, panel);

        UIExWrapPanel wrapPanel = new();
        wrapPanel.Stretch();

        wrapPanel.SetLayoutLinesInfoForBranch(
            state: true,
            thickness: 3f,
            color: Color.DarkOrange);

        ////////////////////////////

        StyleLayoutContainer styleLayout = wrapPanel.StyleLayout;
        StyleLayoutContainerWrapPanel styleLayoutWrap = styleLayout.WrapPanel();

        styleLayout.Set(
            orientation: UIExOrientation.Horizontal,
            justifyContent: UIExAlignment.Center,
            alignItems: UIExAlignment.Center);

        styleLayoutWrap.Set(
            spacingWithinLine: StyleDimension.FromPixels(10f),
            spacingBetweenLines: StyleDimension.FromPixels(15f),
            alignLines: UIExAlignment.Center,
			// 4 variants of the combination of these two values
            reverseWithinLine: true,
            reverseAll: true); //

        ///////////////////////////

        AddPixelButton(wrapPanel, prefix: 0, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 1, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 2, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 3, width: 200f, height: 200f);

        ///////////////////////////

        panel.Append(wrapPanel);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AddPixelButton(UIExLayout layout, int prefix, float width, float height)
        => AddPixelButton(layout, prefix.ToString(), width, height);
    public UIButton<string> AddPixelButton(UIExLayout layout, string prefix, float width, float height)
    {
        UIButton<string> button = new($"{prefix}");
        StyleLayoutChild style = button.StyleLayoutChild();
        style.Width.Pixels = width;
        style.Height.Pixels = height;
        layout.Append(button);
        return button;
    }
}
```

<summary>An example of creating a calculator layout using <code>UIExWrapPanel</code> (without comment, analysis below)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // method OnActivate(a) in this case, only
    // for the “hot code reboot” function in the development environment.
    // It would be better to use the real interface.
    // method OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 650f, panel);

        UIExWrapPanel wrapPanel = new();
        wrapPanel.Stretch();

        ////////////////////////////

        StyleLayoutContainer styleLayout = wrapPanel.StyleLayout;
        StyleLayoutContainerWrapPanel styleLayoutWrap = styleLayout.WrapPanel();

        styleLayout.Set(
            orientation:    UIExOrientation.Horizontal,
            justifyContent: UIExAlignment.Center,
            alignItems:     UIExAlignment.Center);

        styleLayoutWrap.Set(
            spacingWithinLine:      StyleDimension.FromPixels(10f),
            spacingBetweenLines:    StyleDimension.FromPixels(5f),
            alignLines:             UIExAlignment.Center,
            reverseWithinLine:      false,
            reverseAll:             false);

        ///////////////////////////

        AppendButton(wrapPanel, prefix: "RESULT:");

        AppendButton(wrapPanel, prefix: "AC");
        AppendButton(wrapPanel, prefix: "%");
        AppendButton(wrapPanel, prefix: "<<");
        AppendButton(wrapPanel, prefix: "/");

        AppendButton(wrapPanel, prefix: 7);
        AppendButton(wrapPanel, prefix: 8);
        AppendButton(wrapPanel, prefix: 9);
        AppendButton(wrapPanel, prefix: "*");

        AppendButton(wrapPanel, prefix: 4);
        AppendButton(wrapPanel, prefix: 5);
        AppendButton(wrapPanel, prefix: 6);
        AppendButton(wrapPanel, prefix: "-");

        AppendButton(wrapPanel, prefix: 1);
        AppendButton(wrapPanel, prefix: 2);
        AppendButton(wrapPanel, prefix: 3);
        AppendButton(wrapPanel, prefix: "+");

        AppendButton(wrapPanel, prefix: 0);
        AppendButton(wrapPanel, prefix: ",");
        AppendButton(wrapPanel, prefix: "=");

        int count = 0;
        foreach (var child in wrapPanel.Children)
            count++;

        UIButton<string>[] buttons = new UIButton<string>[count];
        count = 0;
        foreach (var child in wrapPanel.Children)
            buttons[count++] = (UIButton<string>)child;

        for (int i = 0; i < count; i++)
        {
            StyleLayoutChild style = buttons[i].StyleLayoutChild();
            if (i == 0)
            {
                style.Width.Precent = 1f;
                style.Height.Precent = 2f / 7.5f;
            }
            else
            {
                style.Width.Precent = 1 / 4.5f;
                style.Height.Precent = 1 / 7.5f;
            }

            if (i == count - 1)
                style.Width.Precent *= 2f;
        }

        ///////////////////////////

        panel.Append(wrapPanel);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AppendButton(UIExLayout layout, int prefix)
        => AppendButton(layout, prefix.ToString());
    public UIButton<string> AppendButton(UIExLayout layout, string prefix)
    {
        UIButton<string> button = new(prefix);
        layout.Append(button);
        return button;
    }
}
```

The layout styles will be:
- Vertical arrangement of the elements.
- Centering elements along all axes within lines.
- The gap between the elements within the lines: `10px`.
- Detachment between lines: `15px`.
- The lines will be centered.
- All items will be arranged in the order in which they are added to the container.<br>

Adding elements.
- Elements begin with the top-left (in this case, it is just a left-handed element with the inscription). `RESULT`).
- All the following elements are located to the left of the previous one and transferred to the next line if necessary.
- Initial displacement of elements by `Top`, `Left` It does not matter and is ignored by the builder.

```csharp
for (int i = 0; i < count; i++)
{
    StyleLayoutChild style = buttons[i].StyleLayoutChild();

    {

```

Before we begin to understand this part of the code, it is necessary to clarify:
- The layout contains 6 lines in each of which (except 2) 4 elements.
- Element with an inscription `RESULT` (is the first added) will occupy the size of 2 lines and the entire width of the line.
- Element with an inscription `=` (This is the last one added) will be in `2` It is twice as wide as other elements (except 1st).
- All other elements will have a height of 1/7 of the container and a width of 1/4 of the line.<br>

All items except the first and last are sized in a block. `else`.<br>
But while I wrote earlier that elements should be 1/7 and 1/4 container sizes, this code shows that the elements are 1/7.5 and 1/4.5.<br>
The whole point is this:
- If it is assumed that the line 4 element, each should occupy 1/4 of its width.
- But apart from the elements themselves, we also have an indentation between the elements in the `10px`.
- So I've reduced the size of the elements themselves to avoid moving them to a new line.<br>

The situation is similar with altitude:
- We have 6 lines, and one of them is 2 times larger than the others, so the elements have to divide the free height by 1/7 (first: 2/7).
- Such a value would mean that the strings would occupy 100% of the height of the inner region of the container.
- But the code defines the interline interval in `15px`This means that the totality of our buttons will take the height: 100% + 15px * 5.
- Therefore, the lines also get 1/7.5 height, so as not to go beyond the boundaries of the main panel.<br>

To summarize:
1. Element with index 0 took the size: 2 lines and the entire width.
2. The place on the first line is over. All the following elements will be moved to the next.
3. Then the following 4 elements are added (index: 1-4) with dimensions 1/4.5 and 1/7.5.
4. The place in the second line is over. All the following elements will be moved to the next.
5. Then the following 4 elements are added (index: 5-8) with dimensions 1/4.5 and 1/7.5.
6. The place in the third line is over. All the following elements will be moved to the next one.
7. Then the following 4 elements are added (index: 9-12) with dimensions 1/4.5 and 1/7.5.
8. The place in line four is over. All the following elements will be moved to the next one.
9. Then the following 4 elements are added (index: 13-16) with dimensions 1/4.5 and 1/7.5.
10. The place in line five is over. All the following elements will be moved to the next.
11. Then add the following 2 elements (index: 17-18) with dimensions 1/4.5 and 1/7.5. **NOT.** It's over.
12. The following elements are then added (index: 19) with dimensions of 2/4.5 and 1/7.5.
13. The place in the line is over, but there's no transfer, because that was the last element.
