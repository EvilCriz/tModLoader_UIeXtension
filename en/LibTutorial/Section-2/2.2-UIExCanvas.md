`UIExCanvas` is a layout container that positions its contents at specified positions (and more).

---

<h2 align="center"><code>UIExCanvas</code> Styles</h2>

`UIExCanvas` fully uses all `StyleLayoutContainer` styles.

* `Orientation`: determines the main axis of the container. This value plays a role when using `JustifyContent`, `JustifySelf`, `AlignItems`, and `AlignSelf`.
* `JustifyContent` and `AlignContent` determine the initial alignment along the main / cross axis for all child elements in the container. These two properties play an important role when working with `UIExCanvas`. More details will be provided below.

It also uses `StyleLayoutChild` for child elements:

* `JustifySelf` and `AlignSelf` override the `JustifyContent` and `AlignContent` values of the container for each individual element.
* `Margin` works as usual.

---

For `UIExCanvas`, there is a style class called `StyleLayoutContainerCanvas`:

```csharp
public class StyleLayoutContainerCanvas : Base.StyleLayoutContainerBase
{
    public bool AllowOverflow = false;
}
```

* `AllowOverflow` determines whether elements can go outside the container boundaries.
* If the value is `false`, the container will first move the element, and if that is not sufficient, shrink the size of the child element.
* Each child element can override this value individually.<br>

You can obtain this style class by calling the `Canvas()` method on the `StyeLayout` field:

```csharp
UIExCanvas canvas = new();
StyleLayoutContainer style = canvas.StyleLayout;
StyleLayoutContainerCanvas styleCanvas = style.Canvas();
bool allowOverflow = styleCanvas.AllowOverflow;
```

---

All elements nested inside `UIExCanvas` can use the `StyleLayoutChildCanvas` style.<br>
To use this style, you need to obtain the `StyleLayoutChild` style using the `UIElement` extension method: `StyleLayoutChild()`.<br>
Then call the `Canvas()` method on the obtained style.

```csharp
UIElement element = new();
StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildCanvas styleCanvas = style.Canvas();
```

<br>

The `StyleLayoutChildCanvas` class itself has the following implementation:

```csharp
public class StyleLayoutChildCanvas : Base.StyleLayoutChildBase
{
    public StyleDimension Left = default(StyleDimension);
    public StyleDimension Top = default(StyleDimension);
    public StyleDimension Right = default(StyleDimension);
    public StyleDimension Bottom = default(StyleDimension);

    public bool? AllowOverflowSelf = null;
}
```

As you can see, this class implements only two things:

1. Adds an offset relative to the selected coordinate.
2. Adds `AllowOverflowSelf`. If this value is not `null`, it overrides the `AllowOverflow` value of the `UIExCanvas` container for this specific element.<br>

Although this layout container may look fairly standard, important nuances appear when we touch `JustifyContent`, `JustifySelf`, `AlignItems`, and `AlignSelf`.<br>
It would be better to demonstrate this with an example right away. Let us imagine 4 different situations:<br>

1. We have an element that does **NOT** use this library. Its `HAlign` and `VAlign` values are `0.5f`. In this case, the element will be positioned in the center.
2. We have an element nested inside `UIExCanvas` with `JustifySelf` and `AlignSelf` set to `UIExAlignment.Start`, and `StyleLayoutCanvas.Left.Precent = 0.5f`, `StyleLayoutCanvas.Top.Precent = 0.5f`. In this case, the result will be analogous to point 1.
3. We have an element nested inside `UIExCanvas` with `JustifySelf` and `AlignSelf` set to `UIExAlignment.Center`, and `StyleLayoutCanvas.Left.Set(0f, 0f)`, `StyleLayoutCanvas.Top.Set(0f, 0f)`. In this case, the result will be analogous to points 1 and 2.
4. We have an element nested inside `UIExCanvas` with `JustifySelf` and `AlignSelf` set to `UIExAlignment.Center`, and `StyleLayoutCanvas.Left.Precent = 0.5f`, `StyleLayoutCanvas.Top.Precent = 0.5f`. In this case, the element will **NOT** be positioned in the center. It will be located exactly at 0.75% of the container's height and width.<br><br>

Why did the result in point 4 turn out this way?<br>
The reason is that `Justify` and `Align` do not simply align the element. They shift the starting point of the coordinate system.<br>
In this case:

1. The element is centered.
2. The starting point of the coordinate system is centered.
3. `StyleLayoutCanvas.Left.Precent = 0.5f` shifts the element by 50% of the distance from its coordinate reference point to the right edge of the container. This is 0.75% of the container width.
4. The same applies to `StyleLayoutCanvas.Top.Precent = 0.5f`<br>

If this is difficult to understand right now, it will become much simpler and clearer when we examine the code example below.<br><br>

Unlike the standard **tModLoader** tools for positioning elements using `Left` and `Top` coordinates, this library provides 4 coordinates.

1. `Top`: offsets the element relative to the top of the container. If the value is 10px, the element will be positioned 10px below the top of the container.
2. `Left`: offsets the element relative to the left side of the container.
3. `Bottom`: offsets the element relative to the bottom of the container.
4. `Right`: offsets the element relative to the right side of the container.

* `Top` and `Bottom` subtract from each other. This means that if `Top.Set(10f, 0f)` and `Bottom.Set(10f, 0f)`, the element's offset will be 0.
* The same applies to `Left` and `Right`.

<h2 align="center">Example of Using <code>UIExCanvas</code></h2>

<details>
<summary>Example of creating a user interface (without comments, explanation below)</summary>

```csharp
using Terraria.UI;

namespace UIeXtenstion;

/// <summary>
///     Allows absolute positioning according to the specified parameters.
/// </summary>
using Microsoft.Xna.Framework;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // The OnActivate() method is used here only
    // for the "hot code reload" feature in the development environment.
    // For a real interface, it would be more appropriate to use
    // the OnInitialize() method.
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.8f, 0.8f, panel);

        UIExCanvas canvas = new UIExCanvas();
        canvas.Stretch();
        canvas.ShowLayoutLines = true;
        canvas.LayoutLinesThickness = 3f;
        canvas.LayoutLinesColor = Color.DarkOrange;

        canvas.StyleLayout.Set(
            orientation: UIExOrientation.Horizontal,
            justifyContent: UIExAlignment.Center);

        panel.Append(canvas);
        Append(panel);

        UIElement[] cubs = AddCubs(canvas, 50, 16);
        StyleLayoutChildCanvas[] stylesCanvas = new StyleLayoutChildCanvas[cubs.Length];
        StyleLayoutChild[] styles = new StyleLayoutChild[cubs.Length];

        for (int i = 0; i < cubs.Length; i++)
        {
            styles[i] = cubs[i].StyleLayoutChild();
            stylesCanvas[i] = styles[i].Canvas();
        }


        ////

        styles[0].Set(
            justifySelf: UIExAlignment.Start,
            alignSelf: UIExAlignment.Start);

        // styles[1]: justifySelf == Auto == JustifyContent(canvas) == Center
        // styles[1]: alignSelf == Auto == AlignContent(canvas) == Auto == Start

        // styles[2]: alignSelf == Auto == AlignContent(canvas) == Auto == Start
        styles[2].Set(
            justifySelf: UIExAlignment.End);

        styles[3].Set(
            justifySelf: UIExAlignment.Start,
            alignSelf: UIExAlignment.Center);

        // styles[4]: justifySelf == Auto == JustifyContent(canvas) == Center
        styles[4].Set(
            alignSelf: UIExAlignment.Center);

        styles[5].Set(
            justifySelf: UIExAlignment.End,
            alignSelf: UIExAlignment.Center);

        styles[6].Set(
            justifySelf: UIExAlignment.Stretch,
            alignSelf: UIExAlignment.End,
            margin: new UIExThickness(
                                pixels: true,
                                right: 25f,
                                bottom: 50f,
                                left: 75f,
                                top: 100f));

        ////////////////
        ////////////////
        ////////////////

        CopyStyle4(indexStart: 7, indexEnd: 15);

        stylesCanvas[7].Top.Pixels = 50f;
        stylesCanvas[8].Bottom.Pixels = 50f;
        stylesCanvas[9].Left.Pixels = 50f;
        stylesCanvas[10].Right.Pixels = 50f;

        stylesCanvas[11].Bottom.Pixels = 50f;
        stylesCanvas[11].Right.Pixels = 50f;

        styles[12].Margin = new UIExThickness(
            pixels: true,
            bottom: 50f,
            right: 100f);
        stylesCanvas[12].Left.Precent = -0.5f;

        stylesCanvas[13].Left.Pixels = 100000f;
        stylesCanvas[13].Top.Pixels = 50f;

        stylesCanvas[14].Left.Precent = 0.5f;

        stylesCanvas[15].Left.Precent = 1.1f;
        stylesCanvas[15].AllowOverflowSelf = true;

        void CopyStyle4(int indexStart, int indexEnd)
        {
            for (int i = indexStart; i <= indexEnd; i++)
                styles[i].Copy(styles[4]);
        }
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
    {
        int count = pixelSizes.Length;
        var buttons = new UIElement[count];
        for (int i = 0; i < count; i++)
            buttons[i] = AddCubs(element, pixelSizes[i], count: 1)[0];
        return buttons;
    }

    public UIElement[] AddCubs(UIElement element, float pixelSize, int count = 1)
    {
        var buttons = new UIElement[count];
        for (int i = 0; i < count; i++)
        {
            buttons[i] = new UIButton<string>(i.ToString());
            StyleLayoutChild style = buttons[i].StyleLayoutChild();
            style.Width.Set(pixelSize, 0f);
            style.Height.Set(pixelSize, 0f);
            element.Append(buttons[i]);
        }
        return buttons;
    }
}
```

A brief note about visual styles. This is the topic of the next section, but there is one important point for layout containers, so this footnote will appear in every article.<br>
As you can see, the system in this code is as follows: main panel -> container -> cube panels.<br>
A separate container is created for the main panel.<br>
This is unnecessary if the result is exactly what we want to see in the image.<br>
`UIExElement` (from which `UIExLayout` inherits) has a style property: `StyleDisplay.tModLoaderStyle (bool)`.<br>
If this value is true, the visual element will use the corresponding **tModLoader** style.<br>
For `UIExElement`, setting it to `true` will result in a style analogous to `UIPanel`.<br>
Therefore, our code could be shortened.<br><br>

This part:

```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);

UIExCanvas canvas = new UIExCanvas();

/*
...
*/

panel.Append(canvas);
Append(panel);
```

can be replaced with:

```csharp
UIExCanvas canvas = new UIExCanvas();
canvas.StyleDisplay.tModLoaderStyle = true;
SetPrecentSizeCenter(0.8f, 0.8f, panel);

/*
...
*/

Append(canvas);
```

As you can see in the second code example, the `UIPanel panel` element has disappeared. The layout container itself, `canvas`, has simultaneously become the main container.

---

The first thing you see in the code is:

```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);
```

This is the main panel that will be added to the `UIState`. The `UIExCanvas` will be placed on it.<br><br>
`SetPrecentSizeCenter` is a helper method that does not exist in the library itself and is defined below in the same class.
It receives N `UIElement`s, assigns them the specified height and width, and centers them. In this case, our `panel` has a size of 80% x 80% of the screen.<br><br>

---

Next in the code comes `UIExCanvas`:

```csharp
UIExCanvas canvas = new UIExCanvas();
canvas.Stretch();
canvas.ShowLayoutLines = true;
canvas.LayoutLinesThickness = 3f;
canvas.LayoutLinesColor = Color.DarkOrange;

canvas.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Center);

panel.Append(canvas);
Append(panel);
```

* `canvas.Stretch();` - sets the size of `canvas` to 100% of the parent element.
* Below, we add `canvas` to the main panel with `panel.Append(canvas);`, which means that `canvas` will arrange elements across the entire main panel, that is, across the entire created interface.
* `canvas.ShowLayoutLines = true;` - indicates that auxiliary lines should be drawn. For `UIExCanvas`, a rectangle is drawn around the **outer** area of the elements. For more detailed information about element areas, see the first part of this section. `canvas.LayoutLinesThickness = 3f;` - the line thickness is 3 pixels. `canvas.LayoutLinesColor = Color.DarkOrange` - the color of the auxiliary lines.
* `Set` is a method available in every style class in the library. Each style's `Set` accepts values for all existing fields of the style class.
* Its `StyleLayoutContainer StyleLayout` styles:

  * `Orientation`: the main axis of the container. `Horizontal` - horizontal.
  * `JustifyContent` (alignment of elements along the main axis) (the main axis is horizontal): `Center` - elements are aligned to the center of the container's width.
  * `AlignItems` (alignment of elements along the cross axis) (the cross axis is vertical): `not specified` - elements are aligned to the top of the container.
* Its `StyleLayoutContainerCanvas StyleLayoutCanvas` styles:

  * `AllowOverflowSelf`: `not specified`. Default: `false`. Nested elements cannot go outside the container boundaries.

Next in the code is the process of creating 16 50x50px cubes and storing their styles:

```csharp
UIElement[] cubs = AddCubs(canvas, 50, 16);
StyleLayoutChildCanvas[] stylesCanvas = new StyleLayoutChildCanvas[cubs.Length];
StyleLayoutChild[] styles = new StyleLayoutChild[cubs.Length];

for (int i = 0; i < cubs.Length; i++)
{
    styles[i] = cubs[i].StyleLayoutChild();
    stylesCanvas[i] = styles[i].Canvas();
}
```

The cubes are added using the `AddCubs` method:

```csharp
public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
{
    int count = pixelSizes.Length;
    var buttons = new UIElement[count];
    for (int i = 0; i < count; i++)
        buttons[i] = AddCubs(element, pixelSizes[i], count: 1)[0];
    return buttons;
}

public UIElement[] AddCubs(UIElement element, float pixelSize, int count = 1)
{
    var buttons = new UIElement[count];
    for (int i = 0; i < count; i++)
    {
        buttons[i] = new UIButton<string>(i.ToString());
        StyleLayoutChild style = buttons[i].StyleLayoutChild();
        style.Width.Set(pixelSize, 0f);
        style.Height.Set(pixelSize, 0f);
        element.Append(buttons[i]);
    }
    return buttons;
}
```

These methods were also created specifically for this example and do not exist in the library itself.<br>

Note that the size inside the method is set using the `StyleLayoutChild` style.<br>
Since child elements inside a layout container can only have their sizes set in this way:

```csharp
buttons[i] = new UIButton<string>(i.ToString());
StyleLayoutChild style = buttons[i].StyleLayoutChild();
style.Width.Set(pixelSize, 0f);
style.Height.Set(pixelSize, 0f);
element.Append(buttons[i]);
```

Next comes the code that sets the style values for the nested cubes:<br>
Alignment of cubes 0-6:<br>
`0`: top horizontally; left vertically;<br>
`1`: top horizontally; center vertically;<br>
`2`: top horizontally; right vertically;<br>
`3`: left horizontally; center vertically;<br>
`4`: centered on the screen;<br>
`5`: right horizontally; center vertically;<br>
`6`: stretched horizontally (with margins); bottom vertically.<br>

```csharp
styles[0].Set(
    justifySelf:    UIExAlignment.Start, 
    alignSelf:      UIExAlignment.Start);

// styles[1]: justifySelf == Auto == JustifyContent(canvas) == Center
// styles[1]: alignSelf == Auto == AlignContent(canvas) == Auto == Start

// styles[2]: alignSelf == Auto == AlignContent(canvas) == Auto == Start
styles[2].Set(
    justifySelf:    UIExAlignment.End);

styles[3].Set(
    justifySelf:    UIExAlignment.Start,
    alignSelf:      UIExAlignment.Center);

// styles[4]: justifySelf == Auto == JustifyContent(canvas) == Center
styles[4].Set(
    alignSelf:      UIExAlignment.Center);

styles[5].Set(
    justifySelf:    UIExAlignment.End,
    alignSelf:      UIExAlignment.Center);

styles[6].Set(
    justifySelf:    UIExAlignment.Stretch,
    alignSelf:      UIExAlignment.End,
    margin:         new UIExThickness(
                        pixels: true, 
                        right:   25f,
                        bottom: 50f,
                        left: 75f,
                        top: 100f));
```

As you can see, some lines are commented out:<br>

* For `styles[1]`, `styles[2]`, and `style[4]`. This is done to show which values these fields would need, but they are already set by the `UIExCanvas canvas` itself.
* For example: element 2 (`style[2]`) is positioned: center horizontally; top vertically. To achieve this alignment using `JustifySelf` and `AlignSelf`, it would need:

  * `JustifySelf = UIExAlignment.Center` (alignment along the main axis. The main axis of `canvas` is horizontal). Center horizontally.
  * `AlignSelf = UIExAlignment.Start` (alignment along the cross axis). Top vertically.
  * `canvas` already has `JustifyContent` set to `UIExAlignment.Center`, which shifts this element. There is no point in setting the `JustifySelf` property.
  * `canvas` does not have `AlignItems` set. Default: `UIExAlignment.Auto` (equivalent to `UIExAlignment.Start`). There is no point in setting the `AlignSelf` property.<br>

---

For element 6 (`style[6]`), the `justifySellf` field is set to `UIExAlignment.Stretch`. This means that it stretches across the entire size of the main axis. In this case, across the entire width, except for the `Margin`.<br><br>
This is one of the two elements whose auxiliary lines do not coincide with the actual elements. `Margin` plays the main role here.<br>

`Margin` increases the outer area of an element. For more information, see the article «*UIExLayout class. Layout basics*».<br>
The outer size is determined as follows:

1. `outer-Top`: `cubs[6].Top - styles[6].Margin.Top;`
2. `outer-Left`: `cubs[6].Left - styles[6].Margin.Left;`
3. `outer-Width`: `cubs[6].Width + styles[6].Margin.Left + styles[6].Margin.Right;`
4. `outer-Height`: `cubs[6].Height + styles[6].Margin.Top + styles[6].Margin.Bottom;`<br>

* `cubs[6].Left` == `Margin.Left`, if it is stretched across the width.
* `cubs[6].Width` == `container width - (Margin.Left + Margin.Right)`, if it is stretched across the width.<br>

Preliminary result: (`c50px` is a conditional notation for the size of a non-stretched cube edge (size: `50px`))

1. `outer-Top`: `container height - c50px - 100px`
2. `outer-Left`: `75px - 75px;`
3. `outer-Width`: `(container width - (Margin.Left + Margin.Right)) + 75px + 25px;`
4. `outer-Height`: `c50px + 100px + 50px;`<br>

Final result:

1. `outer-Top`: `container height - 150px`
2. `outer-Left`: `0px;`
3. `outer-Width`: `150px;`
4. `outer-Height`: `200px;`<br>

`Stretch` stretches the outer area of the element. The regular area (the one actually displayed on the screen) is then calculated using the following formula:<br>
Formulas for calculating positions when stretching (`Left`, `Width` - by width; `Top`, `Height` - by height):

1. `Left = Margin.Left;`
2. `Top = Margin.Top;`
3. `Width = container width - (Margin.Left + Margin.Right)`.
4. `Height = container height - (Margin.Top + Margin.Bottom)`.

Next comes the method:

```csharp
CopyStyle4(indexStart: 7, indexEnd: 15); 
```

This is an internal helper method. It simply copies the values of `style[4]` (`justifySelf: center, alignSelf: center`) to the styles for elements 7-15.<br><br>

Next:

```csharp
stylesCanvas[7].Top.Pixels = 50f;
stylesCanvas[8].Bottom.Pixels = 50f;
stylesCanvas[9].Left.Pixels = 50f;
stylesCanvas[10].Right.Pixels = 50f;

stylesCanvas[11].Bottom.Pixels = 50f;
stylesCanvas[11].Right.Pixels = 50f;
```

All of these elements (as well as all subsequent ones) copied the values of `style[4]`, and their coordinate reference points begin at the center of the container.

1. Element 7 is shifted 50px downward relative to the center and is positioned below the central element 4.
2. Element 8 is shifted 50px upward relative to the center and is positioned above the central element 4.
3. Element 9 is shifted 50px to the right relative to the center and is positioned to the right of the central element 4.
4. Element 10 is shifted 50px to the left relative to the center and is positioned to the left of the central element 4.
5. Element 11 is shifted 50px upward and to the left relative to the center and is positioned above and to the left of the central element 4.<br><br>

Next:

```csharp
styles[12].Margin = new UIExThickness(
    pixels:     true,
    bottom:     50f,
    right:      100f);
stylesCanvas[12].Left.Precent = -0.5f;
```

This example demonstrates:

1. Additional visualization of the use of `Margin`. As you can see in the image, element 12 has an increased outer area, but the element itself is located in its upper-left part. If we specified `left/top` instead of `right/bottom`, the element would also be shifted. This is because the layout container positions the upper-left point of the **outer size** of the element.
2. A position specified as a percentage that is negative. This element is centered, so `-0.5f` will shift the element to the right by 25% of the container (50% of the distance from the centered coordinate reference point to the left edge of the container). More details will be provided when discussing cube 14.

```csharp
styles[12].Bottom.Pixels = 50f;
styles[12].Right.Pixels = 100f;
```

Essentially, there is one crucial difference between these two methods of positioning elements:<br>

* `Left`, `Top`, `Right`, `Bottom` are simple offsets of the element.<br>
* `Margin` is both an offset and an increase of the outer size of the element.<br>
  For this layout container, this only matters if `JustifyContent/Self` and/or `AlignItems/Self` have the value `UIExAlignment.Stretch`.<br>
  For all other settings, there is no difference in what you use to create the offset.<br>

As you can see, unlike all other elements, elements 6 and 12 have their auxiliary rectangles drawn with margins.<br>
This outline is drawn around the outer size of the element.<br>
Furthermore, if we tried to set `Left` or `Right` values for element 6, we would not see any offset when (`AllowOverflow == false && AllowOverflowSelf != true`).<br>

---

Next is cube 13. We will examine it together with 15. For now, let us move on to 14:

```csharp
stylesCanvas[14].Left.Precent = 0.5f;
```

If we were not using this library, we would write `HAlign = 0.5f` - the element would be shifted by 50% of the parent element's size, minus 50% of its own size.<br>
However, in the image this cube is positioned at 75% of the width.<br>
Since `JustifySelf == UIExAlignment.Center`, the coordinate reference point begins at the center of the container.<br>
Therefore, `stylesCanvas[14].Left.Precent = 0.5f;` calculates 50% of the distance between the center and the right edge of the container.

And finally, the last 2 cubes that we have not discussed:

```csharp
stylesCanvas[13].Left.Pixels = 100000f;
stylesCanvas[13].Top.Pixels = 50f;

stylesCanvas[15].Left.Precent = 1.1f;
stylesCanvas[15].AllowOverflowSelf = true;
```

In the first case, the offset is set to 100,000 pixels.<br>
Nevertheless, its `AllowOverflowSelf == false`. This means that the container controls whether the element goes outside its boundaries.<br>
In the image, you can observe it pressed against the right edge.<br><br>

The next element, however, has a left offset of 110% (of the distance between the center and the right edge).<br>
Its `AllowOverflowSelf` value is `true`. The container does not control whether the element goes outside its boundaries.<br>
Therefore, you can see this element to the right of the container boundary.
