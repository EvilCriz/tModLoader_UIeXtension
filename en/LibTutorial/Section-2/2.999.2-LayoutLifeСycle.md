<h2 align="center">The life cycle <code>UIElement</code> into tModLoader</h2>

Before proceeding to the life cycle of the linkers, you should talk about the life cycle of the layout in **tModLoader**.<br>

1. For the root element (`UIState`) the method is called `Recalculate`.
2. Method `Recalculate` calculates 3 areas of the element (for more information about the area of the element, see the article) `UIExLayout`).
3. Then the method `Recalculate` method `RecalculateChildren`.
4. Method `RecalculateChildren` method `Recalculate` for all child elements.<br>

Thus, **tModLoader** method `Recalculate` For the whole tree of elements, each frame.

----

<h2 align="center">The life cycle <code>UIExLayout</code></h2>

First thing he does. `UIExLayout` - interferes with the life cycle `UI` into **tModLoader**:
```csharp
public abstract partial class UIExLayout : UIExElement
{
    private bool _pauseRecalculateChildren = false;

    public override void Recalculate()
    {
        _pauseRecalculateChildren = true;
        base.Recalculate();
        _pauseRecalculateChildren = false;
        RecalculateLayout();
        RecalculateChildren();
    }


    public override void RecalculateChildren()
    {
        if (_pauseRecalculateChildren)
            return;

        base.RecalculateChildren();
    }
}
```
As you can see, `UIExLayout` Add a special flag to block the call. `Recalculate` at the child elements.<br>

The life cycle is now as follows:
1. Placing of the flag `_pauseRecalculateChildren = true`prohibiting the execution of the `RecalculateChildren`.
2. `base.Recalculate` Recalculation of 3 areas of the container.
3. `base.Recalculate` trigger `RecalculateChildren`This method is blocked by the flag. `_pauseRecalculateChildren`.
4. Placing of the flag `_pauseRecalculateChildren = false`permitting the execution of the method `RecalculateChildren`.
5. Recalculation of the entire layout in the method `RecalculateLayout`.
6. The challenge `RecalculateChildren`.<br>

Now:
1. First, 3 areas of the container are recalculated.
2. The elements inside the container are assembled.
3. Recalculated 3 areas of all elements after the layout.

<h3 align="center">Method <code>RecalculateLayout</code></h3>

```csharp
protected virtual void RecalculateLayout()
{
    // stage 1:
    var innerDimension = GetInnerDimensions();
    if (innerDimension.Width == 0f && innerDimension.Height == 0f)
        return;

    // stage 2:
    if (IsLayoutPreparation())
        return;

    // stage 3:
    if (_remainingRecalculateLayoutDelayMs > 0)
        return;

    // stage 4:
    UpdateStyleLayoutChildArray();

    // stage 5:
    if (!IsLastLayoutInfoChanged())
        return;

    // stage 6:
    BeginLayoutContext();

    try
    {
        // stage 7:
        PreRefreshLayout();

        // stage 8:
        RefreshLayout();

        // stage 9:
        PostRefreshLayout();

        // step 10:
        ApplyLayout();

        // stage 11:
        RefreshLayoutDebugLines();
    }
    catch(System.Exception)
    {
        throw new System.Exception("[UIeXtension] RecalculateLayout Exception");
    }
    finally
    {
        // step 12:
        EndLayoutContext();
    }

    // step 13:
    UpdateLastLayoutInfo();

    // step 14:
    int? recalculateLayoutDelayMsState = GetRecalculateLayoutDelayMsState(this);
    _remainingRecalculateLayoutDelayMs =
        recalculateLayoutDelayMsState is not null
            ? (int)recalculateLayoutDelayMsState
            : RecalculateLayoutDelayMs;
}
```

This method determines the entire life cycle of the layout.<br>
General stages:
1. Checking that the container is the size, otherwise it's a way out of the method.
2. Verification that the container is not in a state of preparation (see the previous article), otherwise - an exit from the method.
3. Verification that the container does not have a valid delay before the layout (see the previous article).
4. Update all styles of elements embedded in the container.
5. Checking that the information has changed since the last layout (see previous article).
6. Preparation of temporary data that is used only during a single layout.
7. Preliminary layout algorithm.
8. The basic layout algorithm.
9. Algorithm of the layout after the main stage.
10. Application of Temporary Data to Elements (Installation of Child Items) `Width`, `Height`, `Top`, `Left`).
11. Algorithm of calculation of auxiliary lines.
12. The release of temporary data that is only used during the layout.
13. Record the latest data after the layout (see previous section).
14. Update the minimum delay before the next layout.<br>

- Stage 1: A simple test.
- Stage 2-3: discussed in the previous article.
- Stage 4: Getting all styles of nested elements and keeping them in `private Styles.StyleLayoutChild[] _styleLayoutChildArray;`.
- Step 5: discussed in the previous article.
- Step 6: discussed separately below.
- Step 7-9: Algorithms at these stages of the layout life cycle are determined by each linker.
- Step 10: discussed separately below.
- Step 11: The auxiliary line calculation algorithm determines each linker itself.
- Step 12: discussed separately below.
- Step 13: discussed in the previous article.
- Step 14: See the last lines of the code above and the previous article.

<h3 align="center">Stage 6, 12: <code>BeginLayoutContext</code> and <code>EndLayoutContext</code></h3>

This method generates/releases temporary data that is only relevant during the layout life cycle.<br>
`UIExLayout` Prepares data that is used by all linkers.<br>
Each linker separately prepares/releases its data.<br><br>

```csharp
protected List<UIElement> _elementsContext = null;

protected List<RectangleLayoutContext> _rectangleContexts = null;

protected List<Styles.StyleLayoutChild> _styleElementsContexts = null;

protected CalculatedStyle _innerDimensionsContext;

protected List<CalculatedStyle> _elementsOuterDimensionsContext = null;

protected List<CalculatedStyle> _elementsDimensionsContext = null;
```

- `_elementsContext` a list of child elements that participate in the layout (which have a field) `StyleLayoutChild().WithoutLayout == false`)
- `_rectangleContexts` - list `RectangleLayoutContext`, which will be given the size and displacement of the elements during the layout.
- `_styleElementsContexts` - a list of styles of elements that are involved in the layout.
- `_innerDimensionsContext` - the interior area of the linker.
- `_elementsOuterDimensionsContext` A list of external areas of elements that are involved in the layout.
- `_elementsDimensionsContext` A list of areas of elements that are involved in the layout.<br>

`_styleElementsContexts`, `_styleElementsContexts`, `_elementsOuterDimensionsContext`, `_elementsDimensionsContext` have a list size equal to `_elementsContext.Count`.<br>
All indexes match.<br><br>

- All elements `_elementsContext` into `BeginLayoutContext` fixation `Top`, `Left` on `StyleDimension.Empty`.<br>
<!-- -->
- `_rectangleContexts[i].Width` and `_rectangleContexts[i].Height` default `_elementsContext[i].Width`, `_elementsContext[i].Height` They're pixelated.
- `_rectangleContexts[i].Index = i`.<br><br>

`RectangleLayoutContext` has methods:
```csharp
public CalculatedStyle GetCalculatedStyle()
    => new(Left, Top, Width, Height);

public LayoutDebugRectangle GetLayoutDebugRectangle()
    => new(Left, Top, Width, Height);
```
<br>

In the method `EndLayoutContext` All lists are given meaning. `null`.

<h3 align="center">Step 10: Application of temporal data to elements</h3>

```csharp
protected virtual void ApplyLayout()
{
    foreach (var rectContext in _rectangleContexts)
        ApplyElementLayout(rectContext);
}

protected virtual void ApplyElementLayout(RectangleLayoutContext rectContext)
{
    UIElement element = _elementsContext[rectContext.Index];

    element.Top.Set(rectContext.Top, 0f);
    element.Left.Set(rectContext.Left, 0f);
    element.Width.Set(rectContext.Width, 0f);
    element.Height.Set(rectContext.Height, 0f);
}
```

At this stage, all elements that participate in the layout are set values:
- `Left`;
- `Top`;
- `Width`;
- `Height`.<br>

All meanings are taken from `_rectangleContexts`.
