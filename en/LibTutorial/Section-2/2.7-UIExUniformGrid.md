`UIExUniformGrid` is a layout container for arranging interface elements in two dimensions as rows and columns, which automatically arranges child elements in a grid where every cell has exactly the same size.<br>

**Important!** This article assumes that you have already studied the `UIExGrid` article.<br>
This class works similarly to the base styles, so they will not be covered in this article.<br>
Some `UIExUniformGrid` styles have values analogous to those of `UIExGrid` and will also not be covered in this article.

---

<h2 align="center"><code>UIExUniformGrid</code> Styles</h2>

`UIExUniformGrid` uses `StyleLayoutContainer` and `StyleLayoutChild` values in the same way as `UIExGrid`.

---

`UIExUniformGrid` has a `StyleLayoutContainerUniformGrid` style class:

```csharp
public class StyleLayoutContainerUniformGrid : Base.StyleLayoutContainerBase
{
    public StyleDimension RowsSpace = StyleDimension.Empty;
    public StyleDimension ColumnsSpace = StyleDimension.Empty;

    public Enums.UIExAlignment RowsAlignment = Enums.UIExAlignment.Start;
    public Enums.UIExAlignment ColumnsAlignment = Enums.UIExAlignment.Start;

    public int RowsCount = 0;
    public int ColumnsCount = 0;
}
```

The `RowsSpace`, `ColumnsSpace`, `RowsAlignment`, and `ColumnsAlignment` values work similarly to `UIExGrid`.<br><br>

Unlike `UIExGrid`, it does not contain methods for configuring the grid.<br>
Each cell has a `UIExGridLength` with `Type = UIExGridLengthType.Fraction` and `Fraction = 1f`.<br>
You can only specify the number of grid cells using `RowsCount` and `ColumnsCount`.<br>

`UIExUniformGrid` allows you to specify both `RowsCount` and `ColumnsCount`, specify only one of them, or specify neither of them.<br>
If only one of these values is specified, or neither is specified, `UIExUniformGrid` determines the grid size automatically based on the number of elements.<br>
When doing so, it attempts to make the grid as close to a square shape as possible without creating empty rows/columns.<br>

**Important.** When automatically calculating the cells, the `RowSpan` and `ColumnSpan` values of the elements are not taken into account.<br>
If you want to use these values, you will have to calculate the grid size yourself.<br>
More details about element placement, `RowSpan`, and `ColumnSpan` are provided below.

---

All elements nested inside `UIExUniformGrid` can use the `StyleLayoutChildUniformGrid` style.
To use this style, you need to obtain the `StyleLayoutChild` style using the `StyleLayoutChild()` extension method of `UIElement`.
Then call the `UniformGrid()` method on the obtained style.

```csharp
UIElement element = new();
StyleLayoutChild style = element.UniformGrid();
StyleLayoutChildUniformGrid styleUGrid = style.Grid();
styleUGrid.RowSpan = 2;
```

The `StyleLayoutChildUniformGrid` class itself has the following implementation:

```csharp
public class StyleLayoutChildUniformGrid : Base.StyleLayoutChildBase
{
    public int RowSpan = 1;
    public int ColumnSpan = 1;
}
```

As you can see, unlike `StyleLayoutChildGrid`, this class does **not** define `Row` and `Columns` fields.<br>
`UIExUniformGrid` determines where to place the element itself.<br>
If `RowSpan == 1` and `ColumnSpan == 1`, elements are placed from left to right and from top to bottom.<br>
For example, for a `2x2` grid containing 3 elements, they will be placed in the following order:

* `[element 1]`: `{0, 0}`;
* `[element 2]`: `{0, 1}`;
* `[element 3]`: `{1, 0}`.<br>

1. Each subsequent element moves one column to the right while there are free cells remaining on the right.
2. When there are no more free cells in the row, the element moves to the leftmost column, but one row lower.
3. If there is already an occupied cell along the placement path (as described in the example below), the element moves further.<br>

If there are more elements than the number of cells, all elements that do not fit will be placed in the last cell.<br>
For such elements, `RowSpan` and `ColumnSpan` are not taken into account.

---

That was the case for `RowSpan == 1` and `ColumnSpan == 1`.<br>
Now imagine that the first element has `ColumnSpan == 2`.<br>
In this case, the elements will be placed in the following order:

* `[element 1]`: `{ {0, 0}, {0, 1} }`;
* `[element 2]`: `{1, 0}`;
* `[element 3]`: `{1, 1}`.<br><br>

Now consider the case where the first element has `RowSpan == 2` and `ColumnSpan == 2`.<br>
Then the elements will be placed as follows:

* `[element 1]`: `{ {0, 0}, {0, 1}, {1, 0} }`;
* `[element 2]`: `{1, 1}`;
* `[element 3]`: `{1, 1}`.<br>

1. The first element takes 3 cells: the top-left (`{0, 0}`), top-right (`{0, 1}`), and bottom-left (`{1, 0}`).
2. Only one free cell remains for the second element: the bottom-right (`{1, 1}`).
3. There are no free cells left for the third element, so it occupies the last cell in the grid: the bottom-right (`{1, 1}`).

---

An example of using `UIExUniformGrid` for elements with `RowSpan == 1` and `ColumnSpan == 1`, as well as automatic determination of `RowsCount` and `ColumnsCount`, is shown in the `UIExLayout` article.

<h2 align="center">Example of using <i>UIExUniformGrid</i></h2>

<details>
<summary>Example of creating a calculator layout (without comments, detailed explanation below)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // The OnActivate() method is used here only
    // for the "hot code reload" feature in the development environment.
    // For a real interface, it would be more appropriate to use
    // the OnInitialize() method.
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 650f, panel);

        UIExUniformGrid uGrid = new();
        uGrid.Stretch();

        ////////////////////////////

        StyleLayoutContainer styleLayout = uGrid.StyleLayout;
        StyleLayoutContainerUniformGrid styleLayoutUGrid = styleLayout.UniformGrid();

        styleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Stretch,
            alignItems:         UIExAlignment.Stretch);



        styleLayoutUGrid.Set(
            rowsCount:      7,
            columnsCount:   4,
            rowsSpace:      StyleDimension.FromPixels(10f),
            columnSpace:    StyleDimension.FromPixels(15f));

        ///////////////////////////

        AppendButton(uGrid, prefix: "RESULT:", rowSpan: 2, columnSpan: 4);

        AppendButton(uGrid, prefix: "AC");
        AppendButton(uGrid, prefix: "%");
        AppendButton(uGrid, prefix: "<<");
        AppendButton(uGrid, prefix: "/");

        AppendButton(uGrid, prefix: 7);
        AppendButton(uGrid, prefix: 8);
        AppendButton(uGrid, prefix: 9);
        AppendButton(uGrid, prefix: "*");

        AppendButton(uGrid, prefix: 4);
        AppendButton(uGrid, prefix: 5);
        AppendButton(uGrid, prefix: 6);
        AppendButton(uGrid, prefix: "-");

        AppendButton(uGrid, prefix: 1);
        AppendButton(uGrid, prefix: 2);
        AppendButton(uGrid, prefix: 3);
        AppendButton(uGrid, prefix: "+");

        AppendButton(uGrid, prefix: 0);
        AppendButton(uGrid, prefix: ",");
        AppendButton(uGrid, prefix: "=", columnSpan: 2);

        ///////////////////////////

        panel.Append(uGrid);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AppendButton(UIExLayout layout, int prefix, int rowSpan = 1, int columnSpan = 1)
        => AppendButton(layout, prefix.ToString(), rowSpan, columnSpan);
    public UIButton<string> AppendButton(UIExLayout layout, string prefix, int rowSpan = 1, int columnSpan = 1)
    {
        UIButton<string> button = new(prefix);

        StyleLayoutChildUniformGrid styleGrid = button.StyleLayoutChild().UniformGrid();
        styleGrid.Set(rowSpan, columnSpan);

        layout.Append(button);
        return button;
    }
}
```

This code is almost identical to `UIExGrid`, so we will only examine the parts that differ.

---

```csharp
styleLayoutUGrid.Set(
    rowsCount:      7,
    columnsCount:   4,
    rowsSpace:      StyleDimension.FromPixels(10f),
    columnSpace:    StyleDimension.FromPixels(15f));
```

Here, the number of rows and columns is specified.<br>
`UIExUniformGrid` cannot calculate the grid size automatically because the elements inside it use `RowSpan` and `ColumnSpan`.

---

The elements are then added.<br>
The `AppendButton` method is identical, except that it does not accept `row` and `column` values and does not assign them to the button created inside it.<br>

---

The first addition:

```csharp
AppendButton(uGrid, prefix: "RESULT:", rowSpan: 2, columnSpan: 4);
```

In this case, we know that this is the first element and that it will be placed in the `{0, 0}` cell.<br>
Since the element has `RowSpan == 2` and `ColumnSpan == 4`, it will occupy the following set of cells:

* `{`

  * `{0, 0}, {0, 1}, {0, 2}, {0, 3}`
  * `{1, 0}, {1, 1}, {1, 2}, {1, 3}`
* `}`<br>

The second element being added:

```csharp
AppendButton(uGrid, prefix: "AC");
```

Since the last occupied cell is `{1, 3}`, and this is the last column, the element will be placed in the `{2, 0}` cell.<br>

The next element after it will be placed in `{2, 1}`, and so on.
