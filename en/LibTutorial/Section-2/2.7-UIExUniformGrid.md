`UIExUniformGrid` It is a layout container for two-dimensional arrangement of interface elements in the form of rows and columns, which automatically organizes the child elements in the grid, where each cell is exactly the same size.<br>

**Important!**This article assumes that you have already studied the article. `UIExGrid`.<br>
This class works similarly with basic styles, so they will not be discussed in this article.<br>
Part of the styles `UIExUniformGrid` analogous `UIExGrid`It will also not be discussed in this article.

<h2 align="center">Styles. <code>UIExUniformGrid</code></h2>

`UIExUniformGrid` use-value `StyleLayoutContainer` and `StyleLayoutChild` similarly `UIExGrid`.

----

For `UIExUniformGrid` class `StyleLayoutContainerUniformGrid`:
```csharp
public class StyleLayoutContainerUniformGrid : Base.StyleLayoutContainerBase
{
    public StyleDimension RowsSpace = StyleDimension.Empty;
    public StyleDimension ColumnsSpace = StyleDimension.Empty;

    public Enums.UIExAlignment RowsAlignment = Enums.UIExAlignment.Start;
    public Enums.UIExAlignment ColumnsAlignment = Enums.UIExAlignment.Start;

    public int RowsCount = 0;
    public int ColumnsCount = 0;
}
```

Meanings `RowsSpace`, `ColumnsSpace`, `RowsAlignment`, `ColumnsAlignment` work similarly `UIExGrid`.<br><br>

In contrast, `UIExGrid` It does not contain methods for setting up the grid.<br>
Every cell has `UIExGridLength`: `Type = UIExGridLengthType.Fraction` and `Fraction = 1f`.<br>
You can only set the number of cells in the grid using `RowsCount` and `ColumnsCount`.<br>

`UIExUniformGrid` allows you to specify both values `RowsCount` and `ColumnsCount`Either one of them, or not one of them.<br>
If only one of these values or none of them is indicated, `UIExUniformGrid` He will determine the size of the grid based on the number of elements.<br>
In doing so, it will try to make the grid as close as possible to the square shape, but without creating empty rows/columns.<br>

**It's important.**In the automatic calculation of cells is not taken into account. `RowSpan` and `ColumnSpan` elements.<br>
If you want to use these values, then you will have to calculate the size of the grid yourself.<br>
For more information on the location of the elements, `RowSpan` and `ColumnSpan` will be written below.

----

All invested `UIExUniformGrid` elements can be used in style `StyleLayoutChildUniformGrid`.
In order for you to use this style, you need to have a style. `StyleLayoutChild` expansionist `UIElement`: `StyleLayoutChild()`.
Then, in the resulting style, call the method `UniformGrid()`.
```csharp
UIElement element = new();
StyleLayoutChild style = element.UniformGrid();
StyleLayoutChildUniformGrid styleUGrid = style.Grid();
styleUGrid.RowSpan = 2;
```

Same class. `StyleLayoutChildUniformGrid` has the following implementation:
```csharp
public class StyleLayoutChildUniformGrid : Base.StyleLayoutChildBase
{
    public int RowSpan = 1;
    public int ColumnSpan = 1;
}
```

As you can see, unlike `StyleLayoutChildGrid` classmate **not** field `Row` and `Columns`.<br>
`UIExUniformGrid` It determines where to place the element.<br>
If `RowSpan == 1` and `ColumnSpan == 1`The elements are located from left to right and from top to bottom.<br>
I mean, for a grid size. `2x2` In which 3 elements are added, they will be arranged in the following order:
- `[element 1]`: `{0, 0}`;
- `[element 2]`: `{0, 1}`;
- `[element 3]`: `{1, 0}`.<br>

1. Each subsequent element was shifted one column to the right while the free cells remained on the right.
2. When there were no free cells left in the column, the element moved to the leftmost column, but one row lower.
3. If there were an already occupied cell in the path of location (about this in the example below), the element would move further.<br>

If there are more elements than the number of cells, then all the elements that do not fit will be placed in the last cell.<br>
For such elements `RowSpan` and `ColumnSpan` They don't count.

----

It was an occasion for `RowSpan == 1` and `ColumnSpan == 1`.<br>
Let us assume that the first element has `ColumnSpan == 2`.<br>
In this case, the elements will be arranged in the following order:
- `[element 1]`: `{ {0, 0}, {0, 1} }`;
- `[element 2]`: `{1, 0}`;
- `[element 3]`: `{1, 1}`.<br><br>

Now let’s take the case that the first element has `RowSpan == 2` and `ColumnSpan == 2`.<br>
Then the arrangement of the elements will be as follows:
- `[element 1]`: `{ {0, 0}, {0, 1}, {1, 0} }`;
- `[element 2]`: `{1, 1}`;
- `[element 3]`: `{1, 1}`.<br>

1. The first element took itself 3 cells: left-upper`{0, 0}`), right-upper (`{0, 1}`), left-lower (`{1, 0}`).
2. For the second element, there is only one free cell left: the right-lower cell.`{1, 1}`).
3. For the third element, there were no free cells left, so it occupied the last cell in the grid: the right-lower cell.`{1, 1}`).

----

Example of use in `UIExUniformGrid` for elements, with meanings `RowSpan == 1` and `ColumnSpan == 1`as well as with automatic determination `RowsCount` and `ColumnsCount` illustrated `UIExLayout`.

This means that all auxiliary lines can be drawn simultaneously.

<h2 align="center">Example of use <i>UIExUniformGrid</i></h2>

<details>
<summary>Example of creating a calculator layout (without comments, analysis below)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // method OnActivate(a) in this case, only
    // for the “hot code reboot” function in the development environment.
    // It would be better to use the real interface.
    // method OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 650f, panel);

        UIExUniformGrid uGrid = new();
        uGrid.Stretch();

        ////////////////////////////

        StyleLayoutContainer styleLayout = uGrid.StyleLayout;
        StyleLayoutContainerUniformGrid styleLayoutUGrid = styleLayout.UniformGrid();

        styleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Stretch,
            alignItems:         UIExAlignment.Stretch);



        styleLayoutUGrid.Set(
            rowsCount:      7,
            columnsCount:   4,
            rowsSpace:      StyleDimension.FromPixels(10f),
            columnSpace:    StyleDimension.FromPixels(15f));

        ///////////////////////////

        AppendButton(uGrid, prefix: "RESULT:", rowSpan: 2, columnSpan: 4);

        AppendButton(uGrid, prefix: "AC");
        AppendButton(uGrid, prefix: "%");
        AppendButton(uGrid, prefix: "<<");
        AppendButton(uGrid, prefix: "/");

        AppendButton(uGrid, prefix: 7);
        AppendButton(uGrid, prefix: 8);
        AppendButton(uGrid, prefix: 9);
        AppendButton(uGrid, prefix: "*");

        AppendButton(uGrid, prefix: 4);
        AppendButton(uGrid, prefix: 5);
        AppendButton(uGrid, prefix: 6);
        AppendButton(uGrid, prefix: "-");

        AppendButton(uGrid, prefix: 1);
        AppendButton(uGrid, prefix: 2);
        AppendButton(uGrid, prefix: 3);
        AppendButton(uGrid, prefix: "+");

        AppendButton(uGrid, prefix: 0);
        AppendButton(uGrid, prefix: ",");
        AppendButton(uGrid, prefix: "=", columnSpan: 2);

        ///////////////////////////

        panel.Append(uGrid);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AppendButton(UIExLayout layout, int prefix, int rowSpan = 1, int columnSpan = 1)
        => AppendButton(layout, prefix.ToString(), rowSpan, columnSpan);
    public UIButton<string> AppendButton(UIExLayout layout, string prefix, int rowSpan = 1, int columnSpan = 1)
    {
        UIButton<string> button = new(prefix);

        StyleLayoutChildUniformGrid styleGrid = button.StyleLayoutChild().UniformGrid();
        styleGrid.Set(rowSpan, columnSpan);

        layout.Append(button);
        return button;
    }
}
```

```csharp
styleLayoutUGrid.Set(
    rowsCount:      7,
    columnsCount:   4,
```

This indicates the size of the columns and columns.<br>
`UIExUniformGrid` You will not be able to calculate the size of the mesh yourself, because the elements inside it are used. `RowSpan` and `ColumnSpan`.

----

Then the elements are added.<br>
Method `AppendButton` identical, except that it does not matter. `row`, `column`It does not install the button created inside.<br>

----

First appendix:
```csharp
AppendButton(uGrid, prefix: "RESULT:", rowSpan: 2, columnSpan: 4);
```
In this case, we know that this is the first element and it will be located in the cell. `{0, 0}`.<br>
Since the element `RowSpan == 2` `ColumnSpan == 4`, then this element will occupy the following set of cells:
- `{`
  - `{0, 0}, {0, 1}, {0, 2}, {0, 3}`
  - `{1, 0}, {1, 1}, {1, 2}, {1, 3}`
- `}`<br>

Second element added:
```csharp
AppendButton(uGrid, prefix: "AC");
```
Since the last occupied cell: `{1, 3}`, and this is the extreme column, then this element will be located in the cell: `{2, 0}`.<br>

The next element `{2, 1}` etc.
