<h1 align="center">Structure of library</h1>

When I created this library, I set myself the following goals:

1.	Add elements of the layout that are used in the most modern *UI*: `StackPanel`, `WrapPanel`, `DockPanel`, `Grid`, `GridUniform`, `FlexBox`.
2.	Add tools to enhance user experience optimization (which cannot be automated due to engine limitations) **tModLoader**This will be a separate chapter in the section devoted to the elements of the layout.
3.	Add an analogue of each `UIElement` **tModLoader**But with completely updated style editing tools.
4.	The goal was to create a style system that the user can define using individual classes, so that each element has its own style class, which defines only the fields that a particular object can use. `UIElement`.<br>

**Important!** At the moment, the library is in development, and at the moment it only implements the layout elements: `UIExCanvas`, `UIExStackPanel`, `UIExWrapPanel`, `UIExDockPanel`, `UIExGrid`, `UIExUniformGrid`.<br>
Visual elements will be added later as they are developed.

----

- This library assumes that you have already studied [Extended Guide to Configuring the User Interface](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>
