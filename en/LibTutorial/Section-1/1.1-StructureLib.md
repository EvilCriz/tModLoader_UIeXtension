<h1 align="center">Library Structure</h1>

When creating this library, I set the following goals:

1. Add layout elements that are used in the most modern *UI*: `StackPanel`, `WrapPanel`, `DockPanel`, `Grid`, `GridUniform`, `FlexBox`.
2. Add tools to improve user interface optimization (which cannot be automated due to the limitations of the **tModLoader** engine; this will be covered in a separate chapter in the section dedicated to layout elements).
3. Add an analogue of every **tModLoader** `UIElement`, but with completely updated tools for editing styles.
4. Create a style system that users can define using separate classes. The goal was to create a system where each element has its own style class containing only the fields that can be used by the specific `UIElement` object.<br>

**IMPORTANT!** The library is currently under development. As of today, it only implements layout elements: `UIExCanvas`, `UIExStackPanel`, `UIExWrapPanel`, `UIExDockPanel`, `UIExGrid`, `UIExUniformGrid`.<br>
Visual elements will be added later as development progresses.

---

* This library assumes that you have already studied the [basic tModLoader guide to user interfaces](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
* This library assumes that you have already studied the [advanced guide to customizing user interfaces](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>

---

All UI element classes in this library begin with the «`UIEx`» prefix: `UIExElement`, `UIExLayout`, etc. (as well as the `UIExModSytem` class, which will be discussed later).

* `UIExElement` – is the base class for all UI elements in this library. The element itself is a child class of **tModLoader** `UIElement`.
* `UIExLayout` – is the base class for all layout UI elements in this library.

<ins>Section 1</ins>: Introduction

1. In **this part**, a very brief overview of what the library itself represents is provided.
2. In **part 2**, the auxiliary `UIExModSystem` class is described, which can be completely ignored when working with this library. The purpose of this class is to reduce the basic **ModSystem** implementation for creating a user interface – to a single line.
3. In **part 3**, the style structure is described. Styles will not have a separate section in this guide. Each style is tied to a specific UIEx element and will be covered together with that element.
   For example: The `UIExStackPanel` layout element contains the `StyleLayoutContainerStackPanel` layout style, while the elements nested inside it will use the `StyleLayoutChildStackPanel` style. The part dedicated to `UIExStackPanel` will describe both the element itself and these two style classes.

<ins>Section 2</ins>: Layout Elements

1. In **part 1**, the base class for layout elements, `UIExLayout`, and the style class that will define all layout elements, as well as the styles of the elements nested inside them, will be described: `StyleLayoutContainer`, `StyleLayoutChild`.
2. Each subsequent **part** (except the last three) of <ins>section 2</ins> is dedicated separately to each layout element and its styles. One part - 1 element and 2 style classes.
3. The next **part** of <ins>section 2</ins> will be dedicated to optimization tools.
4. The next **part** of <ins>section 2</ins> will be dedicated to the layout lifecycle implemented in `UIExLayout`.
5. The next **part** of <ins>section 2</ins> will be dedicated to recommendations for creating a custom layout class based on this library.

IMPORTANT!!! This note will appear throughout <ins>the 2nd section</ins>: do not start using layout elements before familiarizing yourself with the optimization information. Due to the limitations of **tModLoader**, some optimization tools in this library had to be delegated to the end user. Using these tools can improve UI performance by thousands of times (depending on the scale of your interface).
