<h1 align="center">The <code>UIExModSystem</code> Class</h1>

The `UIExModSystem` class is a descendant of the `ModSystem` class. Its only purpose is to reduce the implementation of the `ModSystem` class required to create a user interface to a minimum.

As you know, in order to start writing a user interface, you need to implement approximately the following structure:

---

* This library assumes that you have already studied the [basic tModLoader guide to user interfaces](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
* This library assumes that you have already studied the [advanced guide to customizing user interfaces](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>

---

<details>
<summary>Basic <i>ModSystem</i> and <i>UIState</i> implementation for writing UI</summary>

```csharp
public class ExampleMenuBar : UIState
{
    public override void OnInitialize() { }
}

[Autoload(Side = ModSide.Client)]
public class ExampleMenuBarSystem : ModSystem
{
    internal ExampleMenuBar ExmplMenuBar;
    private UserInterface _exampleMenuBar;
    public override void Load()
    {
        ExmplMenuBar = new ExampleMenuBar();
        ExmplMenuBar.Activate();
        _exampleMenuBar = new UserInterface();
    }
    public void SetState(bool state) => _exampleMenuBar.SetState(state ? ExmplMenuBar : null);
    public override void UpdateUI(GameTime gameTime) => _exampleMenuBar?.Update(gameTime);
    public override void ModifyInterfaceLayers(List<GameInterfaceLayer> layers)
    {
        int mouseTextIndex = layers.FindIndex(layer => layer.Name.Equals("Vanilla: Mouse Text"));
        if (mouseTextIndex != -1)
        {
            layers.Insert(mouseTextIndex, new LegacyGameInterfaceLayer(
                "YourMod: A Description",
                delegate
                {
                    _exampleMenuBar.Draw(Main.spriteBatch, new GameTime());
                    return true;
                },
                InterfaceScaleType.UI)
            );
        }
    }
}
```

</details>

The `UIExModSystem` class allows you to reduce this code down to a single line:

```csharp
public class ExampleMenuBar : UIState
{
    public override void OnInitialize() { }
}

public class ExampleMenuBarSystem : UIExModSystem<ExampleMenuBar> { }
```

Instead of `ExampleMenuBar`, any class inherited from `UIState` and supporting a parameterless constructor can be used.

---

<details>
<summary>Implementation of the <i>UIExModSystem</i> class</summary>

```csharp
using Microsoft.Xna.Framework;
using System.Collections.Generic;
using Terraria;
using Terraria.ModLoader;
using Terraria.UI;

namespace UIeXtension;

/// <summary>
///     A helper class created to simplify the creation of the basic ModSystem implementation
///     required for creating a user interface.
/// </summary>
/// <typeparam name="TUIState">
///     UIState whose lifecycle will be managed by this class
/// </typeparam>
[Autoload(Side = ModSide.Client)]
public abstract class UIExModSystem<TUIState> : ModSystem 
    where TUIState : UIState, new()
{

    /// <summary>
    ///     User UIState object
    /// </summary>
    protected TUIState State { get; set; }

    /// <summary>
    ///     Manages the updating and drawing of <see cref="State"/>
    /// </summary>
    protected UserInterface InterfaceState { get; set; }



    /// <summary>
    ///     Stores the last state of <see cref="State"/> / <see cref="InterfaceState"/> (shown / hidden)
    /// </summary>
    protected bool LastState { get; set; }



    /// <summary>
    ///     Stores the value used in <see cref="ModifyInterfaceLayers(List{GameInterfaceLayer})"/>
    /// </summary>
    protected virtual string InterfaceLayerName => "Vanilla: Mouse Text";

    /// <summary>
    ///     Stores the value used in <see cref="ModifyInterfaceLayers(List{GameInterfaceLayer})"/>
    /// </summary>
    protected virtual string InterfaceLayerDescription => "YourMod: A Description";



    /// <summary>
    ///     Allows setting the state (shown / hidden) of the user interface
    /// </summary>
    /// <param name="state">
    ///     New state (shown / hidden) of the user interface
    /// </param>
    public virtual void SetState(bool state)
    {
        if (LastState == state)
            return;

        LastState = !LastState;
        InterfaceState.SetState(LastState ? State : null);
    }

    /// <summary>
    ///     Changes the state of the user interface. If it is shown, it hides it; if it is hidden, it shows it.
    /// </summary>
    public virtual void SwitchState() => SetState(!LastState);

    /// <summary>
    ///     Shows the user interface if it is hidden.
    /// </summary>
    public virtual void Show() => SetState(true);

    /// <summary>
    ///     Hides the user interface if it is shown.
    /// </summary>
    public virtual void Hide() => SetState(false);

    /// <summary>
    ///     Returns the state of <see cref="State"/> (hidden/shown)
    /// </summary>
    public virtual bool GetState() => LastState;

    /// <summary>
    ///     Returns <see cref="State"/>. 
    /// </summary>
    /// <returns></returns>
    public virtual TUIState GetUIState() => State;

    /// <summary>
    ///     Basic <see cref="ModSystem"/> implementation for loading the user interface
    /// </summary>
    public override void Load()
    {
        State = new TUIState();
        State.Activate();
        InterfaceState = new UserInterface();
    }

    /// <summary>
    ///     Basic <see cref="ModSystem"/> implementation for updating the user interface
    /// </summary>
    public override void UpdateUI(GameTime gameTime) => InterfaceState?.Update(gameTime);

    /// <summary>
    ///     Basic <see cref="ModSystem"/> implementation for drawing the user interface
    /// </summary>
    public override void ModifyInterfaceLayers(List<GameInterfaceLayer> layers)
    {
        int mouseTextIndex = layers.FindIndex(layer => layer.Name.Equals(InterfaceLayerName));
        if (mouseTextIndex != -1)
        {
            layers.Insert(mouseTextIndex, new LegacyGameInterfaceLayer(
                InterfaceLayerDescription,
                () =>
                {
                    InterfaceState.Draw(Main.spriteBatch, new GameTime());
                    return true;
                },
                InterfaceScaleType.UI)
            );
        }
    }
}    
```

</details>

* What does this class do?

1. It creates a new object of type `TUIState <where TUIState : UIState, new()>` instead of the user in the `Load()` method. It also creates a `UserInterface` in this method.
2. It updates the `UserInterface` independently in the `UpdateUI(GameTime gameTime)` method.
3. It implements `ModifyInterfaceLayers(List<GameInterfaceLayer> layers)`.

* `TUIState State` and `UserInterface InterfaceState` are protected properties with the default `get; set` implementation, in order to minimize restrictions in inheriting classes.

```csharp
protected TUIState State { get; set; }
protected UserInterface InterfaceState { get; set; }
```

---

* A few words about `ModifyInterfaceLayers(List<GameInterfaceLayer> layers)`:

In the basic guide, the strings **"Vanilla: Mouse Text"** and **"YourMod: A Description"** are used in this method.
In `UIExSystem`, they are moved into separate virtual class properties so that you can change either of them, if necessary, without rewriting the entire method:

```csharp
protected virtual string InterfaceLayerName => "Vanilla: Mouse Text";
protected virtual string InterfaceLayerDescription => "YourMod: A Description";
```

---

* The methods `SetState(bool)`, `SwitchState()`, `Show()`, `Hide()`, `GetState()`, `GetUIState()`, `SetUIState(TUIState)` are defined in this class. They are all virtual.

```csharp
public virtual void SetState(bool state) { /*...*/ }
public virtual void SwitchState() => SetState(!LastState);
public virtual void Show() => SetState(true);
public virtual void Hide() => SetState(false);
public virtual bool GetState() => LastState;
public virtual TUIState GetUIState() => State;
public virtual void SetUIState(TUIState state) { /*...*/ }
```
