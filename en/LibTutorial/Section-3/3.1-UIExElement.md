<h2 align="center">Field. <code>tModLoaderStyle</code></h2>

This field determines whether a particular element will use **visualization**: 
1. This library (which doesn’t exist today)
2. Or use one of the visual styles of the **tModLoader**.<br>

What specific style to take **tModLoader** It depends on the specific element.<br>
`UIExElement` (and all elements of the layout) use style. `UIPanel`.<br><br>

That is, the following three codes will be identical in their visual part:
```csharp
UIPanel panel = new();

panel.HAlign = 0.5f;
panel.VAlign = 0.5f;
panel.Width.Set(0f, 0.8f);
panel.Height.Set(0f, 0.8f);

Append(panel);
```

```csharp
UIExElement element = new();

element.HAlign = 0.5f;
element.VAlign = 0.5f;
element.Width.Set(0f, 0.8f);
element.Height.Set(0f, 0.8f);

element.StyleDisplay.tModLoaderStyle = true;

Append(element);
```

```csharp
UIExCanvas canvas = new();

canvas.HAlign = 0.5f;
canvas.VAlign = 0.5f;
canvas.Width.Set(0f, 0.8f);
canvas.Height.Set(0f, 0.8f);

canvas.StyleDisplay.tModLoaderStyle = true;

Append(canvas);
```

----

This library gives full control of styles outside the classroom.<br>
For example: `UIPanel` **tModLoader** Gives the following access to style management:
```csharp
public class UIPanel : UIElement
{
	private int _cornerSize = 12;
	private int _barSize = 4;
	private Asset<Texture2D> _borderTexture;
	private Asset<Texture2D> _backgroundTexture;
	
	public Color BorderColor = Color.Black;
	public Color BackgroundColor = new Color(63, 82, 151) * 0.7f;

	public UIPanel(Asset<Texture2D> customBackground, Asset<Texture2D> customborder, int customCornerSize = 12, int customBarSize = 4)
	{ /* ... */ }
}
```

As you can see in the code above, `UIPanel` allows you to set all the values in the constructor, but dynamically change only the fields `BorderColor` and `BackgroundColor`.<br><br>

In turn, this library allows you to change the value of any given field at any time.<br>
To do this, you first need to get a basic style for a particular element.<br>
For `UIExElement` It's a class-defined style. `StyleTmlUIPanel` (For other items, the required classes will be written separately as they are added to the library.)<br><br>

Implementation of the class `StyleTmlUIPanel`:
```csharp
public class StyleTmlUIPanel : Base.StyleTmlBase
{
    public int CornerSize = 12;
    public int BarSize = 4;
 
	public Asset<Texture2D> BorderTexture;
    public Asset<Texture2D> BackgroundTexture;
    
	public Color BorderColor = Color.Black;
    public Color BackgroundColor = new Color(63, 82, 151) * 0.7f;
}
```

In this way, we can obtain a given class for a particular element and change all its fields at any time:

```csharp
UIExElement element = new();

StyleVisualElement styleDisplay = element.StyleDisplay;
StyleTmlUIPanel styleTmlUIPanel = styleDisplay.TmlUIPanel();

styleTmlUIPanel.CornerSize = 15;
styleTmlUIPanel.BarSize = 15;

styleTmlUIPanel.BorderTexture = TextureAssets.MagicPixel;
styleTmlUIPanel.BackgroundTexture = TextureAssets.MagicPixel;

styleTmlUIPanel.BorderColor = Color.White;
styleTmlUIPanel.BackgroundColor = Color.Red;
```

<h2 align="center">Field. <code>PaddingAutoControl</code></h2>

This field indicates whether or not the `UIExElement` self-manage `PaddingLeft`, `PaddingTop`, `PaddingRight`, `PaddingBottom`.<br>
If the value `true`These values will be automatically recalculated along with the style changes (by default: true).
