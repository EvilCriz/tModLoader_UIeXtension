**Example of using the mod-library: UIeXtension.**

**About the UIeXtension mod:**

UI Library.

The library is currently unfinished and provides the following container layouts:
Canvas (extended), StackPanel, WrapPanel, DockPanel, Grid, and UniformGrid.

Alpha. The library has not been thoroughly tested yet.

Contains a GitHub page with:

* Source code (with comments).
* A detailed tutorial.
* The source code of the example mod `ExampleModUIeXtension`.
* Documentation will be added in the future.

Reference: https://github.com/EvilCriz/tModLoader_UIeXtension/blob/main/README.md

The source code with comments and the tutorial have been translated into English, Ukrainian, and Russian.
Once the documentation has been added, it will also be translated into all three languages.
