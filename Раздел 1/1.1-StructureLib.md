  Создавая данную библиотеку я ставил перед собой следующие задачи:


1.	Добавить элементы компоновки, которые используются в самых современных UI: StackPanel, FlexPanel, DockPanel, WrapPanel, Grid, GridUniform.

2.	Добавить инструменты для повышения оптимизации пользовательского интерфейса (которые невозможно автоматизировать в связи с ограничениями движка tModLoader, об этом будет отдельная глава в разделе, посвященному элементам компоновки).

3.	Добавить аналог каждого UIElement tModLoader, но с полностью обновленными инструментами для редактирования стилей.

4.	Создание системы стилей, которые пользователь может задавать с помощью отдельных классов. Задача стояла создать такую систему, чтобы пользователь для каждого элемента был свой класс стилей, где определены только те, которые может использовать конкретный объект UIElement.



Все классы данной библиотеки начинаются с префикса «UIEx»: UIExElement, UIExLayout и т.д.
·	UIExElement – является базовым классом для всех элементов данной библиотеки (кроме UIExModSystem, о котором будет речь позже). Сам элемент является дочерним классом UIElement tModLoader.
·	UIExLayout – является базовым классом для всех элементов компоновки данной библиотеки.


Раздел 1: Введение
1.	В части 1.1 написано очень краткое содержание о том, что представляет из себя сама библиотеке.
2.	В части 1.3 описан вспомогательный класс UIExModSystem, который можно полностью игнорировать в рамках данной библиотеки. Задача данного класса – сократить базовую реализацию ModSystem для написания пользовательского интерфейса – до одной строки.
3.	В части 1.4 описана структура стилей. У стилей не будет в данном руководстве отдельного раздела. Каждый стиль привязан к определенному UIEx-элементу и будет рассматриваться вместе с данным элементом.
Например: Элемент компоновки UIExStackPanel содержит в себе стиль компоновки StyleLayoutContainerStackPanel, а вложенные в него элементы будут использовать стиль StyleLayoutChildStackPanel. В части, посвященной UIExStackPanel будет описан как сам элемент, так и эти два класса стилей.
4.	В части 1.5 будет описана ресурсам для дополнительной информацию по данной библиотеке.

Раздел 2: Элементы компоновки
1.	В части 2.1 будет описан базовый класс для элементов компоновки UIExLayout и класс стиля, который будут определять все элементы компоновки, а так же вложенные в них элементы стилей: StyleLayoutContainer, StyleLayoutChild.
2.	Каждая следующая (кроме последней) часть раздела 2 посвящена отдельно каждому элементу компоновки и его стилям.
