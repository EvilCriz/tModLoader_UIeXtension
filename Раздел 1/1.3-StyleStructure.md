<h1 align="center">Структура стилей</h1>

Стили в данной библиотеке делятся на 3 вида:
1. Стили визуального отображения.
2. Стили компоновки контейнера.
3. Стили компоновки отдельного элемента.

<br>

- **Стили визуального отображения** - это все стили, которые отвечают всю визуальную часть, кроме расположения элемента (цвет, форма, обводка и т.п.).

<br>

- **Стили компоновки контейнера** - это все стили, которые используют только компоновщики элементов (*UIExStackPanel*, *UIExDockPanel*, *UIExGrid* и т.п.). Они содержат общие правила о том, как располагать элементы внутри себя.

<br>

- **Стили компоновки отдельного элемента** - это все стили, которые использует компоновщик элементов, по отношению к отдельному *UIElement*. Более подробно это будет разбираться в разделе, посвященному компоновке элементов.

----

В данной статье не будут рассматриваться отдельные классы стилей. Каждый подобный класс связан со своим `UIExElement` (`UIExLayout` для стилей компоновки) и будут рассматриваться совместно с этими элементами в следующих разделах.

----

Самая сложная часть данной библиотеки - это разобраться в том, как же структурированы стили. Сложность связана с тем, что стили для разных элементов разделены по разным классам. 
Например, класс `UIExStackPanel` будет иметь у себя сразу два стиля компоновки: класса `StyleLayoutContainer` и класса `StyleLayoutContainerStackPanel`.

```csharp
UIExStackPanel stackPanel = new UIExStackPanel();
stackPanel.StyleLayout.ShowLyaoutLines = true;
stackPanel.StyleLayoutStackPanel.Orientation = Enums.Orientation.Horizontal;
```
Как видно в данном примере, используются два разных поля у объекта `stackPanel`:
- Поле `StyleLayout` и имеет тип `StyleLayoutContainer` и определено у базового класса UIExLayout.
- Поле `StyleLayoutStackPanel` и имеет тип `StyleLayoutContainerStackPanel` и определено в самом классе UIExElement.
Таким образом у каждого элемента есть свой стиль (если он его определяет) и все стили базовых классов (если они их определяют).

----

Я думаю, вы уже понимаете, в чем сложность. Есть 3 типа стилей, каждых может быть по несколько штук. Как вообще определить, сколько стилей как класс определяет? Какой тип данных у каждого из них? Как называется поле внутри `UIExElement`/`UIExLayout`?

Попытаемся выстроить систему. Начнем с `UIExElement` и всех его дочерних элементов, которые **НЕ** являются элементами компоновки.
Тут все становится сразу проще, так как таких элементов только 1 тип стилей: **стили визуального отображения**.
