IsLastLayoutInfoChanged()

Определяет, требуется ли перекомпоновка элементам.

Declaration
protected bool IsLastLayoutInfoChanged()
Returns
Type Description
bool
Remarks

В tModLoader Terraria.UI.UIElement.Recalculate вызывается всей UI-ветки элементов каждый кадр. Алгоритмы компоновки срабатывают при Terraria.UI.UIElement.Recalculate и ялвяются затратными по ресурсам. Данный метод проверяет:

Изменились размеры самого компоновщика

Изменились дочерние элементы

Изменились ли размеры дочерних элементов

Игнорирует все эти проверки, если UIeXtension.UIExLayout._ignoreLastLayoutInfo == true. Значние данного флага true при первом вызове Terraria.UI.UIElement.Recalculate и при вызове метода EndLayoutPreparation(UIState). После каждой компоновки данный флаг сбрасывается до значения false

Данная информация обновляется после компоновки (если она была) в UpdateLastLayoutInfo()

RecalculateLayout()

Определяет жизненый цикл перерасчета компоновки дочерних элементов

Declaration
protected virtual void RecalculateLayout()
Remarks

Не рекомендуется переопредлять данный метод и вмешиваться в жизненный цикл компоновки без острой необходимости. Вызывается сразу после Terraria.UI.UIElement.Recalculate (который вызывает Terraria.UI.UIElement.RemoveAllChildren). Сперва перерасчитываются размеры текущего UIExLayout, затем перерасчитываются дочерних элементов, затем вызывается данный метод. Подробнее смотрите в описании самого флага и методов BeginLayoutPreparation(UIState) и EndLayoutPreparation(UIState)
