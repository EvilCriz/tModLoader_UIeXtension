<h1 align="center">Создание библиотеки</h1>

----

- Это версия библиотеки в первом ее выпуске.<br>
- Библиотеки находится на стадии Alpha-разработки.<br>
- Все инструменты продолжают тестироваться.

----

При выпуске в библиотеку добавлены:

1. Вспомогательный класс `UIExSystem`.
2. UI-элемент: `UIExElement`.
3. Контейнеры компоновки:
   - `UIExLayout`;
   - `UIExCanvas`;
   - `UIExStackPanel`;
   - `UIExWrapPanel`;
   - `UIExDockPanel`;
   - `UIExGrid`;
   - `UIExUniformGrid`;
