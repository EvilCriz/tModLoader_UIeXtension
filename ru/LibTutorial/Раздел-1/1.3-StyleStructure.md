<h1 align="center">Структура стилей</h1>

Стили в данной библиотеке делятся на 4 вида:
1. Стили визуального отображения.
2. Визуальные стили элементов от **tModLoader**
3. Стили компоновки контейнера.
4. Стили компоновки отдельного элемента.

----

- **Стили визуального отображения** — это все стили, которые отвечают за всю визуальную часть, кроме расположения элемента (цвет, форма, обводка и т. п.).

----

- **Визуальные стили элементов от tModLoader** - это стили, которые позволяют задавать параметры стиля базовых элементов **tModLoader**.<br><br>

В данном пункте требуется уточнение.<br>
Любой элемент в данной библиотеки может принимать визуальный стиль данной библиотеки (см. предыдущий пункт) или стиль элемента **tModLoader**.<br>
Например: элемент `UIExElement` может принять визуальный стиль `UIPanel`.<br>
Подробнее ниже.

----

- **Стили компоновки контейнера** — это все стили, которые используют только компоновщики элементов (*UIExStackPanel*, *UIExDockPanel*, *UIExGrid* и т. п.). Они содержат общие правила о том, как располагать элементы внутри себя.

----

- **Стили компоновки отдельного элемента** — это все стили, которые использует компоновщик элементов по отношению к отдельному *UIElement*. Более подробно это будет разбираться в разделе, посвящeнном компоновке элементов.

----

В данной статье не будут рассматриваться отдельные классы стилей. Каждый подобный класс связан со своим `UIExElement` (`UIExLayout` для стилей компоновки) и будет рассматриваться совместно с этими элементами в следующих разделах.

----

<h2 align="center"><b>Стили визуального отображения</b></h2>

**ВАЖНО!** Библиотека находится в разработке.<br>
В данном блоке о **стилях визуального отображения** приведена информация для понимания общей системы стилей.<br>
В данный момент в библиотеке есть только контейнеры компоновок (о них ниже) и `UIExElement`.<br><br>

`UIExElement` хранит в себе поле:
```csharp
public class UIExElement : UIElement
{
  public Styles.StyleVisualElement StyleDisplay;
}
```
Соответственно, данное поле наследуется всеми элементами данной библиотеки.<br>
Визуальные стили для **любого** элемента будут задаваться через данное поле.


Класс `StyleVisualElement` хранит в себе стили всех `UIExElement` и методы, возвращающие стили любых классов наследников `UIExElement`.<br>
Например, есть классы (приведено для примера; в разработке):
```csharp
public class UIExButton : UIExElement {}
public class UIExTextBlock : UIExButton {}
```
<br>

В этом случае в библиотеке будут соответствующие классы стилей:
```csharp
public class StyleVisualButton {}
public class StyleVisualTextBlock {}
```
<br>

А класс `StyleVisualElement` будет иметь следующие методы:
```csharp
public class StyleVisualElement
{
    public StyleVisualButton Button() { /* ... */ }
    public StyleVisualTextBlock TextBlock() { /* ... */ }
}
```
<br>

Теперь мы можем получать стили следующим образом:
```csharp
UIExElement element = new();
UIExButton button = new();
UIExTextBlock textBlock = new();

StyleVisualElement elementStyleDisplay = element.StyleDisplay;
StyleVisualElement buttonStyleDisplay = button.StyleDisplay;
StyleVisualElement textBlockStyleDisplay = textBlock.StyleDisplay;

StyleVisualButton buttonStyle = buttonStyleDisplay.Button();

StyleVisualTextBlock textBlockStyle = textBlockStyleDisplay.TextBlock();
```
<br>

<h2 align="center"><b>Визуальные стили элементов от tModLoader</b></h2>

Вместо использования **стилей визуального отображения** данной библиотеки, вы можете указать элементу, что он должен использовать стиль определенного (элемент решает сам, какого именно) элемента **tModLoader**.<br>
Для этого в поле `StyleDisplay` нужно задать значение `tModLoaderStyle = true`.
```csharp
UIExElement element = new();
element.StyleDisplay.tModLoaderStyle = true;
```

Каждый элемент сам решает, стиль какого элемента **tModLoader** ему использовать.<br>
`UIExElement` и любой элемент компоновки в этом случае будет использовать стиль `UIPanel`.<br>
- Данная библиотека находится в разработке. На сегодняшний день других элементов нет.<br><br>

Вы можете получить класс базового стиля и изменять его значения.<br>
```csharp
UIExElement element = new();

element.StyleDisplay.tModLoaderStyle = true;

StyleTmlUIPanel styleTmlUIPanel =  element.StyleDisplay.TmlUIPanel();
styleTmlUIPanel.BackgroundColor = Color.Red;
```

В данном примере созданный `UIExElement` будет выглядеть как `UIPanel`, но при этом обводка будет красного цвета.<br>

Названия класса стиля и метода:
- Название класс начинается к `StyleTml`, а далее: название элемента **tModLoader** соответствующего стиля.
- Название метода начинает с `Tml`, а далее: название элемента **tModLoader** соответствующего стиля.

<h2 align="center">Стили компоновки контейнера</h2>

Хранение и получение стилей компоновки контейнера идентичны **стилям визуального отображения**<br>
Класс `UIExLayout` (который наследуют все контейнеры) содержит поле:
```csharp
class UIExLayout : UIExElement
{
    public StyleLayoutContainer StyleLayout
}
```
<br>

Класс `StyleLayoutContainer` по аналогии со `StyleVisualElement` хранит в себе методы, которые возвращают стили компоновки контейнеров классов наследников:
```csharp
// используется для примера. В реальности данный UIExLayout абстрактный.
UIExLayout layout = new();
UIExCanvas canvas = new();
UIExStackPanel stackPanel = new();

StyleLayoutContainer styleLayout = layout.StyleLayout;
StyleLayoutContainer styleLayoutCanvas = canvas.StyleLayout;
StyleLayoutContainer styleLayoutStackPanel = stackPanel.StyleLayout;

StyleLayoutContainerCanvas styleCanvas = styleLayoutCanvas.Canvas();
StyleLayoutContainerStackPanel styleStackPanel = styleLayoutCanvas.StackPanel();
```

----

<h2 align="center">Стили компоновки отдельного элемента</h2>

Тут система очень похожа. Но, в отличие от предыдущих примеров, стиль компоновки отдельного элемента может иметь любой `UIElement` в **tModLoader**.<br>
Поэтому получение этих стилей происходит с помощью метода расширения `UIElement.StyleLayoutChild()`
```csharp
UIElement element = new();
StyleLayoutChild styleLayout = element.StyleLayoutChild();
StyleLayoutChildCanvas styleLayoutCanvas = styleLayout.Canvas();
```
<br>

Закономерность между названием стилей компоновки контейнера и отдельных элементов:
- `UIExLayout` - `StyleLayoutContainer` - `StyleLayoutChild`
- `UIExCanvas` - `StyleLayoutContainerCanvas` - `StyleLayoutChildCanvas`
- `UIExStackPanel` - `StyleLayoutContainerStackPanel` - `StyleLayoutChildStackPanel`<br>

Как видно, названия классов начинаются со `StyleLayout` — далее идeт `Container/Child` — далее название контейнера компоновки (кроме `UIExLayout`).

<h2 align="center">Дополнительная информация</h2>

Все классы стилей являются наследниками класса `StyleBase`.<br>
У данного класса есть только 1 публичный метод.
```csharp
public bool EqualsStylesFields(StyleBase other) { /* ... */ }
```
Данный метод проверяет, совпадают ли все поля всех переданных стилей.<br>
Например:
```csharp
StyleLayoutChildCanvas styleCanvas = new();
StyleLayoutContainer style1 = new();
StyleLayoutContainer style2 = new();


//////////////////

// [1]: метод вернет false
style1.EqualsStylesFields(styleCanvas);


//////////////////

// [2]: метод вернет true
style1.EqualsStylesFields(style2);


//////////////////

style1.JustifyContent = UIExAlignment.Center;

// [3]: метод вернет false
style1.EqualsStylesFields(style2);


//////////////////

style2.JustifyContent = UIExAlignment.Center;

// [4]: метод вернет true
style1.EqualsStylesFields(style2);


//////////////////

style1.UniformGrid();

// [5]: метод вернет false
style1.EqualsStylesFields(style2);


//////////////////

style2.UniformGrid();

// [6]: метод вернет true
style1.EqualsStylesFields(style2);


//////////////////

style2.UniformGrid().ColumnsCount = 5;

// [7]: метод вернет false
style1.EqualsStylesFields(style2);
```

Результаты вызовов `EqualsStylesFields`:
1. Сравниваются два разных класса стилей. Возвращает `false`.
2. Сравниваются два стиля с полями по умолчанию. Возвращает `true`.
3. У `style1` значение `JustifyContent` изменилось. У `style2` - не изменилось. Поля стилей отличаются. Возвращает `false`.
4. У `style2` значение `JustifyContent` изменилось на идентичное `style1`. Поля стилей не отличаются. Возвращает `true`.
5. Для `style1` зарегистрирован стиль `StyleLayoutContainerUniformGrid`. Для `style2` - не зарегистрирован. Возвращает `false`.
6. Для `style2` зарегистрирован стиль `StyleLayoutContainerUniformGrid`. Для `style1` данный стиль зарегистрирован ранее. Возвращает `true`.
7. Значение поля `ColumnsCount` для зарегистрированного стиля `StyleLayoutContainerUniformGrid` `style2` изменилось. Данные поля у стилей не совпадает. Возвращает `false`.

----

Все классы стилей содержат 2 конструктора:
1. По умолчанию.
2. Принимающий все значения для полей данного класса стиля (не указанные принимают значение по умолчанию).

----

Все классы стилей содержат публичные методы по шаблону ниже:
```csharp
/*

public void Set(
	type CLASS_PROPERTY_1 = default(type), 
	type CLASS_PROPERTY_2 = default(type), 
	..., 
	type CLASS_PROPERTY_N = default(type))
		=> SetAllFields(
			CLASS_PROPERTY_1, 
			CLASS_PROPERTY_2, 
			..., 
			CLASS_PROPERTY_N);



public void Copy(TYPE_STYLE style)
    => SetAllFields(
			style.CLASS_PROPERTY_1, 
			style.CLASS_PROPERTY_2, 
			..., 
			style.CLASS_PROPERTY_N);

public TYPE_STYLE GetCopy()
    => GetCopyBase<TYPE_STYLE>();

*/
```

1. Метод `Set` принимает в себя все значения полей, которые содержит данный стиль (не указанные принимают значения по умолчанию).
2. Метод `Copy` принимает в себя аналогичный стиль и копирует все поля переданного стиля.
3. Метод `GetCopy` возвращает новый объект стиля с копией всех полей класса (в том числе хранящий копии зарегистрированных стилей).

----

1. **Стили визуального отображения** наследуют класс: `StyleVisualElementBase`.
2. **Стили компоновки контейнера** наследуют класс: `StyleLayoutContainerBase`.
3. **Стили компоновки вложенных элементов** наследуют класс: `StyleLayoutChildBase`.<br>
