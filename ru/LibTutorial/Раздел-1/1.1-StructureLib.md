<h1 align="center">Структура библиотеки</h1>

Создавая данную библиотеку я ставил перед собой следующие задачи:

1.	Добавить элементы компоновки, которые используются в самых современных *UI*: `StackPanel`, `WrapPanel`, `DockPanel`, `Grid`, `GridUniform`, `FlexBox`.
2.	Добавить инструменты для повышения оптимизации пользовательского интерфейса (которые невозможно автоматизировать в связи с ограничениями движка **tModLoader**, об этом будет отдельная глава в разделе, посвященному элементам компоновки).
3.	Добавить аналог каждого `UIElement` **tModLoader**, но с полностью обновленными инструментами для редактирования стилей.
4.	Создание системы стилей, которые пользователь может задавать с помощью отдельных классов. Задача стояла создать такую систему, чтобы для каждого элемента был свой класс стилей, в котором определены только те поля, которые может использовать конкретный объект `UIElement`.<br>

**ВАЖНО!** В данный момент библиотека находится в разработке. На сегодняшний день она реализует только элементы компоновки: `UIExCanvas`, `UIExStackPanel`, `UIExWrapPanel`, `UIExDockPanel`, `UIExGrid`, `UIExUniformGrid`.<br>
Визуальные элементы будут добавляться позже по мере разработки.

----

- Данная библиотека предполагает, что вы уже изучили [базовое руководство tModLoader по пользовательскому интерфейсу](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Данная библиотека предполагает, что вы уже изучили [расширенное руководство по настройке пользовательского интерфейса](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>

----

Все классы UI-элементов данной библиотеки начинаются с префикса «`UIEx`»: `UIExElement`, `UIExLayout` и т.д. (а так же класс `UIExModSytem`, о котором будет речь позже).
-	`UIExElement` – является базовым классом для всех UI-элементов данной библиотеки. Сам элемент является дочерним классом `UIElement` **tModLoader**.
-	`UIExLayout` – является базовым классом для всех UI-элементов компоновки данной библиотеки.

----

<ins>Раздел 1</ins>: Введение
1.	В **этой части** написано очень краткое содержание о том, что представляет собой сама библиотека.
2.	В **части 2** описан вспомогательный класс `UIExModSystem`, который можно полностью игнорировать в рамках данной библиотеки. Задача данного класса – сократить базовую реализацию **ModSystem** для написания пользовательского интерфейса – до одной строки.
3.	В **части 3** описана структура стилей. У стилей не будет в данном руководстве отдельного раздела. Каждый стиль привязан к определенному UIEx-элементу и будет рассматриваться вместе с данным элементом.
Например: Элемент компоновки `UIExStackPanel` содержит в себе стиль компоновки `StyleLayoutContainerStackPanel`, а вложенные в него элементы будут использовать стиль `StyleLayoutChildStackPanel`. В части, посвященной `UIExStackPanel` будет описан как сам элемент, так и эти два класса стилей.

<ins>Раздел 2</ins>: Элементы компоновки
1.	В **части 1** будет описан базовый класс для элементов компоновки `UIExLayout` и класс стиля, который будут определять все элементы компоновки, а так же вложенные в них элементы стилей: `StyleLayoutContainer`, `StyleLayoutChild`.
2.	Каждая следующая (кроме последних трех) **часть** <ins>раздела 2</ins> посвящена отдельно каждому элементу компоновки и его стилям. Одна часть - 1 элемент и 2 класса стилей.
3.	Следующая **часть** <ins>раздела 2</ins> будет посвящена инструментам оптимизации.
4.	Следующая **часть** <ins>раздела 2</ins> будет посвящена жизненному циклу компоновки, реализованному в `UIExLayout`.
5.	Следующая **часть** <ins>раздела 2</ins> будет посвящена рекомендациям по созданию пользовательского класса компоновки на основе данной библиотеки.

ВАЖНО!!! Данная сноска будет появляться на протяжении всего <ins>2-го раздела</ins>: не начинайте использовать элементы компоновки до того, как ознакомитесь с информацией по оптимизации. В связи с ограничениями **tModLoader** в данной библиотеке часть инструментов оптимизации пришлось отдать ее конечному пользователю. Использование данных инструментов может повысить производительность UI в тысячи раз (в зависимости от масштаба вашего интерфейса).

<ins>Раздел 3</ins>: Новые Элементы интерфейса с системой стилей `UIeXtension`. (**В РАЗРАБОТКЕ**)
1.	<ins>3 раздел</ins> описывает аналоги UI-элементов **tModLoader** использующие систему стилей данной библиотеки. Одна часть - 1 UI-элемент и 1 или 2 класса стиля.
