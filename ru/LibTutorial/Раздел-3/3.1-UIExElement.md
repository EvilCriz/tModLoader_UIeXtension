<h1 align="center">Класс <code>UIExElement</code></h1>

----

- Данная библиотека предполагает, что вы уже изучили [базовое руководство tModLoader по пользовательскому интерфейсу](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Данная библиотека предполагает, что вы уже изучили [расширенное руководство по настройке пользовательского интерфейса](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>
- Данная статья предполагает, что вы изучили статью: [«структура стилей»](../Раздел-1/1.3-StyleStructure.md)

----
<br>

----

`UIExElement` - это базовый UI-элемент для всех прочих UI-элементов данной библиотеки.<br><br>

Он является аналогом `UIElement`, но может принимать визуальный стиль `UIPanel`.

----

На сегодняшний день данный класс не завершен.<br>
На данном этапе развития библиотеки в ней, в основном, созданы лишь элементы компоновки, которым был посвящен последний раздел.

----

Отличие `UIExElement` от `UIElement` состоит в том, что данный класс определяет свои **стили визуального отображения**.<br>
Они могут быть получены с помощью поля:
```csharp
public Styles.StyleVisualElement StyleDisplay;
```

На сегодняшний день класс `StyleVisualElement` содержит только два поля:
```csharp
public partial class StyleVisualElement : Base.StyleVisualBase
{
    public bool tModLoaderStyle = false;
	public bool PaddingAutoControl = true;
}
```

----

<h2 align="center">Поле <code>tModLoaderStyle</code></h2>

Данное поле определяет, будет ли конкретный элемент использовать **стили визуального отображения**: 
1. Данной библиотеки (которые на сегодняшний день не существуют).
2. Или будет использовать один из визуального стиль от **tModLoader**.<br>

Какой конкретно стиль брать **tModLoader** зависит от конкретного элемента.<br>
`UIExElement` (и все элементы компоновки) используют стиль `UIPanel`.<br><br>

То есть, следующие три кода будут идентичны по своей визуальной части:
```csharp
UIPanel panel = new();

panel.HAlign = 0.5f;
panel.VAlign = 0.5f;
panel.Width.Set(0f, 0.8f);
panel.Height.Set(0f, 0.8f);

Append(panel);
```

```csharp
UIExElement element = new();

element.HAlign = 0.5f;
element.VAlign = 0.5f;
element.Width.Set(0f, 0.8f);
element.Height.Set(0f, 0.8f);

element.StyleDisplay.tModLoaderStyle = true;

Append(element);
```

```csharp
UIExCanvas canvas = new();

canvas.HAlign = 0.5f;
canvas.VAlign = 0.5f;
canvas.Width.Set(0f, 0.8f);
canvas.Height.Set(0f, 0.8f);

canvas.StyleDisplay.tModLoaderStyle = true;

Append(canvas);
```

----

Данная библиотека отдает полное управление стилями во вне класса.<br>
Например: `UIPanel` **tModLoader** дает следующий доступ к управлению стилем:
```csharp
public class UIPanel : UIElement
{
	private int _cornerSize = 12;
	private int _barSize = 4;
	private Asset<Texture2D> _borderTexture;
	private Asset<Texture2D> _backgroundTexture;
	
	public Color BorderColor = Color.Black;
	public Color BackgroundColor = new Color(63, 82, 151) * 0.7f;

	public UIPanel(Asset<Texture2D> customBackground, Asset<Texture2D> customborder, int customCornerSize = 12, int customBarSize = 4)
	{ /* ... */ }
}
```

Как видно в коде выше, `UIPanel` позволяет установить все значения в конструкторе, но динамически изменять можно только поля `BorderColor` и `BackgroundColor`.<br><br>

В свою очередь данная библиотека позволяет изменить значение любого из данный полей в любое время.<br>
Для этого сперва требуется получить базовый стиль для конкретного элемента.<br>
Для `UIExElement` это стиль определенный классом `StyleTmlUIPanel` (для прочих элементов нужные классы будут написаны отдельно, по мере их добавления в библиотеку).<br><br>

Реализация класса `StyleTmlUIPanel`:
```csharp
public class StyleTmlUIPanel : Base.StyleTmlBase
{
    public int CornerSize = 12;
    public int BarSize = 4;
 
	public Asset<Texture2D> BorderTexture;
    public Asset<Texture2D> BackgroundTexture;
    
	public Color BorderColor = Color.Black;
    public Color BackgroundColor = new Color(63, 82, 151) * 0.7f;
}
```

Таким образом мы можем получить данный класс для конкретного элемента и в любое время изменять все его поля:

```csharp
UIExElement element = new();

StyleVisualElement styleDisplay = element.StyleDisplay;
StyleTmlUIPanel styleTmlUIPanel = styleDisplay.TmlUIPanel();

styleTmlUIPanel.CornerSize = 15;
styleTmlUIPanel.BarSize = 15;

styleTmlUIPanel.BorderTexture = TextureAssets.MagicPixel;
styleTmlUIPanel.BackgroundTexture = TextureAssets.MagicPixel;

styleTmlUIPanel.BorderColor = Color.White;
styleTmlUIPanel.BackgroundColor = Color.Red;
```

----

<h2 align="center">Поле <code>PaddingAutoControl</code></h2>

Данное поле указывает на то, должен ли `UIExElement` автоматически управлять значениями `PaddingLeft`, `PaddingTop`, `PaddingRight`, `PaddingBottom`.<br>
Если данное значение `true`, то эти значения будут автоматически пересчитываться вместе с изменениями стиля (по умолчанию: true).
