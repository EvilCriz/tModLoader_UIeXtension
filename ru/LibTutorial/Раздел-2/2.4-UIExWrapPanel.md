<h1 align="center">Класс <code>UIExWrapPanel</code></h1>

----

- Данная библиотека предполагает, что вы уже изучили [базовое руководство tModLoader по пользовательскому интерфейсу](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Данная библиотека предполагает, что вы уже изучили [расширенное руководство по настройке пользовательского интерфейса](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>
- Данная статья предполагает, что вы изучили статью: [«структура стилей»](../Раздел-1/1.3-StyleStructure.md)
- Данная статья предполагает, что вы изучили статью: [«класс UIExLayout. Основы компоновки»](2.1-UIExLayout.md)
- Данная статья предполагает, что вы изучили статью: [«класс UIExStackPanel»](2.3-UIExStackPanel.md)

----
<br>

----

`UIExWrapPanel` - это контейнер компоновки, который располагает дочерние элементы в одну строку (или колонку) и автоматически переносит их на новую строку, если они не помещаются в текущую область.<br>

Данный контейнер фактически является усложненной версией `UIExStackPanel`.<br>
Данная статья будет повторять предыдущую в очень сокращенном виде, и предполагая, что вы с ней уже ознакомлены.<br>

----

Перенос элементов происходит, когда следующий элемент не помещается в строку. Например:<br>
- Контейнер шириной `300px` и горизонтальной ориентацией.
- Пространство между элементами: `50px`.
- В контейнер последовательно вложены элементы шириной: `200px`, `50px`, `100px`.<br>
<!-- -->
В результате мы получим следующую цепочку:
1. Элемент шириной `200px` поместился в контейнер.
2. `50px` занимает пространство между элементов `0` и `1`.
3. Элемент шириной `50px` поместился в контейнер. (итого, занятая ширина: `300px`).
4. В строке закончилось свободное пространство, следующий элемент будет располагаться ниже.<br>

Смещение последнего элемента (по поперечной оси) будет определено размером прошлой строки + установленным пространством между строками (об этом ниже).<br>

1. Размер линии по главной оси занимает весь доступный размер контейнера по главной оси.
2. Размер линии по поперечной оси определяется размером самого большого элемента линии по поперечной оси.
3. Размер линий определяется **ДО** того, как элемент будет растянут (`Enums.UIExAlignment.Stretch`).<br>
<!-- -->
Ниже вы узнаете, что элементы могут быть инвертированы.<br>
Инверсия элементов происходит **ДО** расчета линий и компоновщики элемента внутри них.

----

После того как линии сформированы, в каждой из них по отдельности элементы сортируются аналогично `UIExStackPanel.`<br>
Но в этом случае используется другой класс стилей.

----

Базовый стиль компоновки элементов `StyleLayoutContainer`:
```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    public Enums.UIExOrientation Orientation = Enums.UIExOrientation.Vertical;
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
}
```
- `Orientation`: определяет главную ось контейнера, по которой будут выравниваться элементы (внутри линий).
- `JustifyContent`: выравнивание элементов по главной оси (внутри уже сформированных линий).
- `AlignItems`: выравнивание элементов по поперечной оси (внутри уже сформированных линий).

----

Типы выравнивания:

```csharp
public enum UIExAlignment : byte
{
    Auto,
    Start,
    Center,
    End,
    Stretch
}
```
- `Auto`: аналогично `Start`. Используется у вложенных в контейнер элементов.
- `Start`: выравнивание элементов по старту оси (верх/лево).
- `Center`: выравнивание элементов по центру оси.
- `End`: выравнивание элементов по концу оси (низ/право).
- `Stretch`: растягивание элемента по всей оси (за вычетом Margin).

----

Базовые стили дочерних элементов `StyleLayoutChild`:
```csharp
public partial class StyleLayoutChild : Base.StyleLayoutChildBase
{
    public Enums.UIExAlignment JustifySelf = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignSelf = Enums.UIExAlignment.Auto;
    public UIExThickness Margin = new();
    public StyleDimension Width = default(StyleDimension);
    public StyleDimension Height = default(StyleDimension);
}
```
- Поле `JustifySelf` переопределяет значение `JustifyContent` контейнера для конкретного вложенного элемента. У дочерних элементов игнорирует любые значения, кроме значения `Stretch`.
- Поле `AlignSelf` переопределяет значение `AlignItems` контейнера для конкретного вложенного элемента.
- Поле `Margin` работает полноценно.
- Поля `Width` и `Height` подробно разбирались в первой статье данного раздела.

----

Для класса `UIExWrapPanel` используется класс стилей: `StyleLayoutContainerWrapPanel`, который хранит все стили компоновки для данного класса.
```csharp
public class StyleLayoutContainerWrapPanel : Base.StyleLayoutContainerBase
{
    public StyleDimension SpacingWithinLine = StyleDimension.Empty;
    public StyleDimension SpacingBetweenLines = StyleDimension.Empty;
	
    public Enums.UIExAlignment AlignLines = Enums.UIExAlignment.Auto;
	
    public bool ReverseWithinLine = false;
    public bool ReverseAll = false;
}
```

- `SpacingWithinLine`: определяет отступ между элементами внутри линий (работает аналогично `Spacing` контейнера `UIExStackPanel`).
- `SpacingBetweenLines`: определяет отступ между линиями.
- `AlignLines`: определяет выравнивание всех линий по поперечной оси.
- `ReverseWithinLine`: если данное значение `true` - элементы внутри каждой линии будет располагаться в реверсивном порядке.
- `ReverseAll`: если данное значение `true` - все элементы будет располагаться в реверсивном порядке (и будет реверсированы еще до начала компоновки).<br>
<!-- -->
- `ReverseWithinLine` и `ReverseAll` могут реверсировать одновременно. В этом случае до компоновки сработает `ReverseAll`, а внутри линий будут реверсированы элементы отдельно.

----

**НЕ РЕАЛИЗУЕТ** свой класс стиля для дочерних элементов.

----

Базовые стили компоновки контейнера содержатся в поле `StyleLayout`.
Для получения стилей компоновки `UIExWrapPanel` используйте метод `WrapPanel()` у поля StyleLayout.
Для получения базовых стилей для вложенных в контейнер элементов используйте метод расширения`UIElement`: `StyleLayoutChild()`.
```csharp
UIExWrapPanel wrapPanel = new();

StyleLayoutContainer style = wrapPanel.StyleLayout;
StyleLayoutContainerWrapPanel styleWrapPanel = stackPanel.StyleLayout.WrapPanel(); // или style.WrapPanel();

UIElement element = new();
StyleLayoutChild styleChild = element.StyleLayoutChild();

style.JustifyContent = UIExAlignment.Center;
styleWrapPanel.ReverseAll = true;

styleChild.JustifySelf = UIExAlignment.Stretch;
```

```csharp
using Microsoft.Xna.Framework;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.MethodsExtensions;
using UIeXtension.Styles;

namespace UIeXtensionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // метод OnActivate() в данном случае используется только
    // для функции «горячей перезагрузки кода» в среде разработки.
    // для реального интерфейса правильнее было бы использовать
    // метод OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 450f, panel);

        UIExWrapPanel wrapPanel = new();
        wrapPanel.Stretch();

        wrapPanel.SetLayoutLinesInfoForBranch(
            state: true,
            thickness: 3f,
            color: Color.DarkOrange);

        ////////////////////////////

        StyleLayoutContainer styleLayout = wrapPanel.StyleLayout;
        StyleLayoutContainerWrapPanel styleLayoutWrap = styleLayout.WrapPanel();

        styleLayout.Set(
            orientation: UIExOrientation.Horizontal,
            justifyContent: UIExAlignment.Center,
            alignItems: UIExAlignment.Center);

        styleLayoutWrap.Set(
            spacingWithinLine: StyleDimension.FromPixels(10f),
            spacingBetweenLines: StyleDimension.FromPixels(15f),
            alignLines: UIExAlignment.Center,
			// на изображениях 4 варианта комбинации этих двух значений
            reverseWithinLine: true,
            reverseAll: true); //

        ///////////////////////////

        AddPixelButton(wrapPanel, prefix: 0, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 1, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 2, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 3, width: 200f, height: 200f);

        ///////////////////////////

        panel.Append(wrapPanel);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AddPixelButton(UIExLayout layout, int prefix, float width, float height)
        => AddPixelButton(layout, prefix.ToString(), width, height);
    public UIButton<string> AddPixelButton(UIExLayout layout, string prefix, float width, float height)
    {
        UIButton<string> button = new($"{prefix}");
        StyleLayoutChild style = button.StyleLayoutChild();
        style.Width.Pixels = width;
        style.Height.Pixels = height;
        layout.Append(button);
        return button;
    }
}
```

using UIeXtension.Enums;
using UIeXtension.MethodsExtensions;

namespace UIeXtensionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

        AppendButton(wrapPanel, prefix: "RESULT:");

        AppendButton(wrapPanel, prefix: "AC");
        AppendButton(wrapPanel, prefix: "%");
        AppendButton(wrapPanel, prefix: "<<");
        AppendButton(wrapPanel, prefix: "/");

        AppendButton(wrapPanel, prefix: 7);
        AppendButton(wrapPanel, prefix: 8);

    {
        UIButton<string> button = new(prefix);
        layout.Append(button);
        return button;
    }

Стили компоновки будут:
- Вертикальное расположение элементов.
- Центрирование элементов по всем осям внутри линий.
- Отступ между элементами внутри линий: `10px`.
- Отступ между линиями: `15px`.
- Линии будут центрированы.
- Все элементы будут располагаться в том порядке, в каком они добавлены в контейнер.<br>

Добавление элементов.
- Элементы начинаются с верхнего-левого (в данном случае - это просто левый элемент с надписью `RESULT`).
- Все следующее элементы располагаются левее предыдущего и переносятся на следующую строку при необходимости.
- Изначальное смещение элементов по `Top`, `Left` не имеет значения и игнорируется компоновщиком.

Прежде, чем начнем разбирать данную часть кода, нужно прояснить:
- Макет содержит 6 линий в каждой из которых (кроме 2-х) по 4 элемента.
- Элемент с надписью `RESULT` (является первым добавленным) будет занимать размер 2-х линий и всю ширину линии.
- Элемент с надписью `=` (является последним добавленным) будет занимать в `2` раза больше ширины, чем другие элементы (кроме 1-го).
- Все прочие элементы будут иметь занимать высоту 1/7 контейнера и ширину 1/4 линии.<br>

Все элементы, кроме первого и последнего, получают размер в блоке `else`.<br>
Но хотя я ранее написал, что элементы должны занимать 1/7 и 1/4 размера контейнера, в данном коде видно, что элементы занимают 1/7.5 и 1/4.5.<br>
Все дело в следующем:
- Если предполагается, что в строке 4 элемента, то каждый должны занимать 1/4 ее ширины.
- Но помимо самих элементов, у нас также определен отступ между элементами в в `10px`.
- Поэтому я уменьшил размер самих элементов, чтобы избежать их переноса на новую строку.<br>

С высотой ситуация похожая:
- У нас есть 6 строк, и одна из них в 2 раза больше других. То есть элементы должны поделить свободную высоту на 1/7 (первый: на 2/7).
- Такое значение означало бы, что строки займут 100% высоты внутренней области контейнера.
- Но в коде определен межстрочный интервал в `15px`. Это значит, что суммарно наши кнопки займут высоту: 100% + 15px * 5.
- Поэтому линии также получают 1/7.5 высоты, чтобы не выйти за границы главной панели.<br>

```csharp
if (i == 0)
{

    style.Height.Precent = 2f / 7.5f;

```

Отдельное указание первому элементу (`RESULT`) размера:
- Ширина элемента размером с 100% ширины контейнера (значит, что все следующие элементы автоматически будут перенесены на следующую линию).
- Высота элемента в 2/7.5 строки (и так как все прочие элементы имеют значение 1/7.5, это означает, что данная строка будет занимать в 2 раза больше высоты, чем прочие).<br>

После того как последний элемент получит:
- Ширину размером в 1/4.5 ширины контейнера.
- Высоту размером 1/7.5 высоты контейнера.<br>

Его ширина дополнительно увеличивается в 2 раза.<br>
Что делает его в 2 раза больше по ширине, чем все прочие элементы (кроме 1-го).

----

Подводя итог:
1. Элемент с индексом 0 занял размер: 2 линий и всю ширину.
2. Место в первой строке закончилось. Все следующие элементы будут перенесены на следующую.
3. Затем добавляются следующие 4 элемента (индекс: 1-4) с размерами 1/4.5 и 1/7.5.
4. Место во второй строке закончилось. Все следующие элементы будут перенесены на следующую.
