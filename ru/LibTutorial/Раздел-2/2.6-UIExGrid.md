<h1 align="center">Класс <code>UIExGrid</code></h1>

----

- Данная библиотека предполагает, что вы уже изучили [базовое руководство tModLoader по пользовательскому интерфейсу](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Данная библиотека предполагает, что вы уже изучили [расширенное руководство по настройке пользовательского интерфейса](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>
- Данная статья предполагает, что вы изучили статью: [«структура стилей»](../Раздел-1/1.3-StyleStructure.md)
- Данная статья предполагает, что вы изучили статью: [«класс UIExLayout. Основы компоновки»](2.1-UIExLayout.md)

----
<br>

----

`UIExGrid` - это контейнер компоновки для двумерного расположения элементов интерфейса в виде строк и столбцов.

----

<h2 align="center">Стили <code>UIExGrid</code></h2>

- `UIExGrid` полноценно использует все стили `StyleLayoutContainer`.
- `Orientation`: определяет основную ось контейнера. Это значение играет роль при использовании `JustifyContent`, `JustifySelf`, `AlignItems`, `AlignSelf`.
- `JustifyContent` и `AlignContent` определяет выравнивание элементов внутри каждой ячейки по главной / поперечной оси.

А так же использует `StyleLayoutChild` для вложенных элементов:
- `JustifySelf` и `AlignSelf` - переопределяют значения `JustifyContent` и `AlignContent` контейнера для каждого отдельного элемента.
- `Margin` работает стандартно. Если какие-то из отступов указаны в процентах - проценты считаются от размера всего `UIExGrid`.

----

Данный класс стиля позволяет задать настройки сетки.
Получить класс стиля можно вызвав метод `Grid` у поля `StyleLayout`:
```csharp
UIExGrid grid = new();
StyleLayoutContainer style = grid.StyleLayout;
StyleLayoutContainerGrid styleGrid = style.Canvas();
UIExAlignment rowsAlignment = styleGrid.RowsAlignment;
```

----

Настройки сетки задаются с помощью методов:
- `Add(Row/Column)Definition(s)`;
- `Get(Row/Column)Definition(s)`;
- `Remove(Row/Column)DefinitionAt`;
- `Remove(Row/Column)DefinitionsRange`;
- `Replace(Row/Column)Definition`;
- `Insert(Row/Column)Definition(s)`;<br>
<!-- -->
- `Add(Row/Column)Definition(s)`:
  - Перегрузка 1: добавляет строку/столбец размером `UIExGridLength`.
  - Перегрузка 2: добавляет N строк/столбов размером `UIExGridLength`.
  - Перегрузка 3: добавляет массив строк/столбов размером `UIExGridLength`.
  - Перегрузка 4: добавляет список строк/столбов размером `UIExGridLength`.
- `Get(Row/Column)Definition(s)`:
  - Перегрузка 1: Возвращает размером `UIExGridLength` по индексу строки/столбца.
  - Перегрузка 2: Возвращает массив размеров `UIExGridLength` от начального до конечного (включительно) индексов строк/столбцов.
- `Remove(Row/Column)DefinitionAt`;
  - Перегрузка 1: удаляет строку/столбец по переданному индексу.
- `Remove(Row/Column)DefinitionsRangle`:
  - Перегрузка 1: удаляет строки/столбцы от начального до конечного (включительно) индексов.
- `Replace(Row/Column)Definition`:
  - Перегрузка 1: заменяет строку/столбец на переданный размер `UIExGridLength` по переданному индексу.
- `Insert(Row/Column)Definition(s)`:
  - Перегрузка 1: вставляет размер строки/столбца `UIExGridLength` по переданному индексу.
  - Перегрузка 2: вставляет массив размеров строк/столбцов `UIExGridLength` по переданному индексу.
  - Перегрузка 3: вставляет список размеров строк/столбцов `UIExGridLength` по переданному индексу.<br>

----

Структура размера строки/столбца.
```csharp
public struct UIExGridLength
{
    public Enums.UIExGridLengthType Type = Enums.UIExGridLengthType.Auto;

    public float Pixels = 0f;
    public float Precent = 0f;
    public float Fraction = 0f;


    public static UIExGridLength FromPx(float pixels) { /* ... */ }

    public static UIExGridLength FromPr(float precent) { /* ... */ }

    public static UIExGridLength FromFr(float fraction) { /* ... */ }

    public static UIExGridLength FromAuto() { /* ... */ }

    public static UIExGridLength Empty() { /* ... */ }
}

public enum UIExGridLengthType : byte
{
    Pixels,
    Precent,
    Fraction,
    Auto
}
```

Тип размера:
- `Pixels`: размер задается в пикселях в поле `Pixels`.
- `Precent`: размер задается в процентах в поле `Precent`.
- `Fraction`: размер задается во фракциях в поле `Fraction`. После вычисления всех прочих размеров строк/столбцов, свободное пространство будет распределено между строками/столбцами по размеру их фракций.
- `Auto`: размер определяется максимальным размером вложенного в строку/столбец элемента.<br>

Структура также определяет статические методы для быстрого создания объекта структуры нужного типа.

----

`UIExGrid` позволяет указать пространство между строками/столбцами с помощью полей стиля:
```csharp
public StyleDimension RowsSpace = StyleDimension.Empty;
public StyleDimension ColumnsSpace = StyleDimension.Empty;
```

А также позволяет указать выравнивание сетки (если размер высота/ширина сетки меньше высоты/ширины) контейнера.
```csharp
public Enums.UIExAlignment RowsAlignment = Enums.UIExAlignment.Start;
public Enums.UIExAlignment ColumnsAlignment = Enums.UIExAlignment.Start;
```
`Rows/ColumnsAlignment` может принимать только значения `Start`, `Center`, `End`.<br>
Все прочие значения будут приравнены `Start`.

----

Все вложенные в `UIExGrid` элементы могут использовать стиль `StyleLayoutChildGrid`.
Чтобы вы могли использовать данный стиль, вам необходимо получить стиль `StyleLayoutChild` с помощью метода расширения `UIElement`: `StyleLayoutChild()`.
Затем у полученного стиля вызвать метод `Grid()`.
```csharp
UIElement element = new();
StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildGrid styleGrid = style.Grid();
styleGrid.Row = 1;
```

Сам класс `StyleLayoutChildGrid` имеет следующую реализацию:
```csharp
public class StyleLayoutChildGrid : Base.StyleLayoutChildBase
{
    public int Row = 0;
    public int Column = 0;

    public int RowSpan = 1;
    public int ColumnSpan = 1;
}
```

1. Позволяет указать строку и столбец, где данный элемент будет располагаться. `Значения < 0` будет приравнены к `0`. `Значение >= Rows/ColumnsCount` будет приравнено к `Rows/ColumnsCount - 1`.
2. Позволяет указать, сколько строк/столбцов будет элемент занимать. `Значения < 1` будет приравнены к `1`. Элемент не может с помощью `Row/ColumnSpan` выйти за границы сетки.

<h2 align="center">Вспомогательные линии</h2>

`UIExLayout` дает возможность задавать вспомогательные линии (см. статью `UIExLayout`).<br>
Если `UIExLayout.ShowLayoutLines == true`, то вспомогательные линии будут рисоваться:
- Вокруг каждой ячейки.
- Вокруг внешней области каждого элемента внутри контейнера (которой участвует в компоновке).<br>

`UIExGrid` предлагает альтернативную возможность отрисовки вспомогательных линий с помощью полей и методов:
```csharp
public bool ShowGridLines = false;
public float GridLinesThickness = 1f;
public Color GridLinesColor = Color.DarkGray;



public virtual void SetGridLinesInfoForTree(
	bool showGridLines, 
	float gridLinesThickness, 
	Color gridLinesColor) 
		{ /* ... */ }


public virtual void SetGridLinesInfoForBranch(
	bool showGridLines, 
	float gridLinesThickness, 
	Color gridLinesColor)
		{ /* ... */ }
```

В данном случае вспомогательные линии будут отрисованы в виде сетки.

- `ShowGridLines` - определяет, будут ли рисоваться вспомогательные линии в виде сетки.
- `GridLinesThickness` - определяет размер вспомогательных линии в виде сетки в пикселях.
- `GridLinesColor` - определяет цвет вспомогательных линии в виде сетки.<br>
<!-- -->
- `SetGridLinesInfoForTree` - позволяет установить все три значения выше для всего древа элементов.
- `SetGridLinesInfoForBranch` - позволяет установить все три значения выше всех потомком данного контейнера.<br>

`ShowLayoutLines` и `ShowGridLines` работают независимо друг от друга.<br>
Это означает, что все вспомогательные линии могут отрисовываться одновременно.

<h2 align="center">Пример использования <i>UIExGrid</i></h2>

<summary>Пример создания макета калькулятора (без комментариев, разбор ниже)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // метод OnActivate() в данном случае используется только
    // для функции «горячей перезагрузки кода» в среде разработки.
    // для реального интерфейса правильнее было бы использовать
    // метод OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 650f, panel);

        UIExGrid grid = new();
        grid.Stretch();

        ////////////////////////////

        StyleLayoutContainer styleLayout = grid.StyleLayout;
        StyleLayoutContainerGrid styleLayoutGrid = styleLayout.Grid();

        styleLayout.Set(
            justifyContent: UIExAlignment.Stretch,
            alignItems: 	UIExAlignment.Stretch);

        styleLayoutGrid.AddRowDefinition(UIExGridLength.FromFr(1f), repeat: 7);
        styleLayoutGrid.AddColumnDefinition(UIExGridLength.FromFr(1f), repeat: 4);

        styleLayoutGrid.Set(
            rowsSpace: 		StyleDimension.FromPixels(10f),
            columnSpace: 	StyleDimension.FromPixels(15f));

        ///////////////////////////

        AppendButton(grid, prefix: "RESULT:", row: 0, column: 0, rowSpan: 2, columnSpan: 4);

        AppendButton(grid, prefix: "AC", row: 2, column: 0);
        AppendButton(grid, prefix: "%", row: 2, column: 1);
        AppendButton(grid, prefix: "<<", row: 2, column: 2);
        AppendButton(grid, prefix: "/", row: 2, column: 3);

        AppendButton(grid, prefix: 7, row: 3, column: 0);
        AppendButton(grid, prefix: 8, row: 3, column: 1);
        AppendButton(grid, prefix: 9, row: 3, column: 2);
        AppendButton(grid, prefix: "*", row: 3, column: 3);

        AppendButton(grid, prefix: 4, row: 4, column: 0);
        AppendButton(grid, prefix: 5, row: 4, column: 1);
        AppendButton(grid, prefix: 6, row: 4, column: 2);
        AppendButton(grid, prefix: "-", row: 4, column: 3);

        AppendButton(grid, prefix: 1, row: 5, column: 0);
        AppendButton(grid, prefix: 2, row: 5, column: 1);
        AppendButton(grid, prefix: 3, row: 5, column: 2);
        AppendButton(grid, prefix: "+", row: 5, column: 3);

        AppendButton(grid, prefix: 0, row: 6, column: 0);
        AppendButton(grid, prefix: ",", row: 6, column: 1);
        AppendButton(grid, prefix: "=", row: 6, column: 2, rowSpan: 1, columnSpan: 2);

        ///////////////////////////

        panel.Append(grid);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AppendButton(UIExLayout layout, int prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
        => AppendButton(layout, prefix.ToString(), row, column, rowSpan, columnSpan);
    public UIButton<string> AppendButton(UIExLayout layout, string prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
    {
        UIButton<string> button = new(prefix);

        StyleLayoutChildGrid styleGrid = button.StyleLayoutChild().Grid();
        styleGrid.Set(row, column, rowSpan, columnSpan);

        layout.Append(button);
        return button;
    }
}
```

----

Первое, что видно в коде - это создание главной панели размером `450х650px`, которая центрирована на экране.
```csharp
UIPanel panel = new UIPanel();
SetPixelsSizeCenter(width: 450f, height: 650f, panel);
```
Метод `SetPixelsSizeCenter` определен в данном классе для примера и не является методом данной библиотеки.<br>

После этого создается контейнер `UIExGrid`:
```csharp
UIExGrid grid = new();
grid.Stretch();
```
Метод `Stretch()` определен в `UIExLayout` и заставляет контейнер растягиваться по всей высоте и ширине родительского элемента.<br>
В данном примере `grid.Stretch()` растягивает элемент по всему размеру `panel`.

----

Немного о визуальных стилях. Это тема следующего раздела, но тут есть 1 важный момент для компоновщиков, поэтому данная сноска будет в каждой статье.<br>
Как видно, в данном коде система следующая: главная панель -> контейнер -> элементы внутри контейнера.<br>
Для главной панели создается свой контейнер.<br>
Это излишне, если результат именно тот, которые мы хотим видеть на изображении.<br>
`UIExElement` (от которого наследуется `UIExLayout`) имеет свойство стиля: `StyleDisplay.tModLoaderStyle (bool)`.<br>
Если данное значение истинно, то визуальный элемент будет принимать соответствующий стиль **tModLoader**.<br>
Для `UIExElement` значение `true` приведет к тому, что стиль будет аналогичен `UIPanel`.<br>
Следовательно, наш код мог быть сокращен.<br>

Вот эту часть:
```csharp
UIPanel panel = new UIPanel();
SetPixelsSizeCenter(width: 450f, height: 650f, panel);

UIExGrid grid = new();
grid.Stretch();

/*
...
*/

panel.Append(grid);
Append(panel);
```

Можно заменить на следующую:
```csharp
UIExGrid grid = new();
grid.StyleDisplay.tModLoaderStyle = true;
SetPixelsSizeCenter(width: 450f, height: 650f, grid);

/*
...
*/

Append(grid);
```

Как видно во втором коде, элемент `UIPanel panel` исчез. Сам контейнер компоновки `grid` стал одновременно главным контейнером.

----

Далее в коде получаются базовый стиль компоновки контейнера и стиль компоновки `UIExGrid`:
```csharp
StyleLayoutContainer styleLayout = grid.StyleLayout;
StyleLayoutContainerGrid styleLayoutGrid = styleLayout.Grid();
```

Затем задаются значения `justifyContent` и `alignItems`: `UIExAlignment.Stretch`.
```csharp
styleLayout.Set(
	justifyContent: UIExAlignment.Stretch,
	alignItems: 	UIExAlignment.Stretch);
```
Данный код указывает, что все элементы внутри контейнера должны растягиваться по ширине и высоте ячейки/ячеек, которые он занимает.<br>

----

Далее в коде определяется сама сетка:
```csharp
styleLayoutGrid.AddRowDefinition(UIExGridLength.FromFr(1f), repeat: 7);
styleLayoutGrid.AddColumnDefinition(UIExGridLength.FromFr(1f), repeat: 4);
```
Данный код указывает, что:
- строк в сетке должно быть 7 штук, которые поровну распределяют высоту контейнера между собой.
- колонок в сетке должно быть 4 штуки, которые поровну распределяют ширину контейнера между собой.
- пространство распределяется равномерно, так как размер каждой строки/столбца составляет 1 фракцию.<br>

Далее в коде задается пространство между строками и столбцами:
```csharp
styleLayoutGrid.Set(
	rowsSpace: 		StyleDimension.FromPixels(10f),
	columnSpace: 	StyleDimension.FromPixels(15f));
```

----

Затем добавляются кнопки с помощью методов:
```csharp
public UIButton<string> AppendButton(UIExLayout layout, int prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
    => AppendButton(
		layout,
		prefix.ToString(),
		row, column,
		rowSpan, columnSpan);

public UIButton<string> AppendButton(UIExLayout layout, string prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
{
    UIButton<string> button = new(prefix);

    StyleLayoutChildGrid styleGrid = button.StyleLayoutChild().Grid();
    styleGrid.Set(row, column, rowSpan, columnSpan);

    layout.Append(button);
    return button;
}
```
Данные методы также не определены в библиотеки, и созданы для данного примера.<br>
`AppendButton` создает кнопку, задает ей: `Row`, `Column`, `RowSpan`, `ColumnSpan`, переданный текст, и добавляет в переданный контейнер.

----

```csharp
AppendButton(grid, prefix: "RESULT:", row: 0, column: 0, rowSpan: 2, columnSpan: 4);
```
Первый элемент расположен в ячейке `{0, 0}` и занимает 2 строки и 4 колонки.<br>
То есть данный элемент занимает множество ячеек:<br>
- `{`
  - `{0, 0}, {0, 1}, {0, 2}, {0, 3}`,
  - `{1, 0}, {1, 1}, {1, 2}, {1, 3}`
- `}`<br>


Последний элемент расположен в ячейке `{6, 2}` и занимает 1 строку и 2 колонки.<br>
```csharp
AppendButton(grid, prefix: "=", row: 6, column: 2, rowSpan: 1, columnSpan: 2);
```
То есть данный элемент занимает множество ячеек:<br>
- `{ {6, 2}, {6, 3} }`.<br>

Все прочие элементы занимают по 1 ячейке и расположены последовательно слева-направо и сверху-вниз (располагаются вручную):
```csharp
AppendButton(grid, prefix: 7, row: 3, column: 0);
AppendButton(grid, prefix: 8, row: 3, column: 1);
AppendButton(grid, prefix: 9, row: 3, column: 2);
AppendButton(grid, prefix: "*", row: 3, column: 3);

AppendButton(grid, prefix: 4, row: 4, column: 0);
AppendButton(grid, prefix: 5, row: 4, column: 1);
AppendButton(grid, prefix: 6, row: 4, column: 2);
AppendButton(grid, prefix: "-", row: 4, column: 3);

AppendButton(grid, prefix: 1, row: 5, column: 0);
AppendButton(grid, prefix: 2, row: 5, column: 1);
AppendButton(grid, prefix: 3, row: 5, column: 2);
AppendButton(grid, prefix: "+", row: 5, column: 3);

AppendButton(grid, prefix: 0, row: 6, column: 0);
AppendButton(grid, prefix: ",", row: 6, column: 1);
```
