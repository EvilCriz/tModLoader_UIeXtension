<h1 align="center">Класс <code>UIExGrid</code></h1>

----

- Данная библиотека предполагает, что вы уже изучили [базовое руководство tModLoader по пользовательскому интерфейсу](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Данная статья предполагает, что вы изучили статью: [«структура стилей»](../Раздел-1/1.3-StyleStructure.md)
- Данная статья предполагает, что вы изучили статью: [«класс UIExLayout. Основы компоновки»](2.1-UIExLayout.md)

<br>

----

`UIExGrid` - это контейнер компоновки для двумерного расположения элементов интерфейса в виде строк и столбцов.

----

<h2 align="center">Стили <code>UIExGrid</code></h2>

- `UIExGrid` полноценно использует все стили `StyleLayoutContainer`.
- `Orientation`: определяет основную ось контейнера. Это значение играет роль при использовании `JustifyContent`, `JustifySelf`, `AlignItems`, `AlignSelf`.
- `JustifyContent` и `AlignContent` определяет выравнивание элементов внутри каждой ячейки по главной / поперечной оси.

А так же использует `StyleLayoutChild` для вложенных элементов:
- `JustifySelf` и `AlignSelf` - переопределяют значения `JustifyContent` и `AlignContent` контейнера для каждого отдельного элемента.
- `Margin` работает стандартно. Если какие-то из отступов указаны в процентах - проценты считаются от размера всего `UIExGrid`.

----

Данный класс стиля позволяет задать настройки сетки.
Получить класс стиля можно вызвав метод `Grid` у поля `StyleLayout`:
```csharp
UIExGrid grid = new();
StyleLayoutContainer style = grid.StyleLayout;
StyleLayoutContainerGrid styleGrid = style.Canvas();
UIExAlignment rowsAlignment = styleGrid.RowsAlignment;
```

----

Настройки сетки задаются с помощью методов:
- `Add(Row/Column)Definition(s)`;
- `Get(Row/Column)Definition(s)`;
- `Remove(Row/Column)DefinitionAt`;
- `Remove(Row/Column)DefinitionsRange`;
- `Replace(Row/Column)Definition`;
- `Insert(Row/Column)Definition(s)`;<br>
<!-- -->
- `Add(Row/Column)Definition(s)`:
  - Перегрузка 1: добавляет строку/столбец размером `UIExGridLength`.
  - Перегрузка 2: добавляет N строк/столбов размером `UIExGridLength`.
  - Перегрузка 3: добавляет массив строк/столбов размером `UIExGridLength`.
  - Перегрузка 4: добавляет список строк/столбов размером `UIExGridLength`.
- `Get(Row/Column)Definition(s)`:
  - Перегрузка 1: Возвращает размером `UIExGridLength` по индексу строки/столбца.
  - Перегрузка 2: Возвращает массив размеров `UIExGridLength` от начального до конечного (включительно) индексов строк/столбцов.
- `Remove(Row/Column)DefinitionAt`;
  - Перегрузка 1: удаляет строку/столбец по переданному индексу.
- `Remove(Row/Column)DefinitionsRangle`:
  - Перегрузка 1: удаляет строки/столбцы по от начального до конечного (включительно) индексов.
- `Replace(Row/Column)Definition`:
  - Перегрузка 1: заменяет строку/столбец на переданный размер `UIExGridLength` по переданному индексу.
- `Insert(Row/Column)Definition(s)`:
  - Перегрузка 1: вставляет размер строки/столбца `UIExGridLength` по переданному индексу.
  - Перегрузка 2: вставляет массив размеров строк/столбцов `UIExGridLength` по переданному индексу.
  - Перегрузка 3: вставляет список размеров строк/столбцов `UIExGridLength` по переданному индексу.<br>

----

Структура размера строки/столбца.
```csharp
public struct UIExGridLength
{
    public Enums.UIExGridLengthType Type = Enums.UIExGridLengthType.Auto;

    public float Pixels = 0f;
    public float Precent = 0f;
    public float Fraction = 0f;


    public static UIExGridLength FromPx(float pixels) { /* ... */ }

    public static UIExGridLength FromPr(float precent) { /* ... */ }

    public static UIExGridLength FromFr(float fraction) { /* ... */ }

    public static UIExGridLength FromAuto() { /* ... */ }

    public static UIExGridLength Empty() { /* ... */ }
}

public enum UIExGridLengthType : byte
{
    Pixels,
    Precent,
    Fraction,
    Auto
}
```

Тип размера:
- `Pixels`: размер задается в пикселях в поле `Pixels`.
- `Precent`: размер задается в процентах в поле `Precent`.
- `Fraction`: размер задается в фракциях в поле `Fraction`. После вычисление всех прочих размеров строк/столбцов, свободное пространство будет распределено между строками/столбцами по размеру их фракций.
- `Auto`: размер определяется максимальным размеров вложенного в строку/столбец элемента.<br>

Структура также определяет статические методы для быстрого создания объекта структуры нужного типа.

----

`UIExGrid` позволяет указать пространство между строками/столбцами с помощью полей стиля:
```csharp
public StyleDimension RowsSpace = StyleDimension.Empty;
public StyleDimension ColumnsSpace = StyleDimension.Empty;
```

А также позволяет указать выравнивание сетки (если размер высота/ширина сетки меньше высоты/ширины) контейнера.
```csharp
public Enums.UIExAlignment RowsAlignment = Enums.UIExAlignment.Start;
public Enums.UIExAlignment ColumnsAlignment = Enums.UIExAlignment.Start;
```
`Rows/ColumnsAlignment` может принимать только значения `Start`, `Center`, `End`.<br>
Все прочие значения будут приравнены `Start`.

----

Все вложенные в `UIExGrid` элементы могут использовать стиль `StyleLayoutChildGrid`.
Чтобы вы могли использовать данный стиль, вам необходимо получить стиль `StyleLayoutChild` с помощью метода расширения `UIElement`: `StyleLayoutChild()`.
Затем у полученного стиля вызвать метод `Grid()`.
```csharp
UIElement element = new();
StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildGrid styleGrid = style.Grid();
styleGrid.Row = 1;
```

Сам класс `StyleLayoutChildGrid` имеет следующую реализацию:
```csharp
public class StyleLayoutChildGrid : Base.StyleLayoutChildBase
{
    public int Row = 0;
    public int Column = 0;

    public int RowSpan = 1;
    public int ColumnSpan = 1;
}
```

1. Позволяет указать строку и столбец, где данный элемент будет располагаться. `Значения < 0` будет приравнены к `0`. `Значение >= Rows/ColumnsCount` будет приравнено к `Rows/ColumnsCount - 1`.
2. Позволяет указать, сколько строк/столбцов будет элемент занимать. `Значения < 1` будет приравнены к `1`. Элемент не может с помощью `Row/ColumnSpan` выйти за границы сетки.
