<h1 align="center">Класс <code>UIExStackPanel</code></h1>

----

- Данная библиотека предполагает, что вы уже изучили [базовое руководство tModLoader по пользовательскому интерфейсу](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Данная библиотека предполагает, что вы уже изучили [расширенное руководство по настройке пользовательского интерфейса](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>
- Данная статья предполагает, что вы изучили статью: [«структура стилей»](../Раздел-1/1.3-StyleStructure.md)
- Данная статья предполагает, что вы изучили статью: [«класс UIExLayout. Основы компоновки»](2.1-UIExLayout.md)

----
<br>

----

`UIExStackPanel` - это контейнер компоновки, который располагает дочерние элементы в одну линию (стопку) по вертикали или по горизонтали.<br>

----

Базовый стиль компоновки элементов `StyleLayoutContainer`:
```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    public Enums.UIExOrientation Orientation = Enums.UIExOrientation.Vertical;
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
}
```
- `Orientation`: определяет главную ось контейнера, по которой будут выравниваться элементы.
- `JustifyContent`: выравнивание элементов по главной оси.
- `AlignItems`: выравнивание элементов по поперечной оси.<br>

Типы выравнивания:
```csharp
public enum UIExAlignment : byte
{
    Auto,
    Start,
    Center,
    End,
    Stretch
}
```
- `Auto`: аналогично `Start`. Используется у вложенных в контейнер элементов.
- `Start`: выравнивание элементов по старту оси (верх/лево).
- `Center`: выравнивание элементов по центру оси.
- `End`: выравнивание элементов по концу оси (низ/право).
- `Stretch`: растягивание элемента по всей оси (за вычетом `Margin`).<br>

----

Базовые стили дочерних элементов `StyleLayoutChild`:
```csharp
public partial class StyleLayoutChild : Base.StyleLayoutChildBase
{
    public Enums.UIExAlignment JustifySelf = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignSelf = Enums.UIExAlignment.Auto;
    public UIExThickness Margin = new();
    public StyleDimension Width = default(StyleDimension);
    public StyleDimension Height = default(StyleDimension);
}
```
- Поле `JustifySelf` у дочерних элементов игнорирует любые значения, кроме значения `Stretch`.
- Поле `AlignSelf` переопределяет значение `AlignItems` для конкретного вложенного элемента.
- Поле `Margin` работает полноценно.
- Поля `Width` и `Height` подробно разбирались в первой статье данного раздела.

----

Для класса `UIExStackPanel` используется класс стилей: `StyleLayoutContainerStackPanel`, которое хранит все стили компоновки для данного класса.

```csharp
public class StyleLayoutContainerStackPanel : Base.StyleLayoutContainerBase
{
    public StyleDimension Spacing = StyleDimension.Empty;
    public bool Reverse = false;

    public void Set(StyleDimension spacing, bool reverse) { /* ... */ }
    public void Copy(StyleLayoutContainerStackPanel style) { /* ... */ }
    public StyleLayoutContainerStackPanel GetCopy() { /* ... */ }
}
```

- `Spacing`:
  - Отвечает за пространство между дочерними элементами `UIExStackPanel`.
  - Работает даже если `JustifyContent` и/или `AlignItems` == `UIExAlignment.Stretch`
- `Reverse`:
  - Флаг, отвечающий за расположение элементов в реверсивном порядке.
  - При `true` — все элементы будут располагаться в обратном порядке, сохраняя все прочие характеристики стиля.
<br>

----

**НЕ РЕАЛИЗУЕТ** свой класс стиля для дочерних элементов.<br>

----

- Базовые стили компоновки контейнера содержатся в поле `StyleLayout`.
- Для получения стилей компоновки `UIExStackPanel` используйте метод `StackPanel()` у поля `StyleLayout`.
- Для получения базовых стилей для вложенных в контейнер элементов используйте метод расширения `UIElement`: `StyleLayoutChild()`.<br>

```csharp
UIExStackPanel stackPanel = new();

StyleLayoutContainer style = stackPanel.StyleLayout;
StyleLayoutContainerStackPanel styleStackPanel = stackPanel.StyleLayout.StackPanel(); // или style.StackPanel();

UIElement element = new();
StyleLayoutChild styleChild = element.StyleLayoutChild();

style.JustifyContent = UIExAlignment.Center;
styleStackPanel.Reverse = true;

styleChild.JustifySelf = UIExAlignment.Stretch;
```

<details>
<summary>Пример создания пользовательского интерфейса (без комментариев, разбор ниже)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;
using Microsoft.Xna.Framework;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // метод OnActivate() в данном случае используется только
    // для функции «горячей перезагрузки кода» в среде разработки.
    // для реального интерфейса правильнее было бы использовать
    // метод OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.8f, 0.8f, panel);

        UIExStackPanel HStackPanel = new();
        HStackPanel.Stretch();

        HStackPanel.StyleLayout.Set(
            orientation:        UIExOrientation.Horizontal,
            justifyContent:     UIExAlignment.Stretch,
            alignItems:         UIExAlignment.Stretch);
        HStackPanel.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.05f),
            reverse:            false);

        panel.Append(HStackPanel);

        //////

        UIPanel HPanel1 = new(), HPanel2 = new(), HPanel3 = new(), HPanel4 = new();
        HStackPanel.Append(HPanel1);
        HStackPanel.Append(HPanel2);
        HStackPanel.Append(HPanel3);
        HStackPanel.Append(HPanel4);

        /////

        UIExStackPanel VStackPanel1 = new(), VStackPanel2 = new(), VStackPanel3 = new(), VStackPanel4 = new();
        SetPrecentSizeCenter(1f, 1f, VStackPanel1, VStackPanel2, VStackPanel3, VStackPanel4);
        HPanel1.Append(VStackPanel1);
        HPanel2.Append(VStackPanel2);
        HPanel3.Append(VStackPanel3);
        HPanel4.Append(VStackPanel4);

        VStackPanel1.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Start,
            alignItems:         UIExAlignment.Start);
        VStackPanel1.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.1f),
            reverse:            false);

        UIElement selfStylePanel1 = AddCubs(VStackPanel1, pixelSize: 64f, count: 3)[1];

        selfStylePanel1.StyleLayoutChild()
            .Set(alignSelf: UIExAlignment.End);

        ////

        VStackPanel2.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Center,
            alignItems:         UIExAlignment.Center);
        VStackPanel2.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.15f),
            reverse:            true);

        UIElement selfStylePanel2 = AddCubs(VStackPanel2, 16f, 32f, 48f, 64f)[2];

        selfStylePanel2.StyleLayoutChild().Set(
            justifySelf:        UIExAlignment.End, // ничего не делает, UIExStackPanel не учитывает JustifySelf,
            alignSelf:          UIExAlignment.Stretch,
            margin:             new UIExThickness(
                                    pixels: false,
                                    left: 0.1f,
                                    top: 0.075f,
                                    right: 0f,
                                    bottom: 0.15f));

        ////

        VStackPanel3.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.End,
            alignItems:         UIExAlignment.End);
        VStackPanel3.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.20f),
            reverse:            false);

        AddCubs(VStackPanel3, 32f, 48f, 64f);

        ////

        VStackPanel4.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Stretch,
            alignItems:         UIExAlignment.Stretch);
        VStackPanel4.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.20f),
            reverse:            false);

        AddCubs(VStackPanel4, pixelSize: 60f);
        AddCubs(VStackPanel4, pixelSize: 50f);
        AddCubs(VStackPanel4, pixelSize: 70f);

        ////

        HStackPanel.SetLayoutLinesInfoForBranch(
            state: true, 
            thickness: 3f, 
            color: Color.DarkOrange);

        ///

        Append(panel);
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
    {
        int count = pixelSizes.Length;
        var panels = new UIElement[count];
        for (int i = 0; i < count; i++)
            panels[i] = AddCubs(element, pixelSizes[i], count: 1)[0];
        return panels;
    }

    public UIElement[] AddCubs(UIElement element, float pixelSize, int count = 1)
    {
        var panels = new UIElement[count];
        for (int i = 0; i < count; i++)
        {
            panels[i] = new UIPanel();
            StyleLayoutChild style = panels[i].StyleLayoutChild();
            style.Width.Set(pixelSize, 0f);
            style.Height.Set(pixelSize, 0f);
            element.Append(panels[i]);
        }
        return panels;
    }
}
```

На изображении видно следующее:
1. Главная панель (размером в 80% экрана).

----

Немного о визуальных стилях. Это тема следующего раздела, но тут есть 1 важный момент для компоновщиков, поэтому данная сноска будет в каждой статье.<br>
Как видно, в данном коде система следующая: главная панель -> контейнер -> панель секции -> контейнер -> панель куба.<br>
На каждую панель создается свой контейнер (кроме кубов).<br>
Это излишне, если результат именно тот, которые мы хотим видеть на изображении.<br>
`UIExElement` (от которого наследуется `UIExLayout`) имеет свойство стиля: `StyleDisplay.tModLoaderStyle (bool)`.<br>
Если данное значение истинно, то визуальный элемент будет принимать соответствующий стиль **tModLoader**.<br>
Для `UIExElement` значение `true` приведет к тому, что стиль будет аналогичен `UIPanel`.<br>
Следовательно, наш код мог быть сокращен.<br><br>

Например, вот эту часть:
```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);

UIExStackPanel HStackPanel = new();
HStackPanel.Stretch();

HStackPanel.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Stretch,
    alignItems:         UIExAlignment.Stretch);
HStackPanel.StyleLayout.StackPanel().Set(
    spacing:            new StyleDimension(0f, 0.05f),
    reverse:            false);

panel.Append(HStackPanel);
/*
...
*/
Append(panel);
```

Можно заменить на следующую:
```csharp
UIExStackPanel HStackPanel = new();
HStackPanel.StyleDisplay.tModLoaderStyle = true;
SetPrecentSizeCenter(0.8f, 0.8f, HStackPanel);

HStackPanel.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Stretch,
    alignItems:         UIExAlignment.Stretch);
HStackPanel.StyleLayout.StackPanel().Set(
    spacing:            new StyleDimension(0f, 0.05f),
    reverse:            false);
/*
...
*/
Append(HStackPanel);
```

Как видно во втором коде, элемент `UIPanel panel` исчез. Сам контейнер компоновки `HStackPanel` стал одновременно главным контейнером.

----

Первое, что вы видите в коде:
```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);
```
Это главная панель, которая будет добавлена в `UIState`. На ней будут располагаться `UIExStackPanel`.<br><br>
`SetPrecentSizeCenter` - это вспомогательный метод, которого нет в самой библиотеке, и который определен ниже в этом же классе.
Он получает N `UIElement`, устанавливаем им переданную высоту и ширину и центрирует. В данном случае наша `panel` имеет размер: 80%х80% экрана.<br><br>

----

Далее в коде идет первый `UIExStackPanel`:
```csharp
UIExStackPanel HStackPanel = new();
HStackPanel.Stretch();

HStackPanel.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Stretch,
    alignItems:         UIExAlignment.Stretch);
HStackPanel.StyleLayout.StackPanel().Set(
    spacing:            new StyleDimension(0f, 0.05f),
    reverse:            false);

panel.Append(HStackPanel);

//////

UIPanel HPanel1 = new(), HPanel2 = new(), HPanel3 = new(), HPanel4 = new();
HStackPanel.Append(HPanel1);
HStackPanel.Append(HPanel2);
HStackPanel.Append(HPanel3);
HStackPanel.Append(HPanel4);
```

- `HStackPanel.Stretch();` - устанавливает размеры `HStackPanel`: 100% от родительского элемента.
- Ниже мы добавляем `HStackPanel` в главную панель `panel.Append(HStackPanel);`, что означает, что `HStackPanel` будет компоновать элементы по всей главной панели, то есть по всему созданному интерфейсу.
- `Set` - это метод, который есть у любого класса стиля в библиотеке. Каждый Set стиля принимает значения для **ВСЕХ** существующих полей класса стиля.
- Его стили `StyleLayoutContainer StyleLayout`:
  - `Orientation`: Основная ось контейнера. `Vertical` - горизонтальная.
  - `JustifyContent` (выравнивание элементов по основной оси) (основная ось - горизонтальная): `stretch` - элементы занимают все доступное пространство по ширине.
  - `AlignItems` (выравнивание элементов по поперечной оси) (поперечной ось - вертикальная): `stretch` - элементы занимают все доступное пространство по высоте.
- Его стили `StyleLayoutContainerStackPanel StyleLayoutStackPanel`:
  - `Spacing`: 5% от размера основной оси контейнера (в данном случае: 5% от ширины `HStackPanel`).
  - `Reverse`: false - элементы располагаются в том порядке, в каком они будут добавлены в `HStackPanel`.


Ниже в `HStackPanel` добавлены 4 секции `HPanel_N`:
- `HStackPanel` сперва выделит место под `Spacing (5% * HStackPanel.Width * (HStackPanel.GetWithLayoutElementsCount() - 1))`
- Затем посчитает свободное пространство и поделит его между этими секциями.
- Результат этого вы можете посмотреть самостоятельно. На изображении это 4 самые вертикальные секции по всю высоту контейнера.

----

```csharp
UIExStackPanel VStackPanel1 = new(), VStackPanel2 = new(), VStackPanel3 = new(), VStackPanel4 = new();
SetPrecentSizeCenter(1f, 1f, VStackPanel1, VStackPanel2, VStackPanel3, VStackPanel4);
HPanel1.Append(VStackPanel1);
HPanel2.Append(VStackPanel2);
HPanel3.Append(VStackPanel3);
HPanel4.Append(VStackPanel4);
```

К каждой из созданных до этого секций (`HPanel_N`) создается свой `UIExStackPanel (VStackPanel_N)`.<br>
`VStackPanel_N` - будут компоновать кубы внутри каждой из секций.
Далее каждый из `VStackPanel_N` получает размеры 100% своего родителя и добавляются в соответствующие панель `HPanel_N`<br>

----

Хочу на этом месте подвести промежуточный итог.
На данный момент у нас система такая:
- `UIPanel panel` - главная панель. Имеет 80% размера экрана. Внутри нее расположен:<br>
  - `UIExStackPanel HStackPanel` - компоновщик внутри главной панели. Имеет 100% размера главной панели. Внутри него расположены:<br>
    - `UIPanel HPanel_1-4` - секции 1-4. Имеют 100% высоты `HStackPanel` и 25% от свободного пространства. Внутри них:<br>
      - `UIExStackPanel VStackPanel_1-4` - компоновщики внутри соответствующей секции. Имеют 100% размера соответствующей секции. Внутри них<br>
          - N-количеством кубов в разным размером ребер.

Далее для каждого компоновщика внутри каждой секции `VStackPanel_1–4` задается стиль компоновки и добавляются внутрь кубы (`UIPanel`) с помощью методов:
```csharp
public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
{
    int count = pixelSizes.Length;
    var panels = new UIElement[count];
    for (int i = 0; i < count; i++)
        panels[i] = AddCubs(element, pixelSizes[i], count: 1)[0];
    return panels;
}

public UIElement[] AddCubs(UIElement element, float pixelSize, int count = 1)
{
    var panels = new UIElement[count];
    for (int i = 0; i < count; i++)
    {
        panels[i] = new UIPanel();
        StyleLayoutChild style = panels[i].StyleLayoutChild();
        style.Width.Set(pixelSize, 0f);
        style.Height.Set(pixelSize, 0f);
        element.Append(panels[i]);
    }
    return panels;
}
```
Данные методы также созданы специально для данного примера и не существуют в самой библиотеке.<br>

Обратите внимание, что размер внутри метода задается с помощью стиля StyleLayoutChild.
Так как дочерним элементам внутри компоновщика можно задавать размеры только таким образом:
```csharp
panels[i] = new UIPanel();
StyleLayoutChild style = panels[i].StyleLayoutChild();
style.Width.Set(pixelSize, 0f);
style.Height.Set(pixelSize, 0f);
element.Append(panels[i]);
```

Нет смысла разбирать весь код. Разберем только две части кода, где изменяются стили вложенных в контейнер элементов<br><br>

Первая часть:
```csharp
VStackPanel1.StyleLayout.Set(
    orientation:        UIExOrientation.Vertical,
    justifyContent:     UIExAlignment.Start,
    alignItems:         UIExAlignment.Start);
VStackPanel1.StyleLayout.StackPanel().Set(
```

Затем задаются стили для второй куба внутри первой секции.<br>

</table>

Для второго куба зарегистрирован стиль и изменено поле `alignSelf: UIExAlignment.End`.<br>
Это значит, что данный куб игнорирует значение `AlignItems` контейнера, и выравнивается по концу поперечной оси (справа в данном случае).<br><br><br>

Вторая часть кода:
```csharp
VStackPanel2.StyleLayout.Set(
    orientation:        UIExOrientation.Vertical,
    justifyContent:     UIExAlignment.Center,
    alignItems:         UIExAlignment.Center);
VStackPanel2.StyleLayout.StackPanel().Set(
    spacing:            new StyleDimension(0f, 0.15f),
    reverse:            true);

UIElement selfStylePanel2 = AddCubs(VStackPanel2, 16f, 32f, 48f, 64f)[2];

selfStylePanel2.StyleLayoutChild().Set(
    justifySelf:        UIExAlignment.End, // ничего не делает, UIExStackPanel не учитывает JustifySelf,
    alignSelf:          UIExAlignment.Stretch,
    margin:             new UIExThickness(
                            pixels: false,
                            left: 0.1f,
                            top: 0.075f,
                            right: 0f,
                            bottom: 0.15f));
```


<table align="center"> 
    <tr> <th>Стиль</th> <th>Значение</th> </tr> 
    <tr> 
        <td><code>orientation: UIExOrientation.Vertical</code></td> 
        <td>Главная ось компоновки первой секции - вертикальная.</td> 
    </tr>
    <tr> 
        <td><code>justifyContent: UIExAlignment.Center</code></td> 
        <td>Все кубы выравниваются по стартовой позиции по главной оси (сверху)</td> 
    </tr>
    <tr> 
        <td><code>alignItems: UIExAlignment.Center</code></td> 
        <td>Все кубы (кроме 3-го) выравниваются по стартовой позиции по поперечной оси (слева)</td> 
    </tr>
    <tr> 
        <td><code>spacing: new StyleDimension(0f, 0.15f)</code></td> 
        <td>Отступ между элементами по главной оси: 15% от размера главной оси контейнера (15% от `Height` контейнера)</td> 
    </tr>
    <tr> 
        <td><code>reverse: true</code></td> 
        <td>Реверсия элементов. Дочерние элементы располагаются в обратном порядке.</td> 
    </tr> 
</table><br>

Далее добавляются 4 куба и 3-му из них добавляется стиль:
<table align="center"> 
    <tr> <th>Стиль</th> <th>Значение</th> </tr> 
    <tr> 
        <td><code>justifySelf: UIExAlignment.End</code></td> 
        <td>Ничего не делает. Контейнер <code>UIExStackPanel</code> не учитывает это значение у дочерних элементов</td> 
    </tr>
    <tr> 
        <td><code>alignSelf: UIExAlignment.Stretch</code></td> 
        <td>3-й куб растягивается по ширине поперечной оси (по всей ширине 3-й секции, в данном случае)</td> 
    </tr>
    <tr> 
        <td><code>margin:<br>
    new UIExThickness<br>(
        <br>pixels: false,
        <br>left: 0.1f,
        <br>top: 0.075f,
        <br>right: 0f,
        <br>bottom: 0.15f)</code>
        </td> 
        <td>Размер `Margin` в процентах</td> 
    </tr>
</table><br>

В этой статье не будет разбираться `Margin`.<br>
Данное поле крайне детально разобрана в статьях посвященных `UIExLayout` и `UIExCanvas`.
