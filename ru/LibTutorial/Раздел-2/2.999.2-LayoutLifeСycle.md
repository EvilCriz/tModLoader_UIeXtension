<h2 align="center">Жизненный цикл <code>UIElement</code> в tModLoader</h2>

Прежде, чем переходить к жизненному циклу компоновщиков, следует проговорить жизненный цикл компоновки в **tModLoader**.<br>

1. Для корневого элемента (`UIState`) вызывается метод `Recalculate`.
2. Метод `Recalculate` рассчитывает 3 области элемента (подробнее про области элемента см. в статье `UIExLayout`).
3. Затем метод `Recalculate` вызывает метод `RecalculateChildren`.
4. Метод `RecalculateChildren` вызывает метод `Recalculate` для всех дочерних элементов.<br>

Таким образом **tModLoader** вызывает метод `Recalculate` для всего дерева элементов каждый кадр.

<h2 align="center">Жизненный цикл <code>UIExLayout</code></h2>

Первое, что делает `UIExLayout` - вмешивается в жизненный цикл `UI` в **tModLoader**:
```csharp
public abstract partial class UIExLayout : UIExElement
{
    private bool _pauseRecalculateChildren = false;

    public override void Recalculate()
    {
        _pauseRecalculateChildren = true;
        base.Recalculate();
        _pauseRecalculateChildren = false;
        RecalculateLayout();
        RecalculateChildren();
    }


    public override void RecalculateChildren()
    {
        if (_pauseRecalculateChildren)
            return;

        base.RecalculateChildren();
    }
}
```
Как видно, `UIExLayout` добавляет специальный флаг, блокирующий вызов `Recalculate` у дочерних элементов.<br>

Таким образом теперь жизненный цикл такой:
1. Установка флага `_pauseRecalculateChildren = true`, запрещающий выполнение метода `RecalculateChildren`.
2. `base.Recalculate` - пересчет 3-х областей контейнера.
3. `base.Recalculate` вызывает `RecalculateChildren`, но вызов данного метода заблокирован флагом `_pauseRecalculateChildren`.
4. Установка флага `_pauseRecalculateChildren = false`, разрешающий выполнение метода `RecalculateChildren`.
5. Пересчет всей компоновки в методе `RecalculateLayout`.
6. Вызов `RecalculateChildren`.<br>

Теперь:
1. Сперва пересчитываются 3 области контейнера.
2. Элементы внутри контейнера компонуются.
3. Пересчитываются 3 области всех элементов после компоновки.

<h3 align="center">Метод <code>RecalculateLayout</code></h3>

```csharp
protected virtual void RecalculateLayout()
{
    // этап 1:
    var innerDimension = GetInnerDimensions();
    if (innerDimension.Width == 0f && innerDimension.Height == 0f)
        return;

    // этап 2:
    if (IsLayoutPreparation())
        return;

    // этап 3:
    if (_remainingRecalculateLayoutDelayMs > 0)
        return;

    // этап 4:
    UpdateStyleLayoutChildArray();

    // этап 5:
    if (!IsLastLayoutInfoChanged())
        return;

    // этап 6:
    BeginLayoutContext();

    try
    {
        // этап 7:
        PreRefreshLayout();

        // этап 8:
        RefreshLayout();

        // этап 9:
        PostRefreshLayout();

        // этап 10:
        ApplyLayout();

        // этап 11:
        RefreshLayoutDebugLines();
    }
    catch(System.Exception)
    {
        throw new System.Exception("[UIeXtension] RecalculateLayout Exception");
    }
    finally
    {
        // этап 12:
        EndLayoutContext();
    }

    // этап 13:
    UpdateLastLayoutInfo();

    // этап 14:
    int? recalculateLayoutDelayMsState = GetRecalculateLayoutDelayMsState(this);
    _remainingRecalculateLayoutDelayMs =
        recalculateLayoutDelayMsState is not null
            ? (int)recalculateLayoutDelayMsState
            : RecalculateLayoutDelayMs;
}
```

Этот метод определяет весь жизненный цикл компоновки.<br>
Общие этапы:
1. Проверка, что контейнер имеет размер. Иначе - выход из метода.
2. Проверка, что контейнер не в состоянии подготовки (см. предыдущую статью). Иначе - выход из метода.
3. Проверка, что контейнер не имеет действующей задержки перед компоновкой (см. предыдущую статью). Иначе - выход из метода.
4. Обновление всех стилей вложенных в контейнер элементов.
5. Проверка, что информация после последней компоновки изменилась (см. предыдущую статью). Иначе - выход из метода.
6. Подготовка временных данных, которые используются только во время одной компоновки.
7. Предварительный алгоритм компоновки.
8. Основной алгоритм компоновки.
9. Алгоритм компоновки после основного этапа.
10. Применение временных данных к элементам (установка дочерним элемента `Width`, `Height`, `Top`, `Left`).
11. Алгоритм расчета вспомогательных линий.
12. Освобождение временных данных, которые используются только во время компоновки.
13. Запись последних данные после компоновки (см. предыдущий раздел).
14. Обновление минимальной задержки перед следующей компоновкой.<br>

- Этап 1: простая проверка.
- Этап 2-3: рассмотрены в предыдущей статье.
- Этап 4: получение всех стилей вложенных элементов и их сохранение в `private Styles.StyleLayoutChild[] _styleLayoutChildArray;`.
- Этап 5: рассмотрен в предыдущей статье.
- Этап 6: рассмотрен ниже отдельно.
- Этап 7-9: алгоритмы на этих этапах жизненного цикла компоновки определяет каждый компоновщик сам.
- Этап 10: рассмотрен ниже отдельно.
- Этап 11: алгоритм расчета вспомогательных линий определяет каждый компоновщик сам.
- Этап 12: рассмотрен ниже отдельно.
- Этап 13: рассмотрен в предыдущей статье.
- Этап 14: см. в последних строках кода выше и предыдущей статье.

<h3 align="center">Этап 6, 12: <code>BeginLayoutContext</code> и <code>EndLayoutContext</code></h3>

В данном методе подготавливаются/освобождаются временные данные, которые актуальны только во время жизненного цикла компоновки.<br>
`UIExLayout` подготавливает данные, которые используются всеми компоновщиками.<br>
Каждый компоновщик отдельно подготавливает/освобождает свои данные.<br><br>

```csharp
protected List<UIElement> _elementsContext = null;

protected List<RectangleLayoutContext> _rectangleContexts = null;

protected List<Styles.StyleLayoutChild> _styleElementsContexts = null;

protected CalculatedStyle _innerDimensionsContext;

protected List<CalculatedStyle> _elementsOuterDimensionsContext = null;

protected List<CalculatedStyle> _elementsDimensionsContext = null;
```

- `_elementsContext` - список дочерних элементов, которые участвуют в компоновке (у которых поле `StyleLayoutChild().WithoutLayout == false`)
- `_rectangleContexts` - список `RectangleLayoutContext`, которому будут задаваться размер и смещение элементов во время компоновки.
- `_styleElementsContexts` - список стилей элементов, которые участвуют в компоновке.
- `_innerDimensionsContext` - внутренняя область компоновщика.
- `_elementsOuterDimensionsContext` - список внешних областей элементов, которые участвуют в компоновке.
- `_elementsDimensionsContext` - список областей элементов, которые участвуют в компоновке.<br>

`_styleElementsContexts`, `_styleElementsContexts`, `_elementsOuterDimensionsContext`, `_elementsDimensionsContext` имеют размер списка, равный `_elementsContext.Count`.<br>
Все индексы совпадают.<br><br>

- Всем элементам `_elementsContext` в `BeginLayoutContext` устанавливаются значения `Top`, `Left` на `StyleDimension.Empty`.<br>
<!-- -->
- `_rectangleContexts[i].Width` и `_rectangleContexts[i].Height` по умолчанию имеют `_elementsContext[i].Width`, `_elementsContext[i].Height` рассчитанные в пикселях.
- `_rectangleContexts[i].Index = i`.<br><br>

`RectangleLayoutContext` имеет методы:
```csharp
public CalculatedStyle GetCalculatedStyle()
    => new(Left, Top, Width, Height);

public LayoutDebugRectangle GetLayoutDebugRectangle()
    => new(Left, Top, Width, Height);
```
<br>

В методе `EndLayoutContext` всем спискам устанавливается значение `null`.

<h3 align="center">Этап 10: применение временных данных к элементам</h3>

```csharp
protected virtual void ApplyLayout()
{
    foreach (var rectContext in _rectangleContexts)
        ApplyElementLayout(rectContext);
}

protected virtual void ApplyElementLayout(RectangleLayoutContext rectContext)
{
    UIElement element = _elementsContext[rectContext.Index];

    element.Top.Set(rectContext.Top, 0f);
    element.Left.Set(rectContext.Left, 0f);
    element.Width.Set(rectContext.Width, 0f);
    element.Height.Set(rectContext.Height, 0f);
}
```

На данном этапе всем элементам, которые учавствуют в компоновке устанавливаются значения:
- `Left`;
- `Top`;
- `Width`;
- `Height`.<br>

Все значения берутся из `_rectangleContexts`.
