<h1 align="center">Класс <i>UIExStackPanel</i></h1>

`UIExStackPanel` - это контейнер компоновки, который располагает дочерние элементы в одну линию (стопку) по вертикали или по горизонтали.
`UIExStackPanel` определяет поле `public Styles.StyleLayoutContainerStackPanel StyleLayoutStackPanel { get; set; }`, которое хранит все стили компоновки для данного класса.

```csharp
public class StyleLayoutContainerStackPanel : IStyleLayoutContainer, IStyleCopy<StyleLayoutContainerStackPanel>
{
    public Enums.Orientation Orientation = Enums.Orientation.Vertical;
    public Enums.Alignment JustifyContent = Enums.Alignment.Start;
    public Enums.Alignment AlignItems = Enums.Alignment.Start;
    public StyleDimension Spacing = StyleDimension.Empty;
    public bool Reverse = false;

    public StyleLayoutContainerStackPanel Copy() { /* ... */ }
}
```

- `Orientation`:
  - Отвечает за то, по какой оси будет располагаться дочерние элементы.
  - Может принимать два значения: `Enums.Orientation.Vertical` и `Enums.Orientation.Horizontal`.
- `JustifyContent`:
  - Отвечает за то, как будут выравниваться вложенные элементы относительно основной оси:
    - `Enums.Alignment.Start` - элементы будут располагаться с стартовой точки основной оси `UIExStackPanel`. Размер элементов не меняется.
    - `Enums.Alignment.Center` - элементы будут располагаться по центру основной оси `UIExStackPanel`. Размер элементов не меняется.
    - `Enums.Alignment.End` - элементы будут располагаться с конечной точки основной оси `UIExStackPanel`. Размер элементов не меняется.
    - `Enums.Alignment.Stretch` - элементы будут располагаться с стартовой точки основной оси `UIExStackPanel`. `UIExStackPanel` поровну разделит свое пространство по основной на количество дочерних элементов и растянет Height или Width (зависит от оси) элементов, чтобы они заняли все доступное пространство основной оси.
- `AlignItems`:
  - Отвечает за то, как буду выравниваться вложенные элемент относительно поперечной оси.
  - Полный аналог `JustifyContent` для поперечной оси.
- `Spacing`:
  - Отвечает за пространство между дочерними элементами `UIExStackPanel`.
  - Работает даже если `JustifyContent` и/или `AlignItems` == `Enums.Alignment.Stretch`
- `Reverse`:
  - Флаг, отвечающий за расположение элементов в реверсивном порядке.
  - При `true` — все элементы будут располагаться в обратном порядке, сохраняя все прочие характеристики стиля.

<h2 align="center">Пример использования <i>UIExStackPanel</i></h2>

<details>
<summary>Пример создания пользовательского интерфейса</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.UI;

namespace UIeXtenstion;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    public override void OnInitialize()
    {
        UIPanel panel = new UIPanel();
        SetPrecentRectange(0.8f, 0.8f, panel);

        UIExStackPanel HStackPanel = new();
        SetPrecentRectange(1f, 1f, HStackPanel);
        SetStyle(
            stackPanel:         HStackPanel,
            orientation:        Enums.Orientation.Horizontal,
            justifyContent:     Enums.Alignment.Stretch, 
            alignItems:         Enums.Alignment.Stretch, 
            spacingPrecent:     0.05f, 
            reverse:            false);
        
        panel.Append(HStackPanel);

        //////

        UIPanel HPanel1 = new(), HPanel2 = new(), HPanel3 = new(), HPanel4 = new();
        HStackPanel.Append(HPanel1);
        HStackPanel.Append(HPanel2);
        HStackPanel.Append(HPanel3);
        HStackPanel.Append(HPanel4);

        /////

        UIExStackPanel VStackPanel1 = new(), VStackPanel2 = new(), VStackPanel3 = new(), VStackPanel4 = new();
        SetPrecentRectange(1f, 1f, VStackPanel1, VStackPanel2, VStackPanel3, VStackPanel4);
        HPanel1.Append(VStackPanel1);
        HPanel2.Append(VStackPanel2);
        HPanel3.Append(VStackPanel3);
        HPanel4.Append(VStackPanel4);

        SetStyle(
            stackPanel: VStackPanel1,
            orientation: Enums.Orientation.Vertical,
            justifyContent: Enums.Alignment.Start,
            alignItems: Enums.Alignment.Start,
            spacingPrecent: 0.1f,
            reverse: false);

        AddCubs(VStackPanel1, pixelSize: 64f, count: 3);

        ////

        SetStyle(
            stackPanel: VStackPanel2,
            orientation: Enums.Orientation.Vertical,
            justifyContent: Enums.Alignment.Center,
            alignItems: Enums.Alignment.Center,
            spacingPrecent: 0.15f,
            reverse: true);

        AddCubs(VStackPanel2, pixelSize: 16f);
        AddCubs(VStackPanel2, pixelSize: 32f);
        AddCubs(VStackPanel2, pixelSize: 48f);
        AddCubs(VStackPanel2, pixelSize: 64f);

        ////

        SetStyle(
            stackPanel: VStackPanel3,
            orientation: Enums.Orientation.Vertical,
            justifyContent: Enums.Alignment.End,
            alignItems: Enums.Alignment.End,
            spacingPrecent: 0.20f,
            reverse: false);

        AddCubs(VStackPanel3, pixelSize: 32f);
        AddCubs(VStackPanel3, pixelSize: 48f);
        AddCubs(VStackPanel3, pixelSize: 64f);

        ////

        SetStyle(
            stackPanel: VStackPanel4,
            orientation: Enums.Orientation.Vertical,
            justifyContent: Enums.Alignment.Stretch,
            alignItems: Enums.Alignment.Stretch,
            spacingPrecent: 0.20f,
            reverse: false);

        AddCubs(VStackPanel4, pixelSize: 60f);
        AddCubs(VStackPanel4, pixelSize: 50f);
        AddCubs(VStackPanel4, pixelSize: 70f);

        ////

        Append(panel);
    }

    public static void SetStyle(
        UIExStackPanel stackPanel,
        Enums.Orientation orientation,
        Enums.Alignment justifyContent,
        Enums.Alignment alignItems,
        float spacingPrecent,
        bool reverse)
    {
        stackPanel.StyleLayoutStackPanel.Orientation = orientation;
        stackPanel.StyleLayoutStackPanel.JustifyContent = justifyContent;
        stackPanel.StyleLayoutStackPanel.AlignItems = alignItems;
        stackPanel.StyleLayoutStackPanel.Spacing.Set(0f, spacingPrecent);
        stackPanel.StyleLayoutStackPanel.Reverse = reverse;
    }

    public void SetPrecentRectange(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public void AddCubs(UIElement element, float pixelSize, int count = 1)
    {
        for (int i = 0; i < count; i++)
        {
            UIPanel panel = new UIPanel();
            panel.Width.Set(pixelSize, 0f);
            panel.Height.Set(pixelSize, 0f);
            element.Append(panel);
        }
    }
}
```

Первое, что вы видите в коде:
```csharp
UIPanel panel = new UIPanel();
SetPrecentRectange(0.8f, 0.8f, panel);
```
Это обычная панель, которую будет добавлена в `UIState`. На ней будут располагаться `UIExStackPanel`.
На изображение это самая большая и самая прозрачная панель.<br><br>
`SetPrecentRectange` - это вспомогательный метод, которого нет в самой библиотеке, и который определен ниже в этом же классе.
Он получает N `UIElement`, устанавливаем им переданную высоту и ширину и центрирует. В данном случае наша `panel` имеет размер: 80%х80% экрана.<br><br>

Далее в коде идет первый `UIExStackPanel`:
```csharp
UIExStackPanel HStackPanel = new();
SetPrecentRectange(1f, 1f, HStackPanel);
SetStyle(
    stackPanel:         HStackPanel,
    orientation:        Enums.Orientation.Horizontal,
    justifyContent:     Enums.Alignment.Stretch, 
    alignItems:         Enums.Alignment.Stretch, 
    spacingPrecent:     0.05f, 
    reverse:            false);

panel.Append(HStackPanel);
```
- `SetPrecentRectange(1f, 1f, HStackPanel);` - устанавливает размеры `HStackPanel`: 100% от родительского элемента.
- Ниже мы добавляем ее в основную панель `panel.Append(HStackPanel);`, что означает, что `HStackPanel` будет компоновать элементы по всему созданному интерфейсу.
- `SetStyle` -это вспомогательный метод, которого нет в самой библиотеке, и который определен ниже в этом же классе. Он устанавливает все стили, которые может принимать `UIExStackPanel`
- Его стили:
  - `Orientation`: горизонтальная.
  - `JustifyContent` (выравнивание элементов по основной оси) (основная ось - горизонтальная): `stretch` - элементы занимают все доступное пространство по ширине.
  - `AlignItems` (выравнивание элементов по поперечной оси) (поперечной ось - вертикальная): `stretch` - элементы занимают все доступное пространство по высоте.
  - `Spacing`: 5% от размера основной оси контейнера (в данном случае: 5% от ширины `HStackPanel` -> `panel`).
  - `Reverse`: false - элементы располагаются в том порядке, в каком они будут добавлены в `HStackPanel`.


Позже в `HStackPanel` будут добавлены 4 `UIPanel`:
- `HStackPanel` сперва выделит место под `Spacing (5% * HStackPanel.Width * HStackPanel.GetWithoutLayoutElementsCount() - 1)`
- Затем посчитает свободное пространство и поделит его между этими элементами.
- Результат этого вы можете посмотреть самостоятельно. На изображении это 4 самые высокие панели.
