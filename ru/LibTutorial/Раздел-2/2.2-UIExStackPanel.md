<h1 align="center">Класс <i>UIExStackPanel</i></h1>

`UIExStackPanel` - это контейнер компоновки, который располагает дочерние элементы в одну линию (стопку) по вертикали или по горизонтали.
`UIExStackPanel` определяет поле `public Styles.StyleLayoutContainerStackPanel StyleLayoutStackPanel { get; set; }`, которое хранит все стили компоновки для данного класса.

```csharp
public class StyleLayoutContainerStackPanel : IStyleLayoutContainer, IStyleCopy<StyleLayoutContainerStackPanel>
{
    public Enums.Orientation Orientation = Enums.Orientation.Vertical;
    public Enums.Alignment JustifyContent = Enums.Alignment.Start;
    public Enums.Alignment AlignItems = Enums.Alignment.Start;
    public StyleDimension Spacing = StyleDimension.Empty;
    public bool Reverse = false;

    public StyleLayoutContainerStackPanel Copy() { /* ... */ }
}
```

- `Orientation`:
  - Отвечает за то, по какой оси будет располагаться дочерние элементы.
  - Может принимать два значения: `Enums.Orientation.Vertical` и `Enums.Orientation.Horizontal`.
- `JustifyContent`:
  - Отвечает за то, как будут выравниваться вложенные элементы относительно основной оси:
    - `Enums.Alignment.Start` - элементы будут располагаться с стартовой точки основной оси `UIExStackPanel`. Размер элементов не меняется.
    - `Enums.Alignment.Center` - элементы будут располагаться по центру основной оси `UIExStackPanel`. Размер элементов не меняется.
    - `Enums.Alignment.End` - элементы будут располагаться с конечной точки основной оси `UIExStackPanel`. Размер элементов не меняется.
    - `Enums.Alignment.Stretch` - элементы будут располагаться с стартовой точки основной оси `UIExStackPanel`. `UIExStackPanel` поровну разделит свое пространство по основной на количество дочерних элементов и растянет Height или Width (зависит от оси) элементов, чтобы они заняли все доступное пространство основной оси.
- `AlignItems`:
  - Отвечает за то, как буду выравниваться вложенные элемент относительно поперечной оси.
  - Полный аналог `JustifyContent` для поперечной оси.
- `Spacing`:
  - Отвечает за пространство между дочерними элементами `UIExStackPanel`.
  - Работает даже если `JustifyContent` и/или `AlignItems` == `Enums.Alignment.Stretch`
- `Reverse`:
  - Флаг, отвечающий за расположение элементов в реверсивном порядке.
  - При `true` — все элементы будут располагаться в обратном порядке, сохраняя все прочие характеристики стиля.
