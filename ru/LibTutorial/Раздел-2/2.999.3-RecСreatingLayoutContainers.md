<h2 align="center">Создание стилей компоновки</h2>

Перед созданием своего класса контейнера, вы должны ответить себе на два вопроса:
1. Будет ли контейнер определять свой стиль компоновки контейнера?
2. Будет ли контейнер определять свой стиль для вложенных элементов?<br>
<!-- -->
1. Все стили компоновки контейнера должны наследоваться от класса `UIeXtension.Styles.Base.StyleLayoutContainerBase`.
2. Все стили компоновки отдельного элемента должны наследоваться от класса `UIeXtension.Styles.Base.StyleLayoutChildBase`.<br>

Сами классы `StyleLayoutContainerBase` и `StyleLayoutChildBase` наследуют класс `UIeXtension.Styles.Base.StyleBase`.<br>

```csharp
public abstract class StyleBase
{
    protected abstract StyleBase Fabricate();

    protected abstract void CopyBase(StyleBase style);

    protected virtual void CopyInnerStylesBase(StyleBase style) { }

    protected internal T GetCopyBase<T>() where T : StyleBase, new()
    {
        T copy = new();
        copy.CopyBase(this);
        copy.CopyInnerStylesBase(this);
        return copy;
    }


    protected internal StyleBase GetCopyBase()
    { 
        StyleBase copy = Fabricate();
        copy.CopyBase(this);
        copy.CopyInnerStylesBase(this);
        return copy;
    }


    public bool EqualsStylesFields(StyleBase other)
    {
        if (!EqualsFields(other))
            return false;

        return EqualsInnerStylesFields(other);
    }

    protected abstract bool EqualsFields(StyleBase other);


    protected bool EqualsInnerStylesFields<TStyleBase>(Dictionary<Type, TStyleBase> styles1, Dictionary<Type, TStyleBase> styles2) 
        where TStyleBase : StyleBase
    {
        if (styles1.Count != styles2.Count)
            return false;

        foreach (var key in styles1.Keys)
        {
            if (!styles2.ContainsKey(key))
                return false;

            if (!styles1[key].EqualsFields(styles2[key]))
                return false;
        }

        return true;
    }


    protected virtual bool EqualsInnerStylesFields(StyleBase other) => true;
}
```
<br>

Все примеры приведены из класса `StyleLayoutContainerUniformGrid`.

1. Метод `Fabricate` должен возвращать экземпляр созданного вами класса стиля.<br>
```csharp
protected override Base.StyleBase Fabricate() => new StyleLayoutContainerUniformGrid();
```
<br>

2. Метод `CopyBase` рекомендуется реализовывать следующим образом:<br>
```csharp
protected override void CopyBase(Base.StyleBase style)
{
    if (style is StyleLayoutContainerUniformGrid style2)
        Copy(style2);
}
```
<br>

3. В примере использован метод `Copy`. Хотя библиотека не требует создание данного метода, его создание крайне желательно:
```csharp
public void Copy(StyleLayoutContainerUniformGrid style)
{
    RowsCount = style.RowsCount;
    ColumnsCount = style.ColumnsCount;

    RowsAlignment = style.RowsAlignment;
    ColumnsAlignment = style.ColumnsAlignment;

    RowsSpace = style.RowsSpace;
    ColumnsSpace = style.ColumnsSpace;
}
```
<br>

4. С методами `GetCopyBase`, `EqualsStylesFields`, `EqualsInnerStylesFields` не нужно ничего делать. Они уже полностью реализованы.<br><br>

5. Метод `EqualsFields(StyleBase other)` должен сравнивать все поля текущего и переданного стиля:
```csharp
protected override bool EqualsFields(Base.StyleBase other)
{
    if (other is StyleLayoutContainerUniformGrid style)
    {
        if (RowsCount != style.RowsCount ||
            ColumnsCount != style.ColumnsCount)
            return false;

        if (RowsAlignment != style.RowsAlignment ||
            ColumnsAlignment != style.ColumnsAlignment)
            return false;

        if (!Utils.UtilsStyles.EqualsStyleDimensionFields(RowsSpace, style.RowsSpace) ||
            !Utils.UtilsStyles.EqualsStyleDimensionFields(ColumnsSpace, style.ColumnsSpace))
            return false;

        return true;
    }

    return false;
}
```

----

Следующие методы не определены в классе `StyleBase`, но их содержит каждый класс стиля данной библиотеки:
1. Метод `Copy` уже описан выше.<br><br>
2. Методы `Set`, `SetAllProperties`. Оба метода принимают все поля класса. Метод `Set` дает каждому из них параметр по умолчанию:
```csharp
public void Set(
    int rowsCount = 0,
    int columnsCount = 0,
    Enums.UIExAlignment rowsAlignment = Enums.UIExAlignment.Start,
    Enums.UIExAlignment columnsAlignment = Enums.UIExAlignment.Start,
    StyleDimension rowsSpace = default(StyleDimension),
    StyleDimension columnSpace = default(StyleDimension))
        => SetAllFields(
            rowsCount,
            columnsCount,
            rowsAlignment,
            columnsAlignment,
            rowsSpace,
            columnSpace);

protected void SetAllFields(
    int rowsCount,
    int columnsCount,
    Enums.UIExAlignment rowsAlignment,
    Enums.UIExAlignment columnsAlignment,
    StyleDimension rowsSpace,
    StyleDimension columnSpace)
{
    RowsCount = rowsCount;
    ColumnsCount = columnsCount;

    RowsAlignment = rowsAlignment;
    ColumnsAlignment = columnsAlignment;

    RowsSpace = rowsSpace;
    ColumnsSpace = columnSpace;
}
```
<br>

3. Метод `THIS_CLASS GetCopy()` возвращает новый объект класса стиля со всему текущими полями. Если вы реализовали метод `CopyBase` (см. выше), то достаточно следующей реализации:
```csharp
public StyleLayoutContainerUniformGrid GetCopy()
    => GetCopyBase<StyleLayoutContainerUniformGrid>();
```

----

Также все классы стиля данной библиотеки имеют два конструктора:
1. По умолчанию (обязательное требование).
2. Принимающий все поля класса (со значениями по умолчанию).
```csharp
public StyleLayoutContainerUniformGrid() { }

public StyleLayoutContainerUniformGrid(
    int rowsCount = 0,
    int columnsCount = 0,
    Enums.UIExAlignment rowsAlignment = Enums.UIExAlignment.Start,
    Enums.UIExAlignment columnsAlignment = Enums.UIExAlignment.Start,
    StyleDimension rowsSpace = default(StyleDimension),
    StyleDimension columnSpace = default(StyleDimension))
        => SetAllFields(
            rowsCount,
            columnsCount,
            rowsAlignment,
            columnsAlignment,
            rowsSpace,
            columnSpace);
```

<h2 align="center">Регистрация стилей компоновки</h2>

1. Стили компоновки контейнера должны быть зарегистрированы в классе `StyleLayoutContainer`.
2. Стили компоновки отдельного элемента должны быть зарегистрированы в классе `StyleLayoutChild`.<br>

В самой библиотеке все классы контейнеров зарегистрированы в `StyleLayoutContainer` (аналогично для `StyleLayoutChild`):
```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    private readonly System.Collections.Generic.Dictionary<System.Type, Base.StyleLayoutContainerBase> _styles = new();

    public StyleLayoutContainerCanvas Canvas() => GetOrCreateStyle<StyleLayoutContainerCanvas>();
    public StyleLayoutContainerStackPanel StackPanel() => GetOrCreateStyle<StyleLayoutContainerStackPanel>();
    public StyleLayoutContainerDockPanel DockPanel() => GetOrCreateStyle<StyleLayoutContainerDockPanel>();
    public StyleLayoutContainerWrapPanel WrapPanel() => GetOrCreateStyle<StyleLayoutContainerWrapPanel>();
    public StyleLayoutContainerGrid Grid() => GetOrCreateStyle<StyleLayoutContainerGrid>();
    public StyleLayoutContainerUniformGrid UniformGrid() => GetOrCreateStyle<StyleLayoutContainerUniformGrid>();

    public T GetOrCreateStyle<T>() where T : Base.StyleLayoutContainerBase, new()
    {
        if (!_styles.TryGetValue(typeof(T), out Base.StyleLayoutContainerBase value))
        {
            value = new T();
            _styles.Add(typeof(T), value);
        }

        return (T)value;
    }
}
```

Для регистрации вашего стиля нужно использовать метод расширения для данного класса. Например:
```csharp
using UIeXtension;
using UIeXtension.Styles;
using UIeXtension.Styles.Base;

namespace Example;

// ваш класс стиля компоновки контейнера
public class StyleLayoutContainerExample : StyleLayoutContainerBase 
{ 
    /* 
    
    ... 

    */ 
}


// ваш класс с методом расширения для StyleLayoutContainer
public static class StyleLayoutContainerExtensions
{
    public static StyleLayoutContainerExample Example(this StyleLayoutContainer style)
        => style.GetOrCreateStyle<StyleLayoutContainerExample>();
}


// класс для примера получения вашего стиля
public class ExampleClass
{
    public void Initialize()
    {
        UIExGrid customLayout = new(); // вместо UIExGrid - ваш контейнер компоновки
        StyleLayoutContainerExample style = customLayout.StyleLayout.Example(); 
    }
}
```
