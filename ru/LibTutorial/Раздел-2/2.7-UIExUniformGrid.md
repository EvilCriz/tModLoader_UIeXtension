<h1 align="center">Класс <code>UIExUniformGrid</code></h1>

----

- Данная библиотека предполагает, что вы уже изучили [базовое руководство tModLoader по пользовательскому интерфейсу](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Данная статья предполагает, что вы изучили статью: [«структура стилей»](../Раздел-1/1.3-StyleStructure.md)
- Данная статья предполагает, что вы изучили статью: [«класс UIExLayout. Основы компоновки»](2.1-UIExLayout.md)
- Данная статья предполагает, что вы изучили статью: [«класс UIExGrid»](2.6-UIExGrid.md)

----
<br>

----

`UIExUniformGrid` - это контейнер компоновки для двумерного расположения элементов интерфейса в виде строк и столбцов, который автоматически упорядочивает дочерние элементы в сетке, где каждая ячейка имеет абсолютно одинаковый размер.<br>

**Важно!**. Данная статья предполагает, что вы уже изучили статью `UIExGrid`.<br>
Данный класс работает аналогично с базовыми стилями, поэтому в данной статье они рассматриваться не будут.<br>
Часть стилей `UIExUniformGrid` имеет аналогичные значения `UIExGrid`, и также не будет рассматриваться в данной статье.

----

<h2 align="center">Стили <code>UIExUniformGrid</code></h2>

`UIExUniformGrid` использует значения `StyleLayoutContainer` и `StyleLayoutChild` аналогично `UIExGrid`.

----

Для `UIExUniformGrid` существует класс стиля `StyleLayoutContainerUniformGrid`:
```csharp
public class StyleLayoutContainerUniformGrid : Base.StyleLayoutContainerBase
{
    public StyleDimension RowsSpace = StyleDimension.Empty;
    public StyleDimension ColumnsSpace = StyleDimension.Empty;

    public Enums.UIExAlignment RowsAlignment = Enums.UIExAlignment.Start;
    public Enums.UIExAlignment ColumnsAlignment = Enums.UIExAlignment.Start;

    public int RowsCount = 0;
    public int ColumnsCount = 0;
}
```

Значения `RowsSpace`, `ColumnsSpace`, `RowsAlignment`, `ColumnsAlignment` работают аналогично `UIExGrid`.<br><br>

В отличии от `UIExGrid` не содержит методов настройки сетки.<br>
Каждая ячейка имеет `UIExGridLength`: `Type = UIExGridLengthType.Fraction` и `Fraction = 1f`.<br>
Вы только можете задать количество ячеек сетки с помощью `RowsCount` и `ColumnsCount`.<br>

`UIExUniformGrid` позволяет указать оба значения `RowsCount` и `ColumnsCount`, либо же указать только одно из них, или не указывать ни одного из них.<br>
Если указали только одно из этих значений или ни одного, то `UIExUniformGrid` сам определит размер сетки исходя из количества элементов.<br>
При этом он попытается сделать сетку максимально близкой к квадратной форме, но не создавая пустых рядов/колонок.<br>

**Важно**. При автоматическом расчете ячеек не учитывается `RowSpan` и `ColumnSpan` элементов.<br>
Если вы хотите использовать данные значения, то вам придется рассчитать размер сетки самостоятельно.<br>
Более подробно о расположении элементов, `RowSpan` и `ColumnSpan` будет написано ниже.

----

Все вложенные в `UIExUniformGrid` элементы могут использовать стиль `StyleLayoutChildUniformGrid`.
Чтобы вы могли использовать данный стиль, вам необходимо получить стиль `StyleLayoutChild` с помощью метода расширения `UIElement`: `StyleLayoutChild()`.
Затем у полученного стиля вызвать метод `UniformGrid()`.
```csharp
UIElement element = new();
StyleLayoutChild style = element.UniformGrid();
StyleLayoutChildUniformGrid styleUGrid = style.Grid();
styleUGrid.RowSpan = 2;
```

Сам класс `StyleLayoutChildUniformGrid` имеет следующую реализацию:
```csharp
public class StyleLayoutChildUniformGrid : Base.StyleLayoutChildBase
{
    public int RowSpan = 1;
    public int ColumnSpan = 1;
}
```

Как видно, в отличии от `StyleLayoutChildGrid` в данном классе **не** определены поля `Row` и `Columns`.<br>
`UIExUniformGrid` сам определяет, где расположить элемент.<br>
Если `RowSpan == 1` и `ColumnSpan == 1`, то элементы располагаются слева-направо и сверху вниз.<br>
Т.е. для сетки размером `2x2` в которую добавлено 3 элемента, они будут расположены в следующем порядке:
- `[element 1]`: `{0, 0}`;
- `[element 2]`: `{0, 1}`;
- `[element 3]`: `{1, 0}`.<br>

1. Каждый следующий элемент сдвигался на одну колонку вправо, пока справа оставались свободные ячейки.
2. Когда свободных ячеек в колонке не осталось, элемент сдвинулся в самую левую колонку, но на один ряд ниже.
3. Если бы на пути расположения была бы уже занятая ячейка (об этим в примере ниже) - элемент бы сдвинулся дальше.<br>

Если элементов больше, чем количества ячеек, то все элементы, которые не помещаются - будут размещены в последней ячейке.<br>
Для таких элементов `RowSpan` и `ColumnSpan` не учитываются.

----

Это был случай для `RowSpan == 1` и `ColumnSpan == 1`.<br>
Теперь представим, что первый элемент имеет `ColumnSpan == 2`.<br>
В этом случае элементы будут расположены в следующем порядке:
- `[element 1]`: `{ {0, 0}, {0, 1} }`;
- `[element 2]`: `{1, 0}`;
- `[element 3]`: `{1, 1}`.<br><br>

А теперь возьмем случай, если первый элемент имеет `RowSpan == 2` и `ColumnSpan == 2`.<br>
Тогда расположение элементов будет следующим:
- `[element 1]`: `{ {0, 0}, {0, 1}, {1, 0} }`;
- `[element 2]`: `{1, 1}`;
- `[element 3]`: `{1, 1}`.<br>

1. Первый элемент забрал себе 3 ячейки: левую-верхнюю (`{0, 0}`), правую-верхнюю (`{0, 1}`), левую-нижнюю (`{1, 0}`).
2. Для второго элемента осталась только одна свободная ячейка: правая-нижняя (`{1, 1}`).
3. Для третьего элемента не осталось свободных ячеек, поэтому он занял последнюю ячейку в сетке: правую-нижнюю (`{1, 1}`).

----

Пример использования в `UIExUniformGrid` для элементов, со значениями `RowSpan == 1` и `ColumnSpan == 1`, а также с автоматическим определением `RowsCount` и `ColumnsCount` показано с статье `UIExLayout`.

----

означает что все вспомогательные линии могут отрисовываться одновременно.

<h2 align="center">Пример использования <i>UIExUniformGrid</i></h2>

<details>
<summary>Пример создания макета калькулятора (без комментариев, разбор ниже)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // метод OnActivate() в данном случае используется только
    // для функции «горячей перезагрузки кода» в среде разработки.
    // для реального интерфейса правильнее было бы использовать
    // метод OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 650f, panel);

        UIExUniformGrid uGrid = new();
        uGrid.Stretch();

        ////////////////////////////

        StyleLayoutContainer styleLayout = uGrid.StyleLayout;
        StyleLayoutContainerUniformGrid styleLayoutUGrid = styleLayout.UniformGrid();

        styleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Stretch,
            alignItems:         UIExAlignment.Stretch);



        styleLayoutUGrid.Set(
            rowsCount:      7,
            columnsCount:   4,
            rowsSpace:      StyleDimension.FromPixels(10f),
            columnSpace:    StyleDimension.FromPixels(15f));

        ///////////////////////////

        AppendButton(uGrid, prefix: "RESULT:", rowSpan: 2, columnSpan: 4);

        AppendButton(uGrid, prefix: "AC");
        AppendButton(uGrid, prefix: "%");
        AppendButton(uGrid, prefix: "<<");
        AppendButton(uGrid, prefix: "/");

        AppendButton(uGrid, prefix: 7);
        AppendButton(uGrid, prefix: 8);
        AppendButton(uGrid, prefix: 9);
        AppendButton(uGrid, prefix: "*");

        AppendButton(uGrid, prefix: 4);
        AppendButton(uGrid, prefix: 5);
        AppendButton(uGrid, prefix: 6);
        AppendButton(uGrid, prefix: "-");

        AppendButton(uGrid, prefix: 1);
        AppendButton(uGrid, prefix: 2);
        AppendButton(uGrid, prefix: 3);
        AppendButton(uGrid, prefix: "+");

        AppendButton(uGrid, prefix: 0);
        AppendButton(uGrid, prefix: ",");
        AppendButton(uGrid, prefix: "=", columnSpan: 2);

        ///////////////////////////

        panel.Append(uGrid);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AppendButton(UIExLayout layout, int prefix, int rowSpan = 1, int columnSpan = 1)
        => AppendButton(layout, prefix.ToString(), rowSpan, columnSpan);
    public UIButton<string> AppendButton(UIExLayout layout, string prefix, int rowSpan = 1, int columnSpan = 1)
    {
        UIButton<string> button = new(prefix);

        StyleLayoutChildUniformGrid styleGrid = button.StyleLayoutChild().UniformGrid();
        styleGrid.Set(rowSpan, columnSpan);

        layout.Append(button);
        return button;
    }
}
```

----

Данный код практически идентичен `UIExGrid`, поэтому мы будет разбирать только те его части, которые отличаются.

----

```csharp
styleLayoutUGrid.Set(
    rowsCount:      7,
    columnsCount:   4,
    rowsSpace:      StyleDimension.FromPixels(10f),
    columnSpace:    StyleDimension.FromPixels(15f));
```

Тут указывается размер колонок и столбцов.<br>
`UIExUniformGrid` не сможет посчитать размер сетки самостоятельно, так как элементы внутри него используют `RowSpan` и `ColumnSpan`.

----

Далее добавляются элементы.<br>
Метод `AppendButton` идентичный, за исключением того, что он не принимает значения `row`, `column`, и не устанавливает их созданной внутри кнопке.<br>

----

Первое добавление:
```csharp
AppendButton(uGrid, prefix: "RESULT:", rowSpan: 2, columnSpan: 4);
```
В данном случае мы знаем, что это первый элемент и он будет располагаться в ячейке `{0, 0}`.<br>
Так как у элемента `RowSpan == 2` `ColumnSpan == 4`, то данный элемент будет занимать следующее множество ячеек:
- `{`
  - `{0, 0}, {0, 1}, {0, 2}, {0, 3}`
  - `{1, 0}, {1, 1}, {1, 2}, {1, 3}`
- `}`<br>

Второй добавляемый элемент:
```csharp
AppendButton(uGrid, prefix: "AC");
```
Так как последняя занятая ячейка: `{1, 3}`, и это крайняя колонка, то данный элемент будет расположен в ячейке: `{2, 0}`.<br>

Следующий за ним элемент `{2, 1}` и т.д.
