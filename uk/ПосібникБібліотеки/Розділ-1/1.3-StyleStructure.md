<h1 align="center">Структура стилю</h1>

<hr>

- Бібліотека припускає, що ви вже навчилися [базовий посібник tModLoader Користувач-інтерфейс](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Бібліотека припускає, що ви вже навчилися [Розширений посібник з налаштування інтерфейсу користувача](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>

<hr>

Стилі в цій бібліотеці діляться на 4 типи:
1. Стилі візуального відображення.
2. Візуальні стилі елементів з **tModLoader**
3. Контейнерні стилі макета.
4. Стилі макета окремого елемента.

----

- **Стилі візуального відображення** Це всі стилі, які відповідають за всю візуальну частину, крім місця розташування елемента (колір, форма, обрізка тощо).

----

- **Візуальні стилі елементів з tModLoader** Стилі, які дозволяють встановити параметри стилю базових елементів **tModLoader**.<br><br>

Роз’яснення обов’язкове в цьому пункті.<br>
Будь-який елемент в даній бібліотеці може прийняти візуальний стиль даної бібліотеки (див. попередній абзац) або стиль елемента. **tModLoader**.<br>
Наприклад, елемент `UIExElement` може прийняти візуальний стиль `UIPanel`.<br>
Деталі нижче.

----

- **Стилі макета контейнера** Ці всі стилі, які використовуються тільки конструкторами компонентів (*)UIExStackPanel*, *UIExDockPanel*, *UIExGridВони містять загальні правила про те, як влаштовувати елементи у себе.

----

- **Стилі індивідуального макета елемента** Це всі стилі, які використовується елементом конструктора, щодо індивідуального *UIElementРозглянуто докладніше в розділі по макету елементів.

----

Ця стаття не буде займатися індивідуальними класами стилю. `UIExElement` (`UIExLayout` для стилів макета і буде обговорюватися в поєднанні з цими елементами в наступних розділах.

----

<h2 align="center"><b>Стилі візуального відображення</b></h2>

**ВАЖЛИВО!** Бібліотека перебуває в розробці.<br>
У цьому блокі **стилів візуалізації** Інформація для розуміння загальної системи стилю.<br>
На даний момент бібліотека має лише контейнери макетів (близько їх нижче). `UIExElement`.<br><br>

`UIExElement` Він зберігає поле в ній:
```csharp
public class UIExElement : UIElement
{
  public Styles.StyleVisualElement StyleDisplay;
}
```
Відповідно, це поле успадковується усіма елементами бібліотеки.<br>
Візуальні стилі для **будь-який** Елементи будуть встановлюватися через це поле.


Клас `StyleVisualElement` Зберігає стилі всіх `UIExElement` і способи повернення стилів будь-якого класу спадкоємців `UIExElement`.<br>
Наприклад, є класи (в якості прикладу, в розробці):
```csharp
public class UIExButton : UIExElement {}
public class UIExTextBlock : UIExButton {}
```
<br>

У цьому випадку бібліотека буде мати відповідні класи стилю:
```csharp
public class StyleVisualButton {}
public class StyleVisualTextBlock {}
```
<br>

Клас. `StyleVisualElement` будуть мати такі методи:
```csharp
public class StyleVisualElement
{
    public StyleVisualButton Button() { /* ... */ }
    public StyleVisualTextBlock TextBlock() { /* ... */ }
}
```
<br>

Тепер ми можемо отримати стилі наступним чином:
```csharp
UIExElement element = new();
UIExButton button = new();
UIExTextBlock textBlock = new();

StyleVisualElement elementStyleDisplay = element.StyleDisplay;
StyleVisualElement buttonStyleDisplay = button.StyleDisplay;
StyleVisualElement textBlockStyleDisplay = textBlock.StyleDisplay;

StyleVisualButton buttonStyle = buttonStyleDisplay.Button();

StyleVisualTextBlock textBlockStyle = textBlockStyleDisplay.TextBlock();
```
<br>

<h2 align="center"><b>Візуальні стилі елементів з tModLoader</b></h2>

Замість використання **візуалізація** У даній бібліотеці ви можете вказати на предмет, який він повинен використовувати стиль конкретного (у пункті вирішить, який) елемента. **tModLoader**.<br>
Для цього в полі. `StyleDisplay` потрібно вказати `tModLoaderStyle = true`.
```csharp
UIExElement element = new();
element.StyleDisplay.tModLoaderStyle = true;
```

Кожен елемент вирішує стиль якого елемента. **tModLoader** використовувати його.<br>
`UIExElement` А будь-який елемент макета в цьому випадку буде використовувати стиль. `UIPanel`.<br>
- Бібліотека, яка під час розробки. На сьогоднішній день немає інших елементів.<br><br>

Ви можете отримати базовий клас стилю і змінити його значення.<br>
```csharp
UIExElement element = new();

element.StyleDisplay.tModLoaderStyle = true;

StyleTmlUIPanel styleTmlUIPanel =  element.StyleDisplay.TmlUIPanel();
styleTmlUIPanel.BackgroundColor = Color.Red;
```

У цьому прикладі, `UIExElement` Він буде виглядати як `UIPanel`Але це буде колір червоний.<br>

Назва класа стилю і способу:
- Клас імен починається з `StyleTml`а потім: назва елемента **tModLoader** відповідний стиль.
- Назва методу починається з `Tml`а потім: назва елемента **tModLoader** відповідний стиль.

<h2 align="center">Стилі макета контейнера</h2>

Стилі для зберігання та отримання контейнерів ідентичні **візуалізація**<br>
Клас `UIExLayout` (який успадкує всі контейнери) містить поле:
```csharp
class UIExLayout : UIExElement
{
    public StyleLayoutContainer StyleLayout
}
```
<br>

Клас `StyleLayoutContainer` аналогово `StyleVisualElement` Він зберігає методи, які повертають стилями розташування контейнера класу спадкоємця:
```csharp
// Використовуються як приклад. UIExLayout анотація.
UIExLayout layout = new();
UIExCanvas canvas = new();
UIExStackPanel stackPanel = new();

StyleLayoutContainer styleLayout = layout.StyleLayout;
StyleLayoutContainer styleLayoutCanvas = canvas.StyleLayout;
StyleLayoutContainer styleLayoutStackPanel = stackPanel.StyleLayout;

StyleLayoutContainerCanvas styleCanvas = styleLayoutCanvas.Canvas();
StyleLayoutContainerStackPanel styleStackPanel = styleLayoutCanvas.StackPanel();
```

<h2 align="center">Стилі індивідуального макета елемента</h2>

Система дуже схожа тут, але на відміну від попередніх прикладів, стиль макета індивідуального елемента може мати будь-який тип конструкції. `UIElement` Увійти **tModLoader**.<br>
Тому отримання цих стилів відбувається за допомогою методу розширення. `UIElement.StyleLayoutChild()`
```csharp
UIElement element = new();
StyleLayoutChild styleLayout = element.StyleLayoutChild();
StyleLayoutChildCanvas styleLayoutCanvas = styleLayout.Canvas();
```
<br>

Регулярність між назвою контейнерних стилів та окремими елементами:
- `UIExLayout` - `StyleLayoutContainer` - `StyleLayoutChild`
- `UIExCanvas` - `StyleLayoutContainerCanvas` - `StyleLayoutChildCanvas`
- `UIExStackPanel` - `StyleLayoutContainerStackPanel` - `StyleLayoutChildStackPanel`<br>

Як ви можете побачити, імена класів починаються з `StyleLayout` - Вона йде на. `Container/Child` назва контейнера (крім контейнера) `UIExLayout`).

<h2 align="center">Додаткова інформація</h2>

Всі класи стилю - спадкоємці класу. `StyleBase`.<br>
Цей клас має лише 1 публічний метод.
```csharp
public bool EqualsStylesFields(StyleBase other) { /* ... */ }
```
Цей метод перевіряє, чи є всі поля всіх переданих стилів.<br>
Наприклад:
```csharp
StyleLayoutChildCanvas styleCanvas = new();
StyleLayoutContainer style1 = new();
StyleLayoutContainer style2 = new();


//////////////////

// [1]: метод повернеться false
style1.EqualsStylesFields(styleCanvas);


//////////////////

// [2]: метод повернеться true
style1.EqualsStylesFields(style2);


//////////////////

style1.JustifyContent = UIExAlignment.Center;

// [3]: метод повернеться false
style1.EqualsStylesFields(style2);


//////////////////

style2.JustifyContent = UIExAlignment.Center;

// [4]: метод повернеться true
style1.EqualsStylesFields(style2);


//////////////////

style1.UniformGrid();

// [5]: метод повернеться false
style1.EqualsStylesFields(style2);


//////////////////

style2.UniformGrid();

// [6]: метод повернеться true
style1.EqualsStylesFields(style2);


//////////////////

style2.UniformGrid().ColumnsCount = 5;

// [7]: метод повернеться false
style1.EqualsStylesFields(style2);
```

Результати виклику `EqualsStylesFields`:
1. Порівняється з двома різними класами стилю. `false`.
2. Порівняти два стилі на поля за замовчуванням. `true`.
3. Смоктати `style1` значення `JustifyContent` Це змінено. `style2` Поле стилю відрізняються. `false`.
4. Смоктати `style2` значення `JustifyContent` змінено на ідентичність `style1`Поле стилю однакові. `true`.
5. для `style1` Зареєструватися `StyleLayoutContainerUniformGrid`Для мене. `style2` - незареєстровані. `false`.
6. для `style2` Зареєструватися `StyleLayoutContainerUniformGrid`Для мене. `style1` Цей стиль був зареєстрований до. `true`.
7. Значення поля `ColumnsCount` зареєстрований стиль `StyleLayoutContainerUniformGrid` `style2` Це різні. Це різні. Це різні. Це різні. `false`.

----

Всі класи стилю містять 2 конструктори:
1. За замовчуванням.
2. Прийняти всі значення для полів даного класу стилю (не вказано значення за замовчуванням).

----

Всі класи стилю містять публічні методики за шаблоном нижче:
```csharp
/*

public void Set(
	type FIELD_1 = default(type), 
	type FIELD_2 = default(type), 
	..., 
	type FIELD_N = default(type))
		=> SetAllFields(
			FIELD_1, 
			FIELD_2, 
			..., 
			FIELD_N);



public void Copy(TYPE_STYLE style)
    => SetAllFields(
			style.FIELD_1, 
			style.FIELD_2, 
			..., 
			style.FIELD_N);

public TYPE_STYLE GetCopy()
    => GetCopyBase<TYPE_STYLE>();

*/
```

1. Методика `Set` приймає всі значення поля, які містять цей стиль (не вказано значення за замовчуванням).
2. Методика `Copy` Приймає схожий стиль і копіює всі поля перенесеного стилю.
3. Методика `GetCopy` повертає новий стильовий об'єкт з копіюванням всіх полів класу (включаючи копію зареєстрованих стилів).

----

1. **Стилі візуального відображення** Перевага класу: `StyleVisualElementBase`.
2. **Візуальні стилі елементів з tModLoader** Перевага класу: `StyleTmlBase`.
3. **Стилі макета контейнера** Перевага класу: `StyleLayoutContainerBase`.
4. **Стилі верстки приглушених елементів** Перевага класу: `StyleLayoutChildBase`.<br>
