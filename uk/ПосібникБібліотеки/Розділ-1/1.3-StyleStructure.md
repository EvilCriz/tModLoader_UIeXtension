<h1 align="center">Структура стилів</h1>

<hr>

* Ця бібліотека передбачає, що ви вже вивчили [базовий посібник tModLoader з користувацького інтерфейсу]<br>
* Ця бібліотека передбачає, що ви вже вивчили [розширений посібник з налаштування користувацького інтерфейсу]<br>

<hr>

Стилі в цій бібліотеці поділяються на 4 види:

1. Стилі візуального відображення.
2. Візуальні стилі елементів від **tModLoader**
3. Стилі компоновки контейнера.
4. Стилі компоновки окремого елемента.

---

* **Стилі візуального відображення** — це всі стилі, які відповідають за всю візуальну частину, крім розташування елемента (колір, форма, обведення тощо).

---

* **Візуальні стилі елементів від tModLoader** — це стилі, які дозволяють задавати параметри стилю базових елементів **tModLoader**.<br><br>

У цьому пункті потрібне уточнення.<br>
Будь-який елемент у цій бібліотеці може приймати візуальний стиль цієї бібліотеки (див. попередній пункт) або стиль елемента **tModLoader**.<br>
Наприклад: елемент `UIExElement` може прийняти візуальний стиль `UIPanel`.<br>
Детальніше нижче.

---

* **Стилі компоновки контейнера** — це всі стилі, які використовують лише компоновники елементів (*UIExStackPanel*, *UIExDockPanel*, *UIExGrid* тощо). Вони містять загальні правила щодо того, як розташовувати елементи всередині себе.

---

* **Стилі компоновки окремого елемента** — це всі стилі, які використовує компоновник елементів щодо окремого *UIElement*. Детальніше це буде розглядатися в розділі, присвяченому компоновці елементів.

---

У цій статті не розглядатимуться окремі класи стилів. Кожен подібний клас пов'язаний зі своїм `UIExElement` (`UIExLayout` для стилів компоновки) і розглядатиметься разом із цими елементами в наступних розділах.

---

<h2 align="center"><b>Стилі візуального відображення</b></h2>

**ВАЖЛИВО!** Бібліотека перебуває в розробці.<br>
У цьому блоці про **стилі візуального відображення** наведено інформацію для розуміння загальної системи стилів.<br>
На даний момент у бібліотеці є лише контейнери компоновки (про них нижче) та `UIExElement`.<br><br>

`UIExElement` зберігає в собі поле:

```csharp
public class UIExElement : UIElement
{
  public Styles.StyleVisualElement StyleDisplay;
}
```

Відповідно, це поле успадковується всіма елементами цієї бібліотеки.<br>
Візуальні стилі для **будь-якого** елемента будуть задаватися через це поле.

Клас `StyleVisualElement` зберігає в собі стилі всіх `UIExElement` та методи, що повертають стилі будь-яких класів-нащадків `UIExElement`.<br>
Наприклад, є класи (наведено для прикладу; у розробці):

```csharp
public class UIExButton : UIExElement {}
public class UIExTextBlock : UIExButton {}
```

<br>

У цьому випадку в бібліотеці будуть відповідні класи стилів:

```csharp
public class StyleVisualButton {}
public class StyleVisualTextBlock {}
```

<br>

А клас `StyleVisualElement` матиме такі методи:

```csharp
public class StyleVisualElement
{
    public StyleVisualButton Button() { /* ... */ }
    public StyleVisualTextBlock TextBlock() { /* ... */ }
}
```

<br>

Тепер ми можемо отримувати стилі таким чином:

```csharp
UIExElement element = new();
UIExButton button = new();
UIExTextBlock textBlock = new();

StyleVisualElement elementStyleDisplay = element.StyleDisplay;
StyleVisualElement buttonStyleDisplay = button.StyleDisplay;
StyleVisualElement textBlockStyleDisplay = textBlock.StyleDisplay;

StyleVisualButton buttonStyle = buttonStyleDisplay.Button();

StyleVisualTextBlock textBlockStyle = textBlockStyleDisplay.TextBlock();
```

<br>

<h2 align="center"><b>Візуальні стилі елементів від tModLoader</b></h2>

Замість використання **стилів візуального відображення** цієї бібліотеки, ви можете вказати елементу, що він повинен використовувати стиль певного (елемент сам вирішує, якого саме) елемента **tModLoader**.<br>
Для цього в полі `StyleDisplay` потрібно задати значення `tModLoaderStyle = true`.

```csharp
UIExElement element = new();
element.StyleDisplay.tModLoaderStyle = true;
```

Кожен елемент сам вирішує, стиль якого елемента **tModLoader** йому використовувати.<br>
`UIExElement` і будь-який елемент компоновки в цьому випадку використовуватиме стиль `UIPanel`.<br>

* Ця бібліотека перебуває в розробці. На сьогоднішній день інших елементів немає.<br><br>

Ви можете отримати клас базового стилю та змінювати його значення.<br>

```csharp
UIExElement element = new();

element.StyleDisplay.tModLoaderStyle = true;

StyleTmlUIPanel styleTmlUIPanel =  element.StyleDisplay.TmlUIPanel();
styleTmlUIPanel.BackgroundColor = Color.Red;
```

У цьому прикладі створений `UIExElement` виглядатиме як `UIPanel`, але при цьому обведення буде червоного кольору.<br>

Назви класу стилю та методу:

* Назва класу починається з `StyleTml`, а далі: назва елемента **tModLoader** відповідного стилю.
* Назва методу починається з `Tml`, а далі: назва елемента **tModLoader** відповідного стилю.

<h2 align="center">Стилі компоновки контейнера</h2>

Зберігання та отримання стилів компоновки контейнера ідентичні **стилям візуального відображення**<br>
Клас `UIExLayout` (який успадковують усі контейнери) містить поле:

```csharp
class UIExLayout : UIExElement
{
    public StyleLayoutContainer StyleLayout
}
```

<br>

Клас `StyleLayoutContainer` за аналогією зі `StyleVisualElement` зберігає в собі методи, які повертають стилі компоновки контейнерів класів-нащадків:

```csharp
// використовується для прикладу. Насправді цей UIExLayout абстрактний.
UIExLayout layout = new();
UIExCanvas canvas = new();
UIExStackPanel stackPanel = new();

StyleLayoutContainer styleLayout = layout.StyleLayout;
StyleLayoutContainer styleLayoutCanvas = canvas.StyleLayout;
StyleLayoutContainer styleLayoutStackPanel = stackPanel.StyleLayout;

StyleLayoutContainerCanvas styleCanvas = styleLayoutCanvas.Canvas();
StyleLayoutContainerStackPanel styleStackPanel = styleLayoutCanvas.StackPanel();
```

<h2 align="center">Стилі компоновки окремого елемента</h2>

Тут система дуже схожа. Але, на відміну від попередніх прикладів, стиль компоновки окремого елемента може мати будь-який `UIElement` у **tModLoader**.<br>
Тому отримання цих стилів відбувається за допомогою методу розширення `UIElement.StyleLayoutChild()`

```csharp
UIElement element = new();
StyleLayoutChild styleLayout = element.StyleLayoutChild();
StyleLayoutChildCanvas styleLayoutCanvas = styleLayout.Canvas();
```

<br>

Закономірність між назвою стилів компоновки контейнера та окремих елементів:

* `UIExLayout` - `StyleLayoutContainer` - `StyleLayoutChild`
* `UIExCanvas` - `StyleLayoutContainerCanvas` - `StyleLayoutChildCanvas`
* `UIExStackPanel` - `StyleLayoutContainerStackPanel` - `StyleLayoutChildStackPanel`<br>

Як видно, назви класів починаються з `StyleLayout` — далі йде `Container/Child` — далі назва контейнера компоновки (крім `UIExLayout`).

---

<h2 align="center">Додаткова інформація</h2>

Усі класи стилів є нащадками класу `StyleBase`.<br>
У цього класу є лише 1 публічний метод.

```csharp
public bool EqualsStylesFields(StyleBase other) { /* ... */ }
```

Цей метод перевіряє, чи збігаються всі поля всіх переданих стилів.<br>
Наприклад:

```csharp
StyleLayoutChildCanvas styleCanvas = new();
StyleLayoutContainer style1 = new();
StyleLayoutContainer style2 = new();


//////////////////

// [1]: метод поверне false
style1.EqualsStylesFields(styleCanvas);


//////////////////

// [2]: метод поверне true
style1.EqualsStylesFields(style2);


//////////////////

style1.JustifyContent = UIExAlignment.Center;

// [3]: метод поверне false
style1.EqualsStylesFields(style2);


//////////////////

style2.JustifyContent = UIExAlignment.Center;

// [4]: метод поверне true
style1.EqualsStylesFields(style2);


//////////////////

style1.UniformGrid();

// [5]: метод поверне false
style1.EqualsStylesFields(style2);


//////////////////

style2.UniformGrid();

// [6]: метод поверне true
style1.EqualsStylesFields(style2);


//////////////////

style2.UniformGrid().ColumnsCount = 5;

// [7]: метод поверне false
style1.EqualsStylesFields(style2);
```

Результати викликів `EqualsStylesFields`:

1. Порівнюються два різні класи стилів. Повертає `false`.
2. Порівнюються два стилі з полями за замовчуванням. Повертає `true`.
3. У `style1` значення `JustifyContent` змінилося. У `style2` — не змінилося. Поля стилів відрізняються. Повертає `false`.
4. У `style2` значення `JustifyContent` змінилося на ідентичне `style1`. Поля стилів не відрізняються. Повертає `true`.
5. Для `style1` зареєстрований стиль `StyleLayoutContainerUniformGrid`. Для `style2` — не зареєстрований. Повертає `false`.
6. Для `style2` зареєстрований стиль `StyleLayoutContainerUniformGrid`. Для `style1` цей стиль був зареєстрований раніше. Повертає `true`.
7. Значення поля `ColumnsCount` для зареєстрованого стилю `StyleLayoutContainerUniformGrid` `style2` змінилося. Дані поля у стилів не збігаються. Повертає `false`.

---

Усі класи стилів містять 2 конструктори:

1. За замовчуванням.
2. Той, що приймає всі значення для полів цього класу стилю (не вказані приймають значення за замовчуванням).

---

Усі класи стилів містять публічні методи за наведеним нижче шаблоном:

```csharp
/*

public void Set(
	type FIELD_1 = default(type), 
	type FIELD_2 = default(type), 
	..., 
	type FIELD_N = default(type))
		=> SetAllFields(
			FIELD_1, 
			FIELD_2, 
			..., 
			FIELD_N);



public void Copy(TYPE_STYLE style)
    => SetAllFields(
			style.FIELD_1, 
			style.FIELD_2, 
			..., 
			style.FIELD_N);

public TYPE_STYLE GetCopy()
    => GetCopyBase<TYPE_STYLE>();

*/
```

1. Метод `Set` приймає в себе всі значення полів, які містить цей стиль (не вказані приймають значення за замовчуванням).
2. Метод `Copy` приймає в себе аналогічний стиль і копіює всі поля переданого стилю.
3. Метод `GetCopy` повертає новий об'єкт стилю з копією всіх полів класу (зокрема той, що зберігає копії зареєстрованих стилів).

---

1. **Стилі візуального відображення** успадковують клас: `StyleVisualElementBase`.
2. **Візуальні стилі елементів від tModLoader** успадковують клас: `StyleTmlBase`.
3. **Стилі компоновки контейнера** успадковують клас: `StyleLayoutContainerBase`.
4. **Стилі компоновки вкладених елементів** успадковують клас: `StyleLayoutChildBase`.<br>
