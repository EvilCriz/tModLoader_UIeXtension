<h1 align="center">Клас <code>UIExModSystem</code></h1>

Клас `UIExModSystem` є нащадком класу `ModSystem`. Його єдине завдання – скоротити реалізацію класу `ModSystem`, необхідного для створення користувацького інтерфейсу, до мінімуму.

Як ви знаєте, для того, щоб почати писати користувацький інтерфейс, ви повинні реалізувати приблизно таку конструкцію:

---

* Ця бібліотека передбачає, що ви вже вивчили [базовий посібник tModLoader з користувацького інтерфейсу](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element?utm_source=chatgpt.com)<br>
* Ця бібліотека передбачає, що ви вже вивчили [розширений посібник з налаштування користувацького інтерфейсу](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI?utm_source=chatgpt.com)<br>

---

<details>
<summary>Базова реалізація <i>ModSystem</i> та <i>UIState</i> для написання UI</summary>

```csharp
public class ExampleMenuBar : UIState
{
    public override void OnInitialize() { }
}

[Autoload(Side = ModSide.Client)]
public class ExampleMenuBarSystem : ModSystem
{
    internal ExampleMenuBar ExmplMenuBar;
    private UserInterface _exampleMenuBar;
    public override void Load()
    {
        ExmplMenuBar = new ExampleMenuBar();
        ExmplMenuBar.Activate();
        _exampleMenuBar = new UserInterface();
    }
    public void SetState(bool state) => _exampleMenuBar.SetState(state ? ExmplMenuBar : null);
    public override void UpdateUI(GameTime gameTime) => _exampleMenuBar?.Update(gameTime);
    public override void ModifyInterfaceLayers(List<GameInterfaceLayer> layers)
    {
        int mouseTextIndex = layers.FindIndex(layer => layer.Name.Equals("Vanilla: Mouse Text"));
        if (mouseTextIndex != -1)
        {
            layers.Insert(mouseTextIndex, new LegacyGameInterfaceLayer(
                "YourMod: A Description",
                delegate
                {
                    _exampleMenuBar.Draw(Main.spriteBatch, new GameTime());
                    return true;
                },
                InterfaceScaleType.UI)
            );
        }
    }
}
```

</details>

Клас `UIExModSystem` дає вам можливість скоротити цей код аж до одного рядка:

```csharp
public class ExampleMenuBar : UIState
{
    public override void OnInitialize() { }
}

public class ExampleMenuBarSystem : UIExModSystem<ExampleMenuBar> { }
```

Замість `ExampleMenuBar` може бути будь-який клас, успадкований від `UIState` і такий, що підтримує конструктор за замовчуванням

<details>
<summary>Реалізація класу <i>UIExModSystem</i></summary>

```csharp
using Microsoft.Xna.Framework;
using System.Collections.Generic;
using Terraria;
using Terraria.ModLoader;
using Terraria.UI;

namespace UIeXtension;

/// <summary>
///     Допоміжний клас, створений для спрощення створення базової реалізації ModSystem, 
///     необхідної для створення користувацького інтерфейсу.
/// </summary>
/// <typeparam name="TUIState">
///     UIState, життєвим циклом якого керуватиме цей клас
/// </typeparam>
[Autoload(Side = ModSide.Client)]
public abstract class UIExModSystem<TUIState> : ModSystem 
    where TUIState : UIState, new()
{

    /// <summary>
    ///     Користувацький об'єкт UIState
    /// </summary>
    protected TUIState State { get; set; }

    /// <summary>
    ///     Керує оновленням та відмальовуванням <see cref="State"/>
    /// </summary>
    protected UserInterface InterfaceState { get; set; }



    /// <summary>
    ///     Зберігає останній стан <see cref="State"/> / <see cref="InterfaceState"/> (відображається / прихований)
    /// </summary>
    protected bool LastState { get; set; }



    /// <summary>
    ///     Зберігає значення, що використовується в <see cref="ModifyInterfaceLayers(List{GameInterfaceLayer})"/>
    /// </summary>
    protected virtual string InterfaceLayerName => "Vanilla: Mouse Text";

    /// <summary>
    ///     Зберігає значення, що використовується в <see cref="ModifyInterfaceLayers(List{GameInterfaceLayer})"/>
    /// </summary>
    protected virtual string InterfaceLayerDescription => "YourMod: A Description";



    /// <summary>
    ///     Дозволяє задати стан (відображається / прихований) користувацького інтерфейсу
    /// </summary>
    /// <param name="state">
    ///     Новий стан (відображається / прихований) користувацького інтерфейсу
    /// </param>
    public virtual void SetState(bool state)
    {
        if (LastState == state)
            return;

        LastState = !LastState;
        InterfaceState.SetState(LastState ? State : null);
    }

    /// <summary>
    ///     Змінює стан користувацького інтерфейсу. Якщо відображається – приховує; якщо прихований – відображає.
    /// </summary>
    public virtual void SwitchState() => SetState(!LastState);

    /// <summary>
    ///     Відображає користувацький інтерфейс, якщо він прихований.
    /// </summary>
    public virtual void Show() => SetState(true);

    /// <summary>
    ///     Приховує користувацький інтерфейс, якщо він відображається.
    /// </summary>
    public virtual void Hide() => SetState(false);

    /// <summary>
    ///     Повертає стан <see cref="State"/> (прихований/відображається)
    /// </summary>
    public virtual bool GetState() => LastState;

    /// <summary>
    ///     Повертає <see cref="State"/>. 
    /// </summary>
    /// <returns></returns>
    public virtual TUIState GetUIState() => State;

    /// <summary>
    ///     Базова реалізація <see cref="ModSystem"/> для завантаження користувацького інтерфейсу
    /// </summary>
    public override void Load()
    {
        State = new TUIState();
        State.Activate();
        InterfaceState = new UserInterface();
    }

    /// <summary>
    ///     Базова реалізація <see cref="ModSystem"/> для оновлення користувацького інтерфейсу
    /// </summary>
    public override void UpdateUI(GameTime gameTime) => InterfaceState?.Update(gameTime);

    /// <summary>
    ///     Базова реалізація <see cref="ModSystem"/> для виведення користувацького інтерфейсу
    /// </summary>
    public override void ModifyInterfaceLayers(List<GameInterfaceLayer> layers)
    {
        int mouseTextIndex = layers.FindIndex(layer => layer.Name.Equals(InterfaceLayerName));
        if (mouseTextIndex != -1)
        {
            layers.Insert(mouseTextIndex, new LegacyGameInterfaceLayer(
                InterfaceLayerDescription,
                () =>
                {
                    InterfaceState.Draw(Main.spriteBatch, new GameTime());
                    return true;
                },
                InterfaceScaleType.UI)
            );
        }
    }
}    
```

</details>

* Що робить цей клас?

1. Він створює замість користувача новий об'єкт типу `TUIState <where TUIState : UIState, new()>` у методі `Load()`. У цьому ж методі він створює `UserInterface`.
2. Самостійно оновлює `UserInterface` у методі `UpdateUI(GameTime gameTime)`.
3. Реалізує `ModifyInterfaceLayers(List<GameInterfaceLayer> layers)`.

* `TUIState State` та `UserInterface InterfaceState` є захищеними властивостями з реалізацією `get; set` за замовчуванням, з метою мінімізації обмежень у похідних класах.

```csharp
protected TUIState State { get; set; }
protected UserInterface InterfaceState { get; set; }
```

---

* Кілька слів про `ModifyInterfaceLayers(List<GameInterfaceLayer> layers)`:

У базовому посібнику в цьому методі використовуються рядки: **"Vanilla: Mouse Text"** та **"YourMod: A Description"**.
У `UIExSystem` вони винесені в окремі віртуальні властивості класу, щоб ви могли змінити будь-яку з них за необхідності, не переписуючи весь метод:

```csharp
protected virtual string InterfaceLayerName => "Vanilla: Mouse Text";
protected virtual string InterfaceLayerDescription => "YourMod: A Description";
```

---

* У цьому класі визначені методи `SetState(bool)`, `SwitchState()`, `Show()`, `Hide()`, `GetState()`, `GetUIState()`, `SetUIState(TUIState)`. Усі вони є віртуальними.

```csharp
public virtual void SetState(bool state) { /*...*/ }
public virtual void SwitchState() => SetState(!LastState);
public virtual void Show() => SetState(true);
public virtual void Hide() => SetState(false);
public virtual bool GetState() => LastState;
public virtual TUIState GetUIState() => State;
public virtual void SetUIState(TUIState state) => InterfaceState.SetState(state);
```
