<h1 align="center">Клас <code>UIExModSystem</code></h1>

Клас `UIExModSystem` спадкоємц до класу `ModSystem`Його єдине завдання полягає в тому, щоб зменшити виконання класу. `ModSystem`Необхідно створити інтерфейс користувача до мінімуму.


Як ви знаєте, для того, щоб розпочати роботу письменника інтерфейсу користувача, необхідно реалізувати приблизно наступний дизайн:

---

- Бібліотека припускає, що ви вже навчилися [базовий посібник tModLoader Користувач-інтерфейс](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Бібліотека припускає, що ви вже навчилися [Розширений посібник з налаштування інтерфейсу користувача](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>

---

<details>
<summary>Базова реалізація <i>ModSystem</i> і <i>UIState</i> Письма UI</summary>

```csharp
public class ExampleMenuBar : UIState
{
    public override void OnInitialize() { }
}

[Autoload(Side = ModSide.Client)]
public class ExampleMenuBarSystem : ModSystem
{
    internal ExampleMenuBar ExmplMenuBar;
    private UserInterface _exampleMenuBar;
    public override void Load()
    {
        ExmplMenuBar = new ExampleMenuBar();
        ExmplMenuBar.Activate();
        _exampleMenuBar = new UserInterface();
    }
    public void SetState(bool state) => _exampleMenuBar.SetState(state ? ExmplMenuBar : null);
    public override void UpdateUI(GameTime gameTime) => _exampleMenuBar?.Update(gameTime);
    public override void ModifyInterfaceLayers(List<GameInterfaceLayer> layers)
    {
        int mouseTextIndex = layers.FindIndex(layer => layer.Name.Equals("Vanilla: Mouse Text"));
        if (mouseTextIndex != -1)
        {
            layers.Insert(mouseTextIndex, new LegacyGameInterfaceLayer(
                "YourMod: A Description",
                delegate
                {
                    _exampleMenuBar.Draw(Main.spriteBatch, new GameTime());
                    return true;
                },
                InterfaceScaleType.UI)
            );
        }
    }
}
```
</details>

Клас `UIExModSystem` Це дозволяє зафіксувати код до одного рядка:

```csharp
public class ExampleMenuBar : UIState
{
    public override void OnInitialize() { }
}

public class ExampleMenuBarSystem : UIExModSystem<ExampleMenuBar> { }
```

Акурат `ExampleMenuBar` Це може бути будь-яким класом, спадкоємним з `UIState` і конструктора за замовчуванням

<details>
<summary>Реалізація класу <i>UIExModSystem</i></summary>

```csharp
using Microsoft.Xna.Framework;
using System.Collections.Generic;
using Terraria;
using Terraria.ModLoader;
using Terraria.UI;

namespace UIeXtension;

/// <summary>
///     Додатковий клас, призначений для спрощення створення базової реалізації ModSystem, 
///     необхідний для створення інтерфейсу користувача.
/// </summary>
/// <typeparam name="TUIState">
///     UIStateжиттєвий цикл якого в цьому класі буде керуватися
/// </typeparam>
[Autoload(Side = ModSide.Client)]
public abstract class UIExModSystem<TUIState> : ModSystem 
    where TUIState : UIState, new()
{

    /// <summary>
    ///     Об'єкт користувача UIState
    /// </summary>
    protected TUIState State { get; set; }

    /// <summary>
    ///     Оновлення та рендеринг <see cref="State"/>
    /// </summary>
    protected UserInterface InterfaceState { get; set; }



    /// <summary>
    ///     Тримає останню фортуню. <see cref="State"/> / <see cref="InterfaceState"/> (виданий/прихований)
    /// </summary>
    protected bool LastState { get; set; }



    /// <summary>
    ///     Зберігати значення, що використовується в <see cref="ModifyInterfaceLayers(List{GameInterfaceLayer})"/>
    /// </summary>
    protected virtual string InterfaceLayerName => "Vanilla: Mouse Text";

    /// <summary>
    ///     Зберігати значення, що використовується в <see cref="ModifyInterfaceLayers(List{GameInterfaceLayer})"/>
    /// </summary>
    protected virtual string InterfaceLayerDescription => "YourMod: A Description";



    /// <summary>
    ///     Дозволяє встановлювати стан (ображений / прихований) інтерфейсу користувача
    /// </summary>
    /// <param name="state">
    ///     Новий стан (показаний/прихований) інтерфейсу користувача
    /// </param>
    public virtual void SetState(bool state)
    {
        if (LastState == state)
            return;

        LastState = !LastState;
        InterfaceState.SetState(LastState ? State : null);
    }

    /// <summary>
    ///     Він змінює стан інтерфейсу користувача. Якщо він відображається, він приховує; якщо він прихований, він відображає.
    /// </summary>
    public virtual void SwitchState() => SetState(!LastState);

    /// <summary>
    ///     Він відображає інтерфейс користувача, якщо він прихований.
    /// </summary>
    public virtual void Show() => SetState(true);

    /// <summary>
    ///     Приховати інтерфейс користувача, якщо він відображається.
    /// </summary>
    public virtual void Hide() => SetState(false);

    /// <summary>
    ///     Повернення фортуни <see cref="State"/> (приховані/показані)
    /// </summary>
    public virtual bool GetState() => LastState;

    /// <summary>
    ///     Повернення. <see cref="State"/>. 
    /// </summary>
    /// <returns></returns>
    public virtual TUIState GetUIState() => State;

    /// <summary>
    ///     Базова реалізація <see cref="ModSystem"/> навантажувачі
    /// </summary>
    public override void Load()
    {
        State = new TUIState();
        State.Activate();
        InterfaceState = new UserInterface();
    }

    /// <summary>
    ///     Базова реалізація <see cref="ModSystem"/> оновити інтерфейс користувача
    /// </summary>
    public override void UpdateUI(GameTime gameTime) => InterfaceState?.Update(gameTime);

    /// <summary>
    ///     Базова реалізація <see cref="ModSystem"/> інтерфейс користувача
    /// </summary>
    public override void ModifyInterfaceLayers(List<GameInterfaceLayer> layers)
    {
        int mouseTextIndex = layers.FindIndex(layer => layer.Name.Equals(InterfaceLayerName));
        if (mouseTextIndex != -1)
        {
            layers.Insert(mouseTextIndex, new LegacyGameInterfaceLayer(
                InterfaceLayerDescription,
                () =>
                {
                    InterfaceState.Draw(Main.spriteBatch, new GameTime());
                    return true;
                },
                InterfaceScaleType.UI)
            );
        }
    }
}    
```

</details>

- Що робити цей клас?
1. Створює новий тип об’єкта замість користувача. `TUIState <where TUIState : UIState, new()>` методично `Load()`Це той самий метод, який він створює. `UserInterface`.
2. Самовідновлення `UserInterface` методично `UpdateUI(GameTime gameTime)`.
3. Реалізація `ModifyInterfaceLayers(List<GameInterfaceLayer> layers)`.

- `TUIState State` і `UserInterface InterfaceState` захищені властивості з впровадженням `get; set` За замовчуванням, щоб мінімізувати обмеження у спадкових класах.

```csharp
protected TUIState State { get; set; }
protected UserInterface InterfaceState { get; set; }
```

----

- Слово про це. `ModifyInterfaceLayers(List<GameInterfaceLayer> layers)`:

У базовому посібнику використовуються наступні рядки: **"Vanilla: Mouse Text"** і **"YourMod: A Description"**.
В. В. `UIExSystem` Ви можете змінити будь-який з них, якщо це необхідно, не перезаписати весь метод.

```csharp
protected virtual string InterfaceLayerName => "Vanilla: Mouse Text";
protected virtual string InterfaceLayerDescription => "YourMod: A Description";
```

----

- Визначені методи в цьому класі `SetState(bool)`, `SwitchState()`, `Show()`, `Hide()`, `GetState()`, `GetUIState()`, `SetUIState(TUIState)`Усі віртуальні.
```csharp
public virtual void SetState(bool state) { /*...*/ }
public virtual void SwitchState() => SetState(!LastState);
public virtual void Show() => SetState(true);
public virtual void Hide() => SetState(false);
public virtual bool GetState() => LastState;
public virtual TUIState GetUIState() => State;
public virtual void SetUIState(TUIState state) => InterfaceState.SetState(state);
```
