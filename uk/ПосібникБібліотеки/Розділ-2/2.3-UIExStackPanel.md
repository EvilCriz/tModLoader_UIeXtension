----

- Бібліотека припускає, що ви вже навчилися [базовий посібник tModLoader Користувач-інтерфейс](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Бібліотека припускає, що ви вже навчилися [Розширений посібник з налаштування інтерфейсу користувача](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>
- У статті запропоновано, що ви вивчили статтю: ["Схема стилю"](../Розділ-1/1.3-StyleStructure.md)
- У статті запропоновано, що ви вивчили статтю: [клас UIExLayoutОснови макета](2.1-UIExLayout.md)

----
<br>

----

`UIExStackPanel` Це контейнерне планування, яке має дочірні елементи в одній лінії (стопка) вертикально або горизонтально.<br>

----

Базовий стиль облаштування елементів `StyleLayoutContainer`:
```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    public Enums.UIExOrientation Orientation = Enums.UIExOrientation.Vertical;
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
}
```
- `Orientation`: визначає основну вісь контейнера, по якій елементи будуть вирівняти.
- `JustifyContent`: вирівнювання елементів вздовж основної осі.
- `AlignItems`: вирівнювання елементів вздовж поперечної осі.<br>

Типи рівня:
```csharp
public enum UIExAlignment : byte
{
    Auto,
    Start,
    Center,
    End,
    Stretch
}
```
- `Auto`аналогічно `Start`Застосовується для елементів, вбудованих в контейнер.
- `Start`: вирівнювання елементів при старті осі (верх/ліво).
- `Center`: вирівнювання елементів в центрі осі.
- `End`: вирівнювання елементів в кінці осі (знизу/право).
- `Stretch`: розтягування елемента по всій осі (мережі) `Margin`).<br>

----

Основні стилі дитячих елементів `StyleLayoutChild`:
```csharp
public partial class StyleLayoutChild : Base.StyleLayoutChildBase
{
    public Enums.UIExAlignment JustifySelf = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignSelf = Enums.UIExAlignment.Auto;
    public UIExThickness Margin = new();
    public StyleDimension Width = default(StyleDimension);
    public StyleDimension Height = default(StyleDimension);
}
```
- Поле. `JustifySelf` Дитячий елемент ігнорує будь-яке значення, відмінне від значення. `Stretch`.
- Поле. `AlignSelf` руді `AlignItems` для конкретного в'язаного елемента.
- Поле. `Margin` Він чудово працює.
- Сфери `Width` і `Height` У статті описано докладно в першій статті даного розділу.

----

Для класу. `UIExStackPanel` Стильний клас використовується: `StyleLayoutContainerStackPanel`Він зберігає всі стилі макета для цього класу.

```csharp
public class StyleLayoutContainerStackPanel : Base.StyleLayoutContainerBase
{
    public StyleDimension Spacing = StyleDimension.Empty;
    public bool Reverse = false;

    public void Set(StyleDimension spacing, bool reverse) { /* ... */ }
    public void Copy(StyleLayoutContainerStackPanel style) { /* ... */ }
    public StyleLayoutContainerStackPanel GetCopy() { /* ... */ }
}
```

- `Spacing`:
  - Відповідальний простір між дочірніми елементами `UIExStackPanel`.
  - Він працює навіть якщо це робить. `JustifyContent` і `AlignItems` == `UIExAlignment.Stretch`
- `Reverse`:
  - Прапор, відповідальний за розташування елементів у зворотному порядку.
  - Головна `true` Всі елементи будуть розміщені в зворотному порядку, зберігаючи всі інші характеристики стилю.
<br>

----

**Не працює.** Стильний клас для дитячих елементів.<br>

----

- Основні стилі розкладу контейнерів містяться в області `StyleLayout`.
- Для отримання стилів макета `UIExStackPanel` використання методу `StackPanel()` Промисловість `StyleLayout`.
- Для отримання базових стилів для вбудованих елементів в контейнер, використовуйте метод розширення. `UIElement`: `StyleLayoutChild()`.<br>

```csharp
UIExStackPanel stackPanel = new();

StyleLayoutContainer style = stackPanel.StyleLayout;
StyleLayoutContainerStackPanel styleStackPanel = stackPanel.StyleLayout.StackPanel(); // або style.StackPanel();

UIElement element = new();
StyleLayoutChild styleChild = element.StyleLayoutChild();

style.JustifyContent = UIExAlignment.Center;
styleStackPanel.Reverse = true;

styleChild.JustifySelf = UIExAlignment.Stretch;
```

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;
using Microsoft.Xna.Framework;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // методологія OnActivate(a) в цьому випадку, тільки
    // для функції «гарячого перезавантаження коду» у середовищі розробки.
    // Щоб скористатися реальним інтерфейсом, краще використовувати реальний інтерфейс.
    // методологія OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.8f, 0.8f, panel);

        UIExStackPanel HStackPanel = new();
        HStackPanel.Stretch();

        HStackPanel.StyleLayout.Set(
            orientation:        UIExOrientation.Horizontal,
            justifyContent:     UIExAlignment.Stretch,
            alignItems:         UIExAlignment.Stretch);
        HStackPanel.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.05f),
            reverse:            false);

        panel.Append(HStackPanel);

        //////

        UIPanel HPanel1 = new(), HPanel2 = new(), HPanel3 = new(), HPanel4 = new();
        HStackPanel.Append(HPanel1);
        HStackPanel.Append(HPanel2);
        HStackPanel.Append(HPanel3);
        HStackPanel.Append(HPanel4);

        /////

        UIExStackPanel VStackPanel1 = new(), VStackPanel2 = new(), VStackPanel3 = new(), VStackPanel4 = new();
        SetPrecentSizeCenter(1f, 1f, VStackPanel1, VStackPanel2, VStackPanel3, VStackPanel4);
        HPanel1.Append(VStackPanel1);
        HPanel2.Append(VStackPanel2);
        HPanel3.Append(VStackPanel3);
        HPanel4.Append(VStackPanel4);

        VStackPanel1.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Start,
            alignItems:         UIExAlignment.Start);
        VStackPanel1.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.1f),
            reverse:            false);

        UIElement selfStylePanel1 = AddCubs(VStackPanel1, pixelSize: 64f, count: 3)[1];

        selfStylePanel1.StyleLayoutChild()
            .Set(alignSelf: UIExAlignment.End);

        ////

        VStackPanel2.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Center,
            alignItems:         UIExAlignment.Center);
        VStackPanel2.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.15f),
            reverse:            true);

        UIElement selfStylePanel2 = AddCubs(VStackPanel2, 16f, 32f, 48f, 64f)[2];

        selfStylePanel2.StyleLayoutChild().Set(
            justifySelf:        UIExAlignment.End, // Він не робить нічого. UIExStackPanel Неприємний JustifySelf,
            alignSelf:          UIExAlignment.Stretch,
            margin:             new UIExThickness(
                                    pixels: false,
                                    left: 0.1f,
                                    top: 0.075f,
                                    right: 0f,
                                    bottom: 0.15f));

        ////

        VStackPanel3.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.End,
            alignItems:         UIExAlignment.End);
        VStackPanel3.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.20f),
            reverse:            false);

        AddCubs(VStackPanel3, 32f, 48f, 64f);

        ////

        VStackPanel4.StyleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Stretch,
            alignItems:         UIExAlignment.Stretch);
        VStackPanel4.StyleLayout.StackPanel().Set(
            spacing:            new StyleDimension(0f, 0.20f),
            reverse:            false);

        AddCubs(VStackPanel4, pixelSize: 60f);
        AddCubs(VStackPanel4, pixelSize: 50f);
        AddCubs(VStackPanel4, pixelSize: 70f);

        ////

        HStackPanel.SetLayoutLinesInfoForBranch(
            state: true, 
            thickness: 3f, 
            color: Color.DarkOrange);

        ///

        Append(panel);
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
    {
        int count = pixelSizes.Length;
        var panels = new UIElement[count];
        for (int i = 0; i < count; i++)
            panels[i] = AddCubs(element, pixelSizes[i], count: 1)[0];
        return panels;
    }

    public UIElement[] AddCubs(UIElement element, float pixelSize, int count = 1)
    {
        var panels = new UIElement[count];
        for (int i = 0; i < count; i++)
        {
            panels[i] = new UIPanel();
            StyleLayoutChild style = panels[i].StyleLayoutChild();
            style.Width.Set(pixelSize, 0f);
            style.Height.Set(pixelSize, 0f);
            element.Append(panels[i]);
        }
        return panels;
    }
}
```

----

Трохи про візуальні стилі. Це тема наступного розділу, але є 1 важлива точка для будівельників, тому ця примітка буде в кожній статті.<br>
Як ви можете побачити, в цьому коді система виглядає наступним чином: головна панель -> контейнер -> панель розділу -> контейнер -> куб. панель.<br>
Кожна панель має власний контейнер (крім кубів).<br>
Це непотрібно, якщо результат точно те, що ми хочемо бачити в образі.<br>
`UIExElement` (з якого він успадковує) `UIExLayout`) має властивість стилю: `StyleDisplay.tModLoaderStyle (bool)`.<br>
Якщо це значення вірно, то візуальний елемент буде прийняти відповідний стиль. **tModLoader**.<br>
для `UIExElement` значення `true` Це означає, що стиль буде схожим. `UIPanel`.<br>
Таким чином, наш код був скорочений.<br><br>

Наприклад, ця частина тут:
```csharp

SetPrecentSizeCenter(0.8f, 0.8f, panel);

HStackPanel.Stretch();

HStackPanel.StyleLayout.Set(

    alignItems:         UIExAlignment.Stretch);
HStackPanel.StyleLayout.StackPanel().Set(
    spacing:            new StyleDimension(0f, 0.05f),
    reverse:            false);

panel.Append(HStackPanel);
/*
...
*/
Append(panel);
```

Чи можна замінювати наступним чином:
```csharp
UIExStackPanel HStackPanel = new();
HStackPanel.StyleDisplay.tModLoaderStyle = true;
SetPrecentSizeCenter(0.8f, 0.8f, HStackPanel);

HStackPanel.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Stretch,
    alignItems:         UIExAlignment.Stretch);
HStackPanel.StyleLayout.StackPanel().Set(

    reverse:            false);
/*
...
*/
```

Як ви можете побачити в другому коді, `UIPanel panel` Сам контейнер пішов. `HStackPanel` Він став головним контейнером одночасно.

----

Перше, що ви бачите в коді:
```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);
```
Це головна панель, яка буде додана до `UIState`Він буде розміщений на ньому. `UIExStackPanel`.<br><br>
`SetPrecentSizeCenter` Це допоміжний метод, який не знайдено в бібліотеці, і визначений нижче в одному класі.
Він отримує N. `UIElement`Ми встановлюємо висоту і ширину центру. `panel` Він має розмір: 80% на 80% екрана.<br><br>

----

Далі в коді настає перший. `UIExStackPanel`:
```csharp
UIExStackPanel HStackPanel = new();
HStackPanel.Stretch();

HStackPanel.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Stretch,
    alignItems:         UIExAlignment.Stretch);
HStackPanel.StyleLayout.StackPanel().Set(
    spacing:            new StyleDimension(0f, 0.05f),
    reverse:            false);

panel.Append(HStackPanel);

//////

UIPanel HPanel1 = new(), HPanel2 = new(), HPanel3 = new(), HPanel4 = new();
HStackPanel.Append(HPanel1);
HStackPanel.Append(HPanel2);
HStackPanel.Append(HPanel3);
HStackPanel.Append(HPanel4);
```

- `HStackPanel.Stretch();` - розмір-встановлення `HStackPanel`100% від батьківського елемента.
- Далі ми додаємо `HStackPanel` головна панель `panel.Append(HStackPanel);`що означає, що `HStackPanel` Зберігати елементи по всій головній панелі, тобто по всьому створеному інтерфейсу.
- `Set` У бібліотеці є метод, який має кожен клас стилю. **Всі вони.** Вишуканий стиль класу полів.
- Його стилі. `StyleLayoutContainer StyleLayout`:
  - `Orientation`: Основна вісь контейнера. `Vertical` - горизонтальний.
  - `JustifyContent` (вирівнювання елементів по основній віссі) (основна вісь - горизонтальна): `stretch` Елементи займають всі доступні місця по ширині.
  - `AlignItems` (перекладна вісь вирівнювання елементів) (перекладна вісь - вертикальна): `stretch` Елементи займають всі доступні місця у висоту.
- Його стилі. `StyleLayoutContainerStackPanel StyleLayoutStackPanel`:
  - `Spacing`: 5% від основної осі контейнера (в цьому випадку: 5% ширини) `HStackPanel`).
  - `Reverse`: false - елементи розташовуються в порядку, в якому вони будуть додані `HStackPanel`.


Далі. `HStackPanel` додано 4 розділи `HPanel_N`:
- `HStackPanel` перший раз налаштовує місце під `Spacing (5% * HStackPanel.Width * (HStackPanel.GetWithLayoutElementsCount() - 1))`
- Потім відрахуйте вільний простір і розділіть його між розділами.
- Ви можете побачити результат цього для себе. У зображенні це 4 найбільш вертикальні розділи по всій висоті контейнера.

```csharp
UIExStackPanel VStackPanel1 = new(), VStackPanel2 = new(), VStackPanel3 = new(), VStackPanel4 = new();
SetPrecentSizeCenter(1f, 1f, VStackPanel1, VStackPanel2, VStackPanel3, VStackPanel4);
HPanel1.Append(VStackPanel1);
HPanel2.Append(VStackPanel2);
HPanel3.Append(VStackPanel3);
HPanel4.Append(VStackPanel4);
```

До кожного з раніше створених розділів (`HPanel_N`) встановлює власну `UIExStackPanel (VStackPanel_N)`.<br>
`VStackPanel_N` У кожному розділі будуть зібрані кубики.
Далі, кожен `VStackPanel_N` отримує 100% розмір свого батька і додається до відповідної панелі `HPanel_N`<br>

Я хотів би зробити проміжний підсумок в цій точці.
На даний момент наша система знаходиться наступним чином:
- `UIPanel panel` Це 80 відсотків розміру екрана, і він отримав це всередині.<br>
  - `UIExStackPanel HStackPanel` Всередині головного панно, і це 100 відсотків розміру основного панно.<br>
    - `UIPanel HPanel_1-4` Секції 1-4 100% високі. `HStackPanel` І 25 відсотків вільного простору.<br>
      - `UIExStackPanel VStackPanel_1-4` - посилання в відповідному розділі, 100% від розміру відповідного розділу.<br>
          - N-number кубів в різних розмірах ребер.

        <td>Всі кубики вирівнюються від початкової позиції на основній осі (верхній)</td> 
    </tr>
    <tr> 
        <td><code>alignItems: UIExAlignment.Start</code></td> 
        <td>Всі кубики (крім 1-го) вирівнюються з початкової позиції вздовж поперечної осі (ліворуч)</td> 
    </tr>
    <tr> 
        <td><code>spacing: new StyleDimension(0f, 0.1f)</code></td> 
        <td>Зняття між елементами по основній віссі: 10% від розміру основного вісь контейнера (10% від розміру основної осі контейнера) `Height` контейнери</td> 
    </tr>
    <tr> 
        <td><code>reverse: false</code></td> 
        <td>Не існує реверсії елементів. Дитячі елементи розташовуються в порядку, в якому вони додаються.</td> 
    </tr> 
</table>

Для другого куба стиль зареєстрований і поле змінено `alignSelf: UIExAlignment.End`.<br>
Це означає, що куб ігнорує значення. `AlignItems` контейнер, і вирівнюється в кінці поперечної осі (право в цьому випадку).<br><br><br>

Частина 2 коду:
```csharp
VStackPanel2.StyleLayout.Set(
    orientation:        UIExOrientation.Vertical,
    justifyContent:     UIExAlignment.Center,
    alignItems:         UIExAlignment.Center);
VStackPanel2.StyleLayout.StackPanel().Set(
    spacing:            new StyleDimension(0f, 0.15f),
    reverse:            true);

UIElement selfStylePanel2 = AddCubs(VStackPanel2, 16f, 32f, 48f, 64f)[2];

selfStylePanel2.StyleLayoutChild().Set(
    justifySelf:        UIExAlignment.End, // Він не робить нічого. UIExStackPanel Неприємний JustifySelf,
    alignSelf:          UIExAlignment.Stretch,
    margin:             new UIExThickness(
                            pixels: false,
                            left: 0.1f,
                            top: 0.075f,
                            right: 0f,
                            bottom: 0.15f));
```
