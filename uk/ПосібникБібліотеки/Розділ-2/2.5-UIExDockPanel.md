----

`UIExDockPanel` Це контейнер макета, який **послідовно** Доки дочірні елементи до одного з п'яти сторін доступній площі:
- `Left`
- `Right`
- `Top`
- `Bottom`<br>

Решта місце також вважається окремою особою: `Fill`.<br>
Займає всі наявні місця після розрахунку попередніх сторін.<br>

`UIExDockPanel` Ви можете бути звичайно представлені як два рівні макета:
1. Перший рівень: послідовне виділення ділянки `Left`, `Right`, `Top`, `Bottom` і `Fill`;
2. Другий рівень: кожна сторона самостійно збирає елементи, які надягають її відповідно до правил, які практично ідентичні. `UIExStackPanel`.<br>

Компонент робить наступний:
1. Пам'ятайте, на яку сторону з'явився перший елемент, другий елемент і т.д. Наприклад:
   - Першим є ліва сторона.
   - другий на ліву сторону;
   - Третя на праву сторону.
   - четвертий на ліву сторону;
   - П'ять до нижньої сторони.
2. Пам'ятає список партій без звернення в тому ж порядку. Приклад (за абзацом 1):
   - ліворучна сторона;
   - лицьова сторона;
   - Нижня сторона.
3. По-іншому виділяє розмір кожного з сторін на основі переліку вимог 2 та алгоритму нижче.<br>

Розміри сторони визначаються наступним чином:
1. Висота боків `Left` і `Right`Висота вільного простору в контейнері.
2. Хліб з боків `Left` і `Right`: ширина найбільшої зовнішньої області елементів, що надягають до цієї сторони.
3. Хліб з боків `Top` і `Bottom`Ширина вільного простору в контейнері.
4. Висота боків `Top` і `Bottom`: висота найбільшого зовнішнього краю елементів, що надягаються до цієї сторони.<br>

Після розраховується площа першої доданої сторони, площа виключається з вільного простору контейнера.<br>
У прикладі з попереднього зображення спочатку додано кнопка, що стикається з лівою сторінкою.<br>

```csharp
using Microsoft.Xna.Framework;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // методологія OnActivate(a) в цьому випадку, тільки
    // для функції «гарячого перезавантаження коду» у середовищі розробки.
    // Щоб скористатися реальним інтерфейсом, краще використовувати реальний інтерфейс.
    // методологія OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.25f, 0.25f, panel);

        UIExDockPanel dockPanel = new();
        dockPanel.Stretch();
        dockPanel.SetLayoutLinesInfoForBranch(
            state:      true,
            thickness:  3f,
            color:      Color.DarkOrange);

        dockPanel.StyleLayout.JustifyContent = UIExAlignment.Stretch;
        dockPanel.StyleLayout.AlignItems = UIExAlignment.Stretch;

        UIButton<string> buttonTop = CreateAndAddUIBottom(dockPanel, 50f, "top");
        UIButton<string> buttonBottom = CreateAndAddUIBottom(dockPanel, 50f, "bot");
		UIButton<string> buttonLeft = CreateAndAddUIBottom(dockPanel, 50f, "left");
        UIButton<string> buttonRight = CreateAndAddUIBottom(dockPanel, 50f, "right");

        var btTopStyleDock = buttonTop.StyleLayoutChild().DockPanel();
        var btBottomStyleDock = buttonBottom.StyleLayoutChild().DockPanel();
        var btLeftStyleDock = buttonLeft.StyleLayoutChild().DockPanel();
        var btRightStyleDock = buttonRight.StyleLayoutChild().DockPanel();

        btTopStyleDock.Side = UIExSide.Top;
        btBottomStyleDock.Side = UIExSide.Bottom;
        btLeftStyleDock.Side = UIExSide.Left;
        btRightStyleDock.Side = UIExSide.Right;

        ///////////////////

        panel.Append(dockPanel);
        Append(panel);
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> CreateAndAddUIBottom(UIExLayout layout, float pixelsSize, string text)
    {
        UIButton<string> button = new(text);
        button.Width.Pixels = pixelsSize;
        button.Height.Pixels = pixelsSize;
        layout.Append(button);
        return button;
    }
}
```

`UIExDockPanel` також має "за межами" `Fill`Це сторона, яка займає решту площі після обчислення боків. `Left`, `Right`, `Top`, `Bottom`.<br>
Приклад того, що він виглядає, як ви можете побачити нижче.<br>
Порядок додавання елементів c `Side == Fill` не впливає на порядок розрахунку сторін.<br>
`Fill` завжди розраховується після `Left`, `Right`, `Top` і `Bottom` І займає решту простору.<br>

<h2 align="center"><code>UIExStackPanel</code></h2>

На початку глави було попередження, що ця стаття призначена для того, щоб переконатися, що ви вже дізналися елемент макета. `UIExStackPanel`І є важлива причина для цього.<br>

По суті, всі елементи з кожного боку розташовуються так само, як і елементи на внутрішній стороні. `UIExStackPanel`.<br>
Тільки способи налаштування параметрів для кожного окремого бокового зміни.

----

<h2 align="center">Стильи. <code>UIExDockPanel</code></h2>

Базовий стиль облаштування елементів StyleLayoutContainer:
```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    public Enums.UIExOrientation Orientation = Enums.UIExOrientation.Vertical;
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
}
```

- `Orientation`: визначає основну осі **FILL** На боці, на якій елементи вирівнятимуться в ній.
  - Для учасників `Left` і `Right` Консультація завжди вертикальна.
  - Для учасників `Top` і `Bottom` Орієнтація завжди горизонтальна.
- `JustifyContent`: вирівнювання елементів по основній віссі (роботи з усіх боків; можливість перевизначення цього значення для певної сторони та/або певного елемента).
- `AlignItems`: вирівнювання елементів по поперечній віссі (роботи з усіх боків; можливе перевизначення цього значення для певної сторони та/або певного елемента).<br><br>

- Смоктати `Left`, `Right`, `Top` і `Bottom` Напрямок макета чітко визначений самим боком.<br>
- `Fill` Не має фіксованого напрямку, тому його спрямованість визначається `StyleLayout.Orientation`.<br>

Типи рівня:
```csharp
public enum UIExAlignment : byte
{
    Auto,
    Start,
    Center,
    End,
    Stretch
}
```

- `Auto`аналогічно `Start`Використовуються непристойними елементами та/або сторонами.
- `Start`: вирівнювання елементів при старті бічної осі (верх/ліво).
- `Center`: вирівнювання елементів в центрі осі сторони.
- `End`: вирівнювання елементів в кінці бічної осі (знизу/право).
- `Stretch`: розтягування елемента по всій осі сторони (мережа) `Margin`).

----

Основні стилі дитячих елементів `StyleLayoutChild`:
```csharp
public partial class StyleLayoutChild : Base.StyleLayoutChildBase
{
    public Enums.UIExAlignment JustifySelf = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignSelf = Enums.UIExAlignment.Auto;
    public UIExThickness Margin = new();
	public StyleDimension Width = default(StyleDimension);
    public StyleDimension Height = default(StyleDimension);
}
```
- Поле. `JustifySelf` для дитячих елементів будь-яке значення, відмінне від значення `Stretch` Вони будуть ігноруватися. `Auto` означає, що вартість буде контролюватися контейнером/партією.
- Поле. `AlignSelf` руді `AlignItems` для конкретного в'язаного елемента. `Auto` означає, що вартість буде контролюватися контейнером/партією.
- Поле. `Margin` враховується в облаштуванні елемента і при визначенні розміру зовнішньої площі, зайнятої ним.
- Сфери `Width` і `Height` У статті описано докладно в першій статті даного розділу.

----

Для класу. `UIExDockPanel` Стильний клас використовується: `StyleLayoutContainerDockPanel`які зберігає всі стилі макета для цього класу:
```csharp
public class StyleLayoutContainerDockPanel : Base.StyleLayoutContainerBase
{
    public SideStyle SideLeft;
    public SideStyle SideRight;
    public SideStyle SideTop;
    public SideStyle SideBottom;
    public SideStyle SideFill;
}
```
Цей клас стилю містить стилі з чотирьох сторін і для заповнення вільного простору.

```csharp
public class SideStyle : Base.StyleBase
{
    public UIExThickness Padding = default(UIExThickness);
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
    public StyleDimension Spacing = default(StyleDimension);
    public bool Reverse = false;
}
```

- `Padding`: відступи від країв сторони до позначеного положення для елементів в сторони.
- `JustifyContent`: вирівнювання елементів по основній віссі. Надідає значення `JustifyContent` Клас стилю контейнера для тієї чи іншої партії. `Auto` Це означає, що вартість буде контролюватися контейнером.
- `AlignItems`: вирівнювання елементів по поперечній віссі. Надідає значення `AlignItems` Клас стилю контейнера для тієї чи іншої партії. `Auto` Це означає, що вартість буде контролюватися контейнером.
- `Spacing`: несе відповідальність за простір між елементами всередині сторони (простір між елементами на головній віссі).
- `Reverse`: вказується, що елементи партії повинні бути в зворотному порядку.<br>

Щоб отримати стиль `UIExDockPanel` використання методу `DockPanel()` Промисловість `StyleLayout`:
```csharp
UIExDockPanel dockPanel = new();

StyleLayoutContainer styleLayout = dockPanel.StyleLayout;
StyleLayoutContainerDockPanel styleLayoutDockPanel = styleLayout.DockPanel();

styleLayoutDockPanel.SideLeft.Reverse = true;
```

Стиль дитячих елементів `UIExDockPanel`:
```csharp
public class StyleLayoutChildDockPanel : Base.StyleLayoutChildBase
{
    public Enums.UIExSide Side = Enums.UIExSide.Left;
}

public enum UIExSide : byte
{
    Left,
    Right,
    Top,
    Bottom,
    Fill
}
```
Як бачите, стиль дитячих елементів відповідає тільки за яку сторону елемента потрібно докнути.<br>

Щоб отримати базовий стиль дитячих елементів, скористайтеся методикою розширення. `UIElement`: `StyleLayoutChild()`.<br>
Для отримання стилю дитячих елементів з параметрами `UIExDockPanel` методизація `DockPanel()` в базовому стилі:
```csharp
UIElement element = new();

StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildDockPanel styleDockPanel = style.DockPanel();

styleDockPanel.Side = UIExSide.Top;
```

<summary>Приклад створення інтерфейсу користувача (без коментарів, аналіз нижче)</summary>

```csharp
using Microsoft.Xna.Framework;
using System;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // методологія OnActivate(a) в цьому випадку, тільки
    // для функції «гарячого перезавантаження коду» у середовищі розробки.
    // Щоб скористатися реальним інтерфейсом, краще використовувати реальний інтерфейс.
    // методологія OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.8f, 0.8f, panel);

        UIExDockPanel dockPanel = new UIExDockPanel();
		dockPanel.Stretch();

        dockPanel.ShowLayoutLines = true;
        dockPanel.LayoutLinesThickness = 3f;
        dockPanel.LayoutLinesColor = Color.DarkOrange;

        StyleLayoutContainer styleLayout = dockPanel.StyleLayout;
        StyleLayoutContainerDockPanel styleLayoutDock = styleLayout.DockPanel();

        styleLayout.JustifyContent = UIExAlignment.Center;
        styleLayout.AlignItems = UIExAlignment.Center;

        ////////////////

        SideStyle sideBottom = styleLayoutDock.SideBottom;
        sideBottom.Spacing.Pixels = 100f;

        UIElement[] cubsBottom = AddCubs(dockPanel, "b", pixelSize: 50f, 1);
        StyleLayoutChild[] cubsStylesBottom = new StyleLayoutChild[cubsBottom.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockBottom = new StyleLayoutChildDockPanel[cubsBottom.Length];

        for (int i = 0; i < cubsBottom.Length; i++)
        {
            cubsStylesBottom[i] = cubsBottom[i].StyleLayoutChild();
            cubsStylesDockBottom[i] = cubsStylesBottom[i].DockPanel();
            cubsStylesDockBottom[i].Side = UIExSide.Bottom;
        }

        cubsStylesBottom[0].Margin = new(pixels: true, size: 25f);
        cubsStylesBottom[0].JustifySelf = UIExAlignment.Stretch;

        ////////////////

        SideStyle sideLeft = styleLayoutDock.SideLeft;
        sideLeft.Spacing.Pixels = 50f;
        sideLeft.AlignItems = UIExAlignment.End;

        UIElement[] cubsLeft = AddCubs(dockPanel, "l", pixelSize: 50f, 4);
        StyleLayoutChild[] cubsStylesLeft = new StyleLayoutChild[cubsLeft.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockLeft = new StyleLayoutChildDockPanel[cubsLeft.Length];

        for (int i = 0; i < cubsLeft.Length; i++)
        {
            cubsStylesLeft[i] = cubsLeft[i].StyleLayoutChild();
            cubsStylesDockLeft[i] = cubsStylesLeft[i].DockPanel();
            cubsStylesDockLeft[i].Side = UIExSide.Left;
        }

        cubsStylesLeft[1].AlignSelf = UIExAlignment.Start;
        cubsStylesLeft[2].Margin = new(pixels: true, 50f);

        /////////////////

        SideStyle sideTop = styleLayoutDock.SideTop;
        sideTop.Spacing.Pixels = 10f;
        sideTop.JustifyContent = UIExAlignment.End;

        UIElement[] cubsTop = AddCubs(dockPanel, "t", pixelSize: 50f, 3);
        StyleLayoutChild[] cubsStylesTop = new StyleLayoutChild[cubsTop.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockTop = new StyleLayoutChildDockPanel[cubsTop.Length];

        for (int i = 0; i < cubsTop.Length; i++)
        {
            cubsStylesTop[i] = cubsTop[i].StyleLayoutChild();
            cubsStylesDockTop[i] = cubsStylesTop[i].DockPanel();
            cubsStylesDockTop[i].Side = UIExSide.Top;
        }

        cubsStylesTop[1].Margin = new(pixels: true, 10f);

        /////////////////

        SideStyle sideRight = styleLayoutDock.SideRight;
        sideRight.Spacing.Pixels = 30f;
        sideRight.JustifyContent = UIExAlignment.End;
        sideRight.Padding = new UIExThickness(pixels: true, size: 20f);

        UIElement[] cubsRight = AddCubs(dockPanel, "r", pixelSize: 50f, 5);
        StyleLayoutChild[] cubsStylesRight = new StyleLayoutChild[cubsRight.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockRight = new StyleLayoutChildDockPanel[cubsRight.Length];

        for (int i = 0; i < cubsRight.Length; i++)
        {
            cubsStylesRight[i] = cubsRight[i].StyleLayoutChild();
            cubsStylesDockRight[i] = cubsStylesRight[i].DockPanel();
            cubsStylesDockRight[i].Side = UIExSide.Right;
        }

        cubsStylesRight[0].Margin = new(pixels: true, left: 20f, right: 20f);

        /////////////////

        styleLayout.Orientation = UIExOrientation.Horizontal;

        SideStyle fillRight = styleLayoutDock.SideFill;
        fillRight.Spacing.Pixels = 30f;
        fillRight.JustifyContent = UIExAlignment.Center;
        fillRight.Padding = new UIExThickness(pixels: true, size: 20f);

        UIElement[] cubsFill = AddCubs(dockPanel, "f", pixelSize: 50f, 2);
        StyleLayoutChild[] cubsStylesFill = new StyleLayoutChild[cubsFill.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockFill = new StyleLayoutChildDockPanel[cubsFill.Length];

        for (int i = 0; i < cubsFill.Length; i++)
        {
            cubsStylesFill[i] = cubsFill[i].StyleLayoutChild();
            cubsStylesDockFill[i] = cubsStylesFill[i].DockPanel();
            cubsStylesDockFill[i].Side = UIExSide.Fill;
        }

        ///////////////////

        panel.Append(dockPanel);
        Append(panel);
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIElement[] AddCubs(UIElement element, string prefix, params float[] pixelSizes)
	{
	    int count = pixelSizes.Length;
	    var buttons = new UIElement[count];
	    for (int i = 0; i < count; i++)
	        buttons[i] = AddCubs(element, prefix, pixelSizes[i], count: 1)[0];
	    return buttons;
	}
	
	public UIElement[] AddCubs(UIElement element, string prefix, float pixelSize, int count = 1)
	{
	    var buttons = new UIElement[count];
	    for (int i = 0; i < count; i++)
	    {
	        buttons[i] = new UIButton<string>($"{prefix}{i}");
	        StyleLayoutChild style = buttons[i].StyleLayoutChild();
	        style.Width.Set(pixelSize, 0f);
	        style.Height.Set(pixelSize, 0f);
	        element.Append(buttons[i]);
	    }
	    return buttons;
	}
}
```

Перше, що ви бачите в коді:
```csharp
UIPanel panel = new UIPanel();
```

Створено основну панель. `UIPanel` Розмір екрану 80 відсотків і центрований.<br>

Методика `SetPrecentSizeCenter` Він встановлює відсоток і центризує елемент.<br>
Цей метод не знаходиться в бібліотеці, він визначається в одному класі нижче.<br>

Далі створюється контейнер. `UIExDockPanel`.<br>
І простягається по всій ширині батьківського елемента за допомогою методу. `Stretch();`.<br>
Цей метод визначається в класі `UIExLayout`.<br>

Замість створення двох панелей можна зробити основну панель самостійно. `UIExDockPanel dockPanel`.<br>
З цією метою в **візуалізація** `UIExElement` поле-фінал `tModLoaderStyle (bool).`<br>
Важливість даного поля `true` Для будівельників це призведе до того, що вони мають схожий візуальний стиль. `UIPanel`.<br>

```csharp
UIExDockPanel dockPanel = new UIExDockPanel();

SetPrecentSizeCenter(0.8f, 0.8f, dockPanel);
```

Зараз. `dockPanel` Він стане основною панеллю розміром 80% екрана.

2. Кнопка повинна бути розтягнута вздовж основної осі (для нижньої сторони: горизонтально).<br>

1. Запобігання **інтер'єр** нижня збігається з **зовнішнє** гудзики.
2. Висота нижньої сторони: `100px`: `50px` висота кнопок + `Margin.Bottom: 25px` + `Margin.Top: 25px`.<br>

Ми не будемо ходити в деталь на іншому боці, але ми збираємося зосередитись на наступному.

Елементи додаються до коду в наступному порядку:
1. 1 кнопка для нижньої сторони.
2. 4 гудзики зліва.
3. 3 гудзики для верхньої сторони.
4. 5 гудзиків для правої сторони.
5. 2 кнопки для решти простору.<br>

У цьому випадку розмір сторін буде визначено в наступному порядку:
1. Низькі.
2. Ліворуч.
3. Верхній.
4. Право.
5. решта простору.<br>

Якщо ми змінили порядок додавання коду, порядок розподілу простору сторонам також буде змінено.<br>
Прийняття для елементів `Fill`.<br>
Порядок додавання елементів c `Side == Fill` не впливає на порядок розрахунку сторін.<br>
`Fill` завжди розраховується після `Left`, `Right`, `Top` і `Bottom` І займає решту простору.<br>
Це, якщо ми переїжджаємо код, який відповідає за додавання елементів до решти простору до самого початку, результат макета не буде змінено.

Ви можете бачити, що ця сторона має відступи від решти країв.<br>
Все про цю лінію:
```csharp
SideStyle sideRight = styleLayoutDock.SideRight;
sideRight.Padding = new UIExThickness(pixels: true, size: 20f);
```

Ця лінія вказує, що **пердят** Сторони повинні бути змінені `20px` для кожної сторони.<br>
Це область, в якому будуть розміщені елементи, що надягаються до цієї сторони.<br>
Поруч з нами **інтер'єр** Намальовуються допоміжні лінії.<br>
Для самого будівельника ця сторона займає розмір без врахування `Padding`.<br>
