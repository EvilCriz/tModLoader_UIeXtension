---

`UIExDockPanel` — це контейнер компонування, який **послідовно** пристиковує дочірні елементи до однієї з п’яти сторін доступної області:

* `Left`
* `Right`
* `Top`
* `Bottom`<br>

Місце, що залишилося, також вважається окремою стороною: `Fill`.<br>
Вона займає весь доступний простір, що залишився після обчислення попередніх сторін.<br>

`UIExDockPanel` можна умовно представити як два рівні компонування:

1. Перший рівень: послідовне виділення області `Left`, `Right`, `Top`, `Bottom` і `Fill`;
2. Другий рівень: кожна сторона самостійно компонуються пристиковані до неї елементи за правилами, практично ідентичними `UIExStackPanel`.<br>

Кожному елементу (крім 1-го винятку, про який буде розказано пізніше) ми вказуємо сторону, до якої хочемо його пристикувати.<br>
Але ключове значення під час роботи з цим компоновником має порядок додавання елементів до контейнера.<br>

Припустімо, у нас є 4 кнопки, які ми пристикували до сторони відповідно до назви кнопки та додали до компоновника в такому порядку:

1. `buttonTop`.
2. `buttonBottom`
3. `buttonLeft`
4. `buttonRight`<br>

Результат цього ви спостерігали на зображенні вище.<br>

Але тепер змінимо порядок додавання. Самі кнопки залишаться пристикованими до тих самих сторін, але порядок їх додавання до контейнера буде таким:

1. `buttonLeft`
2. `buttonTop`.
3. `buttonBottom`
4. `buttonRight`<br>

Компоновник робить наступне:

1. Запам’ятовує, до якої зі сторін було пристиковано перший елемент; другий елемент тощо. Наприклад:

   * перший — до лівої сторони;
   * другий — до лівої сторони;
   * третій — до правої сторони;
   * четвертий — до лівої сторони;
   * п’ятий — до нижньої сторони.
2. Запам’ятовує список сторін без повторень у тому самому порядку. Приклад (за п.1):

   * ліва сторона;
   * права сторона;
   * нижня сторона.
3. По черзі виділяє розмір кожної зі сторін, виходячи зі списку п.2 та алгоритму нижче.<br>

Розміри сторони визначаються наступним чином:

1. Висота сторін `Left` і `Right`: висота вільного місця в контейнері.
2. Ширина сторін `Left` і `Right`: ширина найбільшої зовнішньої області серед елементів, пристикованих до цієї сторони.
3. Ширина сторін `Top` і `Bottom`: ширина вільного місця в контейнері.
4. Висота сторін `Top` і `Bottom`: висота найбільшої зовнішньої області серед елементів, пристикованих до цієї сторони.<br>

Після того як область першої доданої сторони розрахована, ця область виключається з вільного простору контейнера.<br>
У прикладі з попереднього зображення першою додавалася кнопка, пристикована до лівої сторони.<br>

Ви можете взяти код нижче та змінювати порядок додавання елементів, щоб подивитися на результат.<br>
Намагайтеся при цьому передбачити, як виглядатиме цей результат.<br>
Вам наразі не потрібно розуміти, що робить цей код загалом. Вам важливі лише рядки, що відповідають за порядок додавання елементів:

```csharp
UIButton<string> buttonTop = CreateAndAddUIBottom(dockPanel, 50f, "top");
UIButton<string> buttonBottom = CreateAndAddUIBottom(dockPanel, 50f, "bot");
UIButton<string> buttonLeft = CreateAndAddUIBottom(dockPanel, 50f, "left");
UIButton<string> buttonRight = CreateAndAddUIBottom(dockPanel, 50f, "right");
```

Метод `CreateAndAddUIBottom` створює кнопку та одразу додає її до `UIExDockPanel`.<br>
Змінюйте порядок цих рядків, щоб змінити результат.<br>

<details>
<summary>Код, результат якого ви бачили на рис. 1.1</summary>

```csharp
using Microsoft.Xna.Framework;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // метод OnActivate() у цьому випадку використовується лише
    // для функції «гарячого перезавантаження коду» в середовищі розробки.
    // для реального інтерфейсу правильніше було б використовувати
    // метод OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.25f, 0.25f, panel);

        UIExDockPanel dockPanel = new();
        dockPanel.Stretch();
        dockPanel.SetLayoutLinesInfoForBranch(
            state:      true,
            thickness:  3f,
            color:      Color.DarkOrange);

        dockPanel.StyleLayout.JustifyContent = UIExAlignment.Stretch;
        dockPanel.StyleLayout.AlignItems = UIExAlignment.Stretch;

        UIButton<string> buttonTop = CreateAndAddUIBottom(dockPanel, 50f, "top");
        UIButton<string> buttonBottom = CreateAndAddUIBottom(dockPanel, 50f, "bot");
		UIButton<string> buttonLeft = CreateAndAddUIBottom(dockPanel, 50f, "left");
        UIButton<string> buttonRight = CreateAndAddUIBottom(dockPanel, 50f, "right");

        var btTopStyleDock = buttonTop.StyleLayoutChild().DockPanel();
        var btBottomStyleDock = buttonBottom.StyleLayoutChild().DockPanel();
        var btLeftStyleDock = buttonLeft.StyleLayoutChild().DockPanel();
        var btRightStyleDock = buttonRight.StyleLayoutChild().DockPanel();

        btTopStyleDock.Side = UIExSide.Top;
        btBottomStyleDock.Side = UIExSide.Bottom;
        btLeftStyleDock.Side = UIExSide.Left;
        btRightStyleDock.Side = UIExSide.Right;

        ///////////////////

        panel.Append(dockPanel);
        Append(panel);
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> CreateAndAddUIBottom(UIExLayout layout, float pixelsSize, string text)
    {
        UIButton<string> button = new(text);
        button.Width.Pixels = pixelsSize;
        button.Height.Pixels = pixelsSize;
        layout.Append(button);
        return button;
    }
}
```

</details>

`UIExDockPanel` також має «сторону» `Fill`. Це сторона, яка займає всю область, що залишилася після обчислення сторін `Left`, `Right`, `Top`, `Bottom`.<br>
Приклад того, як це виглядає, ви можете переглянути нижче.<br>
Порядок додавання елементів із `Side == Fill` не впливає на порядок обчислення сторін.<br>
`Fill` завжди обчислюється після `Left`, `Right`, `Top` і `Bottom` та займає весь простір, що залишився.<br>

<h2 align="center"><code>UIExStackPanel</code></h2>

На початку розділу було попередження про те, що ця стаття розрахована на те, що ви вже вивчили елемент компонування `UIExStackPanel`. І для цього є важлива причина.<br>

Фактично, усі елементи на кожній стороні компонуються практично за тим самим принципом, що й елементи всередині `UIExStackPanel`.<br>
Змінюються лише способи задання параметрів кожної окремої сторони.

---

<h2 align="center">Стилі <code>UIExDockPanel</code></h2>

Базовий стиль компонування елементів StyleLayoutContainer:

```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    public Enums.UIExOrientation Orientation = Enums.UIExOrientation.Vertical;
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
}
```

* `Orientation`: визначає головну вісь **FILL** сторони, за якою вирівнюватимуться елементи всередині неї.

  * Для сторін `Left` і `Right` орієнтація завжди вертикальна.
  * Для сторін `Top` і `Bottom` орієнтація завжди горизонтальна.

* `JustifyContent`: вирівнювання елементів за головною віссю (працює для всіх сторін; можна перевизначити це значення для конкретної сторони та/або конкретного елемента).

* `AlignItems`: вирівнювання елементів за поперечною віссю (працює для всіх сторін; можна перевизначити це значення для конкретної сторони та/або конкретного елемента).<br><br>

* У `Left`, `Right`, `Top` і `Bottom` напрямок компонування однозначно визначається самою стороною.<br>

* `Fill` не має фіксованого напрямку, тому його орієнтація задається через `StyleLayout.Orientation`.<br>

Типи вирівнювання:

```csharp
public enum UIExAlignment : byte
{
    Auto,
    Start,
    Center,
    End,
    Stretch
}
```

* `Auto`: аналогічно `Start`. Використовується у вкладених елементах та/або сторонах.
* `Start`: вирівнювання елементів за початком осі сторони (верх/ліворуч).
* `Center`: вирівнювання елементів за центром осі сторони.
* `End`: вирівнювання елементів за кінцем осі сторони (низ/праворуч).
* `Stretch`: розтягування елемента по всій осі сторони (за винятком `Margin`).

---

Базові стилі дочірніх елементів `StyleLayoutChild`:

```csharp
public partial class StyleLayoutChild : Base.StyleLayoutChildBase
{
    public Enums.UIExAlignment JustifySelf = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignSelf = Enums.UIExAlignment.Auto;
    public UIExThickness Margin = new();
	public StyleDimension Width = default(StyleDimension);
    public StyleDimension Height = default(StyleDimension);
}
```

* Поле `JustifySelf` у дочірніх елементів: будь-які значення, крім значення `Stretch`, будуть ігноруватися. Значення `Auto` означає, що значення буде керуватися контейнером/стороною.
* Поле `AlignSelf` перевизначає значення `AlignItems` для конкретного вкладеного елемента. Значення `Auto` означає, що значення буде керуватися контейнером/стороною.
* Поле `Margin` враховується під час компонування елемента та визначення розміру займаної ним зовнішньої області.
* Поля `Width` і `Height` детально розглядалися в першій статті цього розділу.

---

Для класу `UIExDockPanel` використовується клас стилів: `StyleLayoutContainerDockPanel`, який зберігає всі стилі компонування для цього класу:

```csharp
public class StyleLayoutContainerDockPanel : Base.StyleLayoutContainerBase
{
    public SideStyle SideLeft;
    public SideStyle SideRight;
    public SideStyle SideTop;
    public SideStyle SideBottom;
    public SideStyle SideFill;
}
```

Цей клас стилю містить стилі чотирьох сторін та для заповнення вільного простору.

```csharp
public class SideStyle : Base.StyleBase
{
    public UIExThickness Padding = default(UIExThickness);
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
    public StyleDimension Spacing = default(StyleDimension);
    public bool Reverse = false;
}
```

* `Padding`: відступи від країв сторони до виділеного місця для розташування елементів усередині сторони.
* `JustifyContent`: вирівнювання елементів за головною віссю. Перевизначає значення `JustifyContent` класу стилю контейнера для цієї конкретної сторони. Значення `Auto` означає, що значення буде керуватися контейнером.
* `AlignItems`: вирівнювання елементів за поперечною віссю. Перевизначає значення `AlignItems` класу стилю контейнера для цієї конкретної сторони. Значення `Auto` означає, що значення буде керуватися контейнером.
* `Spacing`: відповідає за простір між елементами всередині сторони (простір між елементами за головною віссю).
* `Reverse`: вказує на те, що елементи цієї сторони повинні розташовуватися в реверсивному порядку.<br>

Для отримання стилю `UIExDockPanel` використовуйте метод `DockPanel()` у полі `StyleLayout`:

```csharp
UIExDockPanel dockPanel = new();

StyleLayoutContainer styleLayout = dockPanel.StyleLayout;
StyleLayoutContainerDockPanel styleLayoutDockPanel = styleLayout.DockPanel();

styleLayoutDockPanel.SideLeft.Reverse = true;
```

---

Стиль дочірніх елементів `UIExDockPanel`:

```csharp
public class StyleLayoutChildDockPanel : Base.StyleLayoutChildBase
{
    public Enums.UIExSide Side = Enums.UIExSide.Left;
}

public enum UIExSide : byte
{
    Left,
    Right,
    Top,
    Bottom,
    Fill
}
```

Як видно, стиль дочірніх елементів відповідає лише за те, до якої сторони потрібно пристикувати елемент.<br>

Щоб отримати базовий стиль дочірніх елементів, використовуйте метод розширення `UIElement`: `StyleLayoutChild()`.<br>
Щоб отримати стиль дочірніх елементів із параметрами для `UIExDockPanel`, викличте метод `DockPanel()` у базового стилю:

```csharp
UIElement element = new();

StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildDockPanel styleDockPanel = style.DockPanel();

styleDockPanel.Side = UIExSide.Top;
```

<h2 align="center">Приклад використання <i>UIExDockPanel</i></h2>

<details>
<summary>Приклад створення користувацького інтерфейсу (без коментарів, розбір нижче)</summary>

```csharp
using Microsoft.Xna.Framework;
using System;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.MethodsExtensions;
using UIeXtension.Styles;

namespace UIeXtensionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // метод OnActivate() у цьому випадку використовується лише
    // для функції «гарячого перезавантаження коду» в середовищі розробки.
    // для реального інтерфейсу правильніше було б використовувати
    // метод OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.8f, 0.8f, panel);

        UIExDockPanel dockPanel = new UIExDockPanel();
		dockPanel.Stretch();

        dockPanel.ShowLayoutLines = true;
        dockPanel.LayoutLinesThickness = 3f;
        dockPanel.LayoutLinesColor = Color.DarkOrange;

        StyleLayoutContainer styleLayout = dockPanel.StyleLayout;
        StyleLayoutContainerDockPanel styleLayoutDock = styleLayout.DockPanel();

        styleLayout.JustifyContent = UIExAlignment.Center;
        styleLayout.AlignItems = UIExAlignment.Center;

        ////////////////

        SideStyle sideBottom = styleLayoutDock.SideBottom;
        sideBottom.Spacing.Pixels = 100f;

        UIElement[] cubsBottom = AddCubs(dockPanel, "b", pixelSize: 50f, 1);
        StyleLayoutChild[] cubsStylesBottom = new StyleLayoutChild[cubsBottom.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockBottom = new StyleLayoutChildDockPanel[cubsBottom.Length];

        for (int i = 0; i < cubsBottom.Length; i++)
        {
            cubsStylesBottom[i] = cubsBottom[i].StyleLayoutChild();
            cubsStylesDockBottom[i] = cubsStylesBottom[i].DockPanel();
            cubsStylesDockBottom[i].Side = UIExSide.Bottom;
        }

        cubsStylesBottom[0].Margin = new(pixels: true, size: 25f);
        cubsStylesBottom[0].JustifySelf = UIExAlignment.Stretch;

        ////////////////

        SideStyle sideLeft = styleLayoutDock.SideLeft;
        sideLeft.Spacing.Pixels = 50f;
        sideLeft.AlignItems = UIExAlignment.End;

        UIElement[] cubsLeft = AddCubs(dockPanel, "l", pixelSize: 50f, 4);
        StyleLayoutChild[] cubsStylesLeft = new StyleLayoutChild[cubsLeft.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockLeft = new StyleLayoutChildDockPanel[cubsLeft.Length];

        for (int i = 0; i < cubsLeft.Length; i++)
        {
            cubsStylesLeft[i] = cubsLeft[i].StyleLayoutChild();
            cubsStylesDockLeft[i] = cubsStylesLeft[i].DockPanel();
            cubsStylesDockLeft[i].Side = UIExSide.Left;
        }

        cubsStylesLeft[1].AlignSelf = UIExAlignment.Start;
        cubsStylesLeft[2].Margin = new(pixels: true, 50f);

        /////////////////

        SideStyle sideTop = styleLayoutDock.SideTop;
        sideTop.Spacing.Pixels = 10f;
        sideTop.JustifyContent = UIExAlignment.End;

        UIElement[] cubsTop = AddCubs(dockPanel, "t", pixelSize: 50f, 3);
        StyleLayoutChild[] cubsStylesTop = new StyleLayoutChild[cubsTop.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockTop = new StyleLayoutChildDockPanel[cubsTop.Length];

        for (int i = 0; i < cubsTop.Length; i++)
        {
            cubsStylesTop[i] = cubsTop[i].StyleLayoutChild();
            cubsStylesDockTop[i] = cubsStylesTop[i].DockPanel();
            cubsStylesDockTop[i].Side = UIExSide.Top;
        }

        cubsStylesTop[1].Margin = new(pixels: true, 10f);

        /////////////////

        SideStyle sideRight = styleLayoutDock.SideRight;
        sideRight.Spacing.Pixels = 30f;
        sideRight.JustifyContent = UIExAlignment.End;
        sideRight.Padding = new UIExThickness(pixels: true, size: 20f);

        UIElement[] cubsRight = AddCubs(dockPanel, "r", pixelSize: 50f, 5);
        StyleLayoutChild[] cubsStylesRight = new StyleLayoutChild[cubsRight.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockRight = new StyleLayoutChildDockPanel[cubsRight.Length];

        for (int i = 0; i < cubsRight.Length; i++)
        {
            cubsStylesRight[i] = cubsRight[i].StyleLayoutChild();
            cubsStylesDockRight[i] = cubsStylesRight[i].DockPanel();
            cubsStylesDockRight[i].Side = UIExSide.Right;
        }

        cubsStylesRight[0].Margin = new(pixels: true, left: 20f, right: 20f);

        /////////////////

        styleLayout.Orientation = UIExOrientation.Horizontal;

        SideStyle fillRight = styleLayoutDock.SideFill;
        fillRight.Spacing.Pixels = 30f;
        fillRight.JustifyContent = UIExAlignment.Center;
        fillRight.Padding = new UIExThickness(pixels: true, size: 20f);

        UIElement[] cubsFill = AddCubs(dockPanel, "f", pixelSize: 50f, 2);
        StyleLayoutChild[] cubsStylesFill = new StyleLayoutChild[cubsFill.Length];
        StyleLayoutChildDockPanel[] cubsStylesDockFill = new StyleLayoutChildDockPanel[cubsFill.Length];

        for (int i = 0; i < cubsFill.Length; i++)
        {
            cubsStylesFill[i] = cubsFill[i].StyleLayoutChild();
            cubsStylesDockFill[i] = cubsStylesFill[i].DockPanel();
            cubsStylesDockFill[i].Side = UIExSide.Fill;
        }

        ///////////////////

        panel.Append(dockPanel);
        Append(panel);
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIElement[] AddCubs(UIElement element, string prefix, params float[] pixelSizes)
	{
	    int count = pixelSizes.Length;
	    var buttons = new UIElement[count];
	    for (int i = 0; i < count; i++)
	        buttons[i] = AddCubs(element, prefix, pixelSizes[i], count: 1)[0];
	    return buttons;
	}
	
	public UIElement[] AddCubs(UIElement element, string prefix, float pixelSize, int count = 1)
	{
	    var buttons = new UIElement[count];
	    for (int i = 0; i < count; i++)
	    {
	        buttons[i] = new UIButton<string>($"{prefix}{i}");
	        StyleLayoutChild style = buttons[i].StyleLayoutChild();
	        style.Width.Set(pixelSize, 0f);
	        style.Height.Set(pixelSize, 0f);
	        element.Append(buttons[i]);
	    }
	    return buttons;
	}
}
```

Це області самих сторін.<br>
Елементи компонуються за внутрішньою областю сторін (після віднімання `padding` сторін).<br>

---

Перше, що видно в коді:

```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);

UIExDockPanel dockPanel = new UIExDockPanel();
dockPanel.Stretch();
```

Створюється головна панель `UIPanel` розміром у 80% екрана та центрована.<br>

Метод `SetPrecentSizeCenter` задає розмір у відсотках та центрує елемент.<br>
Цього методу немає в бібліотеці, він визначений у цьому ж класі нижче.<br>

Далі створюється контейнер `UIExDockPanel`.<br>
І він розтягується на всю ширину батьківського елемента за допомогою методу `Stretch();`.<br>
Цей метод визначений у класі `UIExLayout`.<br>

Замість створення двох панелей головною панеллю можна було зробити сам `UIExDockPanel dockPanel`.<br>
Для цього у **стилі візуального відображення** `UIExElement` визначено поле `tModLoaderStyle (bool).`<br>
Значення цього поля `true` для компоновників призведе до того, що вони матимуть візуальний стиль, аналогічний `UIPanel`.<br>

У цьому випадку код вище можна було б замінити наступним:

```csharp
UIExDockPanel dockPanel = new UIExDockPanel();
dockPanel.StyleDisplay.tModLoaderStyle = true;
SetPrecentSizeCenter(0.8f, 0.8f, dockPanel);
```

Тепер `dockPanel` стане головною панеллю розміром у 80% екрана.

Далі йдуть рядки:

```csharp
dockPanel.ShowLayoutLines = true;
dockPanel.LayoutLinesThickness = 3f;
dockPanel.LayoutLinesColor = Color.DarkOrange;
```

Цей код повідомляє компоновнику, що йому потрібно виводити допоміжні лінії розміром `3px` та вказаного кольору.<br>
Для `UIExDockPanel` значення `ShowLayoutLines` призведе до того, що допоміжні лінії виводитимуться навколо:

* **Внутрішньої** області сторін.
* **Зовнішньої** області вкладених у компоновник елементів.

Далі йде код, що відповідає за вирівнювання елементів за головною/поперечною віссю.<br>
Головна вісь сторони визначається автоматично:

1. Для лівої/правої сторони: головна вісь вертикальна.
2. Для верхньої/нижньої сторони: головна вісь горизонтальна.
3. Для області заповнення головна орієнтація визначається значенням `UIExDockPanel >> StyleLayout.Orientation` (буде в коді нижче).

```csharp
styleLayout.JustifyContent = UIExAlignment.Center;
styleLayout.AlignItems = UIExAlignment.Center;
```

Елементи вирівнюватимуться за центром відповідно до цих значень, якщо:

1. Сторона **НЕ** перевизначає одне з цих значень (про це нижче).
2. Елемент **НЕ** перевизначає одне з цих значень (про це нижче).

На зображенні, подивившись на нижню сторону, ви можете помітити наступне:

1. Обведення **внутрішньої області** нижньої сторони збігається з **зовнішньою стороною** кнопки.
2. Висота нижньої сторони: `100px`: `50px` висота кнопки + `Margin.Bottom: 25px` + `Margin.Top: 25px`.<br>

Нагадаю, що висота нижньої та верхньої сторін визначається за найбільшою висотою **зовнішньої області** елементів.

---

На інших прикладах сторін ми не будемо зупинятися докладно. Зараз звернемо увагу на наступне.

У коді елементи додаються в наступному порядку:

1. 1 кнопка для нижньої сторони.
2. 4 кнопки для лівої сторони.
3. 3 кнопки для верхньої сторони.
4. 5 кнопок для правої сторони.
5. 2 кнопки для простору, що залишився.<br>

У цьому випадку розмір сторін визначатиметься в наступному порядку:

1. Нижня.
2. Ліва.
3. Верхня
4. Права.
5. Простір, що залишився.<br>

Якби ми змінили порядок додавання коду — змінився б і порядок розподілу місця між сторонами.<br>
Крім елементів `Fill`.<br>
Порядок додавання елементів із `Side == Fill` не впливає на порядок обчислення сторін.<br>
`Fill` завжди обчислюється після `Left`, `Right`, `Top` і `Bottom` та займає весь простір, що залишився.<br>
Тобто якщо ми перемістимо код, що відповідає за додавання елементів у простір, що залишився, — на самий початок, результат компонування не зміниться.

---

Звернемо увагу на праву сторону на зображенні.<br>
Можна помітити, що ця сторона має відступи від інших країв.<br>
Уся справа в цьому рядку:

```csharp
SideStyle sideRight = styleLayoutDock.SideRight;
sideRight.Padding = new UIExThickness(pixels: true, size: 20f);
```

Цей рядок вказує, що **внутрішня область** сторони повинна бути зміщена на `20px` для кожної сторони.<br>
Це область, у якій будуть розташовуватися пристиковані до цієї сторони елементи.<br>
Саме навколо **внутрішньої області** малюються допоміжні лінії.<br>
Для самого компоновника ця сторона займає розмір без урахування `Padding`.<br>

---

Заповнення простору, що залишився.<br>

```csharp
StyleLayoutContainer styleLayout = dockPanel.StyleLayout;
/*
...
*/
styleLayout.Orientation = UIExOrientation.Horizontal;
```

Цей рядок вказує на орієнтацію розташування елементів усередині сторони `Fill`.<br>
В іншому правила розташування елементів аналогічні іншим сторонам.
