`UIExUniformGrid` Він являє собою контейнер для двовимірного розташування елементів інтерфейсу у вигляді рядків і стовпців, які автоматично організовують елементи дитини в сітку, де кожна клітина рівно однакова величина.<br>

**ВАЖЛИВО!**Ця стаття передбачає, що ви вже вивчили статтю. `UIExGrid`.<br>
Цей клас працює аналогічно з базовими стилями, тому вони не будуть обговорюватися в цій статті.<br>
Частина стилів `UIExUniformGrid` аналоговий `UIExGrid`У статті також не буде розглянуто.

<h2 align="center">Стильи. <code>UIExUniformGrid</code></h2>

`UIExUniformGrid` Користувальницькі `StyleLayoutContainer` і `StyleLayoutChild` аналогічно `UIExGrid`.

----

для `UIExUniformGrid` клас `StyleLayoutContainerUniformGrid`:
```csharp
public class StyleLayoutContainerUniformGrid : Base.StyleLayoutContainerBase
{
    public StyleDimension RowsSpace = StyleDimension.Empty;
    public StyleDimension ColumnsSpace = StyleDimension.Empty;

    public Enums.UIExAlignment RowsAlignment = Enums.UIExAlignment.Start;
    public Enums.UIExAlignment ColumnsAlignment = Enums.UIExAlignment.Start;

    public int RowsCount = 0;
    public int ColumnsCount = 0;
}
```

Напильники `RowsSpace`, `ColumnsSpace`, `RowsAlignment`, `ColumnsAlignment` робота аналогічно `UIExGrid`.<br><br>

На відміну, `UIExGrid` Не містить методів налаштування сітки.<br>
Кожна клітина має `UIExGridLength`: `Type = UIExGridLengthType.Fraction` і `Fraction = 1f`.<br>
Ви можете встановити кількість клітин в сітку за допомогою `RowsCount` і `ColumnsCount`.<br>

`UIExUniformGrid` дозволяє вказати значення обох значень `RowsCount` і `ColumnsCount`Або не один з них.<br>
Якщо вказано лише одне з цих значень або жодне з них, `UIExUniformGrid` Він визначить розмір сітки на основі кількості елементів.<br>
Таким чином, вона спробує зробити сітку якомога ближче до квадратної форми, але без створення порожніх рядків / стовпців.<br>

**Важливо.**У автоматичному розрахунку клітин не враховуються. `RowSpan` і `ColumnSpan` елементи.<br>
Якщо ви хочете використовувати ці значення, то вам доведеться розрахувати розмір сітки самостійно.<br>
Для отримання додаткової інформації про розташування елементів, `RowSpan` і `ColumnSpan` буде написано нижче.

----

Всі інвестовані `UIExUniformGrid` елементи можна використовувати в стилі `StyleLayoutChildUniformGrid`.
Для того, щоб ви використовували цей стиль, вам потрібно мати стиль. `StyleLayoutChild` експлуатація `UIElement`: `StyleLayoutChild()`.
Потім в отриманому стилі зателефонуйте метод `UniformGrid()`.
```csharp
UIElement element = new();
StyleLayoutChild style = element.UniformGrid();
StyleLayoutChildUniformGrid styleUGrid = style.Grid();
styleUGrid.RowSpan = 2;
```

Самий клас. `StyleLayoutChildUniformGrid` має наступну реалізацію:
```csharp
public class StyleLayoutChildUniformGrid : Base.StyleLayoutChildBase
{
    public int RowSpan = 1;
    public int ColumnSpan = 1;
}
```

Як можна побачити, на відміну від `StyleLayoutChildGrid` однокласник **нема** Промисловість `Row` і `Columns`.<br>
`UIExUniformGrid` Визначається, де розмістити елемент.<br>
Зареєструватися `RowSpan == 1` і `ColumnSpan == 1`Елементи розташовані зліва направо і зверху вниз.<br>
Я маю на увазі, для розміру сітки. `2x2` В яких додано 3 елементи, в них буде влаштовано наступне замовлення:
- `[element 1]`: `{0, 0}`;
- `[element 2]`: `{0, 1}`;
- `[element 3]`: `{1, 0}`.<br>

1. Кожен наступний елемент зміщений один стовпчик вправо, поки вільні клітини залишалися на правому.
2. При відсутності вільних клітинок, що залишилися в стовпчику, елемент перейшов на ліву колонку, але один ряд нижче.
3. Якщо було вже зайняте клітинку в шляху розташування (приблизно це в прикладі нижче), то елемент буде рухатися далі.<br>

Якщо є більше елементів, ніж кількість клітин, то всі елементи, які не підходять, будуть розміщені в останню клітинку.<br>
Для таких елементів `RowSpan` і `ColumnSpan` Вони не рахують.

----

Це був час для `RowSpan == 1` і `ColumnSpan == 1`.<br>
Припустимо, що перший елемент має `ColumnSpan == 2`.<br>
У цьому випадку елементи будуть розміщені в наступному порядку:
- `[element 1]`: `{ {0, 0}, {0, 1} }`;
- `[element 2]`: `{1, 0}`;
- `[element 3]`: `{1, 1}`.<br><br>

Тепер беремо справу, що перший елемент має `RowSpan == 2` і `ColumnSpan == 2`.<br>
Далі розташування елементів буде наступним чином:
- `[element 1]`: `{ {0, 0}, {0, 1}, {1, 0} }`;
- `[element 2]`: `{1, 1}`;
- `[element 3]`: `{1, 1}`.<br>

1. Перший елемент взяв себе 3 клітини: ліворуч`{0, 0}`), правонаповнювач (`{0, 1}`), лівий-жовтий (`{1, 0}`).
2. Для другого елемента є тільки одна вільна клітина, яка залишається: пряма комірка.`{1, 1}`).
3. Для третього елемента не залишилося вільних клітин, тому він займав останню клітинку в сітці: пряма комірка.`{1, 1}`).

----

Приклад використання в `UIExUniformGrid` для елементів, з значеннями `RowSpan == 1` і `ColumnSpan == 1`а також з автоматичним визначенням `RowsCount` і `ColumnsCount` ілюстрований `UIExLayout`.

----

Це означає, що всі допоміжні лінії можна тягнути одночасно.

<h2 align="center">Приклад використання <i>UIExUniformGrid</i></h2>

<details>
<summary>Приклад створення розкладу калькулятора (без коментарів, аналіз нижче)</summary>

```csharp
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // методологія OnActivate(a) в цьому випадку, тільки
    // для функції «гарячого перезавантаження коду» у середовищі розробки.
    // Щоб скористатися реальним інтерфейсом, краще використовувати реальний інтерфейс.
    // методологія OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPixelsSizeCenter(width: 450f, height: 650f, panel);

        UIExUniformGrid uGrid = new();
        uGrid.Stretch();

        ////////////////////////////

        StyleLayoutContainer styleLayout = uGrid.StyleLayout;
        StyleLayoutContainerUniformGrid styleLayoutUGrid = styleLayout.UniformGrid();

        styleLayout.Set(
            orientation:        UIExOrientation.Vertical,
            justifyContent:     UIExAlignment.Stretch,
            alignItems:         UIExAlignment.Stretch);



        styleLayoutUGrid.Set(
            rowsCount:      7,
            columnsCount:   4,
            rowsSpace:      StyleDimension.FromPixels(10f),
            columnSpace:    StyleDimension.FromPixels(15f));

        ///////////////////////////

        AppendButton(uGrid, prefix: "RESULT:", rowSpan: 2, columnSpan: 4);

        AppendButton(uGrid, prefix: "AC");
        AppendButton(uGrid, prefix: "%");
        AppendButton(uGrid, prefix: "<<");
        AppendButton(uGrid, prefix: "/");

        AppendButton(uGrid, prefix: 7);
        AppendButton(uGrid, prefix: 8);
        AppendButton(uGrid, prefix: 9);
        AppendButton(uGrid, prefix: "*");

        AppendButton(uGrid, prefix: 4);
        AppendButton(uGrid, prefix: 5);
        AppendButton(uGrid, prefix: 6);
        AppendButton(uGrid, prefix: "-");

        AppendButton(uGrid, prefix: 1);
        AppendButton(uGrid, prefix: 2);
        AppendButton(uGrid, prefix: 3);
        AppendButton(uGrid, prefix: "+");

        AppendButton(uGrid, prefix: 0);
        AppendButton(uGrid, prefix: ",");
        AppendButton(uGrid, prefix: "=", columnSpan: 2);

        ///////////////////////////

        panel.Append(uGrid);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AppendButton(UIExLayout layout, int prefix, int rowSpan = 1, int columnSpan = 1)
        => AppendButton(layout, prefix.ToString(), rowSpan, columnSpan);
    public UIButton<string> AppendButton(UIExLayout layout, string prefix, int rowSpan = 1, int columnSpan = 1)
    {
        UIButton<string> button = new(prefix);

        StyleLayoutChildUniformGrid styleGrid = button.StyleLayoutChild().UniformGrid();
        styleGrid.Set(rowSpan, columnSpan);

        layout.Append(button);
        return button;
    }
}
```

----

Цей код практично ідентичний. `UIExGrid`Так ми розглянемо лише деталі, які різні.

----

```csharp
styleLayoutUGrid.Set(
    rowsCount:      7,
    columnsCount:   4,
    rowsSpace:      StyleDimension.FromPixels(10f),
    columnSpace:    StyleDimension.FromPixels(15f));
```

Це вказує на розмір стовпців і стовпців.<br>
`UIExUniformGrid` Ви не зможете розрахувати розмір сітки самостійно, тому що елементи всередині нього використовуються. `RowSpan` і `ColumnSpan`.

----

Потім додаються елементи.<br>
Методика `AppendButton` ідентичний, крім того, що він не має значення. `row`, `column`Не встановлюйте кнопку, створену всередині.<br>

----

Перший Додаток:
```csharp
AppendButton(uGrid, prefix: "RESULT:", rowSpan: 2, columnSpan: 4);
```
У цьому випадку ми знаємо, що це перший елемент і він буде розташований в комірці. `{0, 0}`.<br>
З елемента `RowSpan == 2` `ColumnSpan == 4`, потім цей елемент буде займати наступний набір клітин:
- `{`
  - `{0, 0}, {0, 1}, {0, 2}, {0, 3}`
  - `{1, 0}, {1, 1}, {1, 2}, {1, 3}`
- `}`<br>

Другий елемент додано:
```csharp
AppendButton(uGrid, prefix: "AC");
```
З останнього окупованого осередку: `{1, 3}`, і це крайній стовпець, потім цей елемент буде розташований в комірці: `{2, 0}`.<br>

Наступний елемент `{2, 1}` і т.д.
