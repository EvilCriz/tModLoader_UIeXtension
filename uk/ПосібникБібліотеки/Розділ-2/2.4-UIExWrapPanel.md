----

`UIExWrapPanel` Це розмітка контейнера, яка розміщує дочірні елементи в одному рядку (або стовпці) і автоматично передає їх в нову лінію, якщо вони не підходять в поточній зоні.<br>

Цей контейнер є дійсно складною версією. `UIExStackPanel`.<br>
Ця стаття повторить попередній у дуже скороченій формі, і припустимо, що ви вже знайомі з нею.<br>

----

Передача елемента відбувається, коли наступний елемент не поміщається в ряд.<br>
- Контейнер широкий `300px` і горизонтальна спрямованість.
- Місце між елементами: `50px`.
- В контейнері послідовно згинаються елементи ширини: `200px`, `50px`, `100px`.<br>
<!-- -->
В результаті ми отримуємо наступний ланцюг:
1. Широкий елемент `200px` Я кладу в контейнер.
2. `50px` простір між елементами `0` і `1`.
3. Широкий елемент `50px` в контейнері. (загальна, зайнята ширина: `300px`).
4. Лінія працює з вільного простору, наступний елемент буде розташовуватися нижче.<br>

Зміщення останнього елемента (на поперечній віссі) буде визначатися за розміром попереднього ряду + встановленим простором між рядами (більше на цьому нижче).<br>

1. Розмір лінії на основній віссі займає весь доступний розмір контейнера на основній віссі.
2. Розмір поперечної осі визначається за розмірами найбільшого поперечного вісьового елемента.
3. Визначено розмір ліній **ДОРОСЛИЙ** як буде розтягувати елемент (04/07/2019)`Enums.UIExAlignment.Stretch`).<br>
<!-- -->
Нижче ви дізнаєтеся, що елементи можна перевернути.<br>
Елементи інверсії відбувається **ДОРОСЛИЙ** Розрахунок ліній і посилань елемента в межах них.

----

Після того, як утворилися лінії, кожен з них окремо відсортовано елементи таким же чином. `UIExStackPanel.`<br>
Але в цьому випадку використовується різний клас стилів.

----

Базовий стиль облаштування елементів `StyleLayoutContainer`:
```csharp
public partial class StyleLayoutContainer : Base.StyleLayoutContainerBase
{
    public Enums.UIExOrientation Orientation = Enums.UIExOrientation.Vertical;
    public Enums.UIExAlignment JustifyContent = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignItems = Enums.UIExAlignment.Auto;
}
```
- `Orientation`: визначає основну вісь контейнера, по якій елементи будуть вирівняні (з лініями).
- `JustifyContent`: вирівнювання елементів вздовж основної осі (з вже сформованими лініями).
- `AlignItems`: вирівнювання елементів вздовж поперечної осі (з вже сформованими лініями).

----

Типи рівня:

```csharp
public enum UIExAlignment : byte
{
    Auto,
    Start,
    Center,
    End,
    Stretch
}
```
- `Auto`аналогічно `Start`Застосовується для елементів, вбудованих в контейнер.
- `Start`: вирівнювання елементів при старті осі (верх/ліво).
- `Center`: вирівнювання елементів в центрі осі.
- `End`: вирівнювання елементів в кінці осі (знизу/право).
- `Stretch`Розтягування елемента по всій осі (мінус Маргін).

----

Основні стилі дитячих елементів `StyleLayoutChild`:
```csharp
public partial class StyleLayoutChild : Base.StyleLayoutChildBase
{
    public Enums.UIExAlignment JustifySelf = Enums.UIExAlignment.Auto;
    public Enums.UIExAlignment AlignSelf = Enums.UIExAlignment.Auto;
    public UIExThickness Margin = new();
    public StyleDimension Width = default(StyleDimension);
    public StyleDimension Height = default(StyleDimension);
}
```
- Поле. `JustifySelf` руді `JustifyContent` Ви ігноруєте будь-яке значення, відмінне від значення контейнера для певного елемента. `Stretch`.
- Поле. `AlignSelf` руді `AlignItems` Контейнер для конкретного виробу.
- Поле. `Margin` Він чудово працює.
- Сфери `Width` і `Height` У статті описано докладно в першій статті даного розділу.

----

Для класу. `UIExWrapPanel` Стильний клас використовується: `StyleLayoutContainerWrapPanel`Він зберігає всі стилі макета для цього класу.
```csharp
public class StyleLayoutContainerWrapPanel : Base.StyleLayoutContainerBase
{
    public StyleDimension SpacingWithinLine = StyleDimension.Empty;
    public StyleDimension SpacingBetweenLines = StyleDimension.Empty;
	
    public Enums.UIExAlignment AlignLines = Enums.UIExAlignment.Auto;
	
    public bool ReverseWithinLine = false;
    public bool ReverseAll = false;
}
```

- `SpacingWithinLine`: визначає відступ між елементами в лініях (працьовуються аналогічно) `Spacing` контейнери `UIExStackPanel`).
- `SpacingBetweenLines`: визначає відступ між лініями.
- `AlignLines`: визначає вирівнювання всіх ліній вздовж поперечної осі.
- `ReverseWithinLine`: якщо це значення `true` Елементи всередині кожної лінії будуть розташовуватися в зворотному порядку.
- `ReverseAll`: якщо це значення `true` Всі елементи будуть розміщені в зворотному порядку (і будуть повернені до початку макета).<br>
<!-- -->
- `ReverseWithinLine` і `ReverseAll` Вони можуть бути перевернуті одночасно, і в цьому випадку буде працювати макет. `ReverseAll`І всередині ліній, елементи будуть перевернуті окремо.

----

**Не працює.** Стильний клас для дитячих елементів.

----

Основні стилі розкладу контейнерів містяться в області `StyleLayout`.
Для отримання стилів макета `UIExWrapPanel` використання методу `WrapPanel()` Промисловість StyleLayout.
Для отримання базових стилів для вбудованих елементів в контейнер, використовуйте метод розширення.`UIElement`: `StyleLayoutChild()`.
```csharp
UIExWrapPanel wrapPanel = new();

StyleLayoutContainer style = wrapPanel.StyleLayout;
StyleLayoutContainerWrapPanel styleWrapPanel = stackPanel.StyleLayout.WrapPanel(); // або style.WrapPanel();

UIElement element = new();
StyleLayoutChild styleChild = element.StyleLayoutChild();

style.JustifyContent = UIExAlignment.Center;
styleWrapPanel.ReverseAll = true;

styleChild.JustifySelf = UIExAlignment.Stretch;
```

using Microsoft.Xna.Framework;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // методологія OnActivate(a) в цьому випадку, тільки
    // для функції «гарячого перезавантаження коду» у середовищі розробки.
    // Щоб скористатися реальним інтерфейсом, краще використовувати реальний інтерфейс.

        UIExWrapPanel wrapPanel = new();

        wrapPanel.SetLayoutLinesInfoForBranch(
            state: true,
            thickness: 3f,
            color: Color.DarkOrange);

        ////////////////////////////

        StyleLayoutContainer styleLayout = wrapPanel.StyleLayout;

        styleLayout.Set(
            orientation: UIExOrientation.Horizontal,
            justifyContent: UIExAlignment.Center,
            alignItems: UIExAlignment.Center);

        styleLayoutWrap.Set(
            spacingWithinLine: StyleDimension.FromPixels(10f),
            spacingBetweenLines: StyleDimension.FromPixels(15f),
            alignLines: UIExAlignment.Center,
			// 4 варіанти поєднання цих двох значень
            reverseWithinLine: true,
            reverseAll: true); //

        ///////////////////////////

        AddPixelButton(wrapPanel, prefix: 0, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 1, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 2, width: 200f, height: 200f);
        AddPixelButton(wrapPanel, prefix: 3, width: 200f, height: 200f);

        ///////////////////////////

        panel.Append(wrapPanel);
        Append(panel);
    }

    public void SetPixelsSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(width, 0f);
            element.Height.Set(height, 0f);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIButton<string> AddPixelButton(UIExLayout layout, int prefix, float width, float height)
        => AddPixelButton(layout, prefix.ToString(), width, height);
    public UIButton<string> AddPixelButton(UIExLayout layout, string prefix, float width, float height)
    {
        UIButton<string> button = new($"{prefix}");
        StyleLayoutChild style = button.StyleLayoutChild();
        style.Width.Pixels = width;
        style.Height.Pixels = height;
        layout.Append(button);
        return button;
    }
}

Стилі макета будуть:
- Вертикальне розташування елементів.

- Зазор між елементами в межах ліній: `10px`.
- Зняття між лініями: `15px`.
- Підготовлені лінії.
- Всі елементи будуть розміщені в порядку, в якому вони додаються в контейнер.<br>

Додавання елементів.

- Всі наступні елементи розташовуються зліва від попереднього і передані в наступну лінію при необхідності.

У цій частині коду розглянуто кількість елементів, створених і їх зберігання в масиві.

----

```csharp
for (int i = 0; i < count; i++)
{
    StyleLayoutChild style = buttons[i].StyleLayoutChild();
    if (i == 0)
    {
        style.Width.Precent = 1f;
        style.Height.Precent = 2f / 7.5f;
    }
    else
    {
        style.Width.Precent = 1 / 4.5f;
        style.Height.Precent = 1 / 7.5f;
    }

    if (i == count - 1)
        style.Width.Precent *= 2f;
}
```

Перед тим як почати розуміти цю частину коду, необхідно уточнити:
- Розмітка містить 6 ліній, в кожній з яких (крім 2) 4 елементи.
- Елементи з написом `RESULT` (в першому доданому) буде займати розмір 2 ліній і всю ширину лінії.
- Елементи з написом `=` (Це останнє долучено) `2` Це два рази більше, ніж інші елементи (крім 1st).
- Всі інші елементи будуть мати висоту 1/7 контейнера і ширину 1/4 лінії.<br>

Всі елементи, крім першого і останнього, негабаритні в блокі. `else`.<br>
Але в той час як я писав раніше, що елементи повинні бути 1/7 і 1/4 контейнерних розмірів, цей код показує, що елементи 1/7.5 і 1/4.5.<br>
Уся точка це:
- Якщо передбачається, що лінія 4 елемента, кожен повинен зайняти 1/4 його ширини.
- Але крім самих елементів, ми також маємо відступ між елементами в `10px`.
- Тому я знизив розмір елементів, щоб уникнути переміщення їх на нову лінію.<br>

Ситуація схожа на висоту:
- У нас є 6 рядків, і один з них становить 2 рази більше, ніж інші, тому елементи повинні розділити висоту безкоштовно на 1/7 (перший: 2/7).
- Таке значення буде означати, що рядки будуть займати 100% від висоти внутрішнього регіону контейнера.
- Але код визначає інтервал міжряддя `15px`Це означає, що загальна кількість наших кнопок займе висота: 100% + 15px * 5.
- Таким чином, лінії також отримують 1/7.5 висоту, щоб не вийти за межі основного панно.<br>

Окрема індикація першого елемента (`RESULT`) розмір:
- Ширина виробу становить близько 100% ширина контейнера (за умови, що всі наступні елементи будуть автоматично передані в наступну лінію).
- Висота елемента становить 2/7.5 ліній (і з усіх інших елементів мають значення 1/7.5, це означає, що ця лінія зайнята 2 рази на висоту інших).<br>

----

```csharp
else
{
    style.Width.Precent = 1 / 4.5f;
    style.Height.Precent = 1 / 7.5f;
}

if (i == count - 1)
    style.Width.Precent *= 2f;
```

Після останнього елемента отримує:
- Ширина - 1/4,5 ширини контейнера.
- Висота 1/7.5 висоти контейнера.<br>

Його ширина збільшена на 2 рази.<br>
Що робить його 2 рази більшою за шириною, ніж всі інші елементи (крім 1-го).

----

Для підведення підсумків:
1. Елемент з індексом 0 взяв розмір: 2 лінії і всю ширину.
2. Місце на першому рядку надходить. Всі наступні елементи будуть пересувні на наступний.
3. Далі додаються наступні 4 елементи (індекс: 1-4) з розмірами 1/4.5 і 1/7.5.
4. Місце в другому рядку надходить. Всі наступні елементи будуть пересувні на наступний.
5. Далі додаються наступні 4 елементи (індекс: 5-8) з розмірами 1/4.5 і 1/7.5.
6. Місце в третьому рядку надходить. Всі наступні елементи будуть переходити в наступну.
7. Далі додаються наступні 4 елементи (індекс: 9-12) з розмірами 1/4.5 і 1/7.5.
8. Місце в рядку чотири поверху. Всі наступні елементи будуть переміщатися в наступну.
9. Далі додаються наступні 4 елементи (індекс: 13-16) з розмірами 1/4.5 і 1/7.5.
10. Місце в рядку п'ять закінчено. Всі наступні елементи будуть переведені на наступний.
11. Потім додайте наступні 2 елементи (індекс: 17-18) з розмірами 1/4.5 і 1/7.5. **Нема.** Це над.
12. Потім додаються наступні елементи (індекс: 19) з розмірами 2/4.5 і 1/7.5.
13. Місце в рядку передається, але немає передачі, тому що це був останній елемент.
