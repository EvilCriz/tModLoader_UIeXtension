`UIExGrid` - це контейнер компоновки для двовимірного розташування елементів інтерфейсу у вигляді рядків і стовпців.

---

<h2 align="center">Стилі <code>UIExGrid</code></h2>

* `UIExGrid` повноцінно використовує всі стилі `StyleLayoutContainer`.
* `Orientation`: визначає основну вісь контейнера. Це значення відіграє роль під час використання `JustifyContent`, `JustifySelf`, `AlignItems`, `AlignSelf`.
* `JustifyContent` і `AlignContent` визначають вирівнювання елементів усередині кожної комірки по головній / поперечній осі.

А також використовує `StyleLayoutChild` для вкладених елементів:

* `JustifySelf` і `AlignSelf` - перевизначають значення `JustifyContent` і `AlignContent` контейнера для кожного окремого елемента.
* `Margin` працює стандартно. Якщо якісь із відступів вказані у відсотках - відсотки обчислюються від розміру всього `UIExGrid`.

---

Цей клас стилю дозволяє задати налаштування сітки.
Отримати клас стилю можна, викликавши метод `Grid` у поля `StyleLayout`:

```csharp
UIExGrid grid = new();
StyleLayoutContainer style = grid.StyleLayout;
StyleLayoutContainerGrid styleGrid = style.Canvas();
UIExAlignment rowsAlignment = styleGrid.RowsAlignment;
```

---

Налаштування сітки задаються за допомогою методів:

* `Add(Row/Column)Definition(s)`;
* `Get(Row/Column)Definition(s)`;
* `Remove(Row/Column)DefinitionAt`;
* `Remove(Row/Column)DefinitionsRange`;
* `Replace(Row/Column)Definition`;
* `Insert(Row/Column)Definition(s)`;<br>

<!-- -->

* `Add(Row/Column)Definition(s)`:

  * Перевантаження 1: додає рядок/стовпець розміром `UIExGridLength`.
  * Перевантаження 2: додає N рядків/стовпців розміром `UIExGridLength`.
  * Перевантаження 3: додає масив рядків/стовпців розміром `UIExGridLength`.
  * Перевантаження 4: додає список рядків/стовпців розміром `UIExGridLength`.
* `Get(Row/Column)Definition(s)`:

  * Перевантаження 1: Повертає розмір `UIExGridLength` за індексом рядка/стовпця.
  * Перевантаження 2: Повертає масив розмірів `UIExGridLength` від початкового до кінцевого (включно) індексів рядків/стовпців.
* `Remove(Row/Column)DefinitionAt`;

  * Перевантаження 1: видаляє рядок/стовпець за переданим індексом.
* `Remove(Row/Column)DefinitionsRangle`:

  * Перевантаження 1: видаляє рядки/стовпці від початкового до кінцевого (включно) індексів.
* `Replace(Row/Column)Definition`:

  * Перевантаження 1: замінює рядок/стовпець на переданий розмір `UIExGridLength` за переданим індексом.
* `Insert(Row/Column)Definition(s)`:

  * Перевантаження 1: вставляє розмір рядка/стовпця `UIExGridLength` за переданим індексом.
  * Перевантаження 2: вставляє масив розмірів рядків/стовпців `UIExGridLength` за переданим індексом.
  * Перевантаження 3: вставляє список розмірів рядків/стовпців `UIExGridLength` за переданим індексом.<br>

---

Структура розміру рядка/стовпця.

```csharp
public struct UIExGridLength
{
    public Enums.UIExGridLengthType Type = Enums.UIExGridLengthType.Auto;

    public float Pixels = 0f;
    public float Precent = 0f;
    public float Fraction = 0f;


    public static UIExGridLength FromPx(float pixels) { /* ... */ }

    public static UIExGridLength FromPr(float precent) { /* ... */ }

    public static UIExGridLength FromFr(float fraction) { /* ... */ }

    public static UIExGridLength FromAuto() { /* ... */ }

    public static UIExGridLength Empty() { /* ... */ }
}

public enum UIExGridLengthType : byte
{
    Pixels,
    Precent,
    Fraction,
    Auto
}
```

Тип розміру:

* `Pixels`: розмір задається в пікселях у полі `Pixels`.
* `Precent`: розмір задається у відсотках у полі `Precent`.
* `Fraction`: розмір задається у фракціях у полі `Fraction`. Після обчислення всіх інших розмірів рядків/стовпців вільний простір буде розподілено між рядками/стовпцями відповідно до розміру їхніх фракцій.
* `Auto`: розмір визначається максимальним розміром елемента, вкладеного в рядок/стовпець.<br>

Структура також визначає статичні методи для швидкого створення об'єкта структури потрібного типу.

---

`UIExGrid` дозволяє вказати простір між рядками/стовпцями за допомогою полів стилю:

```csharp
public StyleDimension RowsSpace = StyleDimension.Empty;
public StyleDimension ColumnsSpace = StyleDimension.Empty;
```

А також дозволяє вказати вирівнювання сітки (якщо розмір висоти/ширини сітки менший за висоту/ширину) контейнера.

```csharp
public Enums.UIExAlignment RowsAlignment = Enums.UIExAlignment.Start;
public Enums.UIExAlignment ColumnsAlignment = Enums.UIExAlignment.Start;
```

`Rows/ColumnsAlignment` може приймати лише значення `Start`, `Center`, `End`.<br>
Усі інші значення будуть прирівняні до `Start`.

---

Усі елементи, вкладені в `UIExGrid`, можуть використовувати стиль `StyleLayoutChildGrid`.
Щоб ви могли використовувати цей стиль, вам необхідно отримати стиль `StyleLayoutChild` за допомогою методу розширення `UIElement`: `StyleLayoutChild()`.
Потім у отриманого стилю викликати метод `Grid()`.

```csharp
UIElement element = new();
StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildGrid styleGrid = style.Grid();
styleGrid.Row = 1;
```

Сам клас `StyleLayoutChildGrid` має наступну реалізацію:

```csharp
public class StyleLayoutChildGrid : Base.StyleLayoutChildBase
{
    public int Row = 0;
    public int Column = 0;

    public int RowSpan = 1;
    public int ColumnSpan = 1;
}
```

1. Дозволяє вказати рядок і стовпець, де буде розташований цей елемент. `Значення < 0` будуть прирівняні до `0`. `Значення >= Rows/ColumnsCount` буде прирівняне до `Rows/ColumnsCount - 1`.
2. Дозволяє вказати, скільки рядків/стовпців буде займати елемент. `Значення < 1` будуть прирівняні до `1`. Елемент не може за допомогою `Row/ColumnSpan` вийти за межі сітки.

<h2 align="center">Допоміжні лінії</h2>

`UIExLayout` дає можливість задавати допоміжні лінії (див. статтю `UIExLayout`).<br>
Якщо `UIExLayout.ShowLayoutLines == true`, то допоміжні лінії будуть промальовуватися:

* Навколо кожної комірки.
* Навколо зовнішньої області кожного елемента всередині контейнера (яка бере участь у компоновці).<br>

`UIExGrid` пропонує альтернативну можливість відображення допоміжних ліній за допомогою полів і методів:

```csharp
public bool ShowGridLines = false;
public float GridLinesThickness = 1f;
public Color GridLinesColor = Color.DarkGray;



public virtual void SetGridLinesInfoForTree(
	bool showGridLines, 
	float gridLinesThickness, 
	Color gridLinesColor) 
		{ /* ... */ }


public virtual void SetGridLinesInfoForBranch(
	bool showGridLines, 
	float gridLinesThickness, 
	Color gridLinesColor)
		{ /* ... */ }
```

У цьому випадку допоміжні лінії будуть відображені у вигляді сітки.

* `ShowGridLines` - визначає, чи будуть відображатися допоміжні лінії у вигляді сітки.
* `GridLinesThickness` - визначає розмір допоміжних ліній у вигляді сітки в пікселях.
* `GridLinesColor` - визначає колір допоміжних ліній у вигляді сітки.<br>

<!-- -->

* `SetGridLinesInfoForTree` - дозволяє встановити всі три наведені вище значення для всього дерева елементів.
* `SetGridLinesInfoForBranch` - дозволяє встановити всі три наведені вище значення для всіх нащадків цього контейнера.<br>

`ShowLayoutLines` і `ShowGridLines` працюють незалежно один від одного.<br>
Це означає, що всі допоміжні лінії можуть відображатися одночасно.

using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState

    // метод OnActivate() в даному випадку використовується тільки

    // для реального інтерфейсу правильніше було б використовувати

        AppendButton(grid, prefix: "/", row: 2, column: 3);

        AppendButton(grid, prefix: 7, row: 3, column: 0);

        AppendButton(grid, prefix: 9, row: 3, column: 2);
        AppendButton(grid, prefix: "*", row: 3, column: 3);

        AppendButton(grid, prefix: 4, row: 4, column: 0);
        AppendButton(grid, prefix: 5, row: 4, column: 1);
        AppendButton(grid, prefix: 6, row: 4, column: 2);
        AppendButton(grid, prefix: "-", row: 4, column: 3);

        AppendButton(grid, prefix: 1, row: 5, column: 0);

    }

---

Перше, що видно в коді - це створення головної панелі розміром `450х650px`, яка центрована на екрані.

```csharp
UIPanel panel = new UIPanel();
SetPixelsSizeCenter(width: 450f, height: 650f, panel);
```

Метод `SetPixelsSizeCenter` визначений у цьому класі для прикладу і не є методом цієї бібліотеки.<br>

Після цього створюється контейнер `UIExGrid`:

```csharp
UIExGrid grid = new();
grid.Stretch();
```

Метод `Stretch()` визначений у `UIExLayout` і змушує контейнер розтягуватися на всю висоту та ширину батьківського елемента.<br>
У цьому прикладі `grid.Stretch()` розтягує елемент на весь розмір `panel`.

---

Трохи про візуальні стилі. Це тема наступного розділу, але тут є 1 важливий момент для компоновщиків, тому ця примітка буде в кожній статті.<br>
Як видно, у цьому коді система наступна: головна панель -> контейнер -> елементи всередині контейнера.<br>
Для головної панелі створюється власний контейнер.<br>
Це зайве, якщо результат саме той, який ми хочемо бачити на зображенні.<br>
`UIExElement` (від якого успадковується `UIExLayout`) має властивість стилю: `StyleDisplay.tModLoaderStyle (bool)`.<br>
Якщо це значення істинне, то візуальний елемент прийматиме відповідний стиль **tModLoader**.<br>
Для `UIExElement` значення `true` призведе до того, що стиль буде аналогічним до `UIPanel`.<br>
Отже, наш код міг бути скорочений.<br>

Ось цю частину:

```csharp
UIPanel panel = new UIPanel();
SetPixelsSizeCenter(width: 450f, height: 650f, panel);

UIExGrid grid = new();
grid.Stretch();

/*
...
*/

panel.Append(grid);
Append(panel);
```

Можна замінити на наступну:

```csharp
UIExGrid grid = new();
grid.StyleDisplay.tModLoaderStyle = true;
SetPixelsSizeCenter(width: 450f, height: 650f, grid);

/*
...
*/

Append(grid);
```

Як видно у другому коді, елемент `UIPanel panel` зник. Сам контейнер компоновки `grid` одночасно став головним контейнером.

---

Далі в коді отримуються базовий стиль компоновки контейнера та стиль компоновки `UIExGrid`:

```csharp
StyleLayoutContainer styleLayout = grid.StyleLayout;
StyleLayoutContainerGrid styleLayoutGrid = styleLayout.Grid();
```

Потім задаються значення `justifyContent` і `alignItems`: `UIExAlignment.Stretch`.

```csharp
styleLayout.Set(
	justifyContent: UIExAlignment.Stretch,
	alignItems: 	UIExAlignment.Stretch);
```

Цей код вказує, що всі елементи всередині контейнера повинні розтягуватися за шириною та висотою комірки/комірок, які вони займають.<br>

---

Далі в коді визначається сама сітка:

```csharp
styleLayoutGrid.AddRowDefinition(UIExGridLength.FromFr(1f), repeat: 7);
styleLayoutGrid.AddColumnDefinition(UIExGridLength.FromFr(1f), repeat: 4);
```

Цей код вказує, що:

* рядків у сітці має бути 7 штук, які порівну розподіляють висоту контейнера між собою.
* колонок у сітці має бути 4 штуки, які порівну розподіляють ширину контейнера між собою.
* простір розподіляється рівномірно, оскільки розмір кожного рядка/стовпця становить 1 фракцію.<br>

Далі в коді задається простір між рядками та стовпцями:

```csharp
styleLayoutGrid.Set(
	rowsSpace: 		StyleDimension.FromPixels(10f),
	columnSpace: 	StyleDimension.FromPixels(15f));
```

---

Потім додаються кнопки за допомогою методів:

```csharp
public UIButton<string> AppendButton(UIExLayout layout, int prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
    => AppendButton(
		layout,
		prefix.ToString(),
		row, column,
		rowSpan, columnSpan);

public UIButton<string> AppendButton(UIExLayout layout, string prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
{
    UIButton<string> button = new(prefix);

    StyleLayoutChildGrid styleGrid = button.StyleLayoutChild().Grid();
    styleGrid.Set(row, column, rowSpan, columnSpan);

    layout.Append(button);
    return button;
}
```

Ці методи також не визначені в бібліотеці та створені для цього прикладу.<br>
`AppendButton` створює кнопку, задає їй: `Row`, `Column`, `RowSpan`, `ColumnSpan`, переданий текст і додає до переданого контейнера.

---

```csharp
AppendButton(grid, prefix: "RESULT:", row: 0, column: 0, rowSpan: 2, columnSpan: 4);
```

Перший елемент розташований у комірці `{0, 0}` і займає 2 рядки та 4 колонки.<br>
Тобто цей елемент займає безліч комірок:<br>

* `{`

  * `{0, 0}, {0, 1}, {0, 2}, {0, 3}`,
  * `{1, 0}, {1, 1}, {1, 2}, {1, 3}`
* `}`<br>

Останній елемент розташований у комірці `{6, 2}` і займає 1 рядок та 2 колонки.<br>

```csharp
AppendButton(grid, prefix: "=", row: 6, column: 2, rowSpan: 1, columnSpan: 2);
```

Тобто цей елемент займає безліч комірок:<br>

* `{ {6, 2}, {6, 3} }`.<br>

Усі інші елементи займають по 1 комірці та розташовані послідовно зліва-направо і зверху-вниз (розташовуються вручну):

```csharp
AppendButton(grid, prefix: 7, row: 3, column: 0);
AppendButton(grid, prefix: 8, row: 3, column: 1);
AppendButton(grid, prefix: 9, row: 3, column: 2);
AppendButton(grid, prefix: "*", row: 3, column: 3);

AppendButton(grid, prefix: 4, row: 4, column: 0);
AppendButton(grid, prefix: 5, row: 4, column: 1);
AppendButton(grid, prefix: 6, row: 4, column: 2);
AppendButton(grid, prefix: "-", row: 4, column: 3);

AppendButton(grid, prefix: 1, row: 5, column: 0);
AppendButton(grid, prefix: 2, row: 5, column: 1);
AppendButton(grid, prefix: 3, row: 5, column: 2);
AppendButton(grid, prefix: "+", row: 5, column: 3);

AppendButton(grid, prefix: 0, row: 6, column: 0);
AppendButton(grid, prefix: ",", row: 6, column: 1);
```
