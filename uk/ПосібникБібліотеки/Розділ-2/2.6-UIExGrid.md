`UIExGrid` Він являє собою контейнер для двовимірного розташування елементів інтерфейсу у вигляді рядків і стовпців.

----

<h2 align="center">Стильи. <code>UIExGrid</code></h2>

- `UIExGrid` Повністю використовує всі стилі `StyleLayoutContainer`.
- `Orientation`: визначає основну вісь контейнера. Це значення відіграє роль при використанні `JustifyContent`, `JustifySelf`, `AlignItems`, `AlignSelf`.
- `JustifyContent` і `AlignContent` визначає вирівнювання елементів в кожній клітинці вздовж основної / поперечної осі.

І він використовує його. `StyleLayoutChild` для в'язаних елементів:
- `JustifySelf` і `AlignSelf` - значення перевизначення `JustifyContent` і `AlignContent` Контейнер для кожного окремого елемента.
- `Margin` Якщо будь-який з відступів вказаний у відсотках, то відсотки відраховуються від розміру загальної суми. `UIExGrid`.

Настроювання сітки встановлюються за допомогою методів:
- `Add(Row/Column)Definition(s)`;
- `Get(Row/Column)Definition(s)`;
- `Remove(Row/Column)DefinitionAt`;
- `Remove(Row/Column)DefinitionsRange`;
- `Replace(Row/Column)Definition`;
- `Insert(Row/Column)Definition(s)`;<br>
<!-- -->
- `Add(Row/Column)Definition(s)`:
  - Перевантаження 1: Додає ряд / об'ємний розмір `UIExGridLength`.
  - Перевантаження 2: Додавання N рядків / стовпців в розмірах `UIExGridLength`.
  - Перевантаження 3: Додавання масиву рядків / стовпців за розміром `UIExGridLength`.
  - Перевантаження 4: Додає список рядків / стовпів розміром `UIExGridLength`.
- `Get(Row/Column)Definition(s)`:
  - Перевантаження 1: повертає розмір `UIExGridLength` по індексу рядка/колюмна.
  - Перевантаження 2: повертає масив розмірів `UIExGridLength` з початкових до кінцевих (включних) показників рядків / стовпців.
- `Remove(Row/Column)DefinitionAt`;
  - Перевантаження 1: видаліть ряд / стовпець з передається індексом.
- `Remove(Row/Column)DefinitionsRangle`:
  - Перевантаження 1: видаляє ряди / стовпи з початкового до кінцевих (включних) показників.
- `Replace(Row/Column)Definition`:
  - Перевантаження 1: Замінює ряд / охолоджується за розмірами передається `UIExGridLength` на передається індекс.
- `Insert(Row/Column)Definition(s)`:
  - Перевантаження 1: вставки ряд / об'ємний розмір `UIExGridLength` на передається індекс.
  - Перевантаження 2: вставляє масив рядків / стовпів розмірів `UIExGridLength` на передається індекс.
  - Перевантаження 3: вставляє список розмірів рядків / стовпців `UIExGridLength` на передається індекс.<br>

Структура розмірів String/column.
```csharp
public struct UIExGridLength
{
    public Enums.UIExGridLengthType Type = Enums.UIExGridLengthType.Auto;

    public float Pixels = 0f;
    public float Precent = 0f;
    public float Fraction = 0f;


    public static UIExGridLength FromPx(float pixels) { /* ... */ }

    public static UIExGridLength FromPr(float precent) { /* ... */ }

    public static UIExGridLength FromFr(float fraction) { /* ... */ }

    public static UIExGridLength FromAuto() { /* ... */ }

    public static UIExGridLength Empty() { /* ... */ }
}

public enum UIExGridLengthType : byte
{
    Pixels,
    Precent,
    Fraction,
    Auto
}
```

Тип розміру:
- `Pixels`: Розмір дається в пікселях в області `Pixels`.
- `Precent`: розмір дається у відсотках у поле `Precent`.
- `Fraction`: розмір встановлюється в дроби в поле `Fraction`Після обчислення всіх інших розмірів рядка / подрібнювача, вільний простір буде розподілятися між рядами / подрібнювачами відповідно до розміру їх дробів.
- `Auto`: розмір визначається максимальним розміром елемента, що пролягає в рядку/холодильнику.<br>

Структура також визначає статичні методи для швидкого створення об’єкту структури необхідного типу.

----

`UIExGrid` дозволяє вказати простір між рядами / стовпчиками з використанням полів стилю:
```csharp
public StyleDimension RowsSpace = StyleDimension.Empty;
public StyleDimension ColumnsSpace = StyleDimension.Empty;
```

Також можна вказати вирівнювання сітки (якщо розмір висоти / ширина сітки менше висоти / пропускної здатності) контейнера.
```csharp
public Enums.UIExAlignment RowsAlignment = Enums.UIExAlignment.Start;
public Enums.UIExAlignment ColumnsAlignment = Enums.UIExAlignment.Start;
```
`Rows/ColumnsAlignment` може приймати тільки сенси `Start`, `Center`, `End`.<br>
Всі інші значення будуть скорочені `Start`.

----

Всі інвестовані `UIExGrid` елементи можна використовувати в стилі `StyleLayoutChildGrid`.
Для того, щоб ви використовували цей стиль, вам потрібно мати стиль. `StyleLayoutChild` експлуатація `UIElement`: `StyleLayoutChild()`.
Потім в отриманому стилі зателефонуйте метод `Grid()`.
```csharp
UIElement element = new();
StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildGrid styleGrid = style.Grid();
styleGrid.Row = 1;
```

Самий клас. `StyleLayoutChildGrid` має наступну реалізацію:
```csharp
public class StyleLayoutChildGrid : Base.StyleLayoutChildBase
{
    public int Row = 0;
    public int Column = 0;

    public int RowSpan = 1;
    public int ColumnSpan = 1;
}
```

1. Дозволяє вказати ряд і стовпчик, де знаходиться цей елемент. `Значения < 0` оцінять `0`. `Значение >= Rows/ColumnsCount` бути еквівалентним `Rows/ColumnsCount - 1`.
2. Дозволяє вказати скільки рядків / стовпців елемент буде зайнятий. `Значения < 1` оцінять `1`Не можна використовувати цей елемент. `Row/ColumnSpan` Виходимо з сітки.

<h2 align="center">Допоміжні лінії</h2>

`UIExLayout` Можна вказати допоміжні лінії (див. статтю). `UIExLayout`).<br>
Зареєструватися `UIExLayout.ShowLayoutLines == true`Допоміжні лінії будуть намальовані:
- Навколо кожної комірки.
- Навколо зовнішнього краю кожного елемента всередині контейнера (який бере участь у плануванні).<br>

`UIExGrid` Пропонує альтернативну можливість надання допоміжних ліній з використанням полів та методів:
```csharp
public bool ShowGridLines = false;
public float GridLinesThickness = 1f;
public Color GridLinesColor = Color.DarkGray;



public virtual void SetGridLinesInfoForTree(
	bool showGridLines, 
	float gridLinesThickness, 
	Color gridLinesColor) 
		{ /* ... */ }


public virtual void SetGridLinesInfoForBranch(
	bool showGridLines, 
	float gridLinesThickness, 
	Color gridLinesColor)
		{ /* ... */ }
```

У цьому випадку будуть намальовані допоміжні лінії у вигляді сітки.

- `ShowGridLines` визначає, чи буде виконано допоміжні лінії у вигляді сітки.
- `GridLinesThickness` визначає розмір допоміжних ліній у вигляді сітки в пікселів.
- `GridLinesColor` - визначає колір допоміжних ліній у вигляді сітки.<br>
<!-- -->
- `SetGridLinesInfoForTree` - дозволяє встановлювати всі три значення над для всього дерева елементів.
- `SetGridLinesInfoForBranch` - дозволяє встановлювати всі три значення, перш за все, нащадком контейнера.<br>

`ShowLayoutLines` і `ShowGridLines` Вони працюють самостійно один від одного.<br>
Це означає, що всі допоміжні лінії можна тягнути одночасно.

----

Перше, що ви бачите в коді, створює розмір майстер панелі. `450х650px`, яка знаходиться на екрані.
```csharp
UIPanel panel = new UIPanel();
SetPixelsSizeCenter(width: 450f, height: 650f, panel);
```
Методика `SetPixelsSizeCenter` Визначено в цьому класі за допомогою прикладу і не є методом цієї бібліотеки.<br>

Після чого створюється контейнер. `UIExGrid`:
```csharp
UIExGrid grid = new();
grid.Stretch();
```
Методика `Stretch()` визначено `UIExLayout` і викликає контейнер для розтягування по всій висоті і ширині батьківського елемента.<br>
У цьому прикладі `grid.Stretch()` розтягує елемент по всій його розмірі `panel`.

----

Трохи про візуальні стилі. Це тема наступного розділу, але є 1 важлива точка для будівельників, тому ця примітка буде в кожній статті.<br>
Як видно, в цьому коді система наступним чином: головна панель -> контейнер -> елементи всередині контейнера.<br>
Контейнер створений для основної панелі.<br>
Це непотрібно, якщо результат точно те, що ми хочемо бачити в образі.<br>
`UIExElement` (з якого він успадковує) `UIExLayout`) має властивість стилю: `StyleDisplay.tModLoaderStyle (bool)`.<br>
Якщо це значення вірно, то візуальний елемент буде прийняти відповідний стиль. **tModLoader**.<br>
для `UIExElement` значення `true` Це означає, що стиль буде схожим. `UIPanel`.<br>
Таким чином, наш код був скорочений.<br>

Ось частина:
```csharp
UIPanel panel = new UIPanel();
SetPixelsSizeCenter(width: 450f, height: 650f, panel);

UIExGrid grid = new();
grid.Stretch();

/*
...
*/

panel.Append(grid);
Append(panel);
```

Чи можна замінювати наступним чином:
```csharp
UIExGrid grid = new();
grid.StyleDisplay.tModLoaderStyle = true;
SetPixelsSizeCenter(width: 450f, height: 650f, grid);

/*
...
*/

Append(grid);
```

Як ви можете побачити в другому коді, `UIPanel panel` Сам контейнер пішов. `grid` Він став головним контейнером одночасно.

----

Далі код отримує основний стиль контейнера і стиль макета `UIExGrid`:
```csharp
StyleLayoutContainer styleLayout = grid.StyleLayout;
StyleLayoutContainerGrid styleLayoutGrid = styleLayout.Grid();
```

Далі встановлюються значення. `justifyContent` і `alignItems`: `UIExAlignment.Stretch`.
```csharp
styleLayout.Set(
	justifyContent: UIExAlignment.Stretch,
	alignItems: 	UIExAlignment.Stretch);
```
Цей код визначає, що всі елементи всередині контейнера повинні бути розтягнуті по ширині і висоті комірок / cells він займає.<br>

----

Код визначає саму сітку:
```csharp
styleLayoutGrid.AddRowDefinition(UIExGridLength.FromFr(1f), repeat: 7);
styleLayoutGrid.AddColumnDefinition(UIExGridLength.FromFr(1f), repeat: 4);
```
Цей код вказує, що:
- Повинен бути 7 ліній в сітці, які однаково розподіляють висоту контейнера між собою.
- Колонки в сітці повинні бути 4 штуки, які однаково розподіляють ширину контейнера між собою.
- Простір рівномірно розподіляється як розмір кожного ряду/колюмна - 1 дроб.<br>

Далі код визначає простір між рядками і стовпчиками:
```csharp

```

Потім кнопки додаються за допомогою методів:
```csharp
public UIButton<string> AppendButton(UIExLayout layout, int prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
    => AppendButton(
		layout,
		prefix.ToString(),
		row, column,
		rowSpan, columnSpan);

public UIButton<string> AppendButton(UIExLayout layout, string prefix, int row, int column, int rowSpan = 1, int columnSpan = 1)
{
    UIButton<string> button = new(prefix);

    StyleLayoutChildGrid styleGrid = button.StyleLayoutChild().Grid();
    styleGrid.Set(row, column, rowSpan, columnSpan);

    layout.Append(button);
    return button;

```
Дані методи не визначені в бібліотеці, і створюються для цього прикладу.<br>
`AppendButton` Створює гудзик, що дає йому: `Row`, `Column`, `RowSpan`, `ColumnSpan`, передається текст і додає до передається контейнер.

----

```csharp
AppendButton(grid, prefix: "RESULT:", row: 0, column: 0, rowSpan: 2, columnSpan: 4);
```
Перший елемент знаходиться в комірці. `{0, 0}` Займає 2 лінії і 4 стовпчики.<br>
Що таке, що цей елемент займає багато клітин:<br>
- `{`
  - `{0, 0}, {0, 1}, {0, 2}, {0, 3}`,
  - `{1, 0}, {1, 1}, {1, 2}, {1, 3}`
- `}`<br>


Останній елемент знаходиться в комірці. `{6, 2}` Займає 1 рядок і 2 стовпчики.<br>
```csharp
AppendButton(grid, prefix: "=", row: 6, column: 2, rowSpan: 1, columnSpan: 2);
```
Що таке, що цей елемент займає багато клітин:<br>
- `{ {6, 2}, {6, 3} }`.<br>

Всі інші елементи займають 1 клітинку і розташовуються послідовно з зліва направо і зверху вниз (розташовується вручну):
```csharp
AppendButton(grid, prefix: 7, row: 3, column: 0);
AppendButton(grid, prefix: 8, row: 3, column: 1);
AppendButton(grid, prefix: 9, row: 3, column: 2);
AppendButton(grid, prefix: "*", row: 3, column: 3);

AppendButton(grid, prefix: 4, row: 4, column: 0);
AppendButton(grid, prefix: 5, row: 4, column: 1);
AppendButton(grid, prefix: 6, row: 4, column: 2);
AppendButton(grid, prefix: "-", row: 4, column: 3);

AppendButton(grid, prefix: 1, row: 5, column: 0);
AppendButton(grid, prefix: 2, row: 5, column: 1);
AppendButton(grid, prefix: 3, row: 5, column: 2);
AppendButton(grid, prefix: "+", row: 5, column: 3);

AppendButton(grid, prefix: 0, row: 6, column: 0);
AppendButton(grid, prefix: ",", row: 6, column: 1);
```
