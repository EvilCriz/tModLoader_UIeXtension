`UIExCanvas` — це контейнер компонування, який розташовує вміст у заданих позиціях (і не тільки).

---

<h2 align="center">Стилі <code>UIExCanvas</code></h2>

`UIExCanvas` повноцінно використовує всі стилі `StyleLayoutContainer`.

* `Orientation`: визначає основну вісь контейнера. Це значення відіграє роль під час використання `JustifyContent`, `JustifySelf`, `AlignItems`, `AlignSelf`.
* `JustifyContent` і `AlignContent` визначають початкове вирівнювання за головною / поперечною віссю всіх вкладених елементів у контейнері. Ці дві властивості відіграють важливу роль під час роботи з `UIExCanvas`. Докладніше про це буде нижче.

А також використовує `StyleLayoutChild` для вкладених елементів:

* `JustifySelf` і `AlignSelf` — перевизначають значення `JustifyContent` і `AlignContent` контейнера для кожного окремого елемента.
* `Margin` працює стандартно.

---

Для `UIExCanvas` існує клас стилю `StyleLayoutContainerCanvas`:

```csharp
public class StyleLayoutContainerCanvas : Base.StyleLayoutContainerBase
{
    public bool AllowOverflow = false;
}
```

* `AllowOverflow` відповідає за те, чи можуть елементи вийти за межі контейнера.
* Якщо значення `false`, то контейнер спочатку зміщуватиме елемент, а якщо цього недостатньо — зменшуватиме розмір вкладеного елемента.
* Кожен вкладений елемент матиме можливість окремо перевизначити це значення.<br>

Отримати цей клас стилю можна, викликавши метод `Canvas()` у поля `StyeLayout`:

```csharp
UIExCanvas canvas = new();
StyleLayoutContainer style = canvas.StyleLayout;
StyleLayoutContainerCanvas styleCanvas = style.Canvas();
bool allowOverflow = styleCanvas.AllowOverflow;
```

---

Усі вкладені в `UIExCanvas` елементи можуть використовувати стиль `StyleLayoutChildCanvas`.<br>
Щоб ви могли використовувати цей стиль, вам необхідно отримати стиль `StyleLayoutChild` за допомогою методу розширення `UIElement`: `StyleLayoutChild()`.<br>
Потім у отриманого стилю викликати метод `Canvas()`.

```csharp
UIElement element = new();
StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildCanvas styleCanvas = style.Canvas();
```

<br>

Сам клас `StyleLayoutChildCanvas` має таку реалізацію:

```csharp
public class StyleLayoutChildCanvas : Base.StyleLayoutChildBase
{
    public StyleDimension Left = default(StyleDimension);
    public StyleDimension Top = default(StyleDimension);
    public StyleDimension Right = default(StyleDimension);
    public StyleDimension Bottom = default(StyleDimension);

    public bool? AllowOverflowSelf = null;
}
```

Як видно, цей клас реалізує всього дві речі:

1. Додає зміщення відносно вибраної координати.
2. Додає `AllowOverflowSelf`. Це значення, якщо воно відрізняється від `null`, перевизначає значення `AllowOverflow` контейнера `UIExCanvas` для цього конкретного елемента.<br>

Нехай цей компоновщик виглядає досить стандартно, у ньому з'являються важливі нюанси, коли ми торкаємося `JustifyContent`, `JustifySelf`, `AlignItems`, `AlignSelf`.<br>
Краще буде одразу продемонструвати це на прикладі. Давайте уявимо 4 різні ситуації:<br>

1. У нас є елемент, який **НЕ** використовує цю бібліотеку. І його значення `HAlign` і `VAlign`: `0.5f`. У цьому випадку цей елемент буде розташований по центру.
2. У нас є елемент, вкладений у `UIExCanvas` зі значеннями `JustifySelf` і `AlignSelf`: `UIExAlignment.Start`, і значеннями `StyleLayoutCanvas.Left.Precent = 0.5f`, `StyleLayoutCanvas.Top.Precent = 0.5f`. У цьому випадку результат буде аналогічним до пункту 1.
3. У нас є елемент, вкладений у `UIExCanvas` зі значеннями `JustifySelf` і `AlignSelf`: `UIExAlignment.Center`, і значеннями `StyleLayoutCanvas.Left.Set(0f, 0f)`, `StyleLayoutCanvas.Top.Set(0f, 0f)`. У цьому випадку результат буде аналогічним до пунктів 1 і 2.
4. У нас є елемент, вкладений у `UIExCanvas` зі значеннями `JustifySelf` і `AlignSelf`: `UIExAlignment.Center`, і значеннями `StyleLayoutCanvas.Left.Precent = 0.5f`, `StyleLayoutCanvas.Top.Precent = 0.5f`. У цьому випадку елемент **НЕ** буде розташований по центру. Він опиниться рівно на 0.75% висоти та ширини контейнера.<br><br>

Чому в пункті 4 результат виявився таким?<br>
Уся справа в тому, що `Justify` і `Align` не просто вирівнюють елемент. Вони зміщують початкову точку відліку координат.<br>
У цьому випадку:

1. Елемент центрований.
2. Початкова точка координат центрована.
3. `StyleLayoutCanvas.Left.Precent = 0.5f` — зміщує елемент на 50% від його точки відліку координат до правого краю контейнера. Це буде 0.75% ширини контейнера.
4. Аналогічно для `StyleLayoutCanvas.Top.Precent = 0.5f`<br>

Якщо зараз це складно для розуміння, то стане значно простіше та зрозуміліше під час розбору прикладу коду нижче.<br><br>

На відміну від стандартних інструментів **tModLoader** для розташування елементів за координатами `Left` і `Top`, ця бібліотека пропонує використовувати 4 координати.

1. `Top`: зміщення елемента відносно верхньої частини контейнера. Якщо значення 10px — елемент буде розташований на 10px нижче верхньої частини контейнера.
2. `Left`: зміщення елемента відносно лівої частини контейнера.
3. `Bottom`: зміщення елемента відносно нижньої частини контейнера.
4. `Right`: зміщення елемента відносно правої частини контейнера.

* `Top` і `Bottom` взаємно віднімають одне одного. Це означає: якщо `Top.Set(10f, 0f)` і `Bottom.Set(10f, 0f)` — то зміщення елемента буде 0.
* Для `Left` і `Right` ситуація аналогічна.

<details>
<summary>Приклад створення користувацького інтерфейсу (без коментарів, розбір нижче)</summary>

```csharp
using Microsoft.Xna.Framework;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtension;
using UIeXtension.Enums;
using UIeXtension.MethodsExtensions;
using UIeXtension.Styles;

namespace UIeXtensionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // метод OnActivate() у цьому випадку використовується лише
    // для функції «гарячого перезавантаження коду» у середовищі розробки.
    // для реального інтерфейсу правильніше було б використовувати
    // метод OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.8f, 0.8f, panel);

        UIExCanvas canvas = new UIExCanvas();
        canvas.Stretch();
        canvas.ShowLayoutLines = true;
        canvas.LayoutLinesThickness = 3f;
        canvas.LayoutLinesColor = Color.DarkOrange;

        canvas.StyleLayout.Set(
            orientation: UIExOrientation.Horizontal,
            justifyContent: UIExAlignment.Center);

        panel.Append(canvas);
        Append(panel);

        UIElement[] cubs = AddCubs(canvas, 50, 16);
        StyleLayoutChildCanvas[] stylesCanvas = new StyleLayoutChildCanvas[cubs.Length];
        StyleLayoutChild[] styles = new StyleLayoutChild[cubs.Length];

        for (int i = 0; i < cubs.Length; i++)
        {
            styles[i] = cubs[i].StyleLayoutChild();
            stylesCanvas[i] = styles[i].Canvas();
        }


        ////

        styles[0].JustifySelf = UIExAlignment.Start;
        styles[0].AlignSelf =   UIExAlignment.Start;

        // styles[1]: JustifySelf == Auto == JustifyContent(canvas) == Center
        // styles[1]: AlignSelf == Auto == AlignContent(canvas) == Auto == Start

        // styles[2]: AlignSelf == Auto == AlignContent(canvas) == Auto == Start
        styles[2].JustifySelf = UIExAlignment.End;

        styles[3].JustifySelf = UIExAlignment.Start;
        styles[3].AlignSelf =   UIExAlignment.Center;

        // styles[4]: JustifySelf == Auto == JustifyContent(canvas) == Center
        styles[4].AlignSelf =   UIExAlignment.Center;

        styles[5].JustifySelf = UIExAlignment.End;
        styles[5].AlignSelf =   UIExAlignment.Center;

        styles[6].JustifySelf = UIExAlignment.Stretch;
        styles[6].AlignSelf =   UIExAlignment.End;
        styles[6].Margin =      new UIExThickness(
                                    pixels:     true,
                                    right:      25f,
                                    bottom:     50f,
                                    left:       75f,
                                    top:        100f);

        ////////////////
        ////////////////
        ////////////////

        CopyStyle4(indexStart: 7, indexEnd: 15);

        stylesCanvas[7].Top.Pixels = 50f;
        stylesCanvas[8].Bottom.Pixels = 50f;
        stylesCanvas[9].Left.Pixels = 50f;
        stylesCanvas[10].Right.Pixels = 50f;

        stylesCanvas[11].Bottom.Pixels = 50f;
        stylesCanvas[11].Right.Pixels = 50f;

        styles[12].Margin = new UIExThickness(
                                pixels:     true,
                                bottom:     50f,
                                right:      100f);
        stylesCanvas[12].Left.Precent = -0.5f;

        stylesCanvas[13].Left.Pixels = 100000f;
        stylesCanvas[13].Top.Pixels = 50f;

        stylesCanvas[14].Left.Precent = 0.5f;

        stylesCanvas[15].Left.Precent = 1.1f;
        stylesCanvas[15].AllowOverflowSelf = true;

        void CopyStyle4(int indexStart, int indexEnd)
        {
            for (int i = indexStart; i <= indexEnd; i++)
                styles[i].Copy(styles[4]);
        }
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
    {
        int count = pixelSizes.Length;
        var buttons = new UIElement[count];
        for (int i = 0; i < count; i++)
            buttons[i] = AddCubs(element, pixelSizes[i], count: 1)[0];
        return buttons;
    }

    public UIElement[] AddCubs(UIElement element, float pixelSize, int count = 1)
    {
        var buttons = new UIElement[count];
        for (int i = 0; i < count; i++)
        {
            buttons[i] = new UIButton<string>(i.ToString());
            StyleLayoutChild style = buttons[i].StyleLayoutChild();
            style.Width.Set(pixelSize, 0f);
            style.Height.Set(pixelSize, 0f);
            element.Append(buttons[i]);
        }
        return buttons;
    }
}
```

Трохи про візуальні стилі. Це тема наступного розділу, але тут є 1 важливий момент для компоновщиків, тому ця примітка буде в кожній статті.<br>
Як видно, у цьому коді система наступна: головна панель -> контейнер -> панелі кубів.<br>
Для головної панелі створюється власний контейнер.<br>
Це зайве, якщо результат саме той, який ми хочемо бачити на зображенні.<br>
`UIExElement` (від якого успадковується `UIExLayout`) має властивість стилю: `StyleDisplay.tModLoaderStyle (bool)`.<br>
Якщо це значення істинне, то візуальний елемент прийматиме відповідний стиль **tModLoader**.<br>
Для `UIExElement` значення `true` призведе до того, що стиль буде аналогічним до `UIPanel`.<br>
Отже, наш код міг бути скорочений.<br><br>

Ось цю частину:

```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);

UIExCanvas canvas = new UIExCanvas();

/*
...
*/

panel.Append(canvas);
Append(panel);
```

Можна замінити на наступну:

```csharp
UIExCanvas canvas = new UIExCanvas();
canvas.StyleDisplay.tModLoaderStyle = true;
SetPrecentSizeCenter(0.8f, 0.8f, panel);

/*
...
*/

Append(canvas);
```

Як видно в другому коді, елемент `UIPanel panel` зник. Сам контейнер компоновки `canvas` став одночасно головним контейнером.

---

Перше, що ви бачите в коді:

```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);
```

Це головна панель, яка буде додана в `UIState`. На ній будуть розташовуватися `UIExCanvas`.<br><br>
`SetPrecentSizeCenter` — це допоміжний метод, якого немає в самій бібліотеці, і який визначений нижче в цьому ж класі.
Він отримує N `UIElement`, встановлює їм передану висоту та ширину і центрує їх. У цьому випадку наша `panel` має розмір: 80%х80% екрана.<br><br>

---

Далі в коді йде `UIExCanvas`:

```csharp
UIExCanvas canvas = new UIExCanvas();
canvas.Stretch();
canvas.ShowLayoutLines = true;
canvas.LayoutLinesThickness = 3f;
canvas.LayoutLinesColor = Color.DarkOrange;

canvas.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Center);

panel.Append(canvas);
Append(panel);
```

* `canvas.Stretch();` — встановлює розміри `canvas`: 100% від батьківського елемента.
* Нижче ми додаємо `canvas` до головної панелі `panel.Append(canvas);`, що означає, що `canvas` компонуватиме елементи по всій головній панелі, тобто по всьому створеному інтерфейсу.
* `canvas.ShowLayoutLines = true;` — вказує, що потрібно відобразити допоміжні лінії. Для `UIExCanvas` малюється прямокутник навколо **зовнішньої** області елементів. Докладнішу інформацію про області елементів дивіться в першій частині цього розділу. `canvas.LayoutLinesThickness = 3f;` — розмір ліній 3 пікселі. `canvas.LayoutLinesColor = Color.DarkOrange` — колір допоміжних ліній.
* `Set` — це метод, який є в будь-якого класу стилю в бібліотеці. Кожен `Set` стилю приймає значення для всіх наявних полів класу стилю.
* Його стилі `StyleLayoutContainer StyleLayout`:

  * `Orientation`: основна вісь контейнера. `Horizontal` — горизонтальна.
  * `JustifyContent` (вирівнювання елементів за основною віссю) (основна вісь — горизонтальна): `Center` — елементи вирівнюються по центру ширини контейнера.
  * `AlignItems` (вирівнювання елементів за поперечною віссю) (поперечна вісь — вертикальна): `не вказано` — елементи вирівнюються по верхній частині контейнера.
* Його стилі `StyleLayoutContainerCanvas StyleLayoutCanvas`:

  * `AllowOverflowSelf`: `не вказано`. За замовчуванням: `false`. Вкладені елементи не можуть вийти за межі контейнера.

Далі в коді йде процес створення 16 кубів 50x50px і збереження їхніх стилів:

```csharp
UIElement[] cubs = AddCubs(canvas, 50, 16);
StyleLayoutChildCanvas[] stylesCanvas = new StyleLayoutChildCanvas[cubs.Length];
StyleLayoutChild[] styles = new StyleLayoutChild[cubs.Length];

for (int i = 0; i < cubs.Length; i++)
{
    styles[i] = cubs[i].StyleLayoutChild();
    stylesCanvas[i] = styles[i].Canvas();
}
```

Куби додаються за допомогою методу `AddCubs`:

```csharp
public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
{
    int count = pixelSizes.Length;
    var buttons = new UIElement[count];
    for (int i = 0; i < count; i++)
        buttons[i] = AddCubs(element, pixelSizes[i], count: 1)[0];
    return buttons;
}

public UIElement[] AddCubs(UIElement element, float pixelSize, int count = 1)
{
    var buttons = new UIElement[count];
    for (int i = 0; i < count; i++)
    {
        buttons[i] = new UIButton<string>(i.ToString());
        StyleLayoutChild style = buttons[i].StyleLayoutChild();
        style.Width.Set(pixelSize, 0f);
        style.Height.Set(pixelSize, 0f);
        element.Append(buttons[i]);
    }
    return buttons;
}
```

Ці методи також створені спеціально для цього прикладу і не існують у самій бібліотеці.<br>

Зверніть увагу, що розмір усередині методу задається за допомогою стилю `StyleLayoutChild`.<br>
Оскільки дочірнім елементам усередині компоновщика можна задавати розміри лише таким чином:

```csharp
buttons[i] = new UIButton<string>(i.ToString());
StyleLayoutChild style = buttons[i].StyleLayoutChild();
style.Width.Set(pixelSize, 0f);
style.Height.Set(pixelSize, 0f);
element.Append(buttons[i]);
```

Далі йде код, який задає значення стилю вкладеним кубам:<br>
Вирівнювання кубів 0-6:<br>
`0`: верх по горизонталі; ліворуч по вертикалі;<br>
`1`: верх по горизонталі; центр по вертикалі;<br>
`2`: верх по горизонталі; праворуч по вертикалі;<br>
`3`: ліворуч по горизонталі; центр по вертикалі;<br>
`4`: по центру екрана;<br>
`5`: праворуч по горизонталі; центр по вертикалі;<br>
`6`: розтягнутий по горизонталі (з відступами); низ по вертикалі.<br>

```csharp
styles[0].JustifySelf = UIExAlignment.Start;
styles[0].AlignSelf =   UIExAlignment.Start;

// styles[1]: JustifySelf == Auto == JustifyContent(canvas) == Center
// styles[1]: AlignSelf == Auto == AlignContent(canvas) == Auto == Start

// styles[2]: AlignSelf == Auto == AlignContent(canvas) == Auto == Start
styles[2].JustifySelf = UIExAlignment.End;

styles[3].JustifySelf = UIExAlignment.Start;
styles[3].AlignSelf =   UIExAlignment.Center;

// styles[4]: JustifySelf == Auto == JustifyContent(canvas) == Center
styles[4].AlignSelf =   UIExAlignment.Center;

styles[5].JustifySelf = UIExAlignment.End;
styles[5].AlignSelf =   UIExAlignment.Center;

styles[6].JustifySelf = UIExAlignment.Stretch;
styles[6].AlignSelf =   UIExAlignment.End;
styles[6].Margin =      new UIExThickness(
                            pixels:     true,
                            right:      25f,
                            bottom:     50f,
                            left:       75f,
                            top:        100f);
```

Як видно, частина рядків закоментована:<br>

* Для `styles[1]`, `styles[2]`, `style[4]`. Це зроблено, щоб показати, які значення для цих полів їм потрібні були б, але вони вже встановлені в самого `UIExCanvas canvas`.
* Наприклад: елемент 2 (`style[2]`) розташований: центр по горизонталі; верх по вертикалі. Щоб отримати це вирівнювання за допомогою `JustifySelf` і `AlignSelf`, йому потрібно встановити:

  * `JustifySelf = UIExAlignment.Center` (вирівнювання за основною віссю. Основна вісь у `canvas` вказана як горизонтальна). Центр по горизонталі.
  * `AlignSelf = UIExAlignment.Start` (вирівнювання за поперечною віссю). Верх по вертикалі.
  * У `canvas` поле `JustifyContent` вже встановлено в `UIExAlignment.Center`, яке зміщує цей елемент. Властивість `JustifySelf` немає сенсу встановлювати.
  * У `canvas` поле `AlignItems` не встановлено. За замовчуванням: `UIExAlignment.Auto` (аналогічно до `UIExAlignment.Start`). Властивість `AlignSelf` немає сенсу встановлювати.<br>

---

У елемента 6 (`style[6]`) поле `justifySellf == UIExAlignment.Stretch`. Це означає, що він розтягується за всім розміром головної осі. У цьому випадку — по всій ширині, крім відступу `Margin`.<br><br>
Це один із двох елементів, у якого допоміжні лінії не збігаються з реальними елементами. І головну роль тут відіграє `Margin`.<br>

`Margin` збільшує зовнішню область елемента. Докладніше про це читайте в статті «*Клас UIExLayout. Основи компонування*».<br>
Зовнішній розмір визначається таким чином:

1. `outer-Top`: `cubs[6].Top - styles[6].Margin.Top;`
2. `outer-Left`: `cubs[6].Left - styles[6].Margin.Left;`
3. `outer-Width`: `cubs[6].Width + styles[6].Margin.Left + styles[6].Margin.Right;`
4. `outer-Height`: `cubs[6].Height + styles[6].Margin.Top + styles[6].Margin.Bottom;`<br>

* `cubs[6].Left` == `Margin.Left`, якщо він розтягнутий по ширині.
* `cubs[6].Width` == `ширина контейнера - (Margin.Left + Margin.Right)`, якщо він розтягнутий по ширині.<br>

Результат (попередній): (`c50px` — умовне позначення розміру нерозтягнутого ребра куба (розмір: `50px`))

1. `outer-Top`: `висота контейнера - c50px - 100px`
2. `outer-Left`: `75px - 75px;`
3. `outer-Width`: `(ширина контейнера - (Margin.Left + Margin.Right)) + 75px + 25px;`
4. `outer-Height`: `c50px + 100px + 50px;`<br>

Результат (остаточний):

1. `outer-Top`: `висота контейнера - 150px`
2. `outer-Left`: `0px;`
3. `outer-Width`: `150px;`
4. `outer-Height`: `200px;`<br>

`Stretch` розтягує зовнішню область елемента. А звичайна область (яка і відображається на екрані) **після** розтягування обчислюється за формулою:<br>
Формули для розрахунку позицій під час розтягування (`Left`, `Width` — за шириною; `Top`, `Height` — за висотою):

1. `Left = Margin.Left;`
2. `Top = Margin.Top;`
3. `Width = ширина контейнера - (Margin.Left + Margin.Right)`.
4. `Height = висота контейнера - (Margin.Top + Margin.Bottom)`.

---

Далі йде метод:

```csharp
CopyStyle4(indexStart: 7, indexEnd: 15); 
```

Це внутрішній допоміжний метод. Він просто копіює значення `style[4]` (`justifySelf: center, alignSelf: center`) у стилі для 7-15 елементів.<br><br>

Далі:

```csharp
stylesCanvas[7].Top.Pixels = 50f;
stylesCanvas[8].Bottom.Pixels = 50f;
stylesCanvas[9].Left.Pixels = 50f;
stylesCanvas[10].Right.Pixels = 50f;

stylesCanvas[11].Bottom.Pixels = 50f;
stylesCanvas[11].Right.Pixels = 50f;
```

Усі ці елементи (як і всі наступні) скопіювали значення `style[4]`, і відлік їхніх координат починається від центру контейнера.

1. Елемент 7 зміщений на 50px вниз відносно центру і розташований нижче центрального елемента 4.
2. Елемент 8 зміщений на 50px вгору відносно центру і розташований вище центрального елемента 4.
3. Елемент 9 зміщений на 50px праворуч відносно центру і розташований праворуч від центрального елемента 4.
4. Елемент 10 зміщений на 50px ліворуч відносно центру і розташований ліворуч від центрального елемента 4.
5. Елемент 11 зміщений на 50px вгору і вліво відносно центру і розташований вище та ліворуч від центрального елемента 4.<br><br>

Далі:

```csharp
styles[12].Margin = new UIExThickness(
    pixels:     true,
    bottom:     50f,
    right:      100f);
stylesCanvas[12].Left.Precent = -0.5f;
```

Цей приклад демонструє:

1. Додаткову візуалізацію використання `Margin`. Як видно на зображенні, у елемента 12 збільшена зовнішня область, але сам він знаходиться в її лівій-верхній частині. Якби замість right, bottom ми вказали left/top — елемент при цьому змістився б. Оскільки компоновщик встановлює позиції верхньої-лівої точки **зовнішнього розміру** елемента.
2. Позицію, вказану у відсотках, яка є від'ємною. Цей елемент центрований, тому -0.5f змістить елемент праворуч на 25% контейнера (50% від центрованої точки відліку координат до лівого краю контейнера). Докладніше це буде під час розбору куба з індексом 14.

```csharp
styles[12].Bottom.Pixels = 50f;
styles[12].Right.Pixels = 100f;
```

По суті: у цих двох способів розташування елементів є найважливіша відмінність:<br>

* `Left`, `Top`, `Right`, `Bottom` — це просте зміщення елемента.<br>
* `Margin` — це зміщення та збільшення зовнішнього розміру елемента.<br>
  Для цього компоновщика це має значення, тільки якщо `JustifyContent/Self` і/або `AlignItems/Self` мають значення `UIExAlignment.Stretch`.<br>
  Для всіх інших налаштувань немає жодної різниці, що саме використовувати для зміщення.<br>

Як можна помітити, на відміну від усіх інших елементів, у елементів 6 і 12 допоміжний прямокутник намальований із відступом.<br>
Ця обводка малюється навколо зовнішнього розміру елемента.<br>
Крім того, якби ми спробували для елемента 6 задати `Left` або `Right` значення — ми б не побачили жодного зміщення, за (`AllowOverflow == false && AllowOverflowSelf != true`).<br>

---

Далі куб 13. Його ми розберемо разом із 15. А зараз переходимо до 14:

```csharp
stylesCanvas[14].Left.Precent = 0.5f;
```

Якби ми не використовували цю бібліотеку, написали б: `HAlign = 0.5f` — елемент змістився б на 50% від розміру батьківського елемента, мінус 50% його розміру.<br>
Але на зображенні цей куб розташований на 75% ширини.<br>
Оскільки `JustifySelf == UIExAlignment.Center`, точка відліку починається від центру контейнера.<br>
Отже, `stylesCanvas[14].Left.Precent = 0.5f;` обчислює 50% від відстані між центром і правим краєм контейнера.

---

І останні 2 куби, які ми не розбирали:

```csharp
stylesCanvas[13].Left.Pixels = 100000f;
stylesCanvas[13].Top.Pixels = 50f;

stylesCanvas[15].Left.Precent = 1.1f;
stylesCanvas[15].AllowOverflowSelf = true;
```

У першому випадку видно, що зміщення встановлено на 100 тисяч пікселів.<br>
Тим не менш його значення `AllowOverflowSelf == false`. Це означає, що контейнер контролює, щоб елемент не вийшов за його межі.<br>
На зображенні ви можете спостерігати його притиснутим до правого краю.<br><br>

А ось наступний елемент має ліве зміщення на 110% (від різниці між центром і правим краєм).<br>
І значення `AllowOverflowSelf == true`. Контейнер не контролює те, чи виходить елемент за його межі.<br>
Тому ви можете побачити цей елемент праворуч від межі контейнера.
