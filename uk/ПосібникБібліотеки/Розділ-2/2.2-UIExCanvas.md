<h2 align="center">Стильи. <code>UIExCanvas</code></h2>

`UIExCanvas` Повністю використовує всі стилі `StyleLayoutContainer`.
- `Orientation`: визначає основну вісь контейнера. Це значення відіграє роль при використанні `JustifyContent`, `JustifySelf`, `AlignItems`, `AlignSelf`.
- `JustifyContent` і `AlignContent` визначає початкове вирівнювання вздовж основної / поперечної осі для всіх пристосованих елементів в контейнері. `UIExCanvas`Більше про це буде нижче.

І він використовує його. `StyleLayoutChild` для в'язаних елементів:
- `JustifySelf` і `AlignSelf` - значення перевизначення `JustifyContent` і `AlignContent` Контейнер для кожного окремого елемента.
- `Margin` Працює в стандарті.

----

для `UIExCanvas` клас `StyleLayoutContainerCanvas`:
```csharp
public class StyleLayoutContainerCanvas : Base.StyleLayoutContainerBase
{
    public bool AllowOverflow = false;
}
```
- `AllowOverflow` Відповідає за визначення, чи можуть виходити предмети за межі контейнера.
- якщо `false` контейнер спочатку зрушить елемент, і якщо це недостатньо - стискати розмір в'язаного елемента.
- Кожен в'язаний елемент буде мати можливість почервоніння цього значення окремо.<br>

Отримання цього класу стилю можна назвати методом `Canvas()` Промисловість `StyeLayout`:
```csharp
UIExCanvas canvas = new();
StyleLayoutContainer style = canvas.StyleLayout;
StyleLayoutContainerCanvas styleCanvas = style.Canvas();
bool allowOverflow = styleCanvas.AllowOverflow;
```

----

Всі інвестовані `UIExCanvas` елементи можна використовувати в стилі `StyleLayoutChildCanvas`.<br>
Для того, щоб ви використовували цей стиль, вам потрібно мати стиль. `StyleLayoutChild` експлуатація `UIElement`: `StyleLayoutChild()`.<br>
Потім в отриманому стилі зателефонуйте метод `Canvas()`.
```csharp
UIElement element = new();
StyleLayoutChild style = element.StyleLayoutChild();
StyleLayoutChildCanvas styleCanvas = style.Canvas();
```
<br>

Самий клас. `StyleLayoutChildCanvas` має наступну реалізацію:
```csharp
public class StyleLayoutChildCanvas : Base.StyleLayoutChildBase
{
    public StyleDimension Left = default(StyleDimension);
    public StyleDimension Top = default(StyleDimension);
    public StyleDimension Right = default(StyleDimension);
    public StyleDimension Bottom = default(StyleDimension);

    public bool? AllowOverflowSelf = null;
}
```

Як бачите, цей клас реалізовує тільки два речі:
1. Додає зміщення відносно вибраної координати.
2. Добавка`AllowOverflowSelf`Це значення, якщо відрізняється від `null` руді `AllowOverflow` контейнери `UIExCanvas` для цього конкретного елемента.<br>

Незважаючи на те, що цей лайнер виглядає досить стандартно, він має важливі нюанси при дотику до нього. `JustifyContent`, `JustifySelf`, `AlignItems`, `AlignSelf`.<br>
Покажемо, що ми можемо самі зателефонувати одержувачу і узгодити зручний час.<br>
1. У нас є елемент, який **Нема.** У цій бібліотеці та його значеннях. `HAlign` і `VAlign`: `0.5f`У цьому випадку цей елемент буде розташовуватися в центрі.
2. У нас є елемент, вбудований `UIExCanvas` смоктання `JustifySelf` і `AlignSelf`: `UIExAlignment.Start`, і значення `StyleLayoutCanvas.Left.Precent = 0.5f`, `StyleLayoutCanvas.Top.Precent = 0.5f`У цьому випадку результат буде схожий на абзац 1.
3. У нас є елемент, вбудований `UIExCanvas` смоктання `JustifySelf` і `AlignSelf`: `UIExAlignment.Center`, і значення `StyleLayoutCanvas.Left.Set(0f, 0f)`, `StyleLayoutCanvas.Top.Set(0f, 0f)`У цьому випадку результат буде схожий на абзаци 1 і 2.
4. У нас є елемент, вбудований `UIExCanvas` смоктання `JustifySelf` і `AlignSelf`: `UIExAlignment.Center`, і значення `StyleLayoutCanvas.Left.Precent = 0.5f`, `StyleLayoutCanvas.Top.Precent = 0.5f`У цьому випадку елемент **Нема.** Це буде рівно 0,75% від висоти та ширини контейнера.<br><br>

Чому це призвело до абзацу 4?<br>
Що таке, `Justify` і `Align` Вони не просто вирівнюють елемент. Вони зрушують початкову точку координатного звіту.<br>
У цьому випадку:
1. Центрується елемент.
2. Початкова точка знаходиться в центрі.
3. `StyleLayoutCanvas.Left.Precent = 0.5f` Зрушає елемент 50 відсотків від його довідкової точки до правого краю контейнера, який становить 0,55 відсотків ширини контейнера.
4. Схожі для `StyleLayoutCanvas.Top.Precent = 0.5f`<br>

Якщо це важко зрозуміти зараз, це стане набагато простіше і зрозуміліше, при парсингу коду прикладу нижче.<br><br>

На відміну від стандартних інструментів. **tModLoader** позиціонування `Left` і `Top`У цій бібліотеці використовуються 4 координати.
1. `Top`Якщо значення 10px, елемент буде розташований 10px нижче вершини контейнера.
2. `Left`Розміщення елемента з відносно лівої сторони контейнера.
3. `Bottom`Розміщення елемента з відносно нижньої частини контейнера.
4. `Right`Розміщення елемента з відносної правої сторони контейнера.

- `Top` і `Bottom` Вони висувають один одному, що означає, що якщо `Top.Set(10f, 0f)` і `Bottom.Set(10f, 0f)` - зміщення елемента буде 0.
- для `Left` і `Right` Ситуація схожа.

```csharp
using Terraria.UI;

namespace UIeXtenstion;

/// <summary>
///     Дозволяє встановлювати абсолютне позиціонування за вказаними параметрами.
/// </summary>
using Microsoft.Xna.Framework;
using Terraria.GameContent.UI.Elements;
using Terraria.ModLoader.UI;
using Terraria.UI;
using UIeXtenstion;
using UIeXtenstion.Enums;
using UIeXtenstion.Styles;

namespace UIeXtenstionExample;

public class ExampleMenuUI : UIExModSystem<ExamplePanelUI> { }

public class ExamplePanelUI : UIState
{
    // методологія OnActivate(a) в цьому випадку, тільки
    // для функції «гарячого перезавантаження коду» у середовищі розробки.
    // Щоб скористатися реальним інтерфейсом, краще використовувати реальний інтерфейс.
    // методологія OnInitialize()
    public override void OnActivate()
    {
        RemoveAllChildren();

        UIPanel panel = new UIPanel();
        SetPrecentSizeCenter(0.8f, 0.8f, panel);

        UIExCanvas canvas = new UIExCanvas();
        canvas.Stretch();
        canvas.ShowLayoutLines = true;
        canvas.LayoutLinesThickness = 3f;
        canvas.LayoutLinesColor = Color.DarkOrange;

        canvas.StyleLayout.Set(
            orientation: UIExOrientation.Horizontal,
            justifyContent: UIExAlignment.Center);

        panel.Append(canvas);
        Append(panel);

        UIElement[] cubs = AddCubs(canvas, 50, 16);
        StyleLayoutChildCanvas[] stylesCanvas = new StyleLayoutChildCanvas[cubs.Length];
        StyleLayoutChild[] styles = new StyleLayoutChild[cubs.Length];

        for (int i = 0; i < cubs.Length; i++)
        {
            styles[i] = cubs[i].StyleLayoutChild();
            stylesCanvas[i] = styles[i].Canvas();
        }


        ////

        styles[0].Set(
            justifySelf: UIExAlignment.Start,
            alignSelf: UIExAlignment.Start);

        // styles[1]: justifySelf == Auto == JustifyContent(canvas) == Center
        // styles[1]: alignSelf == Auto == AlignContent(canvas) == Auto == Start

        // styles[2]: alignSelf == Auto == AlignContent(canvas) == Auto == Start
        styles[2].Set(
            justifySelf: UIExAlignment.End);

        styles[3].Set(
            justifySelf: UIExAlignment.Start,
            alignSelf: UIExAlignment.Center);

        // styles[4]: justifySelf == Auto == JustifyContent(canvas) == Center
        styles[4].Set(
            alignSelf: UIExAlignment.Center);

        styles[5].Set(
            justifySelf: UIExAlignment.End,
            alignSelf: UIExAlignment.Center);

        styles[6].Set(
            justifySelf: UIExAlignment.Stretch,
            alignSelf: UIExAlignment.End,
            margin: new UIExThickness(
                                pixels: true,
                                right: 25f,
                                bottom: 50f,
                                left: 75f,
                                top: 100f));

        ////////////////
        ////////////////
        ////////////////

        CopyStyle4(indexStart: 7, indexEnd: 15);

        stylesCanvas[7].Top.Pixels = 50f;
        stylesCanvas[8].Bottom.Pixels = 50f;
        stylesCanvas[9].Left.Pixels = 50f;
        stylesCanvas[10].Right.Pixels = 50f;

        stylesCanvas[11].Bottom.Pixels = 50f;
        stylesCanvas[11].Right.Pixels = 50f;

        styles[12].Margin = new UIExThickness(
            pixels: true,
            bottom: 50f,
            right: 100f);
        stylesCanvas[12].Left.Precent = -0.5f;

        stylesCanvas[13].Left.Pixels = 100000f;
        stylesCanvas[13].Top.Pixels = 50f;

        stylesCanvas[14].Left.Precent = 0.5f;

        stylesCanvas[15].Left.Precent = 1.1f;
        stylesCanvas[15].AllowOverflowSelf = true;

        void CopyStyle4(int indexStart, int indexEnd)
        {
            for (int i = indexStart; i <= indexEnd; i++)
                styles[i].Copy(styles[4]);
        }
    }

    public void SetPrecentSizeCenter(float width, float height, params UIElement[] elements)
    {
        foreach (var element in elements)
        {
            element.Width.Set(0f, width);
            element.Height.Set(0f, height);
            element.HAlign = 0.5f;
            element.VAlign = 0.5f;
        }
    }

    public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
    {
        int count = pixelSizes.Length;
        var buttons = new UIElement[count];
        for (int i = 0; i < count; i++)
            buttons[i] = AddCubs(element, pixelSizes[i], count: 1)[0];
        return buttons;
    }

    public UIElement[] AddCubs(UIElement element, float pixelSize, int count = 1)
    {
        var buttons = new UIElement[count];
        for (int i = 0; i < count; i++)
        {
            buttons[i] = new UIButton<string>(i.ToString());
            StyleLayoutChild style = buttons[i].StyleLayoutChild();
            style.Width.Set(pixelSize, 0f);
            style.Height.Set(pixelSize, 0f);
            element.Append(buttons[i]);
        }
        return buttons;
    }
}
```

Це непотрібно, якщо результат точно те, що ми хочемо бачити в образі.<br>

Якщо це значення вірно, то візуальний елемент буде прийняти відповідний стиль. **tModLoader**.<br>
для `UIExElement` значення `true` Це означає, що стиль буде схожим. `UIPanel`.<br>
Таким чином, наш код був скорочений.<br><br>

Ось частина:

Чи можна замінювати наступним чином:

Як ви можете побачити в другому коді, `UIPanel panel` Сам контейнер пішов. `canvas` Він став головним контейнером одночасно.

----

Перше, що ви бачите в коді:
```csharp
UIPanel panel = new UIPanel();
SetPrecentSizeCenter(0.8f, 0.8f, panel);
```

Це головна панель, яка буде додана до `UIState`Він буде розміщений на ньому. `UIExCanvas`.<br><br>
`SetPrecentSizeCenter` Це допоміжний метод, який не знайдено в бібліотеці, і визначений нижче в одному класі.
Він отримує N. `UIElement`Ми встановлюємо висоту і ширину центру. `panel` Він має розмір: 80% на 80% екрана.<br><br>

----

Далі в коді йде `UIExCanvas`:
```csharp
UIExCanvas canvas = new UIExCanvas();
canvas.Stretch();
canvas.ShowLayoutLines = true;
canvas.LayoutLinesThickness = 3f;
canvas.LayoutLinesColor = Color.DarkOrange;

canvas.StyleLayout.Set(
    orientation:        UIExOrientation.Horizontal,
    justifyContent:     UIExAlignment.Center);

panel.Append(canvas);
Append(panel);
```

- `canvas.Stretch();` - розмір-встановлення `canvas`100% від батьківського елемента.
- Далі ми додаємо `canvas` головна панель `panel.Append(canvas);`що означає, що `canvas` Зберігати елементи по всій головній панелі, тобто по всьому створеному інтерфейсу.
- `canvas.ShowLayoutLines = true;` - вказуємо, що потрібно накреслювати допоміжні лінії. `UIExCanvas` намалювати прямокутник навколо **зовнішнє** Для отримання більш детальної інформації про ділянки елементів див. першу частину даного розділу. `canvas.LayoutLinesThickness = 3f;`- розмір лінії 3 пікселів. `canvas.LayoutLinesColor = Color.DarkOrange` - колір допоміжних ліній.
- `Set` У бібліотеці є метод, що кожен клас стилю в бібліотеці має, і кожен набір стилів бере на сенси для всіх існуючих стильних полів.
- Його стилі. `StyleLayoutContainer StyleLayout`:
  - `Orientation`: основна вісь контейнера. `Horizontal` - горизонтальний.
  - `JustifyContent` (вирівнювання елементів по основній віссі) (основна вісь - горизонтальна): `Center` - елементи вирівнюються в центрі ширини контейнера.
  - `AlignItems` (перекладна вісь вирівнювання елементів) (перекладна вісь - вертикальна): `не указано` - елементи вирівнюються у верхній частині контейнера.
- Його стилі. `StyleLayoutContainerCanvas StyleLayoutCanvas`:
  - `AllowOverflowSelf`: `не указано`За замовчуванням: `false`Закриті елементи не можуть заходити за межі контейнера.

```csharp
public UIElement[] AddCubs(UIElement element, params float[] pixelSizes)
```

Далі йде код, який встановлює значення стилів кубів, що вміщуються:<br>
Вирівнювання куба 0-6:<br>
`0`: зверху горизонтально; зліва вертикально<br>
`1`горизонтальна вершина; центральна вертикальна;<br>
`2`: горизонтальна вершина; вертикальне право;<br>
`3`: зліва горизонтально; центр вертикально<br>
`4`: центр екрана;<br>
`5`прямо горизонтально; центр вертикально;<br>
`6`: розтягувати горизонтально (з відступами); по вертикалі.<br>
```csharp
styles[0].Set(
    justifySelf:    UIExAlignment.Start, 
    alignSelf:      UIExAlignment.Start);

// styles[1]: justifySelf == Auto == JustifyContent(canvas) == Center
// styles[1]: alignSelf == Auto == AlignContent(canvas) == Auto == Start

// styles[2]: alignSelf == Auto == AlignContent(canvas) == Auto == Start
styles[2].Set(
    justifySelf:    UIExAlignment.End);

styles[3].Set(
    justifySelf:    UIExAlignment.Start,
    alignSelf:      UIExAlignment.Center);

// styles[4]: justifySelf == Auto == JustifyContent(canvas) == Center
styles[4].Set(
    alignSelf:      UIExAlignment.Center);

styles[5].Set(
    justifySelf:    UIExAlignment.End,
    alignSelf:      UIExAlignment.Center);

styles[6].Set(
    justifySelf:    UIExAlignment.Stretch,
    alignSelf:      UIExAlignment.End,
    margin:         new UIExThickness(
                        pixels: true, 
                        right:   25f,
                        bottom: 50f,
                        left: 75f,
                        top: 100f));
```

Як ви бачите, деякі лінії коментують:<br>
- для `styles[1]`, `styles[2]`, `style[4]`Це зроблено для того, щоб показати, які значення, які вони будуть потрібні для цих полів, але вони вже були встановлені самим полем. `UIExCanvas canvas`.
- Наприклад, елемент 2 (`style[2]`) центр горизонтально; верхнє вертикально для отримання цього вирівнювання за допомогою `JustifySelf` і `AlignSelf` Він повинен виставити його там.
  -  `JustifySelf = UIExAlignment.Center` (основна вісь вирівнювання. основна вісь y) `canvas` Горизонтальний центр. Центр горизонтальний.
  -  `AlignSelf = UIExAlignment.Start` (попередньо вирівнюється вісь) вертикально.
  -  Смоктати `canvas` Промисловість `JustifyContent` вже встановлена `UIExAlignment.Center`, який замінює цей елемент. `JustifySelf` Не має сенсу налаштуватися.
  -  Смоктати `canvas` Промисловість `AlignItems` Не встановлено. За замовчуванням: `UIExAlignment.Auto` (однорідно) `UIExAlignment.Start`Властивості. `AlignSelf` Не має сенсу налаштуватися.<br>

----

6 елемента`style[6]`Промисловість `justifySellf == UIExAlignment.Stretch`Це означає, що вона простягається по всьому розміру основної осі. При цьому всю ширину, крім відступу. `Margin`.<br><br>
Це один з двох елементів, в яких допоміжні лінії не відповідають фактичним елементам. `Margin`.<br>

`Margin` Збільшує зовнішній регіон елемента. Детальніше про це в статті "*Class" UIExLayoutОснови макета*.<br>
Зовнішній розмір визначається наступним чином:
1. `outer-Top`: `cubs[6].Top - styles[6].Margin.Top;`
2. `outer-Left`: `cubs[6].Left - styles[6].Margin.Left;`
3. `outer-Width`: `cubs[6].Width + styles[6].Margin.Left + styles[6].Margin.Right;`
4. `outer-Height`: `cubs[6].Height + styles[6].Margin.Top + styles[6].Margin.Bottom;`<br>

- `cubs[6].Left` == `Margin.Left`Якщо вона простягається по ширині.
- `cubs[6].Width` == `ширина контейнера - (Margin.Left + Margin.Right)`Якщо вона простягається по ширині.<br>

Результат (попередній):`c50px` - символ розміру необоротного ребра куба (розмір: `50px`))
1. `outer-Top`: `высота контейнера - c50px - 100px`
2. `outer-Left`: `75px - 75px;`
3. `outer-Width`: `(ширина контейнера - (Margin.Left + Margin.Right)) + 75px + 25px;`
4. `outer-Height`: `c50px + 100px + 50px;`<br>

Результат (фінал):
1. `outer-Top`: `высота контейнера - 150px`
2. `outer-Left`: `0px;`
3. `outer-Width`: `150px;`
4. `outer-Height`: `200px;`<br>

`Stretch` Він розтягує зовнішній простір елемента. І нормальна площа (яка відображається на екрані) **після** Розширення обчислюється за формулою:<br>
Препарати для розрахунку розтягуючих позицій (`Left`, `Width` - ширина; `Top`, `Height` - у висоту:
1. `Left = Margin.Left;`
2. `Top = Margin.Top;`
3. `Width = ширина контейнера - (Margin.Left + Margin.Right)`.
4. `Height = высота контейнера - (Margin.Top + Margin.Bottom)`.

Далі йде метод:
```csharp
CopyStyle4(indexStart: 7, indexEnd: 15); 
```
Це внутрішній допоміжний метод. Він просто копіює значення. `style[4]` (`justifySelf: center, alignSelf: center`) в стилі для 7-15 елементів.<br><br>

Далі:
```csharp
stylesCanvas[7].Top.Pixels = 50f;
stylesCanvas[8].Bottom.Pixels = 50f;
stylesCanvas[9].Left.Pixels = 50f;
stylesCanvas[10].Right.Pixels = 50f;

stylesCanvas[11].Bottom.Pixels = 50f;
stylesCanvas[11].Right.Pixels = 50f;
```
Всі ці елементи (як і всі наступні) скопіювали значення. `style[4]` А їхні координати починаються в центрі контейнера.
1. Елементи 7 зміщений 50px вниз відносно центру і знаходиться нижче центрального елемента 4.
2. 8 елемента переміщається 50px вгору з центру і знаходиться над центральним елементом 4.
3. Елементи 9 зміщено 50px на право відносно центру і знаходиться праворуч від центрального елемента 4.
4. 10 елемента пересувається 50ПВ до лівої відносно центру і знаходиться зліва від центрального елемента 4.
5. 11 елемента зміщений 50px вгору і зліва відносно центру і знаходиться вище і зліва від центрального елемента 4.<br><br>

Далі:
```csharp
styles[12].Margin = new UIExThickness(
    pixels:     true,
    bottom:     50f,
    right:      100f);
stylesCanvas[12].Left.Precent = -0.5f;
```

Цей приклад показує:
1. Додаткова візуалізація використання `Margin`. Як ви можете бачити в зображенні, елемент 12 має збільшений зовнішній регіон, але це в верхній лівій частині його. Якщо замість правого, низу ми залишимося / вгору, елемент буде зміщений. **суперфіціал** елемент.
2. Цей пункт знаходиться в центрі, тому -0.5f перемістить елемент направо на 25% контейнера (50% відцентрованої точки до лівого краю контейнера).

```csharp
styles[12].Bottom.Pixels = 50f;
styles[12].Right.Pixels = 100f;
```
У суть ці два способи облаштування елементів мають важливу різницю:<br>
- `Left`, `Top`, `Right`, `Bottom` Це простий зміщення елемента.<br>
- `Margin` Це зміщення і збільшення зовнішнього розміру елемента.<br>
Це тільки актуально для будівельника, якщо `JustifyContent/Self` і `AlignItems/Self` актуальна `UIExAlignment.Stretch`.<br>
Для всіх інших налаштувань немає різниці, що саме для використання для зносу.<br>

Як видно, на відміну від всіх інших елементів, елемент 6 і 12 допоміжний прямокутник намальовується з відступом.<br>
Ця нитка намальована навколо зовнішнього розміру елемента.<br>
Також, якщо ми були намагатися елементу 6, запитайте `Left` або `Right` Ми не бачили його, а не побачили його.`AllowOverflow == false && AllowOverflowSelf != true`).<br>


----

Далі куб 13. Ми збираємось взяти його окремо з 15. І зараз ми збираємося до 14.
```csharp
stylesCanvas[14].Left.Precent = 0.5f;
```
Якщо ми не використовуємо цю бібліотеку, ми пишемо: `HAlign = 0.5f` Елементи зміщуються на 50% від розміру батьківського елемента, мінус 50% від його розміру.<br>
Але в зображенні цей куб на 75% широка.<br>
Сонце `JustifySelf == UIExAlignment.Center`Початкова точка починається в центрі контейнера.<br>
Засоби, які `stylesCanvas[14].Left.Precent = 0.5f;` нараховує 50% розміру між центрами і правим краєм контейнера.

І останні 2 куби, які ми не розібралися:
```csharp
stylesCanvas[13].Left.Pixels = 100000f;
stylesCanvas[13].Top.Pixels = 50f;

stylesCanvas[15].Left.Precent = 1.1f;
stylesCanvas[15].AllowOverflowSelf = true;
```
У першому випадку можна побачити, що офсет встановлюється на 100 тис. пікселів.<br>
Тим не менш, його значення `AllowOverflowSelf == false`Це означає, що контейнер контролює, що елемент не виходить за межі його межі.<br>
У зображенні можна побачити її натиснути на правий край.<br><br>

Але наступний елемент має лівий зсув 110% (від різниці між центром і правим краєм).<br>
І значення. `AllowOverflowSelf == true`Контейнер не контролює, чи йде товар за межі його межі.<br>
Таким чином, ви можете бачити цей елемент праворуч від контейнерного кордону.
