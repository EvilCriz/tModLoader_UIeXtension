---

`UIExElement` is the base UI element for all other UI elements in this library.<br><br>

It is analogous to `UIElement`, but can use the visual style of a `UIPanel`.

---

At the moment, this class is not complete.<br>
At the current stage of the library's development, it mainly contains layout elements, which were covered in the previous section.

---

The difference between `UIExElement` and `UIElement` is that this class defines its own **visual styles**.<br>
They can be accessed through the field:

```csharp
public Styles.StyleVisualElement StyleDisplay;
```

At the moment, the `StyleVisualElement` class contains only two fields:

```csharp
public partial class StyleVisualElement : Base.StyleVisualBase
{
    public bool tModLoaderStyle = false;
	public bool PaddingAutoControl = true;
}
```

---

<h2 align="center">Field <code>tModLoaderStyle</code></h2>

This field determines whether a specific element will use **visual display styles**:

1. From this library (which currently do not exist).
2. Or one of the visual styles provided by **tModLoader**.<br>

Which specific style from **tModLoader** is used depends on the particular element.<br>
`UIExElement` (and all layout elements) use the `UIPanel` style.<br><br>

Thus, the following three pieces of code are identical in terms of their visual appearance:

```csharp
UIPanel panel = new();

panel.HAlign = 0.5f;
panel.VAlign = 0.5f;
panel.Width.Set(0f, 0.8f);
panel.Height.Set(0f, 0.8f);

Append(panel);
```

```csharp
UIExElement element = new();

element.HAlign = 0.5f;
element.VAlign = 0.5f;
element.Width.Set(0f, 0.8f);
element.Height.Set(0f, 0.8f);

element.StyleDisplay.tModLoaderStyle = true;

Append(element);
```

```csharp
UIExCanvas canvas = new();

canvas.HAlign = 0.5f;
canvas.VAlign = 0.5f;
canvas.Width.Set(0f, 0.8f);
canvas.Height.Set(0f, 0.8f);

canvas.StyleDisplay.tModLoaderStyle = true;

Append(canvas);
```

---

This library gives complete control over styles from outside the class.<br>
For example, `UIPanel` in **tModLoader** provides the following access to style customization:

```csharp
public class UIPanel : UIElement
{
	private int _cornerSize = 12;
	private int _barSize = 4;
	private Asset<Texture2D> _borderTexture;
	private Asset<Texture2D> _backgroundTexture;
	
	public Color BorderColor = Color.Black;
	public Color BackgroundColor = new Color(63, 82, 151) * 0.7f;

	public UIPanel(Asset<Texture2D> customBackground, Asset<Texture2D> customborder, int customCornerSize = 12, int customBarSize = 4)
	{ /* ... */ }
}
```

As can be seen from the code above, `UIPanel` allows all values to be specified in the constructor, but only the `BorderColor` and `BackgroundColor` fields can be changed dynamically.<br><br>

In contrast, this library allows any of these fields to be changed at any time.<br>
To do this, you first need to obtain the base style for the specific element.<br>
For `UIExElement`, this style is defined by the `StyleTmlUIPanel` class (for other elements, the required classes will be described separately as they are added to the library).<br><br>

Implementation of the `StyleTmlUIPanel` class:

```csharp
public class StyleTmlUIPanel : Base.StyleTmlBase
{
    public int CornerSize = 12;
    public int BarSize = 4;
 
	public Asset<Texture2D> BorderTexture;
    public Asset<Texture2D> BackgroundTexture;
    
	public Color BorderColor = Color.Black;
    public Color BackgroundColor = new Color(63, 82, 151) * 0.7f;
}
```

Thus, we can obtain this class for a specific element and change all of its fields at any time:

```csharp
UIExElement element = new();

StyleVisualElement styleDisplay = element.StyleDisplay;
StyleTmlUIPanel styleTmlUIPanel = styleDisplay.TmlUIPanel();

styleTmlUIPanel.CornerSize = 15;
styleTmlUIPanel.BarSize = 15;

styleTmlUIPanel.BorderTexture = TextureAssets.MagicPixel;
styleTmlUIPanel.BackgroundTexture = TextureAssets.MagicPixel;

styleTmlUIPanel.BorderColor = Color.White;
styleTmlUIPanel.BackgroundColor = Color.Red;
```

---

<h2 align="center">Field <code>PaddingAutoControl</code></h2>

This field specifies whether `UIExElement` should automatically manage the values of `PaddingLeft`, `PaddingTop`, `PaddingRight`, and `PaddingBottom`.<br>
If this value is `true`, these values will be automatically recalculated whenever the style changes (default: true).
