<h1 align="center">Клас <code>UIExElement</code></h1>

----

- Бібліотека припускає, що ви вже навчилися [базовий посібник tModLoader Користувач-інтерфейс](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
- Бібліотека припускає, що ви вже навчилися [Розширений посібник з налаштування інтерфейсу користувача](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>
- У статті запропоновано, що ви вивчили статтю: ["Схема стилю"](../Розділ-1/1.3-StyleStructure.md)

----
<br>

----

`UIExElement` - це базова. UI- елемент для всіх інших. UI- елементи цієї бібліотеки.<br><br>

Це аналог. `UIElement`Він може взяти на себе візуальний стиль. `UIPanel`.

----

На сьогоднішній день цей клас не був завершений.<br>
На цьому етапі розробки бібліотеки в ній в основному створювалися тільки елементи макета, які були присвячені останньому розділу.

----

Випадковий `UIExElement` з `UIElement` Іншими словами, цей клас визначає його **візуалізація**.<br>
Вони можуть бути отримані за допомогою поля:
```csharp
public Styles.StyleVisualElement StyleDisplay;
```

На сьогоднішній день клас `StyleVisualElement` Містить лише два поля:
```csharp
public partial class StyleVisualElement : Base.StyleVisualBase
{
    public bool tModLoaderStyle = false;
	public bool PaddingAutoControl = true;
}
```

----

<h2 align="center">Поле. <code>tModLoaderStyle</code></h2>

Це поле визначає, чи використовуватиметься окремий елемент **візуалізація**: 
1. Бібліотека (що не існує сьогодні)
2. Або скористайтеся одним з візуальних стилів **tModLoader**.<br>

Який конкретний стиль прийняти **tModLoader** В залежності від конкретного елемента.<br>
`UIExElement` (і всі елементи макета) використовують стиль. `UIPanel`.<br><br>

Тобто такі три коди будуть ідентичні у своїй візуальній частині:
```csharp
UIPanel panel = new();

panel.HAlign = 0.5f;
panel.VAlign = 0.5f;
panel.Width.Set(0f, 0.8f);
panel.Height.Set(0f, 0.8f);

Append(panel);
```

```csharp
UIExElement element = new();

element.HAlign = 0.5f;
element.VAlign = 0.5f;
element.Width.Set(0f, 0.8f);
element.Height.Set(0f, 0.8f);

element.StyleDisplay.tModLoaderStyle = true;

Append(element);
```

```csharp
UIExCanvas canvas = new();

canvas.HAlign = 0.5f;
canvas.VAlign = 0.5f;
canvas.Width.Set(0f, 0.8f);
canvas.Height.Set(0f, 0.8f);

canvas.StyleDisplay.tModLoaderStyle = true;

Append(canvas);
```

----

Бібліотека надає повний контроль стилів за класичною кімнатою.<br>
Наприклад: `UIPanel` **tModLoader** Подарує наступний доступ до стилю управління:
```csharp
public class UIPanel : UIElement
{
	private int _cornerSize = 12;
	private int _barSize = 4;
	private Asset<Texture2D> _borderTexture;
	private Asset<Texture2D> _backgroundTexture;
	
	public Color BorderColor = Color.Black;
	public Color BackgroundColor = new Color(63, 82, 151) * 0.7f;

	public UIPanel(Asset<Texture2D> customBackground, Asset<Texture2D> customborder, int customCornerSize = 12, int customBarSize = 4)
	{ /* ... */ }
}
```

Як ви бачите в коді вище, `UIPanel` дозволяє встановлювати всі значення в конструкторі, але динамічно змінювати тільки поля `BorderColor` і `BackgroundColor`.<br><br>

У свою чергу, ця бібліотека дозволяє змінити значення будь-якого даної галузі в будь-який час.<br>
Щоб зробити це, вам спочатку потрібно отримати базовий стиль для певного елемента.<br>
для `UIExElement` Це класний стиль. `StyleTmlUIPanel` (Для інших речей, необхідні заняття будуть записані окремо, оскільки вони додаються до бібліотеки.)<br><br>

Реалізація класу `StyleTmlUIPanel`:
```csharp
public class StyleTmlUIPanel : Base.StyleTmlBase
{
    public int CornerSize = 12;
    public int BarSize = 4;
 
	public Asset<Texture2D> BorderTexture;
    public Asset<Texture2D> BackgroundTexture;
    
	public Color BorderColor = Color.Black;
    public Color BackgroundColor = new Color(63, 82, 151) * 0.7f;
}
```

Таким чином, ми можемо отримати певний клас для певного елемента і змінити всі його поля в будь-який час:

```csharp
UIExElement element = new();

StyleVisualElement styleDisplay = element.StyleDisplay;
StyleTmlUIPanel styleTmlUIPanel = styleDisplay.TmlUIPanel();

styleTmlUIPanel.CornerSize = 15;
styleTmlUIPanel.BarSize = 15;

styleTmlUIPanel.BorderTexture = TextureAssets.MagicPixel;
styleTmlUIPanel.BackgroundTexture = TextureAssets.MagicPixel;

styleTmlUIPanel.BorderColor = Color.White;
styleTmlUIPanel.BackgroundColor = Color.Red;
```

<h2 align="center">Поле. <code>PaddingAutoControl</code></h2>

Це поле вказує, чи не є `UIExElement` самовдосконалення `PaddingLeft`, `PaddingTop`, `PaddingRight`, `PaddingBottom`.<br>
Якщо значення значення `true`Ці значення будуть автоматично перераховані разом із змінами стилю (за замовчуванням: true).
