<h1 align="center">Клас <code>UIExElement</code></h1>

---

* Дана бібліотека передбачає, що ви вже вивчили [базовий посібник tModLoader щодо користувацького інтерфейсу](https://github.com/tModLoader/tModLoader/wiki/Basic-UI-Element)<br>
* Дана бібліотека передбачає, що ви вже вивчили [розширений посібник із налаштування користувацького інтерфейсу](https://github.com/tModLoader/tModLoader/wiki/Advanced-guide-to-custom-UI)<br>
* Дана стаття передбачає, що ви вивчили статтю: [«структура стилів»](../Розділ-1/1.3-StyleStructure.md)

---

<br>

---

`UIExElement` — це базовий UI-елемент для всіх інших UI-елементів даної бібліотеки.<br><br>

Він є аналогом `UIElement`, але може приймати візуальний стиль `UIPanel`.

---

На сьогоднішній день цей клас не завершений.<br>
На цьому етапі розвитку бібліотеки в ній, в основному, створені лише елементи компонування, яким був присвячений попередній розділ.

---

Відмінність `UIExElement` від `UIElement` полягає в тому, що цей клас визначає власні **стилі візуального відображення**.<br>
Їх можна отримати за допомогою поля:

```csharp
public Styles.StyleVisualElement StyleDisplay;
```

На сьогоднішній день клас `StyleVisualElement` містить лише два поля:

```csharp
public partial class StyleVisualElement : Base.StyleVisualBase
{
    public bool tModLoaderStyle = false;
	public bool PaddingAutoControl = true;
}
```

---

<h2 align="center">Поле <code>tModLoaderStyle</code></h2>

Це поле визначає, чи буде конкретний елемент використовувати **стилі візуального відображення**:

1. Даної бібліотеки (яких на сьогоднішній день не існує).
2. Або буде використовувати один із візуальних стилів від **tModLoader**.<br>

Який саме стиль брати **tModLoader**, залежить від конкретного елемента.<br>
`UIExElement` (і всі елементи компонування) використовують стиль `UIPanel`.<br><br>

Тобто наступні три фрагменти коду будуть ідентичними за своєю візуальною частиною:

```csharp
UIPanel panel = new();

panel.HAlign = 0.5f;
panel.VAlign = 0.5f;
panel.Width.Set(0f, 0.8f);
panel.Height.Set(0f, 0.8f);

Append(panel);
```

```csharp
UIExElement element = new();

element.HAlign = 0.5f;
element.VAlign = 0.5f;
element.Width.Set(0f, 0.8f);
element.Height.Set(0f, 0.8f);

element.StyleDisplay.tModLoaderStyle = true;

Append(element);
```

```csharp
UIExCanvas canvas = new();

canvas.HAlign = 0.5f;
canvas.VAlign = 0.5f;
canvas.Width.Set(0f, 0.8f);
canvas.Height.Set(0f, 0.8f);

canvas.StyleDisplay.tModLoaderStyle = true;

Append(canvas);
```

---

Дана бібліотека передає повне керування стилями назовні класу.<br>
Наприклад: `UIPanel` **tModLoader** надає наступний доступ до керування стилем:

```csharp
public class UIPanel : UIElement
{
	private int _cornerSize = 12;
	private int _barSize = 4;
	private Asset<Texture2D> _borderTexture;
	private Asset<Texture2D> _backgroundTexture;
	
	public Color BorderColor = Color.Black;
	public Color BackgroundColor = new Color(63, 82, 151) * 0.7f;

	public UIPanel(Asset<Texture2D> customBackground, Asset<Texture2D> customborder, int customCornerSize = 12, int customBarSize = 4)
	{ /* ... */ }
}
```

Як видно з наведеного вище коду, `UIPanel` дозволяє встановити всі значення в конструкторі, але динамічно змінювати можна лише поля `BorderColor` і `BackgroundColor`.<br><br>

Своєю чергою дана бібліотека дозволяє змінити значення будь-якого з цих полів у будь-який час.<br>
Для цього спочатку потрібно отримати базовий стиль для конкретного елемента.<br>
Для `UIExElement` це стиль, визначений класом `StyleTmlUIPanel` (для інших елементів потрібні класи будуть написані окремо, у міру їх додавання до бібліотеки).<br><br>

Реалізація класу `StyleTmlUIPanel`:

```csharp
public class StyleTmlUIPanel : Base.StyleTmlBase
{
    public int CornerSize = 12;
    public int BarSize = 4;
 
	public Asset<Texture2D> BorderTexture;
    public Asset<Texture2D> BackgroundTexture;
    
	public Color BorderColor = Color.Black;
    public Color BackgroundColor = new Color(63, 82, 151) * 0.7f;
}
```

Таким чином, ми можемо отримати цей клас для конкретного елемента та в будь-який час змінювати всі його поля:

```csharp
UIExElement element = new();

StyleVisualElement styleDisplay = element.StyleDisplay;
StyleTmlUIPanel styleTmlUIPanel = styleDisplay.TmlUIPanel();

styleTmlUIPanel.CornerSize = 15;
styleTmlUIPanel.BarSize = 15;

styleTmlUIPanel.BorderTexture = TextureAssets.MagicPixel;
styleTmlUIPanel.BackgroundTexture = TextureAssets.MagicPixel;

styleTmlUIPanel.BorderColor = Color.White;
styleTmlUIPanel.BackgroundColor = Color.Red;
```

---

<h2 align="center">Поле <code>PaddingAutoControl</code></h2>

Це поле вказує, чи повинен `UIExElement` автоматично керувати значеннями `PaddingLeft`, `PaddingTop`, `PaddingRight`, `PaddingBottom`.<br>
Якщо це значення `true`, ці значення будуть автоматично перераховуватися разом зі змінами стилю (за замовчуванням: true).
