<h1 align="center">Створення бібліотеки</h1>

<h2 align="center">Додані заняття/генерації</h2>

Після виходу до бібліотеки додано:

1. Класи. UI-елементи (не будівельників):
- `UIExElement`.<br><br>

2. Класи контейнерів:
- `UIExLayout`;
- `UIExCanvas`;
- `UIExFlowPanel`
- `UIExStackPanel`;
- `UIExWrapPanel`;
- `UIExDockPanel`;
- `UIExGridBase`;
- `UIExGrid`;
- `UIExUniformGrid`.<br><br>
<!-- -->

3. Класи стилів:
- `StyleBase`;
- `StyleVisualBase`;
- `StyleLayoutContainerBase`;
- `StyleLayoutChildBase`;
- `StyleTmlBase`;
- `StyleVisualElement`;
- `StyleLayoutContainer`;
- `StyleLayoutContainerCanvas`;
- `StyleLayoutContainerStackPanel`;
- `StyleLayoutContainerWrapPanel`;
- `StyleLayoutContainerDockPanel`;
- `StyleLayoutContainerGrid`;
- `StyleLayoutContainerUniformGrid`;
- `StyleLayoutChild`;
- `StyleLayoutChildCanvas`;
- `StyleLayoutChildDockPanel`;
- `StyleLayoutChildGrid`;
- `StyleLayoutChildUniformGrid`;
- `StyleTmlUIPanel`.<br><br>

4. Допоміжні заняття для планування:

- `LayoutDebugRectangle`.<br><br>

5. Класи підтримки стилів:
- `StyleSide`;

6. Списки:
- `UIExOrientation`;
- `UIExAlignment`;
- `UIExSide`;
- `UIExGridLengthType`.<br><br>
<!-- -->

7. Класи підтримки: аналоги **tModLoader**:
- `UIExModSystem`.<br><br>

8. Статичні класи для методів розширення:
